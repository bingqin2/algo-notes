# 230. 二叉搜索树中第 K 小的元素

> [力扣 230](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/) · 近两年面经里出现在：**招商银行笔试**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

二叉搜索树（BST）+「第 k 小 / 排序 / 前驱后继」→ **中序遍历是升序的**。招商银行笔试考过。

## 解法一：迭代中序，数到第 k 个就停（推荐）

**思路**：用栈模拟中序遍历：一路往左走到底，弹出一个结点就是下一个更大的值，数到第 k 个就返回。不需要遍历整棵树。

<StepPlayer src="/viz/lc230.json" />

```python
def kthSmallest(root, k):
    stack, node = [], root
    while stack or node:
        while node:
            stack.append(node); node = node.left
        node = stack.pop()
        k -= 1
        if k == 0: return node.val
        node = node.right
```

**复杂度**：时间 O(h + k)，空间 O(h)。

## 解法二：递归中序

```python
def kthSmallest(root, k):
    ans = None
    def inorder(node):
        nonlocal k, ans
        if not node or ans is not None: return
        inorder(node.left)
        k -= 1
        if k == 0: ans = node.val; return
        inorder(node.right)
    inorder(root)
    return ans
```

**复杂度**：时间 O(h + k)（找到后提前返回），空间 O(h)。递归写法提前停止要靠外部变量判断，没有迭代写法直接。

## 解法三：记录子树大小（频繁查询时）

**思路**：每个结点额外存「以它为根的子树结点数」size。查第 k 小时：左子树大小为 L，k ≤ L 就去左边找；k = L + 1 就是当前结点；否则去右边找第 k − L − 1 小。

**复杂度**：每次查询 O(h)。树会频繁增删时，插入和删除顺带更新路径上的 size，这就是题目的进阶问题。平衡树（红黑树、AVL）上 h = O(log n)。

## 易错点

- 用前序或层序遍历：结果不是有序的。
- 递归写法找到答案后没有停止，继续遍历整棵树（结果对，但浪费时间）。

## 面试追问

- **BST 被频繁修改、频繁查询第 k 小？** 用解法三，或者直接用有序集合（Java 的 `TreeMap` 不支持按排名查找，要自己维护 size；Redis 的 ZSet 用跳表支持按排名查找，见[数据结构](https://bingqin2.github.io/bagu-notes/07-redis/data-structures)）。
- **第 k 大？** 反向中序（先右后根再左），或者求第 n − k + 1 小。
- **验证一棵树是不是 BST？** [98](./lc98)：中序遍历是否严格递增，或者递归时传上下界。

## Java 版

```java
public int kthSmallest(TreeNode root, int k) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode node = root;
    while (node != null || !stack.isEmpty()) {
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
        node = stack.pop();
        if (--k == 0) return node.val;
        node = node.right;
    }
    return -1;
}
```
