# 380. O(1) 时间插入、删除和获取随机元素

> [力扣 380](https://leetcode.cn/problems/insert-delete-getrandom-o1/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

插入、删除、**等概率随机取**都要 O(1)：哈希表支持 O(1) 插入删除但不能随机取，数组支持 O(1) 随机取但删除要 O(n)。组合起来：**数组存值、哈希表存值到下标的映射**，删除时用最后一个元素填补空位。

## 最优解法

**思路**：删除 val 时，把数组最后一个元素 last 移到 val 的位置，更新 last 的下标，然后弹出数组末尾、从哈希表删掉 val。

```python
import random

class RandomizedSet:
    def __init__(self):
        self.vals = []                     # 数组：支持 O(1) 随机访问
        self.idx = {}                      # 值 → 在数组里的下标

    def insert(self, val):
        if val in self.idx:
            return False
        self.idx[val] = len(self.vals)
        self.vals.append(val)
        return True

    def remove(self, val):
        if val not in self.idx:
            return False
        i, last = self.idx[val], self.vals[-1]
        self.vals[i] = last                # 用最后一个元素填到被删的位置
        self.idx[last] = i
        self.vals.pop()
        del self.idx[val]                  # 要在更新 last 之后删（val 可能就是 last）
        return True

    def getRandom(self):
        return random.choice(self.vals)
```

**复杂度**：每个操作 O(1)（均摊），空间 O(n)。

## 易错点

- 删除的就是最后一个元素时：先更新 `idx[last] = i`、再 `del idx[val]`，顺序反了会把刚删掉的 key 又加回去。
- 允许重复元素的版本（[381](https://leetcode.cn/problems/insert-delete-getrandom-o1-duplicates-allowed/)）：哈希表的值改成下标的集合。
