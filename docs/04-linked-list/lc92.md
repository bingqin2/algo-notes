# 92. 反转链表 II

> [力扣 92](https://leetcode.cn/problems/reverse-linked-list-ii/) · 中等 · 近两年面经：**美团 · 腾讯 WXG**（WXG 问的是「分段反转链表」）
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

只反转链表中间的一段（第 left 到第 right 个结点）。关键是找到这一段的**前驱**和**后继**，反转后把两头接回去。

## 解法一：截断 → 反转 → 接回

**思路**：

1. 用哑结点，走 left − 1 步找到前驱 `pre`。
2. 再走 right − left + 1 步找到区间最后一个结点 `end`，记下后继 `succ = end.next`。
3. 断开 `end.next`，用 [206](./lc206) 的方法反转 `start..end`。
4. 接回：`pre.next = end`，`start.next = succ`。

```python
def reverseBetween(head, left, right):
    dummy = ListNode(0, head)
    pre = dummy
    for _ in range(left - 1):
        pre = pre.next
    end = pre
    for _ in range(right - left + 1):
        end = end.next
    start, succ = pre.next, end.next
    end.next = None                    # 断开
    prev, cur = None, start
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    pre.next, start.next = end, succ   # 接回
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)。最坏要遍历两遍（找 end 一遍，反转一遍）。

## 解法二：头插法，一次遍历

**思路**：`pre` 固定在区间前驱，`cur` 固定指向区间第一个结点（它最后会变成区间的尾巴）。每次把 `cur` 后面的结点摘下来，插到 `pre` 后面。做 right − left 次就完成了。

```python
def reverseBetween(head, left, right):
    dummy = ListNode(0, head)
    pre = dummy
    for _ in range(left - 1):
        pre = pre.next
    cur = pre.next
    for _ in range(right - left):
        nxt = cur.next
        cur.next = nxt.next      # 1. 摘下 nxt
        nxt.next = pre.next      # 2. nxt 指向当前区间的头
        pre.next = nxt           # 3. nxt 成为新的区间头
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)，只遍历一遍。

头插的三行顺序很重要，记法：**先摘下、再指向头、最后成为头**。

## 两种解法对比

| | 截断反转接回 | 头插法 |
|---|---|---|
| 遍历次数 | 最坏两遍 | 一遍 |
| 代码 | 复用 206，好理解 | 更短，但三行指针操作要记牢 |
| 推广 | 直接推广到 [25 K 个一组](./lc25) | 也可以推广，每组做 k − 1 次头插 |

## 易错点

- 不用哑结点：left = 1 时前驱不存在，要特判。
- 头插法里 `cur` 不要移动：它一直是原来区间的第一个结点，每次摘的都是它后面那个。
- 截断法忘了先记下 `succ` 就断开了。

## 面试追问

- **反转多个区间（分段反转）？** 把这个函数写成「给定前驱和长度，反转并返回新的前驱」，在外面循环调用。等长分段就是 [25](./lc25)。
- **区间越界（right 大于链表长度）？** 找 `end` 的时候判空，越界就只反转到末尾或者直接返回，先和面试官确认需求。
- **递归怎么写？** 先实现「反转前 n 个结点」：递归到第 n 个，回溯时把后继接到原来的头后面；再递归地把 left 往前推到 1。代码短但不直观，知道即可。

## Java 版

```java
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0, head), pre = dummy;
    for (int i = 0; i < left - 1; i++) pre = pre.next;
    ListNode cur = pre.next;
    for (int i = 0; i < right - left; i++) {
        ListNode nxt = cur.next;
        cur.next = nxt.next;
        nxt.next = pre.next;
        pre.next = nxt;
    }
    return dummy.next;
}
```
