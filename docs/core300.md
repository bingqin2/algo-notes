# 核心 300 题

一共 **300** 题，包含完整的 LeetCode 热题 100。每题一个页面，按章节归类，按层级决定投入多少。

## 进度

| 层级 | 要求 | 题数 | 已完成 |
|---|---|---|---|
| A 层 · 面经高频 | 所有常见解法都要会，闭卷写出，能讲清追问。每周轮一遍。 | 80 | 68 |
| B 层 · 必会 | 掌握最优解法，20 分钟内写出。每两周一遍。 | 120 | 0 |
| C 层 · 认得题型 | 看到题能说出用什么方法、难点在哪。考前过一遍。 | 100 | 0 |
| **合计** | | **300** | **68** |

## 300 题是怎么来的

| 来源 | 题数 | 说明 |
|---|---|---|
| Hot 100 | 100 | 力扣「LeetCode 热题 100」全部收录 |
| 面试经典 150 | 83 | 力扣「面试经典 150 题」里不在 Hot 100 的题 |
| 面经 | 25 | 近两年后端面经里出现、但不在上面两张题单里的题 |
| 手写 | 9 | 非力扣原题，面试常让手写：排序、限流器、线程池、singleflight 等 |
| 题型补强 | 83 | Hot 100 覆盖薄的题型：单调栈、二分答案、前缀和与差分、并查集、最短路、状态机 DP、背包、区间 DP 等 |

分层规则：近两年面经里出现过的题和手写题进 A 层，再补几道 Hot 100 里最经典的题；剩下的题里，简单题、非 Hot 100 的困难题和部分偏门的中等题进 C 层，其余进 B 层。
