# 设计题（手写数据结构与并发组件）

## 核心框架

面试官最常让你手写的组件：LRU、限流器、线程池、生产者消费者。先说接口和复杂度，再写代码，最后讲线程安全。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |

| [460. LFU 缓存](./lc460) | 高频经典 | key→(val,freq) + freq→有序集合 + minFreq |
