# 30. 串联所有单词的子串

> [力扣 30](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

找由所有单词（等长）串联成的子串：单词长度固定为 w，按起点模 w 分成 w 组，每组是一个**以单词为单位**滑动的窗口。

## 关键点

- 窗口里某个单词数量超过需要时，左边按单词收缩；遇到不在列表里的单词，窗口清空、从下一个单词重新开始。
- 单词数等于总数时记录左端点。时间 O(w · n / w · w) = O(n · w)。
- 暴力做法：每个起点截取 k 个单词比较计数，O(n · k · w)。

```python
from collections import Counter

def findSubstring(s, words):
    if not words:
        return []
    w, k = len(words[0]), len(words)
    need = Counter(words)
    res = []
    for start in range(w):                 # 按起点 mod w 分成 w 组，每组是一个按单词滑动的窗口
        left, cnt, window = start, 0, Counter()
        for right in range(start, len(s) - w + 1, w):
            word = s[right:right + w]
            if word not in need:
                window.clear(); cnt = 0; left = right + w
                continue
            window[word] += 1
            cnt += 1
            while window[word] > need[word]:   # 这个单词多了，左边收缩
                window[s[left:left + w]] -= 1
                cnt -= 1
                left += w
            if cnt == k:
                res.append(left)
    return sorted(res)
```
