# 295. 数据流的中位数

> [力扣 295](https://leetcode.cn/problems/find-median-from-data-stream/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数据流里随时取中位数：中位数只和「中间的一两个数」有关，把数据分成较小的一半和较大的一半，用两个堆分别维护，**堆顶**就是中间的数。

## 解法一：大顶堆存较小一半 + 小顶堆存较大一半

**思路**：

- `small`：大顶堆（Python 存负数），较小的一半；`large`：小顶堆，较大的一半。
- 不变式：small 里所有数 ≤ large 里所有数；`len(small) == len(large)` 或者多一个。
- 加入 num：先放进 small，再把 small 的最大值移到 large（保证顺序不变式）；如果 large 比 small 多，再把 large 的最小值移回 small（保证个数不变式）。
- 中位数：small 多一个就是 small 的堆顶，否则是两个堆顶的平均。

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []                    # 大顶堆（存负数），较小的一半
        self.large = []                    # 小顶堆，较大的一半

    def addNum(self, num):
        heapq.heappush(self.small, -num)                         # 先进 small
        heapq.heappush(self.large, -heapq.heappop(self.small))   # 把 small 最大的移到 large
        if len(self.large) > len(self.small):                    # 保持 small 不少于 large
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def findMedian(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

**复杂度**：addNum O(log n)，findMedian O(1)，空间 O(n)。

## 易错点

- 直接按大小判断放哪个堆，再平衡：也可以，但「先进 small 再移一个到 large」的写法不用分情况，不容易错。
- Python 的 heapq 只有小顶堆，大顶堆要存相反数，取出来记得再取反。
- Java 的 `PriorityQueue<Integer>` 大顶堆写 `(a, b) -> b - a` 可能溢出，用 `Collections.reverseOrder()`。

**追问**：数据都在 [0, 100] 之间？用计数数组，O(1) 加入、O(100) 查询。99% 的数在这个范围？范围内计数，范围外用两个计数器或堆单独处理。
