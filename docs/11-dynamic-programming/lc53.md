# 53. 最大子数组和

> [力扣 53](https://leetcode.cn/problems/maximum-subarray/) · 近两年面经里出现在：**字节 ×2 · 小红书**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

连续子数组的最大和。字节 2 次、小红书 1 次，还常常连着问 [152 乘积最大子数组](./lc152)。

## 解法一：Kadane（动态规划）

**思路**：设 cur = **以当前元素结尾**的最大子数组和。对当前元素 x，要么接在前面的子数组后面（cur + x），要么自己重新开始（x）。前面的和是负数时，接上只会更小，就重新开始。

<StepPlayer src="/viz/lc53.json" />

```python
def maxSubArray(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)      # 以 x 结尾：要么接上前面，要么重新开始
        best = max(best, cur)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法二：前缀和

**思路**：子数组和 = 两个前缀和之差。以 i 结尾的最大子数组和 = 当前前缀和 − 之前出现过的最小前缀和。和 [121 股票](./lc121) 的「当前价格 − 历史最低价」是同一个模型。

```python
def maxSubArray(nums):
    pre, low, best = 0, 0, -float("inf")
    for x in nums:
        pre += x
        best = max(best, pre - low)
        low = min(low, pre)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法三：分治（题目进阶要求）

**思路**：最大子数组要么在左半边，要么在右半边，要么跨过中点。为了在 O(1) 时间合并，每段返回四个值：总和、最大前缀和、最大后缀和、最大子段和。

```python
def maxSubArray(nums):
    def go(l, r):                  # 返回 (区间和, 最大前缀, 最大后缀, 最大子段)
        if l == r: return nums[l], nums[l], nums[l], nums[l]
        m = (l + r) // 2
        a, b = go(l, m), go(m + 1, r)
        return (a[0] + b[0], max(a[1], a[0] + b[1]), max(b[2], b[0] + a[2]),
                max(a[3], b[3], a[2] + b[1]))
    return go(0, len(nums) - 1)[3]
```

**复杂度**：时间 O(n)，空间 O(log n)。比 Kadane 复杂，但它可以放到**线段树**上，支持「数组被修改后，反复查询某个区间的最大子段和」。

## 易错点

- 初始值设成 0：全是负数时会返回 0，而答案应该是最大的那个负数。用 nums[0] 初始化。
- 先更新 best 再更新 cur：顺序反了会少算当前元素。

## 面试追问

- **要返回子数组的起止位置？** 重新开始时记下起点 start，best 更新时记录 (start, i)。动画里演示了这一步。
- **乘积最大呢？** 负负得正，要同时维护最大和最小，见 [152](./lc152)。
- **环形数组？** 见 [918](./lc918)：max(普通最大子段和, 总和 − 最小子段和)，注意全负数的情况。
- **二维（最大子矩阵和）？** 枚举上下边界，把每列压缩成一个数，变成一维的最大子数组和，O(n²·m)。优必选笔试考过。

## Java 版

```java
public int maxSubArray(int[] nums) {
    int cur = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        best = Math.max(best, cur);
    }
    return best;
}
```
