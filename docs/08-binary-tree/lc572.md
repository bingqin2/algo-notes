# 572. 另一棵树的子树

> [力扣 572](https://leetcode.cn/problems/subtree-of-another-tree/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

判断 sub 是不是 root 的某棵子树（结构和值都完全相同）。字节考过。它由两个子问题组成：**判断两棵树是否相同**（[100](./lc100)），以及**对每个结点都判断一次**。

## 解法一：逐个结点比较

**思路**：对 root 的每个结点，判断以它为根的子树是否和 sub 相同。

```python
def isSubtree(root, sub):
    def same(a, b):
        if not a or not b: return a is b
        return a.val == b.val and same(a.left, b.left) and same(a.right, b.right)
    if not root: return False
    return same(root, sub) or isSubtree(root.left, sub) or isSubtree(root.right, sub)
```

**复杂度**：时间 O(m·n)，m、n 分别是两棵树的结点数；空间 O(h)。

## 解法二：序列化 + 字符串匹配

**思路**：把两棵树都按前序序列化，**空结点也要写出来**，然后判断 sub 的序列是不是 root 序列的子串。

```python
def isSubtree(root, sub):
    def ser(node, out):
        if not node: out.append("#"); return
        out.append(f"^{node.val}")         # 加前缀分隔，避免 2 匹配到 12
        ser(node.left, out); ser(node.right, out)
    a, b = [], []
    ser(root, a); ser(sub, b)
    return "," + ",".join(b) + "," in "," + ",".join(a) + ","
```

**复杂度**：序列化 O(m + n)；Python 的 `in` 一般很快，严格的线性时间要用 KMP，总共 O(m + n)。

**两个容易漏的细节：**

1. 空结点必须写出来，否则不同形状的树可能序列化成一样的字符串。
2. 每个值前要加分隔符：不加的话，sub = 2 的序列 `2,#,#` 会匹配到 root = 12 的序列 `12,#,#` 的一部分。上面的写法给每个值加了 `^` 前缀，整个序列前后也加了逗号。

## 解法三：树哈希

**思路**：后序计算每棵子树的哈希值（由值和左右子树的哈希组合），比较哈希值，相等时再精确比较一次防止冲突。O(m + n)，了解即可。

## 易错点

- 解法一里判断相同的函数写错空结点的情况：`a`、`b` 都为空才返回 true，只有一个为空返回 false。
- 序列化时没写空结点或没加分隔符，见上面两个细节。

## 面试追问

- **和「子结构」（剑指 Offer 26）有什么区别？** 子结构只要求 sub 是 root 某一部分的「上半截」，sub 的叶子下面 root 还可以有结点。判断函数改成：sub 为空返回 true，root 为空返回 false。
- **相同的树、对称的树？** [100](./lc100)、[101](./lc101)：都是同时递归两个结点。

## Java 版

```java
public boolean isSubtree(TreeNode root, TreeNode subRoot) {
    if (root == null) return false;
    return same(root, subRoot) || isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
}

private boolean same(TreeNode a, TreeNode b) {
    if (a == null || b == null) return a == b;
    return a.val == b.val && same(a.left, b.left) && same(a.right, b.right);
}
```
