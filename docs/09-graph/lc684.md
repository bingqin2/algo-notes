# 684. 冗余连接

> [力扣 684](https://leetcode.cn/problems/redundant-connection/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

在树上多加了一条边形成环，找出这条边：按顺序加边，用**并查集**判断两端是否已经连通，已经连通的那条边就是多余的。

## 最优解法

**思路**：遍历每条边 (a, b)：如果 a、b 已经在同一个集合里，再加这条边就成环，返回它；否则合并。题目要求返回最后出现的那条，按顺序遍历第一个成环的边正好就是它（环上其他边都在它之前）。

```python
def findRedundantConnection(edges):
    parent = list(range(len(edges) + 1))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra == rb:                       # 已经连通，这条边会形成环
            return [a, b]
        parent[ra] = rb
    return []
```

**复杂度**：时间 O(n α(n))，近似 O(n)；空间 O(n)。

## 易错点

- 结点编号从 1 开始，parent 数组开 n + 1。
- 并查集要路径压缩（`parent[x] = parent[parent[x]]`），否则可能退化成链。
