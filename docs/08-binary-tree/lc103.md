# 103. 二叉树的锯齿形层序遍历

> [力扣 103](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

层序遍历的变体：奇数层从左到右、偶数层从右到左。BFS 照常进行（孩子的入队顺序不变），只在**输出这一层**时决定方向。

## 最优解法

**思路**：每层用一个双端队列收集值，方向是从左到右就 `append`，否则 `appendleft`。每层结束后翻转方向标记。

```python
from collections import deque

def zigzagLevelOrder(root):
    if not root:
        return []
    res, q, left_to_right = [], deque([root]), True
    while q:
        level = deque()
        for _ in range(len(q)):
            node = q.popleft()
            if left_to_right:
                level.append(node.val)
            else:
                level.appendleft(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(list(level))
        left_to_right = not left_to_right
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 改变孩子的入队顺序来实现锯齿：下一层的顺序会被打乱，第三层就错了。
- 也可以每层收集完后按需 `reverse()`，同样 O(n)。
