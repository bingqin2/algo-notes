# 373. 查找和最小的 K 对数字

> [力扣 373](https://leetcode.cn/problems/find-k-pairs-with-smallest-sums/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

两个有序数组各取一个数，和最小的 k 对：**多路归并**，看成 n 条有序链表（每个 i 一条：`(i,0), (i,1), …`），用小顶堆合并。

## 关键点

- 初始把每个 i 的第一对放进堆（最多 k 个），弹出 (i, j) 后放入 (i, j+1)。
- O(k log k)。

```python
import heapq

def kSmallestPairs(nums1, nums2, k):
    heap = [(nums1[i] + nums2[0], i, 0) for i in range(min(k, len(nums1)))]
    heapq.heapify(heap)
    res = []
    while heap and len(res) < k:
        _, i, j = heapq.heappop(heap)
        res.append([nums1[i], nums2[j]])
        if j + 1 < len(nums2):             # 同一个 i 的下一对
            heapq.heappush(heap, (nums1[i] + nums2[j + 1], i, j + 1))
    return res
```
