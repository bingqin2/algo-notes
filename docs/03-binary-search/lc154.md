# 154. 寻找旋转排序数组中的最小值 II

> [力扣 154](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

旋转排序数组**有重复**元素时找最小值：和 [153](./lc153) 一样和右端比较，相等时只能 `hi −= 1`。

## 关键点

- `nums[mid] == nums[hi]` 时无法判断最小值在哪边，但去掉 hi 不会丢失最小值（mid 和它相等，还在区间里）。
- 最坏 O(n)（全是相同元素）。

```python
def findMin(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]:
            lo = mid + 1
        elif nums[mid] < nums[hi]:
            hi = mid
        else:
            hi -= 1                        # 相等时分不清，去掉 hi（mid 还在，最小值不会丢）
    return nums[lo]
```
