# 22. 括号生成

> [力扣 22](https://leetcode.cn/problems/generate-parentheses/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

生成所有合法的括号组合。合法的条件可以**边生成边检查**：任何前缀里右括号都不能比左括号多。

## 解法一：回溯，只走合法的分支

**思路**：用 open、close 记录已放的左右括号数。

- `open < n`：还能放左括号。
- `close < open`：还能放右括号（放了之后前缀仍然合法）。

这样生成的每个叶子都是合法的，不需要最后再检查。

<StepPlayer src="/viz/lc22.json" />

```python
def generateParenthesis(n):
    res, path = [], []

    def dfs(open_, close):                 # 已经放了几个左括号、几个右括号
        if len(path) == 2 * n:
            res.append(''.join(path))
            return
        if open_ < n:                      # 左括号还没用完
            path.append('(')
            dfs(open_ + 1, close)
            path.pop()
        if close < open_:                  # 右括号不能比左括号多
            path.append(')')
            dfs(open_, close + 1)
            path.pop()

    dfs(0, 0)
    return res
```

**复杂度**：答案数是第 n 个卡特兰数 C(n) = C(2n, n) / (n + 1)，约 4ⁿ / (n^1.5)。时间 O(4ⁿ / √n)，每个答案要 O(n) 拼接。

## 解法二：按「第一个括号和它的配对」拆分

**思路**：任何合法串都能**唯一**写成 `"(" + a + ")" + b`，其中 a、b 都是合法串（a 是第一个左括号里面的部分）。如果 a 有 i 对，b 就有 n − 1 − i 对。从小到大算出所有 dp[k]。

```python
def generateParenthesis(n):
    # 任何合法串都能唯一写成 "(" + a + ")" + b，a 有 i 对，b 有 k-1-i 对
    dp = [[""]]
    for k in range(1, n + 1):
        dp.append(["(" + a + ")" + b
                   for i in range(k) for a in dp[i] for b in dp[k - 1 - i]])
    return dp[n]
```

**复杂度**：和答案数同阶。这个拆分也是卡特兰数递推式 C(n) = Σ C(i) · C(n−1−i) 的来源。

## 易错点

- 先生成所有 2²ⁿ 个串再判断合法：n = 8 时 65536 个串，能过但面试官会追问剪枝。
- 放右括号的条件写成 `close < n`：会生成 `"())("` 这样不合法的串。

## 面试追问

- **只求个数？** 卡特兰数，直接用公式，或者 DP：dp[n] = Σ dp[i] · dp[n−1−i]。
- **有多种括号？** 回溯时用栈记录未闭合的括号类型，放右括号时必须和栈顶匹配。
- **判断一个串是否合法？** 见 [20](../05-stack-monotonic/lc20)。
- **卡特兰数还在哪儿出现？** 不同的二叉搜索树（[96](../11-dynamic-programming/lc96)）、出栈序列个数。

## Java 版

```java
public List<String> generateParenthesis(int n) {
    List<String> res = new ArrayList<>();
    dfs(n, 0, 0, new StringBuilder(), res);
    return res;
}

private void dfs(int n, int open, int close, StringBuilder sb, List<String> res) {
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    if (open < n) {
        sb.append('(');
        dfs(n, open + 1, close, sb, res);
        sb.deleteCharAt(sb.length() - 1);
    }
    if (close < open) {
        sb.append(')');
        dfs(n, open, close + 1, sb, res);
        sb.deleteCharAt(sb.length() - 1);
    }
}
```
