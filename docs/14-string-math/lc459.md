# 459. 重复的子字符串

> [力扣 459](https://leetcode.cn/problems/repeated-substring-pattern/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

s 能否由一个子串重复多次构成：把两个 s 拼起来、去掉首尾字符，如果 s 还在里面，就是重复构成的。

## 关键点

- 原理：s 由子串 t 重复构成时，s 旋转 |t| 位还等于自己，所以会出现在 `(s + s)[1:-1]` 里，反过来也成立。
- KMP 做法：n = len(s)，p = n − lps[n−1]，`lps[n−1] > 0` 且 `n % p == 0` 时成立。O(n)。

```python
def repeatedSubstringPattern(s):
    return s in (s + s)[1:-1]
```
