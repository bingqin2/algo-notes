# 115. 不同的子序列

> [力扣 115](https://leetcode.cn/problems/distinct-subsequences/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

s 的子序列里有多少个等于 t：二维 DP，`dp[i][j]` 是 s[:i] 中等于 t[:j] 的子序列个数。

## 关键点

- `s[i−1] == t[j−1]` 时：用这个字符 `dp[i−1][j−1]` + 不用 `dp[i−1][j]`；不等时只能不用。
- `dp[i][0] = 1`：空串是任何串的子序列。
- 压成一维时 j 要**倒序**遍历，否则会用到本行刚更新的值。O(mn)。

```python
def numDistinct(s, t):
    dp = [1] + [0] * len(t)                # dp[j]: s 的前缀里有多少个子序列等于 t[:j]
    for ch in s:
        for j in range(len(t), 0, -1):     # 倒序，保证用的是上一行的值
            if t[j - 1] == ch:
                dp[j] += dp[j - 1]
    return dp[len(t)]
```
