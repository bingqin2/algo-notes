# 82. 删除排序链表中的重复元素 II

> [力扣 82](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

有序链表里删除所有**出现过重复**的值（一个都不留）：头结点也可能被删，用哑结点；prev 指向最后一个确定保留的结点。

## 最优解法

**思路**：看 `prev.next`：如果它和下一个值相同，就跳过所有这个值的结点，让 `prev.next` 直接指向第一个不同的结点（prev 不动，因为新的 prev.next 还要再检查）；否则它是唯一的，prev 前进。

```python
def deleteDuplicates(head):
    dummy = ListNode(0, head)
    prev = dummy
    while prev.next:
        cur = prev.next
        if cur.next and cur.next.val == cur.val:
            v = cur.val
            while cur and cur.val == v:    # 跳过所有值为 v 的结点
                cur = cur.next
            prev.next = cur
        else:
            prev = cur
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 删除一段重复值后 prev 前进了：新接上的结点可能也是重复的（`1 → 1 → 2 → 2 → 3`），会漏删。
- 和 [83](./lc83) 区分：83 是保留一个，不需要哑结点。
