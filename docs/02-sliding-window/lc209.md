# 209. 长度最小的子数组

> [力扣 209](https://leetcode.cn/problems/minimum-size-subarray-sum/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

正整数数组里找和 ≥ target 的**最短**子数组：可变长滑动窗口。元素都是正数，窗口扩大和一定变大，满足单调性。求最短是「满足条件时尽量收缩」，和求最长（不满足时收缩）正好相反。

## 最优解法

**思路**：right 扩张、累加和；只要和 ≥ target，就更新答案并收缩 left。

```python
def minSubArrayLen(target, nums):
    best = float("inf")
    left = s = 0
    for right, x in enumerate(nums):
        s += x
        while s >= target:                 # 满足条件就尽量缩短
            best = min(best, right - left + 1)
            s -= nums[left]
            left += 1
    return 0 if best == float("inf") else best
```

**复杂度**：时间 O(n)：每个元素最多进出窗口一次。空间 O(1)。

## 易错点

- 更新答案放在 while 外面：收缩过程中更短的窗口没被记录。
- 找不到时返回 0，不是 inf。
- 有负数时滑动窗口不成立（和不再单调），要用前缀和 + 单调队列（[862](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)）。

**进阶**：O(n log n) 解法：前缀和数组单调递增，对每个 i 二分找最小的 j 使 `pre[j] − pre[i] ≥ target`。
