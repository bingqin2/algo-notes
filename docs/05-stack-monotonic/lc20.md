# 20. 有效的括号

> [力扣 20](https://leetcode.cn/problems/valid-parentheses/) · 近两年面经里出现在：**腾讯 ×2 · 阿里笔试**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

括号匹配、嵌套是否合法：**最近打开的最先关闭**，正好是栈的后进先出。

## 解法一：栈匹配

**思路**：左括号入栈；遇到右括号，栈顶必须是对应的左括号，否则不合法。最后栈要为空。

<StepPlayer src="/viz/lc20.json" />

```python
def isValid(s):
    pair = {')': '(', ']': '[', '}': '{'}
    st = []
    for c in s:
        if c in pair:                      # 右括号：栈顶必须是对应的左括号
            if not st or st[-1] != pair[c]:
                return False
            st.pop()
        else:
            st.append(c)
    return not st                          # 还有没匹配的左括号也不行
```

**复杂度**：时间 O(n)，空间 O(n)。

小优化：长度是奇数直接返回 False。

## 解法二：只有一种括号时用计数

**思路**：只有 `(` 和 `)` 时不需要栈，一个计数器 `bal` 表示「还没关闭的左括号数」。中途变成负数说明右括号多了。

```python
def isValid(s):                         # 只有 ( 和 ) 两种字符
    bal = 0
    for c in s:
        bal += 1 if c == '(' else -1
        if bal < 0:                        # 右括号比左括号多了
            return False
    return bal == 0
```

**复杂度**：时间 O(n)，空间 O(1)。多种括号时计数不行：`([)]` 每种括号数量都平衡，但交叉了。

## 易错点

- 遇到右括号时栈为空：要先判空再看栈顶（`"]"`）。
- 循环结束忘了检查栈是否为空（`"(("`）。
- Java 里用 `Stack` 也能过，但推荐 `ArrayDeque`：`Stack` 继承自 `Vector`，每个方法都加了锁。

## Java 版

```java
public boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') st.push(')');          // 压入期望的右括号，比较时更简单
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.isEmpty() || st.pop() != c) return false;
    }
    return st.isEmpty();
}
```
