# 678. 有效的括号字符串

> [力扣 678](https://leetcode.cn/problems/valid-parenthesis-string/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

括号匹配里有万能字符 `*`（可以当左括号、右括号或空）：不用枚举，维护**未匹配左括号数量的可能范围** `[lo, hi]`。

## 最优解法

**思路**：

- `(`：lo、hi 都 +1；`)`：都 −1；`*`：lo − 1（当成右括号）、hi + 1（当成左括号）。
- hi < 0：就算所有 `*` 都当左括号，右括号还是太多，返回 False。
- lo 不能小于 0（未匹配数不能为负，那种选法不合法，丢弃），`lo = max(lo, 0)`。
- 最后 lo == 0 说明存在一种选法让左括号全部匹配。

```python
def checkValidString(s):
    lo = hi = 0                            # 未匹配的左括号数量的可能范围 [lo, hi]
    for ch in s:
        if ch == "(":
            lo, hi = lo + 1, hi + 1
        elif ch == ")":
            lo, hi = lo - 1, hi - 1
        else:                              # * 可以是 (、)、空
            lo, hi = lo - 1, hi + 1
        if hi < 0:                         # 就算所有 * 都当左括号也不够
            return False
        lo = max(lo, 0)                    # 未匹配数不能为负
    return lo == 0
```

**复杂度**：时间 O(n)，空间 O(1)。

**另一种做法**：两个栈分别存左括号和 `*` 的下标。遇到 `)` 先用左括号匹配，没有就用 `*`；最后剩下的左括号要用它**后面**的 `*` 匹配（比较下标）。O(n) 空间，容易理解。

## 易错点

- 只维护一个计数：`*` 有三种可能，必须用范围。
- 忘了 `lo = max(lo, 0)`：`"(*)"` 之类的会判断错。
