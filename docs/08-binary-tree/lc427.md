# 427. 建立四叉树

> [力扣 427](https://leetcode.cn/problems/construct-quad-tree/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

用四叉树表示 0/1 网格：**分治**，把网格分成四块分别建树，四块都是值相同的叶子时合并成一个叶子。

## 关键点

- 题目里的结点类叫 `Node`，这里为了和其他题区分叫 `QNode`。
- 也可以先用二维前缀和判断一块是否全相同，全相同直接建叶子，避免递归到底。O(n²)。

```python
class QNode:                               # 427 的四叉树结点（力扣里叫 Node）
    def __init__(self, val, isLeaf, topLeft=None, topRight=None, bottomLeft=None, bottomRight=None):
        self.val, self.isLeaf = val, isLeaf
        self.topLeft, self.topRight, self.bottomLeft, self.bottomRight = topLeft, topRight, bottomLeft, bottomRight
```

```python
def construct(grid):
    def build(r, c, size):
        if size == 1:
            return QNode(grid[r][c] == 1, True)
        h = size // 2
        kids = [build(r, c, h), build(r, c + h, h), build(r + h, c, h), build(r + h, c + h, h)]
        if all(k.isLeaf for k in kids) and len({k.val for k in kids}) == 1:
            return QNode(kids[0].val, True)    # 四块一样，合并成叶子
        return QNode(True, False, *kids)

    return build(0, 0, len(grid))
```
