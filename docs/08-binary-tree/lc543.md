# 543. 二叉树的直径

> [力扣 543](https://leetcode.cn/problems/diameter-of-binary-tree/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

二叉树直径（任意两结点间最长路径的边数）：经过某个结点的最长路径 = 左深度 + 右深度。后序遍历时顺便更新全局最大值。

## 关键点

- 递归函数**返回**深度（给父结点用），**更新**的是经过当前结点的路径长度，两者不同。
- 直径不一定经过根。O(n)。

```python
def diameterOfBinaryTree(root):
    best = 0

    def depth(node):
        nonlocal best
        if not node:
            return 0
        l, r = depth(node.left), depth(node.right)
        best = max(best, l + r)            # 经过 node 的最长路径（边数）
        return 1 + max(l, r)

    depth(root)
    return best
```
