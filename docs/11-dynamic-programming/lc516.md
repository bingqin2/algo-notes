# 516. 最长回文子序列

> [力扣 516](https://leetcode.cn/problems/longest-palindromic-subsequence/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

一个字符串内部的子序列问题：**区间 DP**，`dp[i][j]` 表示 `s[i..j]` 的答案，由更短的区间推出来。

## 最优解法

**思路**：

- `s[i] == s[j]`：两端都可以放进回文，`dp[i][j] = dp[i+1][j−1] + 2`；
- 否则去掉一端，`dp[i][j] = max(dp[i+1][j], dp[i][j−1])`。

`dp[i][j]` 依赖 `dp[i+1][..]`，所以 i 从大到小遍历，j 从小到大。

```python
def longestPalindromeSubseq(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]       # dp[i][j]：s[i..j] 的最长回文子序列
    for i in range(n - 1, -1, -1):         # i 倒序，因为依赖 dp[i+1][..]
        dp[i][i] = 1
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    return dp[0][n - 1]
```

**复杂度**：时间 O(n²)，空间 O(n²)，可以压缩成一维。

**另一种思路**：s 的最长回文子序列 = s 和它反转后的[最长公共子序列](./lc1143)。

## 易错点

- 遍历顺序错误：i 正序会用到还没算出来的 `dp[i+1][..]`。
- 和[最长回文子串](./lc5)区分：子串要连续，常用中心扩展。
