# 165. 比较版本号

> [力扣 165](https://leetcode.cn/problems/compare-version-numbers/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

按分隔符拆开，逐段比较数值：版本号每段转成整数比较（自动去掉前导 0），缺的段当 0。

## 最优解法

```python
def compareVersion(version1, version2):
    a, b = version1.split("."), version2.split(".")
    for i in range(max(len(a), len(b))):
        x = int(a[i]) if i < len(a) else 0     # int 会去掉前导 0；缺的段当 0
        y = int(b[i]) if i < len(b) else 0
        if x != y:
            return 1 if x > y else -1
    return 0
```

**复杂度**：时间 O(m + n)，空间 O(m + n)。

**O(1) 空间**：双指针，各自往后读到 `.` 为止，边读边算出这一段的数值，比较后跳过 `.` 继续。

## 易错点

- 按字符串比较：`"10" < "9"`。
- `1.0` 和 `1` 相等：缺的段当 0。
- 段很长时可能超过 int 范围：Java 里要么用双指针逐位比较（先比较去掉前导 0 后的长度），要么用 long / BigInteger。
