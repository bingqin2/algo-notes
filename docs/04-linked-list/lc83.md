# 83. 删除排序链表中的重复元素

> [力扣 83](https://leetcode.cn/problems/remove-duplicates-from-sorted-list/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序链表去重（保留一个）：相邻比较，相同就跳过下一个结点。

## 关键点

- 删除后 cur 不动，继续和新的下一个比较；不同才前进。
- 头结点不会被删，不需要哑结点（和 [82](./lc82) 不同）。

```python
def deleteDuplicates(head):
    cur = head
    while cur and cur.next:
        if cur.next.val == cur.val:
            cur.next = cur.next.next
        else:
            cur = cur.next
    return head
```
