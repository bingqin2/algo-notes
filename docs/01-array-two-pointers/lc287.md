# 287. 寻找重复数

> [力扣 287](https://leetcode.cn/problems/find-the-duplicate-number/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

n + 1 个数都在 [1, n] 里，只有一个数重复（可能重复多次），要求不修改数组、O(1) 空间：把下标 i → nums[i] 看成**链表**，重复的数会被两个下标指向，形成环，**环的入口**就是答案（Floyd 判圈）。

## 最优解法

**思路**：

1. 从 0 出发（0 不会被任何位置指向，所以一定在环外），快指针每次走两步 `nums[nums[fast]]`，慢指针走一步，直到相遇。
2. 慢指针回到 0，两个指针每次各走一步，再次相遇的位置就是环的入口。

和 [142. 环形链表 II](../04-linked-list/lc142) 完全一样，只是「下一个结点」变成了 `nums[i]`。

```python
def findDuplicate(nums):
    # 把 i -> nums[i] 看成链表，重复的数就是环的入口
    slow = fast = 0
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow = 0
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 第一阶段用 `while slow != fast` 但初始时两者相等：要先走一步再判断（写成 `while True` + break）。
- 第二阶段找到的是**下标**还是**值**：返回的 slow 本身就是重复的那个数（它是被两个位置指向的值）。

**其他解法**：二分答案：统计 ≤ mid 的数的个数，大于 mid 说明重复的数在 [1, mid]，O(n log n)。排序或哈希表不满足题目限制。
