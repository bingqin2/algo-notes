# 167. 两数之和 II - 输入有序数组

> [力扣 167](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

**有序**数组找两个数之和为 target：左右指针相向而行，利用有序性每一步排除一行或一列，O(n) 时间 O(1) 空间（比哈希表省空间）。

## 最优解法

**思路**：l 指向最小，r 指向最大。和太小，只能让 l 右移（r 左移只会更小）；和太大，r 左移。

为什么不会错过答案：和小于 target 时，`nums[l]` 和当前 r 左边的任何数相加都更小，所以 `nums[l]` 不可能是答案的一部分，可以排除。

```python
def twoSum(numbers, target):
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target:
            return [l + 1, r + 1]          # 题目下标从 1 开始
        if s < target:
            l += 1
        else:
            r -= 1
    return []
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 返回的下标从 **1** 开始。
- 循环条件 `l < r`：同一个元素不能用两次。
