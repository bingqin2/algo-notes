# 148. 排序链表

> [力扣 148](https://leetcode.cn/problems/sort-list/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

链表排序，要求 O(n log n)：链表不能随机访问，快排和堆排都不方便，**归并排序**最合适：找中点用快慢指针，合并两个有序链表不需要额外空间。

## 解法一：自顶向下归并 O(log n) 栈

**思路**：快慢指针找中点，断成两半，分别递归排序，再合并。

```python
def merge_two(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next
```

```python
def sortList(head):
    if not head or not head.next:
        return head
    slow, fast = head, head.next           # 快慢指针找中点，fast 从 head.next 出发，偶数长度时 slow 停在前半段末尾
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    mid, slow.next = slow.next, None       # 断开
    return merge_two(sortList(head), sortList(mid))
```

**复杂度**：时间 O(n log n)，空间 O(log n)（递归栈）。

## 解法二：自底向上归并 O(1) 空间

**思路**：先把相邻的长度为 1 的段两两合并，再合并长度为 2 的段，然后 4、8……直到段长 ≥ n。每一轮从头扫一遍：切下两段（`split` 返回剩余部分的头）、合并、接到已处理部分的末尾。

```python
def split(head, k):
    """从 head 开始数 k 个结点后断开，返回后半部分的头。"""
    for _ in range(k - 1):
        if not head:
            break
        head = head.next
    if not head:
        return None
    rest, head.next = head.next, None
    return rest
```

```python
def sortList(head):
    n, cur = 0, head
    while cur:
        n, cur = n + 1, cur.next
    dummy = ListNode(0, head)
    step = 1
    while step < n:                        # 每轮把相邻的两段长度为 step 的有序链表合并
        prev, cur = dummy, dummy.next
        while cur:
            left = cur
            right = split(left, step)      # 切下 step 个，返回剩下部分的头
            cur = split(right, step)
            prev.next = merge_two(left, right)
            while prev.next:               # 走到合并后的末尾，接下一组
                prev = prev.next
        step *= 2
    return dummy.next
```

**复杂度**：时间 O(n log n)，空间 O(1)。题目进阶要求的就是这个。

## 易错点

- 找中点时 fast 从 `head.next` 出发：两个结点时 slow 停在第一个，能正确断开；从 head 出发的话 slow 会停在第二个，左半部分永远是两个结点，无限递归。
- 断开中点：`slow.next = None`，否则两半还连着。
- 自底向上：合并后要走到新段的末尾，才能接下一组。
