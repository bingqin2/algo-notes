# 647. 回文子串

> [力扣 647](https://leetcode.cn/problems/palindromic-substrings/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

统计回文子串的个数（或者找最长回文子串）：**中心扩展**：回文串关于中心对称，枚举每个中心往两边扩，扩一次就多一个回文串。

## 最优解法

**思路**：长度为 n 的字符串有 `2n − 1` 个中心：n 个单字符中心（奇数长度回文）和 n − 1 个字符间隙（偶数长度回文）。用一个循环统一处理：`center` 从 0 到 2n − 2，`l = center // 2`，`r = l + center % 2`。

```python
def countSubstrings(s):
    n, res = len(s), 0
    for center in range(2 * n - 1):        # 2n-1 个中心：n 个字符 + n-1 个空隙
        l, r = center // 2, center // 2 + center % 2
        while l >= 0 and r < n and s[l] == s[r]:
            res += 1
            l -= 1
            r += 1
    return res
```

**复杂度**：时间 O(n²)，空间 O(1)。

**DP 写法**：`dp[i][j] = s[i] == s[j] and (j − i < 2 or dp[i+1][j−1])`，也是 O(n²)，但要 O(n²) 空间。**Manacher 算法**可以做到 O(n)，面试一般不要求。

## 易错点

- 只枚举单字符中心：漏掉所有偶数长度的回文（`"aa"`）。
