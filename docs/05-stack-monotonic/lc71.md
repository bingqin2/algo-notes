# 71. 简化路径

> [力扣 71](https://leetcode.cn/problems/simplify-path/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

简化 Unix 路径：按 `/` 分割，**栈**处理：`..` 弹出、`.` 和空串跳过、其他入栈。

## 关键点

- 根目录下的 `..` 不弹（栈为空时忽略）。
- `...` 是合法的目录名，不是特殊符号。

```python
def simplifyPath(path):
    stack = []
    for part in path.split("/"):
        if part == "..":
            if stack:
                stack.pop()
        elif part and part != ".":
            stack.append(part)
    return "/" + "/".join(stack)
```
