# 数组与双指针

## 核心框架

左右指针相向（有序数组、回文）、快慢指针同向（原地修改）。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [88. 合并两个有序数组](./lc88) | 美团 ×2 · 小米 | 合并后排序 / 从后往前双指针 O(1) 空间 |
| [15. 三数之和](./lc15) | 高频经典 | 排序 + 固定一个数 + 左右指针 / 去重的三处细节 |
| [11. 盛最多水的容器](./lc11) | 美团 | 暴力 O(n²) / 左右指针，每次移动较短的一边 |
| [42. 接雨水](./lc42) | 高频经典 | 按列：左右最大值数组 / 双指针 O(1) 空间 / 单调栈按行计算 |
| [31. 下一个排列](./lc31) | 字节 ×2 | 从后找第一个下降点 → 交换 → 反转后缀 |
| [179. 最大数](./lc179) | 字节 ×3 | 自定义比较：a+b 与 b+a 比较 / 全 0 的边界 |
| [54. 螺旋矩阵](./lc54) | 美团 · 招银 | 按层模拟：上右下左四个边界收缩 |
| [6. Z 字形变换 / 矩阵 Z 字形遍历](./lc6) | 腾讯 ×2 | 按行模拟，方向在首末行翻转 / 按周期 2n-2 直接计算下标 |
