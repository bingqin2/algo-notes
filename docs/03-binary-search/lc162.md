# 162. 寻找峰值

> [力扣 162](https://leetcode.cn/problems/find-peak-element/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数组不是有序的，也能二分：只要能根据 mid 处的信息判断**答案一定在某一边**。这里往「上坡」方向走一定能找到峰值（两端可以看成负无穷）。

## 最优解法

**思路**：

- `nums[mid] < nums[mid+1]`：mid 处在上坡，右边一定有峰（一直上坡到末尾，末尾就是峰），`lo = mid + 1`；
- 否则 mid 处在下坡或者就是峰，左边（含 mid）一定有峰，`hi = mid`。

```python
def findPeakElement(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid + 1]:      # 往上坡走，右边一定有峰
            lo = mid + 1
        else:
            hi = mid
    return lo
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 易错点

- 比较 `nums[mid]` 和 `nums[mid − 1]`：mid = 0 时越界。和 `mid + 1` 比较时，因为 `lo < hi`，mid 一定小于 hi，不会越界。
- 题目保证相邻元素不相等；如果有相等的，这个方法就不成立了（平地上无法判断方向）。
