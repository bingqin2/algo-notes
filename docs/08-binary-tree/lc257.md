# 257. 二叉树的所有路径

> [力扣 257](https://leetcode.cn/problems/binary-tree-paths/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

输出根到叶子的所有路径：DFS 带着路径往下走，到叶子时记录。

## 关键点

- 路径用新列表传递（`path + [x]`）就不用手动回溯；用同一个列表时要在返回前 pop。

```python
def binaryTreePaths(root):
    res = []

    def dfs(node, path):
        if not node:
            return
        path = path + [str(node.val)]
        if not node.left and not node.right:
            res.append("->".join(path))
        dfs(node.left, path)
        dfs(node.right, path)

    dfs(root, [])
    return res
```
