# 567. 字符串的排列

> [力扣 567](https://leetcode.cn/problems/permutation-in-string/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

判断 s2 是否包含 s1 的某个排列：长度为 |s1| 的固定窗口，计数相同就找到了。和 [438](./lc438) 是同一题，只是返回布尔值。

## 最优解法

**思路**：固定窗口滑动，维护 `diff` = 有几种字符在窗口里的个数和 s1 不一样。每次加入或移出一个字符 c，只有 c 这一种的状态会变：变化前相等则 diff + 1，变化后相等则 diff − 1。`diff == 0` 时返回 True。

```python
def checkInclusion(s1, s2):
    m = len(s1)
    if m > len(s2):
        return False
    need, win = [0] * 26, [0] * 26
    for ch in s1:
        need[ord(ch) - 97] += 1
    diff = sum(1 for c in range(26) if need[c] != 0)   # 有多少种字符的数量还对不上

    def change(c, d):
        nonlocal diff
        if win[c] == need[c]:
            diff += 1
        win[c] += d
        if win[c] == need[c]:
            diff -= 1

    for i, ch in enumerate(s2):
        change(ord(ch) - 97, 1)
        if i >= m:
            change(ord(s2[i - m]) - 97, -1)
        if diff == 0:
            return True
    return False
```

**复杂度**：时间 O(n + 26)，空间 O(26)。

## 易错点

- `diff` 的初值是 s1 里出现过的**字符种数**（窗口为空时这些字符的计数都对不上）。
- change 里要先判断「变化前是否相等」再改计数，最后判断「变化后是否相等」：变化前相等说明这一种原本对得上，现在要对不上了，diff + 1；变化后相等说明对上了，diff − 1。两步顺序不能颠倒。
- 简单写法每次比较两个 26 位的数组也完全能过，面试时先写简单的。
