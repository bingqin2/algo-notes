# 763. 划分字母区间

> [力扣 763](https://leetcode.cn/problems/partition-labels/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把字符串切成尽量多的段，每个字母只出现在一段里：先记录每个字母**最后出现的位置**，从左往右扫，当前段的结束位置至少要延伸到段内所有字母的最后位置；扫到这个位置就切一刀。

## 最优解法

```python
def partitionLabels(s):
    last = {ch: i for i, ch in enumerate(s)}   # 每个字母最后出现的位置
    res, start, end = [], 0, 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])           # 这一段至少要延伸到 end
        if i == end:                       # 段里所有字母都不会再出现了
            res.append(end - start + 1)
            start = i + 1
    return res
```

**复杂度**：时间 O(n)，空间 O(26)。

## 易错点

- 返回的是每段的**长度**，不是结束位置。
- 本质是区间合并：每个字母对应一个区间 [第一次出现, 最后一次出现]，合并重叠的区间。
