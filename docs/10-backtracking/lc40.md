# 40. 组合总和 II

> [力扣 40](https://leetcode.cn/problems/combination-sum-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数组**有重复元素**，每个元素只能用一次，结果不能重复：排序 + **同一层跳过相同的值**（树层去重）。

## 最优解法

**思路**：排序后，在同一层的 for 循环里，`i > start` 且 `candidates[i] == candidates[i−1]` 时跳过：这一层已经用相同的值开过一个分支了，再开会得到重复的组合。而**不同层**（往下递归）可以用相同的值（比如 `[1, 1, 6]`）。递归传 `i + 1`，每个元素只用一次。

```python
def combinationSum2(candidates, target):
    candidates.sort()
    res, path = [], []

    def backtrack(start, remain):
        if remain == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if i > start and candidates[i] == candidates[i - 1]:
                continue                   # 同一层不选相同的数（树层去重）
            if candidates[i] > remain:
                break
            path.append(candidates[i])
            backtrack(i + 1, remain - candidates[i])    # 每个数只能用一次：i + 1
            path.pop()

    backtrack(0, target)
    return res
```

**复杂度**：时间 O(2ⁿ · n)，空间 O(n)。

## 易错点

- 去重条件写成 `i > 0`：会把不同层的相同值也跳过，`[1, 1, 6]` 这种解就丢了。必须是 `i > start`。
- 不排序：相同的值不相邻，没法这样去重。
- 用 set 对结果去重：能过但慢，面试官会追问怎么在搜索过程中去重。
