# 151. 反转字符串中的单词

> [力扣 151](https://leetcode.cn/problems/reverse-words-in-a-string/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

反转单词顺序，去掉多余空格：Python 一行 `split` + 反转 + `join`。面试官通常会追问**原地**做法。

## 关键点

- 原地三步：先去掉多余空格（读写双指针），再整体反转，最后把每个单词再反转回来。O(n) 时间，C++ / 字符数组 O(1) 额外空间。

```python
def reverseWords(s):
    return " ".join(reversed(s.split()))
```

```python
def reverseWords(s):
    a = list(s)

    def rev(l, r):
        while l < r:
            a[l], a[r] = a[r], a[l]
            l += 1
            r -= 1

    k = i = 0                              # 第一步：去掉多余空格（读写双指针）
    while i < len(a):
        if a[i] != " ":
            if k:
                a[k] = " "
                k += 1
            while i < len(a) and a[i] != " ":
                a[k] = a[i]
                k += 1
                i += 1
        i += 1
    del a[k:]
    rev(0, len(a) - 1)                     # 第二步：整体反转
    start = 0
    for i in range(len(a) + 1):            # 第三步：每个单词再反转回来
        if i == len(a) or a[i] == " ":
            rev(start, i - 1)
            start = i + 1
    return "".join(a)
```
