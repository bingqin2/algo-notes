# 621. 任务调度器

> [力扣 621](https://leetcode.cn/problems/task-scheduler/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

同种任务之间至少间隔 n 个时间单位，求最短总时间：瓶颈是**出现次数最多**的任务。按它排出一个「框架」，其他任务往空位里填。

## 最优解法

**思路**：设最多的次数为 max_cnt，有 num_max 种任务都出现了 max_cnt 次。把最多的任务排成 max_cnt 行、每行 n + 1 个位置：前 max_cnt − 1 行是满的（不够就用空闲填），最后一行只放 num_max 个。总长 `(max_cnt − 1) · (n + 1) + num_max`。如果任务种类多到空位放不下，就不需要空闲，答案是任务总数。两者取最大。

```python
def leastInterval(tasks, n):
    cnt = [0] * 26
    for t in tasks:
        cnt[ord(t) - 65] += 1
    max_cnt = max(cnt)
    num_max = cnt.count(max_cnt)           # 出现次数最多的任务有几种
    # 前 max_cnt-1 轮每轮 n+1 个槽，最后一轮放 num_max 个；任务多到填满空闲时就是任务总数
    return max((max_cnt - 1) * (n + 1) + num_max, len(tasks))
```

**复杂度**：时间 O(n)，空间 O(26)。

## 易错点

- 忘了和任务总数取 max：n 很小、任务种类很多时，公式算出来比总数还小。
- 最后一行放的是 num_max 个，不是 1 个。

**模拟做法**：每个时间单位从大顶堆里取剩余次数最多的、不在冷却中的任务，能输出具体的调度顺序。
