# 97. 交错字符串

> [力扣 97](https://leetcode.cn/problems/interleaving-string/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

s3 能否由 s1 和 s2 交错组成：二维 DP，`dp[i][j]` 表示 s1 前 i 个和 s2 前 j 个能否组成 s3 前 i + j 个。

## 关键点

- 最后一个字符来自 s1：`dp[i−1][j]` 且 `s1[i−1] == s3[i+j−1]`；来自 s2 同理。
- 先判断长度 `m + n == len(s3)`。
- 双指针贪心是错的：两个串当前字符都能匹配时不知道该用哪个。O(mn) 时间，O(n) 空间。

```python
def isInterleave(s1, s2, s3):
    m, n = len(s1), len(s2)
    if m + n != len(s3):
        return False
    dp = [False] * (n + 1)                 # dp[j]: s1[:i] 和 s2[:j] 能否交错成 s3[:i+j]
    for i in range(m + 1):
        for j in range(n + 1):
            if i == 0 and j == 0:
                dp[j] = True
                continue
            from_s1 = i > 0 and dp[j] and s1[i - 1] == s3[i + j - 1]
            from_s2 = j > 0 and dp[j - 1] and s2[j - 1] == s3[i + j - 1]
            dp[j] = from_s1 or from_s2
    return dp[n]
```
