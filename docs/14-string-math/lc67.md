# 67. 二进制求和

> [力扣 67](https://leetcode.cn/problems/add-binary/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

两个二进制字符串相加：和 [415. 字符串相加](./lc415) 一样，从低位开始逐位相加，进位制换成 2。

## 关键点

- 循环条件带上 `carry`，最高位进位就不会丢。
- 结果先倒着存，最后反转。O(max(m, n))。

```python
def addBinary(a, b):
    i, j, carry, res = len(a) - 1, len(b) - 1, 0, []
    while i >= 0 or j >= 0 or carry:
        if i >= 0:
            carry += int(a[i])
            i -= 1
        if j >= 0:
            carry += int(b[j])
            j -= 1
        res.append(str(carry % 2))
        carry //= 2
    return "".join(reversed(res))
```
