# 104. 二叉树的最大深度

> [力扣 104](https://leetcode.cn/problems/maximum-depth-of-binary-tree/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

二叉树最大深度：后序递归，`1 + max(左深度, 右深度)`；或者 BFS 数层数。

## 关键点

- 深度很大时递归可能栈溢出，可以用 BFS。O(n)。

```python
def maxDepth(root):
    return 1 + max(maxDepth(root.left), maxDepth(root.right)) if root else 0
```
