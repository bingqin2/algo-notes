# 189. 轮转数组

> [力扣 189](https://leetcode.cn/problems/rotate-array/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数组整体循环移动、要求 O(1) 额外空间：**三次反转**。字符串左旋（剑指 Offer 58）也是同一个技巧。

## 最优解法

**思路**：向右轮转 k 位 = 把最后 k 个数移到前面。

1. 整体反转：`[1,2,3,4,5,6,7]` → `[7,6,5,4,3,2,1]`
2. 反转前 k 个（k = 3）：→ `[5,6,7,4,3,2,1]`
3. 反转后 n − k 个：→ `[5,6,7,1,2,3,4]`

```python
def rotate(nums, k):
    n = len(nums)
    k %= n

    def reverse(i, j):
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1

    reverse(0, n - 1)                      # 整体反转
    reverse(0, k - 1)                      # 前 k 个反转
    reverse(k, n - 1)                      # 后 n-k 个反转
    return nums
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 忘了 `k %= n`：k 可能大于数组长度。
- Python 写 `nums = nums[-k:] + nums[:-k]` 不会修改原数组（只是让局部变量指向新列表），要写 `nums[:] = ...`；而且这样是 O(n) 额外空间。
- k = 0 时 `nums[-0:]` 是整个数组，切片写法要特殊处理。
