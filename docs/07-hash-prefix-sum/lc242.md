# 242. 有效的字母异位词

> [力扣 242](https://leetcode.cn/problems/valid-anagram/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

字母异位词：两个字符串的字符计数相同。

## 关键点

- 长度不同直接 False。只有小写字母时用 26 位数组计数，O(n)。
- 追问：包含 Unicode 字符？用哈希表计数。

```python
from collections import Counter

def isAnagram(s, t):
    return len(s) == len(t) and Counter(s) == Counter(t)
```
