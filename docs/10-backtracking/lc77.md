# 77. 组合

> [力扣 77](https://leetcode.cn/problems/combinations/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

从 n 个数里选 k 个的所有组合：组合型回溯模板，`start` 控制只往后选。可以剪枝：剩下的数不够凑满 k 个就不用继续。

## 最优解法

**思路**：path 还需要 `k − len(path)` 个数，x 最大只能到 `n − (k − len(path)) + 1`，否则后面的数不够。

```python
def combine(n, k):
    res, path = [], []

    def backtrack(start):
        if len(path) == k:
            res.append(path[:])
            return
        for x in range(start, n - (k - len(path)) + 2):   # 剩下的数不够凑满 k 个就不用试
            path.append(x)
            backtrack(x + 1)
            path.pop()

    backtrack(1)
    return res
```

**复杂度**：时间 O(C(n, k) · k)，空间 O(k)。

## 易错点

- 记录答案时要复制：`res.append(path[:])`，否则存的是同一个列表的引用，最后全是空的。
- 剪枝的上界算错：最好举个例子验证（n = 4, k = 2，path 为空时 x 最大到 3）。
