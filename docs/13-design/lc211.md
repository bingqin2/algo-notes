# 211. 添加与搜索单词 - 数据结构设计

> [力扣 211](https://leetcode.cn/problems/design-add-and-search-words-data-structure/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

添加单词、查询时 `.` 能匹配任意字母：字典树（[208](./lc208)）+ 查询时遇到 `.` 就 DFS 所有孩子。

## 关键点

- 普通字符沿着孩子走；`.` 时任何一个孩子能匹配剩下的部分就返回 True。
- 结尾要检查单词结束标记，不能只看路径存在。
- 添加 O(L)；查询最坏 O(26^L)，但实际单词长度很短，`.` 也不多。

```python
class WordDictionary:
    def __init__(self):
        self.root = {}

    def addWord(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True                   # 单词结尾标记

    def search(self, word):
        def dfs(node, i):
            if i == len(word):
                return "$" in node
            ch = word[i]
            if ch == ".":                  # 通配符：试所有孩子
                return any(dfs(child, i + 1) for k, child in node.items() if k != "$")
            return ch in node and dfs(node[ch], i + 1)
        return dfs(self.root, 0)
```
