# 1047. 删除字符串中的所有相邻重复项

> [力扣 1047](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

反复删除相邻的重复字符：**栈**，当前字符和栈顶相同就弹出（相当于消掉一对），否则入栈。

## 关键点

- 删除后新出现的相邻重复会在下一步自然处理（和栈顶比较）。O(n)。

```python
def removeDuplicates(s):
    stack = []
    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)
    return "".join(stack)
```
