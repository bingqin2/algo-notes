# 68. 文本左右对齐

> [力扣 68](https://leetcode.cn/problems/text-justification/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

文本左右对齐：模拟题。每行贪心地放尽量多的单词，然后分配空格。

## 关键点

- 放得下的条件：`单词总长 + 单词数 − 1 ≤ maxWidth`（单词之间至少一个空格）。
- 普通行：空格平均分到间隙里，除不尽的**从左边开始**多分一个。
- 最后一行，或者这一行只有一个单词：左对齐，单词之间一个空格，右边补空格。

```python
def fullJustify(words, maxWidth):
    res, i = [], 0
    while i < len(words):
        j, width = i, 0                    # 贪心地放尽量多的单词：words[i:j]
        while j < len(words) and width + len(words[j]) + (j - i) <= maxWidth:
            width += len(words[j])
            j += 1
        gaps = j - i - 1
        if j == len(words) or gaps == 0:   # 最后一行或只有一个单词：左对齐
            line = " ".join(words[i:j])
            res.append(line + " " * (maxWidth - len(line)))
        else:
            spaces, extra = divmod(maxWidth - width, gaps)
            line = ""
            for k in range(i, j - 1):      # 多出来的空格从左边开始分
                line += words[k] + " " * (spaces + (1 if k - i < extra else 0))
            res.append(line + words[j - 1])
        i = j
    return res
```
