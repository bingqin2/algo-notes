# 160. 相交链表

> [力扣 160](https://leetcode.cn/problems/intersection-of-two-linked-lists/) · 近两年面经里出现在：**高频经典**
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

两个链表找第一个公共结点：哈希表存一个链表的结点；或者 O(1) 空间的双指针：**两个指针都走 A + B 的总长度**，会同时到达交点。

## 解法一：哈希表

```python
def getIntersectionNode(headA, headB):
    seen = set()
    while headA:
        seen.add(headA)
        headA = headA.next
    while headB:
        if headB in seen:
            return headB
        headB = headB.next
    return None
```

**复杂度**：时间 O(m + n)，空间 O(m)。

## 解法二：双指针走 A+B 路程

**思路**：a 从 A 出发，走到末尾后跳到 B 的头；b 从 B 出发，走到末尾后跳到 A 的头。两者走的总路程都是「A 独有 + B 独有 + 公共部分」，所以在交点相遇；不相交时同时走到 None，循环也会结束。

```python
def getIntersectionNode(headA, headB):
    a, b = headA, headB
    while a is not b:                      # 都走 A+B 的总长，同时到达交点；不相交就同时到 None
        a = a.next if a else headB
        b = b.next if b else headA
    return a
```

**复杂度**：时间 O(m + n)，空间 O(1)。

## 易错点

- 比较结点要用 `is`（同一个对象），不能比较 val。
- 跳转条件写成 `a.next if a.next else headB`：两个链表不相交时永远不会同时为 None，死循环。要让指针**走到 None 这一步**再跳。
- 另一种 O(1) 写法：先求两个长度，长的先走差值步，再一起走。
