# 701. 二叉搜索树中的插入操作

> [力扣 701](https://leetcode.cn/problems/insert-into-a-binary-search-tree/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

BST 插入：从根往下比较，走到空位置就插入新结点。新结点总是成为叶子，不需要调整结构。

## 最优解法

```python
def insertIntoBST(root, val):
    if not root:
        return TreeNode(val)
    cur = root
    while True:
        if val < cur.val:
            if not cur.left:
                cur.left = TreeNode(val)
                return root
            cur = cur.left
        else:
            if not cur.right:
                cur.right = TreeNode(val)
                return root
            cur = cur.right
```

**复杂度**：时间 O(h)，空间 O(1)。递归写法 `root.left = insertIntoBST(root.left, val)` 更短，空间 O(h)。

## 易错点

- 空树：直接返回新结点。
- 题目保证 val 不在树中；如果可能重复，要约定放左边还是右边。
- 不平衡：一直插入有序数据会退化成链表，O(n)。工程上用红黑树、AVL 等自平衡树。
