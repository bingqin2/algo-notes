# 153. 寻找旋转排序数组中的最小值

> [力扣 153](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

旋转排序数组（无重复）找最小值：和**右端点**比较，判断 mid 在左段还是右段。

## 最优解法

**思路**：最小值是右段的第一个数。

- `nums[mid] > nums[hi]`：mid 在左段（较大的那段），最小值在 mid 右边，`lo = mid + 1`；
- 否则 mid 在右段，mid 可能就是最小值，`hi = mid`。

lo == hi 时就是答案。

```python
def findMin(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]:           # 最小值在 mid 右边
            lo = mid + 1
        else:                              # mid 可能就是最小值
            hi = mid
    return nums[lo]
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 易错点

- 和 `nums[lo]` 比较：数组没有旋转时（整体升序），`nums[mid] > nums[lo]` 但最小值在左边，会走错方向。和 `nums[hi]` 比较不会有这个问题。
- 循环条件 `lo < hi` 配 `hi = mid`；写成 `lo <= hi` 会死循环。
