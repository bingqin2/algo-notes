# 297. 二叉树的序列化与反序列化

> [力扣 297](https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

序列化和反序列化二叉树：**前序遍历 + 空结点标记**（比如 `#`），反序列化时按同样的前序顺序递归构建。

## 关键点

- 必须记录空结点，否则无法唯一确定结构。
- 层序遍历（BFS）也可以，和力扣的输入格式一样。
- 反序列化用迭代器依次取值，不用切片。

```python
class Codec:                               # 297：前序 + 空结点标记
    def serialize(self, root):
        out = []

        def dfs(node):
            if not node:
                out.append("#")
                return
            out.append(str(node.val))
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return ",".join(out)

    def deserialize(self, data):
        vals = iter(data.split(","))

        def build():
            v = next(vals)
            if v == "#":
                return None
            node = TreeNode(int(v))
            node.left = build()
            node.right = build()
            return node

        return build()
```
