# 96. 不同的二叉搜索树

> [力扣 96](https://leetcode.cn/problems/unique-binary-search-trees/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

1 到 n 能组成多少种不同的 BST：枚举根 root，左子树由 `root − 1` 个数组成，右子树由 `n − root` 个数组成，种数相乘再累加。结果是**卡特兰数**。

## 最优解法

**思路**：BST 的形状只和结点个数有关，和具体的值无关。`dp[i] = Σ dp[root − 1] · dp[i − root]`，`dp[0] = 1`（空树也算一种）。

```python
def numTrees(n):
    dp = [1] + [0] * n                     # dp[i]：i 个结点能组成的 BST 数量
    for i in range(1, n + 1):
        for root in range(1, i + 1):       # 以 root 为根：左边 root-1 个，右边 i-root 个
            dp[i] += dp[root - 1] * dp[i - root]
    return dp[n]
```

**复杂度**：时间 O(n²)，空间 O(n)。

**公式**：卡特兰数 `C(n) = C(2n, n) / (n + 1)`，O(n)。卡特兰数还对应：合法括号序列的个数、出栈序列的个数、凸多边形三角划分数。

## 易错点

- `dp[0] = 1`，不是 0，否则所有「一边为空」的情况都没算进去。
