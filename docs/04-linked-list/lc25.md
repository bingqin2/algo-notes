# 25. K 个一组翻转链表

> [力扣 25](https://leetcode.cn/problemset/?search=25) · 近两年面经里出现在：**字节 ×3 · 美团 ×2**

## 识别信号

按固定长度分段处理链表。只要会 [206. 反转链表](./lc206)，这道题就是「找一组 → 断开 → 反转 → 接回」四步的循环。

## 解法一：迭代（分组截断 + 反转 + 接回）

**思路**：

1. 加哑结点 `dummy`，让 `pre` 指向「上一组的尾巴」。第一组的前面就是 `dummy`。
2. 从 `pre` 往后走 k 步找到 `end`。不足 k 个就结束，剩下的保持原样。
3. 记住 `start = pre.next`（组头）和 `nxt = end.next`（下一组的开头），然后断开 `end.next`。
4. 反转 `start..end`。反转后 `end` 变成组头，`start` 变成组尾。
5. 接回：`pre.next = end`，`start.next = nxt`，再让 `pre = start`。

<StepPlayer src="/viz/lc25.json" />

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    pre = dummy
    while True:
        end = pre
        for _ in range(k):
            end = end.next
            if end is None:
                return dummy.next          # 不足 k 个，结束
        start, nxt = pre.next, end.next
        end.next = None                    # 断开这一组
        pre.next = reverse(start)          # 反转后返回 end
        start.next = nxt                   # start 现在是组尾
        pre = start


def reverse(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    return prev
```

**复杂度**：时间 O(n)（每个结点被找一次、反转一次），空间 O(1)。

## 解法二：递归

**思路**：先检查前面够不够 k 个；够的话，把前 k 个反转，然后让原来的组头（现在的组尾）接上「递归处理剩下部分」的结果。

```python
def reverseKGroup(head, k):
    cur = head
    for _ in range(k):
        if cur is None:
            return head                    # 不足 k 个，原样返回
        cur = cur.next
    # 反转 [head, cur)，cur 是下一组的开头
    prev, p = None, head
    while p is not cur:
        p.next, prev, p = prev, p, p.next
    head.next = reverseKGroup(cur, k)      # head 变成组尾
    return prev
```

**复杂度**：时间 O(n)，空间 O(n/k)（递归栈）。

## 易错点

- 找 `end` 时没检查空指针：剩下不足 k 个时要直接返回。
- 断开之前没存 `nxt`，反转后就接不回去了。
- 接回之后忘记移动 `pre`，下一轮会重复处理同一组。
- Python 的多重赋值 `cur.next, prev, cur = prev, cur, cur.next` 是先算出右边全部的值再从左往右赋值，这里顺序是安全的。没把握时就拆成三行写。

## 面试追问

- **剩下不足 k 个也要反转，怎么改？** 找 `end` 时遇到空指针不要直接返回，而是把剩下的部分也反转一次。
- **从链表尾部开始分组呢？** 先整体反转，按 k 分组反转，再整体反转回来。也可以先求出长度 n，跳过前面 n % k 个结点再分组。
