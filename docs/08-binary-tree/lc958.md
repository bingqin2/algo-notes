# 958. 二叉树的完全性检验

> [力扣 958](https://leetcode.cn/problems/check-completeness-of-a-binary-tree/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

判断完全二叉树：BFS 时把空孩子也入队，一旦遇到空结点，后面就不能再出现非空结点。

## 最优解法

**思路**：层序遍历，空结点也放进队列。用 `seen_null` 记录是否已经遇到过空结点；之后再遇到非空结点，说明中间有空缺，不是完全二叉树。

```python
from collections import deque

def isCompleteTree(root):
    q = deque([root])
    seen_null = False
    while q:
        node = q.popleft()
        if node is None:
            seen_null = True
        else:
            if seen_null:                  # 空结点之后又出现了非空结点
                return False
            q.append(node.left)
            q.append(node.right)
    return True
```

**复杂度**：时间 O(n)，空间 O(n)。

**另一种做法**：按满二叉树给结点编号（根为 1），完全二叉树当且仅当最大编号等于结点总数。

## 易错点

- 只检查「有右孩子没左孩子」：`[1,2,3,4,null,5]` 检测不到。这棵树里没有结点「有右无左」，但结点 2 缺了右孩子，结点 3 却有左孩子，中间有空缺。
- 不要把空结点的孩子入队（空结点没有孩子）。
