# 52. N 皇后 II

> [力扣 52](https://leetcode.cn/problems/n-queens-ii/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

N 皇后只要数量、不要方案：和 [51](./lc51) 一样逐行放，用三个**位掩码**记录被占用的列和两条对角线。

## 关键点

- `free = full & ~(cols | d1 | d2)` 是当前行能放的位置；`free & −free` 取最低位的 1。
- 进入下一行时，两条对角线的掩码分别左移、右移一位。
- 不用位运算的话，用三个集合记录 `c`、`r − c`、`r + c` 也行。

```python
def totalNQueens(n):
    full = (1 << n) - 1

    def dfs(cols, d1, d2):                 # 三个掩码：被列、两条对角线占用的位置
        if cols == full:
            return 1
        cnt = 0
        free = full & ~(cols | d1 | d2)
        while free:
            bit = free & -free             # 取最低位的空位
            free -= bit
            cnt += dfs(cols | bit, (d1 | bit) << 1 & full, (d2 | bit) >> 1)
        return cnt

    return dfs(0, 0, 0)
```
