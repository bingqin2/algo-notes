# 1091. 二进制矩阵中的最短路径

> [力扣 1091](https://leetcode.cn/problems/shortest-path-in-binary-matrix/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

网格里求**最短路径**、每一步代价相同：BFS。BFS 第一次到达某个格子时的步数就是最短距离。这题可以走 8 个方向。

## 最优解法

**思路**：起点或终点是 1 直接返回 −1。从左上角 BFS，**入队时**就标记已访问（并记录距离），第一次弹出终点时返回距离。直接把距离写进原数组，省一个 visited。

```python
from collections import deque

def shortestPathBinaryMatrix(grid):
    n = len(grid)
    if grid[0][0] or grid[n - 1][n - 1]:
        return -1
    q = deque([(0, 0)])
    grid[0][0] = 1                         # 直接在原数组上记录距离（也当作已访问）
    while q:
        r, c = q.popleft()
        d = grid[r][c]
        if (r, c) == (n - 1, n - 1):
            return d
        for dr in (-1, 0, 1):
            for dc in (-1, 0, 1):
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 0:
                    grid[nr][nc] = d + 1   # 入队时就标记，避免重复入队
                    q.append((nr, nc))
    return -1
```

**复杂度**：时间 O(n²)，空间 O(n²)。

## 易错点

- 出队时才标记：同一个格子会被多次入队，最坏变成指数级（8 个方向时尤其明显），会超时。
- 路径长度按**格子数**算，起点算 1。
- 用 DFS 找最短路：要遍历所有路径，超时。
