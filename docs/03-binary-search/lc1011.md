# 1011. 在 D 天内送达包裹的能力

> [力扣 1011](https://leetcode.cn/problems/capacity-to-ship-packages-within-d-days/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

「最小化最大值」「最少需要多大的能力才能在限制内完成」：**二分答案**。答案越大越容易满足（单调），在 [下界, 上界] 里二分找第一个满足的值，每次用贪心检查是否可行。

## 最优解法

**思路**：运力 cap 的范围是 [max(weights), sum(weights)]（至少装得下最重的包裹；最多一天全运完）。对于某个 cap，贪心地按顺序装，装不下就开始新的一天，算出需要的天数。天数 ≤ days 说明 cap 够用，试更小的；否则要更大的。

```python
def shipWithinDays(weights, days):
    def need_days(cap):
        d, cur = 1, 0
        for w in weights:
            if cur + w > cap:
                d += 1
                cur = 0
            cur += w
        return d

    lo, hi = max(weights), sum(weights)    # 运力至少能装下最重的包裹
    while lo < hi:
        mid = (lo + hi) // 2
        if need_days(mid) <= days:         # mid 够用，答案在左边（含 mid）
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**复杂度**：时间 O(n log(sum))，空间 O(1)。

## 易错点

- 下界写成 1 或 0：cap 小于最重的包裹时贪心会出错（那个包裹永远装不上），或者死循环。
- 检查函数里新的一天开始时，`cur` 要从当前包裹开始算（先 `cur = 0` 再 `cur += w`）。
- 二分写法：找「第一个满足」的值用左闭右开的 lower_bound 模板（见 [704](./lc704)）。
