# 75. 颜色分类

> [力扣 75](https://leetcode.cn/problems/sort-colors/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

只有三种值的数组原地排序：**荷兰国旗问题**，三个指针一次遍历，把数组分成「0 区、1 区、未处理、2 区」。快排的三路划分就是这个。

## 最优解法

**思路**：不变式：`[0, lo)` 都是 0，`[lo, i)` 都是 1，`(hi, n−1]` 都是 2，`[i, hi]` 还没看。

- `nums[i] == 0`：和 lo 交换，lo、i 都右移（换过来的一定是 1，已经看过）；
- `nums[i] == 2`：和 hi 交换，hi 左移，**i 不动**（换过来的数还没看过）；
- `nums[i] == 1`：i 右移。

```python
def sortColors(nums):
    lo, i, hi = 0, 0, len(nums) - 1        # [0, lo) 是 0，[lo, i) 是 1，(hi, n) 是 2
    while i <= hi:
        if nums[i] == 0:
            nums[lo], nums[i] = nums[i], nums[lo]
            lo += 1
            i += 1
        elif nums[i] == 2:
            nums[i], nums[hi] = nums[hi], nums[i]
            hi -= 1                        # 换过来的数还没看过，i 不动
        else:
            i += 1
    return nums
```

**复杂度**：时间 O(n)，一次遍历；空间 O(1)。

## 易错点

- 和 hi 交换后 i 也右移：换过来的可能是 0 或 2，被跳过了。
- 循环条件写成 `i < hi`：`hi` 位置的元素没检查。

**另一种写法**：计数排序，两次遍历：先数 0、1、2 各有几个，再按个数填回去。简单，但面试官通常要求一次遍历。
