# 112. 路径总和

> [力扣 112](https://leetcode.cn/problems/path-sum/) · 近两年面经里出现在：**字节 ×2**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

判断是否存在一条**从根到叶子**的路径，路径上的和等于目标值。路径总和系列有三题，区别在路径的定义：

| 题目 | 路径 | 方法 |
|---|---|---|
| 112 | 根到叶，判断存在 | DFS，目标值逐层减去当前值 |
| [113](./lc113) | 根到叶，输出所有路径 | DFS + 回溯 |
| [437](./lc437) | 任意向下的路径，求条数 | 前缀和 + 哈希表 |

## 解法一：递归 DFS

**思路**：每往下走一层，目标值减去当前结点的值。到了叶子结点，看剩下的值是否正好等于叶子的值。

```python
def hasPathSum(root, target):
    if not root: return False
    if not root.left and not root.right: return root.val == target
    return hasPathSum(root.left, target - root.val) or hasPathSum(root.right, target - root.val)
```

**复杂度**：时间 O(n)，空间 O(h)。

## 解法二：BFS

**思路**：队列里存 (结点, 根到它的路径和)，遇到叶子就判断。

```python
from collections import deque

def hasPathSum(root, target):
    if not root: return False
    q = deque([(root, root.val)])
    while q:
        node, s = q.popleft()
        if not node.left and not node.right and s == target: return True
        for ch in (node.left, node.right):
            if ch: q.append((ch, s + ch.val))
    return False
```

**复杂度**：时间 O(n)，空间 O(w)。

## 易错点

- 判断条件放在空结点上（`if not root: return target == 0`）：一个结点只有一个孩子时，空的那一边会被当成叶子，错误地返回 true。必须在**叶子结点**上判断。
- 空树返回 false，即使 target 是 0。
- 结点值可能是负数，所以不能「和超过 target 就提前剪枝」。

## 面试追问

- **输出所有路径？** 见 [113](./lc113)。
- **路径不一定从根开始、不一定到叶子结束？** 见 [437](./lc437)：前缀和 + 哈希表，O(n)。
- **求根到叶子的路径组成的数字之和？** [129](./lc129)：往下传 `cur * 10 + val`。

## Java 版

```java
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    if (root.left == null && root.right == null) return root.val == targetSum;
    return hasPathSum(root.left, targetSum - root.val) || hasPathSum(root.right, targetSum - root.val);
}
```
