# 205. 同构字符串

> [力扣 205](https://leetcode.cn/problems/isomorphic-strings/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

两个字符串是否同构：字符之间必须是**一一对应**，用两个哈希表分别检查两个方向。

## 关键点

- 只检查 s → t 不够：`"ab"` 和 `"aa"` 中 a→a、b→a，单向没冲突，但 t 的 a 对应了两个字符。

```python
def isIsomorphic(s, t):
    st, ts = {}, {}
    for a, b in zip(s, t):
        if st.get(a, b) != b or ts.get(b, a) != a:   # 双向都要一一对应
            return False
        st[a], ts[b] = b, a
    return True
```
