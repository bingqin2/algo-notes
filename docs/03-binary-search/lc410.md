# 410. 分割数组的最大值

> [力扣 410](https://leetcode.cn/problems/split-array-largest-sum/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

把数组分成 k 段，最小化「各段和的最大值」：**二分答案**，检查「每段不超过 limit 时最少要分几段」。

## 关键点

- 答案范围 [max(nums), sum(nums)]。
- 贪心检查：能放进当前段就放，放不下就开新段。段数 ≤ k 说明 limit 可行（段数可以再多切几刀凑够 k）。
- O(n log(sum))。也可以 DP，O(k · n²)。

```python
def splitArray(nums, k):
    def parts(limit):                      # 每段和不超过 limit 时至少要分几段
        cnt, cur = 1, 0
        for x in nums:
            if cur + x > limit:
                cnt += 1
                cur = 0
            cur += x
        return cnt

    lo, hi = max(nums), sum(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if parts(mid) <= k:
            hi = mid
        else:
            lo = mid + 1
    return lo
```
