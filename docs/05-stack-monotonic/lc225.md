# 225. 用队列实现栈

> [力扣 225](https://leetcode.cn/problems/implement-stack-using-queues/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

用队列实现栈：一个队列就够，push 时把前面的元素依次移到队尾，新元素就到了队头。

## 关键点

- push O(n)，pop / top O(1)。
- 两个队列的写法本质一样。反过来用栈实现队列（[232](./lc232)）可以做到均摊 O(1)。

```python
from collections import deque

class MyStack:                             # 225：用一个队列实现栈
    def __init__(self):
        self.q = deque()

    def push(self, x):
        self.q.append(x)
        for _ in range(len(self.q) - 1):   # 把前面的元素依次移到后面，新元素就到了队头
            self.q.append(self.q.popleft())

    def pop(self):
        return self.q.popleft()

    def top(self):
        return self.q[0]

    def empty(self):
        return not self.q
```
