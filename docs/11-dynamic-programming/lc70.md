# 70. 爬楼梯

> [力扣 70](https://leetcode.cn/problems/climbing-stairs/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

每次爬 1 或 2 级：`f(n) = f(n−1) + f(n−2)`，就是斐波那契。

## 关键点

- 只依赖前两项，两个变量滚动，O(n) 时间 O(1) 空间。
- 追问：每次可以爬 1~m 级？`f(n) = f(n−1) + … + f(n−m)`，用前缀和或滑动和 O(n)。n 极大时用矩阵快速幂 O(log n)。

```python
def climbStairs(n):
    a, b = 1, 1                            # f(0), f(1)
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```
