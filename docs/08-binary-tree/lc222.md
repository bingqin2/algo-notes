# 222. 完全二叉树的节点个数

> [力扣 222](https://leetcode.cn/problems/count-complete-tree-nodes/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

完全二叉树的结点数，要求小于 O(n)：一直向左和一直向右的深度相同，说明是**满**二叉树，直接 `2^h − 1`；否则递归左右子树。

## 关键点

- 每层只有一边会继续递归（另一边一定是满的），O(log² n)。
- 另一种做法：二分最后一层的结点个数。

```python
def countNodes(root):
    if not root:
        return 0
    lh = rh = 0
    l, r = root, root
    while l:
        lh, l = lh + 1, l.left
    while r:
        rh, r = rh + 1, r.right
    if lh == rh:                           # 一直向左和一直向右一样深：满二叉树
        return (1 << lh) - 1
    return 1 + countNodes(root.left) + countNodes(root.right)
```
