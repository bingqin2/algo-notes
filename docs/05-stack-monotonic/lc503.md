# 503. 下一个更大元素 II

> [力扣 503](https://leetcode.cn/problems/next-greater-element-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

**循环数组**的「下一个更大元素」：单调栈 + 把数组遍历**两遍**（下标取模），第二遍让末尾的元素能看到开头的元素。

## 最优解法

**思路**：单调递减栈存下标。遍历 `i` 从 0 到 2n − 1，当前值 `nums[i % n]` 比栈顶大，栈顶的答案就是它。只在第一遍时入栈（第二遍只负责给还在栈里的元素找答案）。

```python
def nextGreaterElements(nums):
    n = len(nums)
    res = [-1] * n
    stack = []                             # 单调递减栈，存下标
    for i in range(2 * n):                 # 循环数组：遍历两遍
        x = nums[i % n]
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        if i < n:
            stack.append(i)
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 第二遍也入栈：结果不会错，但栈里会有重复下标，多做无用功。
- 栈里存值而不是下标：没法写回答案位置。
- 比较用 `<` 而不是 `<=`：相等的不算「更大」。
