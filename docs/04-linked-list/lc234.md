# 234. 回文链表

> [力扣 234](https://leetcode.cn/problems/palindrome-linked-list/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断回文链表，要求 O(1) 空间：快慢指针找中点 → 反转后半段 → 两段逐个比较。

## 关键点

- 奇数长度时中间结点归到后半段，比较时以后半段走完为准。
- 面试时可以说一句：比较完最好把后半段再反转回来，恢复原链表。
- 简单做法：值复制到数组再判断回文，O(n) 空间。

```python
def isPalindrome(head):
    slow = fast = head
    while fast and fast.next:              # 找中点
        slow, fast = slow.next, fast.next.next
    prev = None
    while slow:                            # 反转后半段
        slow.next, prev, slow = prev, slow, slow.next
    a, b = head, prev
    while b:
        if a.val != b.val:
            return False
        a, b = a.next, b.next
    return True
```
