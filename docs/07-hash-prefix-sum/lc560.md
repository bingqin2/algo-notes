# 560. 和为 K 的子数组

> [力扣 560](https://leetcode.cn/problems/subarray-sum-equals-k/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数组**有负数**，求和为 k 的子数组**个数**：滑动窗口不能用（和不单调），用**前缀和 + 哈希表计数**：以 i 结尾、和为 k 的子数组个数，就是之前出现过多少次前缀和 `s − k`。

## 解法一：前缀和 + 哈希表计数

**思路**：遍历时维护前缀和 s，先累加 `count[s − k]` 到答案，再把 `count[s]` 加一。初始 `count[0] = 1`（空前缀）。

<StepPlayer src="/viz/lc560.json" />

```python
from collections import Counter

def subarraySum(nums, k):
    count = Counter({0: 1})                # 前缀和 → 出现次数；空前缀和为 0
    s = res = 0
    for x in nums:
        s += x
        res += count[s - k]                # 之前有几个前缀和等于 s - k，就有几个以这里结尾的子数组
        count[s] += 1
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 先 `count[s] += 1` 再查 `count[s − k]`：k = 0 时会把空子数组也算进去。
- 忘了 `count[0] = 1`：从下标 0 开始的子数组算不到。
- 求**个数**存次数，求**最长**存最早下标（[525](./lc525)），求**最短**存最晚下标。
