# 785. 判断二分图

> [力扣 785](https://leetcode.cn/problems/is-graph-bipartite/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

判断能否把点分成两组、每条边连接的两点不在同一组：**二分图**判定，用**染色**：BFS / DFS 时给相邻点染相反的颜色，冲突就不是二分图。

## 最优解法

**思路**：图可能不连通，每个未染色的点都要作为起点。BFS 时邻居没染色就染成相反色，已染色且和当前点同色就返回 False。

```python
from collections import deque

def isBipartite(graph):
    color = [0] * len(graph)               # 0 未染色，1 / -1 两种颜色
    for s in range(len(graph)):
        if color[s]:
            continue
        color[s] = 1
        q = deque([s])
        while q:
            u = q.popleft()
            for v in graph[u]:
                if color[v] == 0:
                    color[v] = -color[u]
                    q.append(v)
                elif color[v] == color[u]: # 相邻的两个点同色
                    return False
    return True
```

**复杂度**：时间 O(V + E)，空间 O(V)。

**另一种判定**：二分图 ⟺ 没有奇数长度的环。也可以用并查集：每个点的所有邻居应该在同一个集合，并且不能和这个点在同一个集合。

## 易错点

- 只从 0 号点开始：不连通的图会漏掉其他连通块。
