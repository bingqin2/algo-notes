# 15. 三数之和

> [力扣 15](https://leetcode.cn/problems/3sum/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

在数组里找若干个数和为目标值，并且**结果不能重复**：先排序，固定一个数，剩下的用左右指针。k 数之和就是 k − 2 层循环 + 双指针，O(n^(k−1))。

## 解法一：排序 + 固定一个数 + 左右指针

**思路**：排序后枚举第一个数 `nums[i]`，在 `[i+1, n−1]` 里用左右指针找两个数的和等于 `−nums[i]`：和小了 l 右移，和大了 r 左移。

```python
def threeSum(nums):
    nums.sort()
    n, res = len(nums), []
    for i in range(n - 2):
        if nums[i] > 0:                    # 最小的数都大于 0，后面不可能和为 0
            break
        if i > 0 and nums[i] == nums[i - 1]:   # 去重 1：固定的数不重复
            continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]:   # 去重 2、3：找到一组后跳过相同的
                    l += 1
                while l < r and nums[r] == nums[r - 1]:
                    r -= 1
                l += 1
                r -= 1
    return res
```

**复杂度**：时间 O(n²)，空间 O(log n)（排序）。

## 解法二：去重的三处细节

不用 set 去重，靠排序后跳过相同的值，一共三处：

1. **固定的数**：`nums[i] == nums[i−1]` 时跳过。注意是和**前一个**比，不是和后一个比（和后一个比会漏掉 `[-1, -1, 2]` 这种用到两个相同数的组合）。
2. **找到一组后的 l**：跳过所有和 `nums[l]` 相同的。
3. **找到一组后的 r**：跳过所有和 `nums[r]` 相同的。

只有在**找到一组答案之后**才需要跳过 l、r 的重复值；没找到时普通地移动一格就行。

剪枝：`nums[i] > 0` 时直接结束，后面的数都更大。

## 易错点

- 去重比较写成 `nums[i] == nums[i+1]`：会漏解。
- 找到答案后忘了同时移动 l 和 r：死循环。
- 用 `set(tuple)` 去重也能过，但面试官会追问怎么不用额外空间去重。
