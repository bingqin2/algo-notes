# 18. 四数之和

> [力扣 18](https://leetcode.cn/problems/4sum/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

k 数之和的通用解法：排序后，外面 k − 2 层循环固定前面的数，最内层用双指针。四数之和是两层循环 + 双指针，O(n³)。

## 最优解法

**思路**：在三数之和外面再套一层。两层固定的数都要跳过重复值：第二层的去重条件是 `b > a + 1`（第二层自己的第一个元素不跳过）。

```python
def fourSum(nums, target):
    nums.sort()
    n, res = len(nums), []
    for a in range(n - 3):
        if a > 0 and nums[a] == nums[a - 1]:
            continue
        for b in range(a + 1, n - 2):
            if b > a + 1 and nums[b] == nums[b - 1]:
                continue
            l, r = b + 1, n - 1
            while l < r:
                s = nums[a] + nums[b] + nums[l] + nums[r]
                if s < target:
                    l += 1
                elif s > target:
                    r -= 1
                else:
                    res.append([nums[a], nums[b], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l + 1]:
                        l += 1
                    while l < r and nums[r] == nums[r - 1]:
                        r -= 1
                    l += 1
                    r -= 1
    return res
```

**复杂度**：时间 O(n³)，空间 O(log n)。

## 易错点

- 第二层去重写成 `b > 0`：会把 `nums[b] == nums[a]` 的合法情况（比如 `[2, 2, 2, 2]` 和为 8）跳过。
- 剪枝 `nums[a] > target` 就 break 是**错的**：target 可能是负数（`[-4, -1, 0, 0]`，target = −5），只有当 `nums[a] > 0 且 nums[a] > target` 时才能剪。
- Java 里四个数相加可能溢出 int（元素到 10⁹），要转成 long。
