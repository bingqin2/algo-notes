# 470. 用 Rand7() 实现 Rand10()

> [力扣 470](https://leetcode.cn/problems/implement-rand10-using-rand7/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「用一个随机数生成器构造另一个」：先用多次调用**扩大**出一个均匀的大范围，再**拒绝**多出来的部分，剩下的正好是目标范围的整数倍，取模映射过去。

## 解法一：拒绝采样：(rand7 − 1) × 7 + rand7 得 1..49

**思路**：

1. 两次 rand7 看成一个 7 进制两位数：`(rand7() − 1) × 7 + rand7()`，49 个结果每个概率都是 1/49，均匀。
2. 只要 1..40（40 是 10 的倍数），41..49 拒绝重来。
3. `(x − 1) % 10 + 1` 映射到 1..10，每个数字对应 4 个结果，概率 4/40 = 1/10。

```python
import random

def rand7():
    return random.randint(1, 7)
```

```python
def rand10():
    while True:
        x = (rand7() - 1) * 7 + rand7()    # 均匀的 1..49
        if x <= 40:                        # 只留 40 个，正好 10 的倍数
            return (x - 1) % 10 + 1
```

**期望调用次数**：每轮成功概率 40/49，期望 49/40 轮，每轮 2 次，约 **2.45 次** rand7。

## 解法二：利用被拒绝的结果

**思路**：被拒绝的 41..49 本身也是均匀的 1..9，再调一次 rand7 就得到均匀的 1..63，留 1..60；被拒绝的 61..63 是均匀的 1..3，再调一次得 1..21，留 1..20。只有剩下最后 1 个结果时才从头开始。

```python
def rand10():
    while True:
        a = (rand7() - 1) * 7 + rand7()    # 1..49
        if a <= 40:
            return (a - 1) % 10 + 1
        b = (a - 40 - 1) * 7 + rand7()     # 拒绝的 41..49 是均匀的 1..9，再乘 7：1..63
        if b <= 60:
            return (b - 1) % 10 + 1
        c = (b - 60 - 1) * 7 + rand7()     # 61..63 是 1..3，再乘 7：1..21
        if c <= 20:
            return (c - 1) % 10 + 1
        # 剩下 1 个数，从头再来
```

期望调用次数降到约 **2.19 次**。

## 为什么不能直接 rand7() + rand7()

两个随机数相加**不均匀**：和为 2 只有 (1, 1) 一种，和为 8 有 7 种。必须用「一个当高位、一个当低位」的方式组合，每个结果才只对应一种组合。

## 易错点

- 写成 `rand7() * 7 + rand7()`：范围是 8..56，不是从 1 开始，而且这样就不是连续的。
- 只保留 1..10、拒绝 11..49：也对，但每轮成功概率只有 10/49，期望调用次数变成约 9.8 次。
- 取模写成 `x % 10`：得到 0..9，要再加 1，或者写成 `(x − 1) % 10 + 1`。

## 面试追问

- **反过来，用 rand10 实现 rand7？** 直接调 rand10，大于 7 就拒绝，期望 10/7 次。
- **用 rand5 实现 rand7？** `(rand5() − 1) × 5 + rand5()` 得 1..25，留 1..21。
- **给一个不均匀的硬币（正面概率 p），怎么得到公平硬币？** 抛两次：正反算 0，反正算 1，两次一样就重抛。两种结果概率都是 p(1 − p)。
- **怎么验证一个随机函数是均匀的？** 大量采样，用卡方检验看频率和期望的偏差。本页的代码是用 20 万次采样 + 卡方检验验证的。

// rand7() 由题目提供（LeetCode 模板是 class Solution extends SolBase）
public int rand10() {
    while (true) {
        int x = (rand7() - 1) * 7 + rand7();           // 1..49 均匀
        if (x <= 40) return (x - 1) % 10 + 1;
    }
}
