# 11. 盛最多水的容器

> [力扣 11](https://leetcode.cn/problems/container-with-most-water/) · 近两年面经里出现在：**美团**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

从两端选两条线，面积 = 短板高度 × 宽度。**左右指针从两端往中间收**，每次排除一批不可能更优的组合。

## 解法一：暴力 O(n²)

```python
def maxArea(height):
    n = len(height)
    return max((min(height[i], height[j]) * (j - i)
                for i in range(n) for j in range(i + 1, n)), default=0)
```

**复杂度**：时间 O(n²)，n = 10⁵ 会超时。

## 解法二：左右指针，每次移动较短的一边

**思路**：l = 0，r = n − 1。算完当前面积后，移动较短的那一边。

**为什么移动短板是对的**：设 h[l] < h[r]。以 l 为左边、右边是 l+1..r−1 中任意一条的组合，高度 ≤ h[l]，宽度 < r − l，面积一定比现在小。所以 l 和所有其他线的组合都可以排除，放心把 l 往右移。移动长板就不行：宽度变小，高度还是被短板限制，只会更小，却可能错过更好的组合。

```python
def maxArea(height):
    l, r = 0, len(height) - 1
    best = 0
    while l < r:
        best = max(best, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:          # 移动短板：长板不动、宽度变小，面积只会更小
            l += 1
        else:
            r -= 1
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 移动了长板。
- 两边一样高时移哪边都行：两边都不可能再和对方以外的线组成更大的面积。
- 和 [42. 接雨水](./lc42) 混淆：42 是每个位置能存多少水（求和），这题是只选两条线（求最大）。

## 面试追问

- **怎么证明不会漏掉最优解？** 上面的排除论证：每一步都只排除了「不可能比当前已算过的更大」的组合。也可以画成 n × n 的矩阵，每次移动删掉一整行或一整列。
- **能优化常数吗？** 移动短板时，可以一直跳过比原来的短板还矮的线，它们不可能更优。

## Java 版

```java
public int maxArea(int[] height) {
    int l = 0, r = height.length - 1, best = 0;
    while (l < r) {
        best = Math.max(best, Math.min(height[l], height[r]) * (r - l));
        if (height[l] < height[r]) l++;
        else r--;
    }
    return best;
}
```
