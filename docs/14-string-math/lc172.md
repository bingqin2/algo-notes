# 172. 阶乘后的零

> [力扣 172](https://leetcode.cn/problems/factorial-trailing-zeroes/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

n! 末尾有几个 0：每个 0 来自一对 2 × 5，2 比 5 多，所以就是数 1~n 里**因子 5 的个数**。

## 关键点

- `n/5 + n/25 + n/125 + …`：25 贡献两个 5，所以要再数一遍 25 的倍数，依此类推。
- 不要真去算阶乘。O(log n)。

```python
def trailingZeroes(n):
    cnt = 0
    while n:
        n //= 5                            # 数 5、25、125……的倍数
        cnt += n
    return cnt
```
