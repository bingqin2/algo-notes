# 173. 二叉搜索树迭代器

> [力扣 173](https://leetcode.cn/problems/binary-search-tree-iterator/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

BST 迭代器，next 均摊 O(1)、空间 O(h)：用栈**模拟中序遍历**，栈里只存当前的左链。

## 关键点

- 初始化时把根的左链全部压栈；next 弹出栈顶，再把它右子树的左链压栈。
- 每个结点进出栈一次，所以 next 均摊 O(1)。

```python
class BSTIterator:                         # 173：模拟中序遍历，栈里存左链
    def __init__(self, root):
        self.stack = []
        self._push_left(root)

    def _push_left(self, node):
        while node:
            self.stack.append(node)
            node = node.left

    def next(self):
        node = self.stack.pop()
        self._push_left(node.right)
        return node.val

    def hasNext(self):
        return bool(self.stack)
```
