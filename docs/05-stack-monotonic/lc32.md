# 32. 最长有效括号

> [力扣 32](https://leetcode.cn/problems/longest-valid-parentheses/) · 近两年面经里出现在：**字节 · 华为**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

求**最长**的合法括号**子串**（连续）。三种解法都要会，面试官经常要求先说思路再选一种写。

## 解法一：栈存下标

**思路**：栈里存下标。栈底始终是「最后一个没被匹配的右括号」的下标（一开始放 -1），它是合法子串的左边界。

- 遇到 `(`：下标入栈。
- 遇到 `)`：弹出栈顶。
  - 栈空了：这个 `)` 没人配对，把它的下标压进去作为新的边界。
  - 栈不空：当前合法子串是 (栈顶, i]，长度 `i - 栈顶`。

<StepPlayer src="/viz/lc32.json" />

```python
def longestValidParentheses(s):
    st = [-1]                              # 栈底放「最后一个没匹配的右括号」的下标
    best = 0
    for i, c in enumerate(s):
        if c == '(':
            st.append(i)
        else:
            st.pop()
            if not st:                     # 这个 ) 没人匹配，成为新的分界
                st.append(i)
            else:
                best = max(best, i - st[-1])
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法二：动态规划

**定义**：dp[i] = 以 s[i] **结尾**的最长有效括号长度。只有 s[i] = `)` 时才可能不为 0。

- s[i−1] = `(`，形如 `…()`：dp[i] = dp[i−2] + 2。
- s[i−1] = `)`，形如 `…))`：先跳过 s[i−1] 结尾的那段合法串，看它前面一位 j = i − dp[i−1] − 1。如果 s[j] = `(`，就和 s[i] 配上：dp[i] = dp[i−1] + 2 + dp[j−1]（把 j 前面紧挨着的合法串也接上）。

```python
def longestValidParentheses(s):
    n = len(s)
    dp = [0] * n                           # dp[i]：以 i 结尾的最长有效括号长度
    for i in range(1, n):
        if s[i] != ')':
            continue
        if s[i - 1] == '(':                # ...()
            dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
        else:                              # ...))
            j = i - dp[i - 1] - 1          # 和 s[i] 配对的位置
            if j >= 0 and s[j] == '(':
                dp[i] = dp[i - 1] + 2 + (dp[j - 1] if j >= 1 else 0)
    return max(dp, default=0)
```

**复杂度**：时间 O(n)，空间 O(n)。最容易漏的是最后的 `dp[j-1]`：`"()(())"` 在最后一位要把前面的 `"()"` 接上才是 6。

## 解法三：左右两遍计数 O(1) 空间

**思路**：从左往右扫，`left`、`right` 分别数左、右括号。相等时得到一个合法串；`right > left` 时前面不可能再接上，两个都清零。

只扫一遍会漏掉 `"(()"`：左括号一直比右括号多，`left == right` 永远不成立。所以反过来再扫一遍，规则对称。

```python
def longestValidParentheses(s):
    def scan(chars, open_ch):
        best = left = right = 0
        for c in chars:
            if c == open_ch:
                left += 1
            else:
                right += 1
            if left == right:
                best = max(best, 2 * right)
            elif right > left:             # 关闭的比打开的多，前面的作废
                left = right = 0
        return best
    # 从左往右漏掉 "(()" 这种左括号多的情况，所以再从右往左扫一遍
    return max(scan(s, '('), scan(reversed(s), ')'))
```

**复杂度**：时间 O(n)，空间 O(1)。

## 三种解法对比

| 解法 | 空间 | 关键点 |
|---|---|---|
| 栈存下标 | O(n) | 栈底放 -1 作为边界，栈空时压入当前 `)` |
| 动态规划 | O(n) | 以 i 结尾；`…))` 要找配对位置 j，再接上 dp[j−1] |
| 两遍计数 | O(1) | 右多于左就清零；反向再扫一遍处理左多的情况 |

## 易错点

- 栈解法忘了一开始压 -1：第一个合法串从下标 0 开始时，长度没法算。
- DP 里 j 越界（j < 0）或者 j − 1 越界，都要判断。
- 两遍计数只扫了一遍。

## 面试追问

- **要输出这个子串本身？** 栈解法在更新 best 时记下起点 `栈顶 + 1` 即可。
- **能不能一遍扫描、O(1) 空间？** 两遍计数已经是 O(1) 空间；一遍扫描通常需要栈或 DP。

## Java 版

```java
public int longestValidParentheses(String s) {
    Deque<Integer> st = new ArrayDeque<>();
    st.push(-1);                             // 最后一个没匹配的右括号的下标
    int best = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == '(') {
            st.push(i);
        } else {
            st.pop();
            if (st.isEmpty()) st.push(i);
            else best = Math.max(best, i - st.peek());
        }
    }
    return best;
}
```
