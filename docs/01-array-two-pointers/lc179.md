# 179. 最大数

> [力扣 179](https://leetcode.cn/problems/largest-number/) · 近两年面经里出现在：**字节 ×3**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

把一组数拼成最大（或最小）的数。不能按数值排序（`[10, 2]` 应该是 `"210"`），也不能简单按字典序（`[3, 30]` 应该是 `"330"`，但字典序 `"30" > "3"`）。

**关键**：对两个串 a、b，比较 `a + b` 和 `b + a`，大的那个顺序就是它们应该的顺序。

## 解法一：自定义比较排序

**思路**：都转成字符串，按「a + b > b + a 则 a 在前」排序，再拼起来。全是 0 时结果是 `"000"`，要返回 `"0"`。

```python
from functools import cmp_to_key

def largestNumber(nums):
    strs = list(map(str, nums))

    def cmp(a, b):                         # a 应该排在 b 前面 ⇔ a+b > b+a
        if a + b > b + a:
            return -1
        if a + b < b + a:
            return 1
        return 0

    strs.sort(key=cmp_to_key(cmp))
    res = ''.join(strs)
    return '0' if res[0] == '0' else res   # [0, 0] 要返回 "0"
```

**复杂度**：时间 O(n log n · L)，L 是数字的最大位数（一次比较要拼接 O(L) 的字符串）。空间 O(n · L)。

**为什么这个比较是合法的（传递性）**：把串 a 看成一个数，`a + b` 就是 `a × 10^len(b) + b`。`a + b > b + a` 等价于 `a / (10^len(a) − 1) > b / (10^len(b) − 1)`。每个串对应一个实数，比较的就是这个实数的大小，所以有传递性，排序结果是确定的。面试被问到能说出「等价于比较 a 和 b 无限循环后的大小」就够了。

## 解法二：不用库排序，手写快排

字节有面试官要求不调库，比较规则不变，排序自己写：

```python
def largestNumber(nums):
    a = list(map(str, nums))

    def before(x, y):                      # x 应该排在 y 前面
        return x + y > y + x

    def quick(lo, hi):
        if lo >= hi:
            return
        pivot = a[(lo + hi) // 2]
        i, j = lo, hi
        while i <= j:
            while before(a[i], pivot):
                i += 1
            while before(pivot, a[j]):
                j -= 1
            if i <= j:
                a[i], a[j] = a[j], a[i]
                i += 1
                j -= 1
        quick(lo, j)
        quick(i, hi)

    quick(0, len(a) - 1)
    res = ''.join(a)
    return '0' if res[0] == '0' else res
```

**复杂度**：平均 O(n log n · L)。

## 易错点

- 全 0 的边界：`[0, 0]` 要返回 `"0"`，检查排序后第一个是不是 `"0"` 即可。
- Python 3 的 `sort` 不接受比较函数，要用 `functools.cmp_to_key`。
- Java 的 `Comparator` 要满足一致性，用 `(b + a).compareTo(a + b)` 直接返回，不要只返回 1 和 −1 而不处理相等的情况。

## 面试追问

- **拼成最小的数？** 比较规则反过来，并去掉前导 0（剑指 Offer 45）。
- **删掉 k 位让剩下的最小？** 不是排序，是单调栈，见 [402](../05-stack-monotonic/lc402)。
- **从两个数组里各取数拼成长度 k 的最大数？** 321 题：每个数组用单调栈取最大子序列，再合并。

## Java 版

```java
public String largestNumber(int[] nums) {
    String[] strs = new String[nums.length];
    for (int i = 0; i < nums.length; i++) strs[i] = String.valueOf(nums[i]);
    Arrays.sort(strs, (a, b) -> (b + a).compareTo(a + b));   // a+b 大的排前面
    if (strs[0].equals("0")) return "0";
    return String.join("", strs);
}
```
