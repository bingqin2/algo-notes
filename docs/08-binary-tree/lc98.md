# 98. 验证二叉搜索树

> [力扣 98](https://leetcode.cn/problems/validate-binary-search-tree/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

验证 BST：不能只比较结点和它的左右孩子，要保证**整棵左子树**都小于根。递归时传下**取值范围** `(lo, hi)`，或者利用「中序遍历严格递增」。

## 最优解法

**思路**：根的范围是 (−∞, +∞)；进入左子树时上界变成当前值，进入右子树时下界变成当前值。

```python
def isValidBST(root):
    def check(node, lo, hi):               # node 的值必须在开区间 (lo, hi) 内
        if not node:
            return True
        if not (lo < node.val < hi):
            return False
        return check(node.left, lo, node.val) and check(node.right, node.val, hi)

    return check(root, float("-inf"), float("inf"))
```

**复杂度**：时间 O(n)，空间 O(h)。

**中序遍历写法**：维护上一个访问的值 prev，中序遍历时必须严格大于 prev。

## 易错点

- 只比较父子：`[5, 4, 6, null, null, 3, 7]` 里 3 在 5 的右子树里却比 5 小，检测不出来。
- 等于也不合法：BST 要求严格小于、严格大于（按题目定义）。
- Java 用 `Integer.MIN_VALUE` 当初始边界：结点值本身可能就是它，要用 `Long` 或者传 `null` 表示无界。
