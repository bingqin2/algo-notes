# 188. 买卖股票的最佳时机 IV

> [力扣 188](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

股票最多交易 k 次：[123](./lc123) 推广成两个长度 k + 1 的数组，`buy[j]`、`sell[j]` 表示第 j 次买入后、卖出后的最大收益。

## 关键点

- `buy[j] = max(buy[j], sell[j−1] − p)`，`sell[j] = max(sell[j], buy[j] + p)`。
- k ≥ n / 2 时次数等于不限，直接按 [122](./lc122) 把所有上涨加起来，避免 k 很大时超时。
- O(nk) 时间，O(k) 空间。

```python
def maxProfit(k, prices):
    if not prices or k == 0:
        return 0
    if k >= len(prices) // 2:              # 次数不限，等价于 122
        return sum(max(0, prices[i] - prices[i - 1]) for i in range(1, len(prices)))
    buy = [float("-inf")] * (k + 1)
    sell = [0] * (k + 1)
    for p in prices:
        for j in range(1, k + 1):
            buy[j] = max(buy[j], sell[j - 1] - p)
            sell[j] = max(sell[j], buy[j] + p)
    return sell[k]
```
