# 871. 最低加油次数

> [力扣 871](https://leetcode.cn/problems/minimum-number-of-refueling-stops/) · 近两年面经里出现在：**顺丰笔试**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「路上能拿资源，资源有限，求最少拿几次」：**延迟决策**。路过的时候不急着决定，先把选项存进堆里；真走不动了，再从存着的里面挑最好的。这样做的前提是：之前的选择**事后补选**和当时就选，效果一样。

## 解法一：DP O(n²)

**思路**：`dp[k]` 表示加 k 次油最远能开到哪。依次考虑每个加油站，如果 `dp[k]` 能到这个站，加一次油就能让 `dp[k+1]` 变成 `dp[k] + fuel`。和 0-1 背包一样，k 倒序，保证每个站只用一次。最后找最小的 k 使 `dp[k] ≥ target`。

```python
def minRefuelStops(target, startFuel, stations):
    n = len(stations)
    dp = [startFuel] + [0] * n             # dp[k]：加 k 次油最远能到哪
    for i, (pos, fuel) in enumerate(stations):
        for k in range(i, -1, -1):         # 倒序，每个站只用一次
            if dp[k] >= pos:
                dp[k + 1] = max(dp[k + 1], dp[k] + fuel)
    for k, d in enumerate(dp):
        if d >= target:
            return k
    return -1
```

**复杂度**：时间 O(n²)，空间 O(n)。

## 解法二：大顶堆：路过的加油站先存着，没油了再取最大

**思路**：一直往前开，把能到达的加油站的油量放进大顶堆。开不到终点时，从堆里取油量最多的加上（相当于「当时在那个站加了油」），次数 +1。堆空了还到不了，返回 −1。

为什么贪心是对的：要加 k 次油，选油量最大的 k 个**能到达**的站一定不差。每次没油时，在当前能到的站里补一个最大的，就保证了用最少的次数走得最远。

```python
import heapq

def minRefuelStops(target, startFuel, stations):
    heap = []                              # 路过的加油站的油量（取负，当大顶堆）
    reach, i, stops = startFuel, 0, 0
    while reach < target:
        while i < len(stations) and stations[i][0] <= reach:
            heapq.heappush(heap, -stations[i][1])   # 能到的站先存着，不急着加
            i += 1
        if not heap:
            return -1                      # 到不了下一个站，也没有存着的油
        reach += -heapq.heappop(heap)      # 没油了：补一次，选油最多的
        stops += 1
    return stops
```

**复杂度**：时间 O(n log n)，空间 O(n)。

## 易错点

- 在每个站都决定加不加：这是错误的贪心，没有全局信息。正确做法是先存着。
- 只在刚好到不了下一站时才处理：要处理的是「到不了终点」，所以外层循环条件是 `reach < target`。
- Java 里 reach 用 int：初始油和每站油都可能到 10⁹，累加会溢出，用 long。
- 起点就能到终点时返回 0。

## 面试追问

- **同类题？** [630 课程表 III](https://leetcode.cn/problems/course-schedule-iii/)：按截止时间排序，先选上，超时了就从堆里扔掉最长的课；[1642 可以到达的最远建筑](https://leetcode.cn/problems/furthest-building-you-can-reach/)：梯子留给最高的落差。都是「先选上 / 先存着，不行再反悔」，叫**反悔贪心**。
- **DP 和贪心怎么选？** n 小、或者要输出具体在哪些站加油时 DP 更直观；n 到 10⁵ 用堆。
- **油箱有容量上限？** 贪心不再成立（存着的油不一定加得进去），要用 DP 或按位置做状态。

## Java 版

```java
public int minRefuelStops(int target, int startFuel, int[][] stations) {
    PriorityQueue<Integer> heap = new PriorityQueue<>(Comparator.reverseOrder());
    long reach = startFuel;                            // 油量累加可能超过 int
    int i = 0, stops = 0;
    while (reach < target) {
        while (i < stations.length && stations[i][0] <= reach) heap.offer(stations[i++][1]);
        if (heap.isEmpty()) return -1;
        reach += heap.poll();
        stops++;
    }
    return stops;
}
```
