# 215. 数组中的第K个最大元素

> [力扣 215](https://leetcode.cn/problems/kth-largest-element-in-an-array/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

无序数组里找第 k 大（小）的**一个**数，不需要全部排好序。三种做法对应三种复杂度：排序 O(n log n)、堆 O(n log k)、快速选择平均 O(n)。

## 解法一：排序 O(n log n)

```python
def findKthLargest(nums, k):
    return sorted(nums)[-k]
```

最简单，面试时先说出来作为基线。

## 解法二：大小为 k 的小顶堆 O(n log k)

**思路**：堆里只保留目前最大的 k 个数。新数入堆后如果超过 k 个，弹出最小的。最后堆顶就是这 k 个里最小的，也就是第 k 大。

```python
import heapq

def findKthLargest(nums, k):
    heap = []                              # 小顶堆，保留最大的 k 个
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap[0]                         # 堆顶是这 k 个里最小的，即第 k 大
```

**复杂度**：时间 O(n log k)，空间 O(k)。适合数据流、或者 n 很大而 k 很小的情况。

## 解法三：快速选择 平均 O(n)

**思路**：第 k 大就是升序下标 n − k 的数。用快排的划分：划分后主元落在最终位置，比较它和目标下标，**只去目标所在的一边**继续。主元随机选；用三路划分，大量重复元素时也不会退化。

```python
import random

def findKthLargest(nums, k):
    target = len(nums) - k                 # 第 k 大 = 升序下标 n - k
    lo, hi = 0, len(nums) - 1
    while True:
        p = random.randint(lo, hi)
        pivot = nums[p]
        # 三路划分：[lo, lt) < pivot，[lt, gt] == pivot，(gt, hi] > pivot
        lt, i, gt = lo, lo, hi
        while i <= gt:
            if nums[i] < pivot:
                nums[lt], nums[i] = nums[i], nums[lt]
                lt += 1
                i += 1
            elif nums[i] > pivot:
                nums[i], nums[gt] = nums[gt], nums[i]
                gt -= 1
            else:
                i += 1
        if target < lt:
            hi = lt - 1
        elif target > gt:
            lo = gt + 1
        else:
            return pivot
```

**复杂度**：期望时间 O(n)（n + n/2 + n/4 + …），最坏 O(n²)；空间 O(1)。

## 易错点

- 第 k **大**对应升序下标 `n − k`，不是 `k − 1`。
- 快速选择不随机选主元：有序数组每次只去掉一个元素，退化成 O(n²)，力扣上会超时。
- 两路划分遇到全是相同元素的数组也会退化，用三路划分。
- 堆的写法用了大顶堆、把 n 个数全放进去再弹 k 次：O(n + k log n)，也可以，但不如小顶堆省空间。
