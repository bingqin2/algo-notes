# 496. 下一个更大元素 I

> [力扣 496](https://leetcode.cn/problems/next-greater-element-i/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

求「下一个更大元素」：**单调递减栈**。nums1 是 nums2 的子集，先对 nums2 算出每个值的答案存进哈希表。

## 关键点

- 遍历 nums2，当前值比栈顶大，栈顶的下一个更大元素就是它。
- O(m + n)。

```python
def nextGreaterElement(nums1, nums2):
    nxt, stack = {}, []
    for x in nums2:
        while stack and stack[-1] < x:
            nxt[stack.pop()] = x
        stack.append(x)
    return [nxt.get(x, -1) for x in nums1]
```
