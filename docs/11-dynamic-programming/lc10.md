# 10. 正则表达式匹配

> [力扣 10](https://leetcode.cn/problems/regular-expression-matching/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

`.` 匹配任意字符、`x*` 匹配 0 个或多个 x：二维 DP，`dp[i][j]` 表示 s 的前 i 个和 p 的前 j 个能否匹配。

## 关键点

- p[j−1] 是 `*`：匹配 0 次 `dp[i][j−2]`；或者 s[i−1] 能和 `*` 前面的字符匹配，那就吃掉 s 的一个字符 `dp[i−1][j]`（`*` 还能继续用）。
- 否则：当前字符相同或者是 `.`，看 `dp[i−1][j−1]`。
- 初始化第 0 行：`a*b*` 这类模式可以匹配空串。O(mn)。

```python
def isMatch(s, p):
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]   # dp[i][j]: s[:i] 能否匹配 p[:j]
    dp[0][0] = True
    for j in range(2, n + 1):
        if p[j - 1] == "*":
            dp[0][j] = dp[0][j - 2]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j - 1] == "*":
                # x* 匹配 0 次；或者匹配 1 次以上（s[i-1] 和 x 相同，s 退一个字符）
                dp[i][j] = dp[i][j - 2] or (p[j - 2] in (s[i - 1], ".") and dp[i - 1][j])
            else:
                dp[i][j] = p[j - 1] in (s[i - 1], ".") and dp[i - 1][j - 1]
    return dp[m][n]
```
