# 110. 平衡二叉树

> [力扣 110](https://leetcode.cn/problems/balanced-binary-tree/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断平衡二叉树：后序遍历同时算高度和是否平衡，不平衡时返回 −1 作为标记，避免重复计算高度。

## 关键点

- 自顶向下对每个结点分别求左右高度是 O(n²)（链状树）；自底向上一次遍历 O(n)。

```python
def isBalanced(root):
    def height(node):                      # 不平衡时返回 -1
        if not node:
            return 0
        l, r = height(node.left), height(node.right)
        if l < 0 or r < 0 or abs(l - r) > 1:
            return -1
        return 1 + max(l, r)

    return height(root) >= 0
```
