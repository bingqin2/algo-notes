# 49. 字母异位词分组

> [力扣 49](https://leetcode.cn/problems/group-anagrams/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把「本质相同」的元素分到一组：设计一个**规范化的 key**，key 相同就是同一组。字母异位词的 key 是排序后的字符串，或者 26 个字母的计数。

## 最优解法

**思路**：每个字符串算出 26 位计数的元组作为 key，放进 `defaultdict(list)`。

```python
from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = [0] * 26                     # 用字符计数做 key，O(L)；也可以用 sorted(s)，O(L log L)
        for ch in s:
            key[ord(ch) - 97] += 1
        groups[tuple(key)].append(s)
    return list(groups.values())
```

**复杂度**：时间 O(n · L)（L 是字符串长度），空间 O(n · L)。用 `"".join(sorted(s))` 做 key 是 O(n · L log L)，更好写，面试时两种都可以说。

## 易错点

- Python 的 list 不能当 dict 的 key，要转成 tuple。
- Java 里计数数组做 key 要转成字符串（`Arrays.toString` 或者拼接成 `"#1#0#2…"`），直接用 `int[]` 当 key 比较的是地址。
