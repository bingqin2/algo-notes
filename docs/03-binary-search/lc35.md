# 35. 搜索插入位置

> [力扣 35](https://leetcode.cn/problems/search-insert-position/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序数组找插入位置：就是 lower_bound（第一个 ≥ target 的位置）。

## 关键点

- 区间 [lo, hi)，hi 从 n 开始，这样 target 比所有数都大时返回 n。
- Python 里就是 `bisect.bisect_left(nums, target)`。

```python
def searchInsert(nums, target):
    lo, hi = 0, len(nums)                  # lower_bound
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```
