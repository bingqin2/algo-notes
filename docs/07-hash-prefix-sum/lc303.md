# 303. 区域和检索 - 数组不可变

> [力扣 303](https://leetcode.cn/problems/range-sum-query-immutable/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

多次查询区间和：**前缀和**，`pre[i]` 是前 i 个数的和，区间 [l, r] 的和是 `pre[r+1] − pre[l]`。

## 关键点

- 前缀和数组多开一位，`pre[0] = 0`，避免边界判断。预处理 O(n)，查询 O(1)。
- 数组会被修改时用树状数组或线段树。

```python
class NumArray:                            # 303
    def __init__(self, nums):
        self.pre = [0]
        for x in nums:
            self.pre.append(self.pre[-1] + x)

    def sumRange(self, left, right):
        return self.pre[right + 1] - self.pre[left]
```
