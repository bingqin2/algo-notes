# 202. 快乐数

> [力扣 202](https://leetcode.cn/problems/happy-number/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

快乐数：反复求各位平方和，要么到 1，要么进入循环。**判环**：快慢指针或者哈希集合。

## 关键点

- 和链表判环一样，快指针每次算两步。
- 为什么一定会循环：数字很大时平方和会迅速变小（3 位数的平方和最多 243），最终落在有限的范围里。

```python
def isHappy(n):
    def nxt(x):
        return sum(int(d) ** 2 for d in str(x))

    slow, fast = n, nxt(n)
    while fast != 1 and slow != fast:      # 快慢指针判环
        slow, fast = nxt(slow), nxt(nxt(fast))
    return fast == 1
```
