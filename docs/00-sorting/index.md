# 排序与选择

## 核心框架

快排、归并、堆排序要能手写；第 K 大用快速选择或堆。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [手写快速排序（含三路划分）](./quick-sort) | 美团 · 小红书 · 腾讯 · 帆软 | Lomuto 划分 / Hoare 双指针划分 / 三路划分（大量重复元素） / 随机化选主元 |
| [手写归并排序（含原地归并追问）](./merge-sort) | 腾讯 | 自顶向下递归 / 自底向上迭代 / 逆序对计数（归并的应用） |
| [手写堆排序](./heap-sort) | 腾讯 | 下沉建堆 O(n) / 逐个弹出堆顶 |
| [215. 数组中的第 K 个最大元素](./lc215) | 高频经典 | 排序 O(n log n) / 大小为 k 的小顶堆 O(n log k) / 快速选择 平均 O(n) |
