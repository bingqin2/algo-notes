# 994. 腐烂的橘子

> [力扣 994](https://leetcode.cn/problems/rotting-oranges/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

多个起点**同时**向外扩散，求扩散完的时间：**多源 BFS**。一开始把所有起点都放进队列，然后按层 BFS，层数就是时间。

## 解法一：多个起点同时入队

**思路**：先统计新鲜橘子数，所有腐烂的橘子入队。每一层（一分钟）把队列里当前的橘子都处理掉，感染相邻的新鲜橘子并入队。新鲜橘子数变成 0 就停。最后还有新鲜的返回 −1。

```python
from collections import deque

def orangesRotting(grid):
    m, n = len(grid), len(grid[0])
    q = deque()
    fresh = 0
    for r in range(m):
        for c in range(n):
            if grid[r][c] == 2:
                q.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    while q and fresh:                     # 所有腐烂的橘子同时向外扩散，一层是一分钟
        minutes += 1
        for _ in range(len(q)):
            r, c = q.popleft()
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    q.append((nr, nc))
    return -1 if fresh else minutes
```

**复杂度**：时间 O(mn)，空间 O(mn)。

## 易错点

- 每个腐烂的橘子分别 BFS 再取最小：O((mn)²)，而且写起来更复杂。
- 循环条件只写 `while q`：最后一层感染完后还会再多算一分钟（队列里还有最后一批橘子）。加上 `and fresh`，或者最后结果减一。
- 一开始就没有新鲜橘子：答案是 0，不是 −1。
