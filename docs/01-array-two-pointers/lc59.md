# 59. 螺旋矩阵 II

> [力扣 59](https://leetcode.cn/problems/spiral-matrix-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

按螺旋顺序**填**一个 n × n 矩阵：和 [54](./lc54) 一样维护上下左右四个边界，每走完一条边就收缩对应的边界。

## 最优解法

**思路**：上边从左到右填，top 下移；右边从上到下填，right 左移；下边从右到左填，bottom 上移；左边从下到上填，left 右移。填满 n² 个数停止。

```python
def generateMatrix(n):
    res = [[0] * n for _ in range(n)]
    top, bottom, left, right = 0, n - 1, 0, n - 1
    k = 1
    while k <= n * n:
        for j in range(left, right + 1):
            res[top][j] = k; k += 1
        top += 1
        for i in range(top, bottom + 1):
            res[i][right] = k; k += 1
        right -= 1
        for j in range(right, left - 1, -1):
            res[bottom][j] = k; k += 1
        bottom -= 1
        for i in range(bottom, top - 1, -1):
            res[i][left] = k; k += 1
        left += 1
    return res
```

**复杂度**：时间 O(n²)，空间 O(1)（不算结果）。

## 易错点

- 每条边的范围要用**更新后的**边界，否则角上的格子会被填两次。
- 这题是方阵，循环条件用 `k <= n²` 就够了；[54](./lc54) 是 m × n 的长方形，每走一条边后都要检查边界是否交错，否则单行或单列会重复读。
