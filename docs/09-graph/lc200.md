# 200. 岛屿数量

> [力扣 200](https://leetcode.cn/problems/number-of-islands/) · 近两年面经里出现在：**字节 ×4**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

网格里的**连通块**个数。网格就是一张图：每个格子是点，上下左右相邻的格子之间有边。DFS、BFS、并查集三种都要会，字节近两年考了 4 次，常见追问是「递归太深怎么办」和「陆地会动态增加怎么办」。

## 解法一：DFS 沉岛

**思路**：遍历每个格子，遇到 '1' 就找到了一个新岛，计数加 1，然后从它开始 DFS，把相连的陆地都改成 '0'（「沉岛」），这样同一个岛不会被数两次。

<StepPlayer src="/viz/lc200.json" />

```python
def numIslands(grid):
    m, n = len(grid), len(grid[0])

    def sink(i, j):                        # 把这块陆地连着的都淹掉
        if not (0 <= i < m and 0 <= j < n) or grid[i][j] != '1':
            return
        grid[i][j] = '0'
        sink(i + 1, j)
        sink(i - 1, j)
        sink(i, j + 1)
        sink(i, j - 1)

    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                count += 1
                sink(i, j)
    return count
```

**复杂度**：时间 O(mn)，空间 O(mn)（最坏整个网格都是陆地，递归深度 mn）。

Python 递归默认上限 1000，300 × 300 的全陆地网格会超过。要么 `sys.setrecursionlimit`，要么用 BFS 或显式栈。

## 解法二：BFS

**思路**：同样遇到 '1' 计数，用队列扩展。**入队时就标记**为 '0'，不要等出队时再标记，否则同一个格子会被多个邻居重复入队。

```python
from collections import deque

def numIslands(grid):
    m, n = len(grid), len(grid[0])
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] != '1':
                continue
            count += 1
            grid[i][j] = '0'               # 入队时就标记，避免重复入队
            q = deque([(i, j)])
            while q:
                x, y = q.popleft()
                for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
                    if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == '1':
                        grid[nx][ny] = '0'
                        q.append((nx, ny))
    return count
```

**复杂度**：时间 O(mn)，空间 O(min(m, n))（队列最多是一条对角线那么长）。

## 解法三：并查集

**思路**：先假设每块陆地都是一个独立的岛（count = 陆地数），然后把相邻的陆地合并，每成功合并一次 count 减 1。每个格子只需要看右边和下边，每条边只处理一次。

```python
def numIslands(grid):
    m, n = len(grid), len(grid[0])
    parent = list(range(m * n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # 路径减半
            x = parent[x]
        return x

    count = sum(row.count('1') for row in grid)   # 先假设每块陆地都是一个岛
    for i in range(m):
        for j in range(n):
            if grid[i][j] != '1':
                continue
            for x, y in ((i + 1, j), (i, j + 1)):  # 只看右和下，每条边只合并一次
                if x < m and y < n and grid[x][y] == '1':
                    a, b = find(i * n + j), find(x * n + y)
                    if a != b:
                        parent[a] = b
                        count -= 1         # 两个岛连成一个
    return count
```

**复杂度**：时间 O(mn · α(mn))，α 是反阿克曼函数，可以看作常数。空间 O(mn)。

## 三种解法怎么选

| 解法 | 优点 | 缺点 |
|---|---|---|
| DFS | 代码最短 | 递归深度可能到 mn |
| BFS | 没有栈溢出问题 | 代码稍长 |
| 并查集 | 支持动态加陆地（305 题），不修改原网格 | 代码最长 |

## 易错点

- BFS 出队时才标记：同一个格子被重复入队，最坏变慢很多。
- 修改了输入网格：如果题目不允许，用一个 `visited` 数组。
- 网格是字符 '1'，不是数字 1。

## 面试追问

- **最大岛屿面积？** DFS 返回面积，见 [695](./lc695)。
- **陆地一块块加进来，每次都要岛屿数（305）？** 并查集：加一块陆地 count + 1，和四周已有的陆地合并，每合并一次 count − 1。
- **被水完全包围的区域（130）？** 反过来从边界出发，标记和边界相连的 'O'，见 [130](./lc130)。
- **到最近的陆地 / 腐烂的橘子？** 多源 BFS，见 [994](./lc994)、[1162](./lc1162)。

## Java 版

```java
public int numIslands(char[][] grid) {
    int count = 0;
    for (int i = 0; i < grid.length; i++)
        for (int j = 0; j < grid[0].length; j++)
            if (grid[i][j] == '1') {
                count++;
                sink(grid, i, j);
            }
    return count;
}

private void sink(char[][] g, int i, int j) {
    if (i < 0 || j < 0 || i >= g.length || j >= g[0].length || g[i][j] != '1') return;
    g[i][j] = '0';
    sink(g, i + 1, j);
    sink(g, i - 1, j);
    sink(g, i, j + 1);
    sink(g, i, j - 1);
}
```
