# 239. 滑动窗口最大值

> [力扣 239](https://leetcode.cn/problems/sliding-window-maximum/) · 近两年面经里出现在：**腾讯**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

**固定长度**的窗口滑动，每个位置都要窗口的最大值（或最小值）。窗口每次进一个、出一个，需要一个能快速取最大值、又能删除过期元素的结构。

## 解法一：暴力 O(nk)

```python
def maxSlidingWindow(nums, k):
    return [max(nums[i:i + k]) for i in range(len(nums) - k + 1)]
```

**复杂度**：时间 O(nk)，n、k 都到 10⁵ 时超时。

## 解法二：大顶堆 + 懒删除 O(n log n)

**思路**：堆里存 (值, 下标)。每次取最大值前，检查堆顶的下标是否已经滑出窗口，滑出了就弹掉，直到堆顶在窗口里。不在堆顶的过期元素先不管（懒删除），等它们到堆顶时再删。

Python 的 `heapq` 是小顶堆，存 −值。

```python
import heapq

def maxSlidingWindow(nums, k):
    heap = []                              # 存 (-值, 下标)，堆顶是最大值
    res = []
    for i, x in enumerate(nums):
        heapq.heappush(heap, (-x, i))
        if i >= k - 1:
            while heap[0][1] <= i - k:     # 懒删除：堆顶已经不在窗口里才删
                heapq.heappop(heap)
            res.append(-heap[0][0])
    return res
```

**复杂度**：时间 O(n log n)（堆里最多 n 个元素），空间 O(n)。

## 解法三：单调递减队列 O(n)

**思路**：双端队列存下标，对应的值从队头到队尾**递减**。

- 新元素 x 入队前，把队尾所有 ≤ x 的弹出：它们比 x 早离开窗口、又不比 x 大，以后**永远不可能**是最大值。
- 队头下标滑出窗口就弹出。
- 队头就是当前窗口的最大值。

```python
from collections import deque

def maxSlidingWindow(nums, k):
    q = deque()                            # 存下标，对应的值从队头到队尾递减
    res = []
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:      # 比 x 小的永远不会再是最大值
            q.pop()
        q.append(i)
        if q[0] <= i - k:                  # 队头滑出窗口
            q.popleft()
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

**复杂度**：时间 O(n)：每个下标最多入队、出队一次。空间 O(k)。

## 易错点

- 队列里存值而不是下标：没法判断是否滑出窗口。
- 判断过期写成 `q[0] < i − k`：窗口是 [i − k + 1, i]，下标 ≤ i − k 的都过期了。
- 队尾弹出用 `<` 还是 `<=`：两种都对。`<=` 让队列更短。
- 前 k − 1 个位置还没形成完整窗口，不要记录答案。

## 面试追问

- **单调队列和单调栈的区别？** 单调栈只在一端进出，找「下一个更大」（[739](../05-stack-monotonic/lc739)）；单调队列两端都能出，队头处理过期元素，用于窗口最值。
- **同时要最大值和最小值？** 开两个单调队列，一个递减一个递增。
- **最大值减最小值 ≤ limit 的最长子数组（1438）？** 可变长窗口 + 两个单调队列。
- **用单调队列优化 DP？** dp[i] = max(dp[j]) + nums[i]，j 在 [i − k, i − 1] 里：就是滑动窗口最大值，比如跳跃游戏 VI（1696）。

## Java 版

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> q = new ArrayDeque<>();            // 下标，对应的值递减
    for (int i = 0; i < n; i++) {
        while (!q.isEmpty() && nums[q.peekLast()] <= nums[i]) q.pollLast();
        q.offerLast(i);
        if (q.peekFirst() <= i - k) q.pollFirst();
        if (i >= k - 1) res[i - k + 1] = nums[q.peekFirst()];
    }
    return res;
}
```
