# 238. 除了自身以外数组的乘积

> [力扣 238](https://leetcode.cn/problems/product-of-array-except-self/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每个位置要「除自己以外所有数」的乘积，不能用除法：**前缀积 × 后缀积**。

## 最优解法

**思路**：第一遍从左往右，`res[i]` 存 i 左边所有数的乘积；第二遍从右往左，用一个变量 `right` 记录 i 右边所有数的乘积，乘进 `res[i]`。

```python
def productExceptSelf(nums):
    n = len(nums)
    res = [1] * n
    for i in range(1, n):                  # res[i] 先存左边所有数的乘积
        res[i] = res[i - 1] * nums[i - 1]
    right = 1
    for i in range(n - 1, -1, -1):         # 再乘上右边所有数的乘积
        res[i] *= right
        right *= nums[i]
    return res
```

**复杂度**：时间 O(n)，空间 O(1)（输出数组不算）。

## 易错点

- 用除法：有 0 时出错，而且题目禁止。
- 第二遍先乘 `right` 再更新 `right *= nums[i]`，顺序反了就把自己乘进去了。
