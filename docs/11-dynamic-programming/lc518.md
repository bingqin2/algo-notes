# 518. 零钱兑换 II

> [力扣 518](https://leetcode.cn/problems/coin-change-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

凑出金额的**组合数**，每种硬币无限个：**完全背包计数**。关键是循环顺序：外层硬币、内层金额得到组合数（不计顺序）；外层金额、内层硬币得到排列数。

## 最优解法

**思路**：`dp[j]` 是凑出 j 的组合数，`dp[0] = 1`。每种硬币可以用多次，内层**正序**。

```python
def change(amount, coins):
    dp = [0] * (amount + 1)                # dp[j]：凑出 j 的组合数
    dp[0] = 1
    for c in coins:                        # 外层硬币、内层金额：求组合（不计顺序）
        for j in range(c, amount + 1):     # 完全背包：正序
            dp[j] += dp[j - c]
    return dp[amount]
```

**复杂度**：时间 O(n · amount)，空间 O(amount)。

## 易错点

- 循环顺序反了：外层金额、内层硬币时，`1 + 2` 和 `2 + 1` 会被当成两种，算出来的是排列数（那是 [377. 组合总和 Ⅳ](https://leetcode.cn/problems/combination-sum-iv/)）。
- 内层倒序：变成 0-1 背包，每种硬币只能用一次。
