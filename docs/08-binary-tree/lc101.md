# 101. 对称二叉树

> [力扣 101](https://leetcode.cn/problems/symmetric-tree/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断树是否轴对称：比较左子树和右子树是否**互为镜像**：外侧和外侧比、内侧和内侧比。

## 关键点

- `mirror(a, b)`：值相等，且 `a.left` 和 `b.right` 镜像、`a.right` 和 `b.left` 镜像。
- 迭代写法：队列里成对放入要比较的两个结点。

```python
def isSymmetric(root):
    def mirror(a, b):                      # a 和 b 是否互为镜像
        if not a or not b:
            return a is b
        return a.val == b.val and mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right) if root else True
```
