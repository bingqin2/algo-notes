# 37. 解数独

> [力扣 37](https://leetcode.cn/problems/sudoku-solver/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

填满数独（保证有唯一解）：回溯。先记录每行、每列、每宫已经用了哪些数，依次给空格试 1~9。

## 关键点

- 判断冲突用 27 个集合（或位掩码）O(1) 查询，不要每次扫一整行。
- `dfs` 返回 True 表示已经填完，一路直接返回，不再撤销。
- 优化：每次先填**候选数最少**的空格（MRV），能大幅减少搜索量。

```python
def solveSudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    empty = []
    for i in range(9):
        for j in range(9):
            if board[i][j] == ".":
                empty.append((i, j))
            else:
                d = board[i][j]
                rows[i].add(d); cols[j].add(d); boxes[i // 3 * 3 + j // 3].add(d)

    def dfs(k):
        if k == len(empty):
            return True
        i, j = empty[k]
        b = i // 3 * 3 + j // 3
        for d in "123456789":
            if d in rows[i] or d in cols[j] or d in boxes[b]:
                continue
            board[i][j] = d
            rows[i].add(d); cols[j].add(d); boxes[b].add(d)
            if dfs(k + 1):
                return True                # 找到一个解就一路返回
            rows[i].remove(d); cols[j].remove(d); boxes[b].remove(d)
        board[i][j] = "."
        return False

    dfs(0)
```
