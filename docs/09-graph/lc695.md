# 695. 岛屿的最大面积

> [力扣 695](https://leetcode.cn/problems/max-area-of-island/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

网格里的连通块计数或求面积：DFS / BFS 沉岛，和 [200](./lc200) 是同一个模板，只是把「计数」换成「求每块的大小，取最大」。

## 最优解法

**思路**：遍历每个格子，是 1 就从它开始 DFS，把访问过的置 0（沉岛），返回这一块的格子数。

```python
def maxAreaOfIsland(grid):
    m, n = len(grid), len(grid[0])

    def area(r, c):
        if not (0 <= r < m and 0 <= c < n) or grid[r][c] != 1:
            return 0
        grid[r][c] = 0                     # 沉岛，标记已访问
        return 1 + area(r + 1, c) + area(r - 1, c) + area(r, c + 1) + area(r, c - 1)

    return max((area(r, c) for r in range(m) for c in range(n)), default=0)
```

**复杂度**：时间 O(mn)，空间 O(mn)（递归栈）。

## 易错点

- 先递归再置 0：同一个格子会被重复计数，甚至无限递归。必须进入时立刻标记。
- 不想修改输入时用 visited 集合。
