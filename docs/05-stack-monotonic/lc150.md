# 150. 逆波兰表达式求值

> [力扣 150](https://leetcode.cn/problems/evaluate-reverse-polish-notation/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

后缀表达式（逆波兰）求值：遇到数字压栈，遇到运算符弹出两个数计算后压回。不需要考虑优先级和括号，这正是后缀表达式的优点。

## 最优解法

```python
def evalRPN(tokens):
    stack = []
    for t in tokens:
        if t in "+-*/":
            b, a = stack.pop(), stack.pop()     # 先弹出的是右操作数
            if t == "+":
                stack.append(a + b)
            elif t == "-":
                stack.append(a - b)
            elif t == "*":
                stack.append(a * b)
            else:
                stack.append(int(a / b))   # 向零取整，不能用 //
        else:
            stack.append(int(t))
    return stack[0]
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 弹出的顺序：先弹出的是**右**操作数，`a − b` 和 `a / b` 不能写反。
- 除法要**向零取整**：Python 的 `//` 是向下取整，`-7 // 2 = -4`，题目要 −3，用 `int(a / b)`。Java 的 `/` 本身就是向零取整。
- 判断是不是运算符时，`"-3"` 这样的负数也以 `-` 开头，要整个 token 比较，不能只看第一个字符。
