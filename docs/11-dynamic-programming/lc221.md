# 221. 最大正方形

> [力扣 221](https://leetcode.cn/problems/maximal-square/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

求全为 1 的最大正方形：`dp[i][j]` 表示**以 (i, j) 为右下角**的最大正方形边长，它受左边、上边、左上三个方向的限制，取三者最小值 + 1。

## 最优解法

**思路**：`matrix[i][j] == '1'` 时，`dp[i][j] = min(上, 左, 左上) + 1`。为什么是最小值：三个方向中最短的那个决定了能扩展到多大。多开一行一列省去边界判断。

```python
def maximalSquare(matrix):
    m, n = len(matrix), len(matrix[0])
    dp = [[0] * (n + 1) for _ in range(m + 1)]   # dp[i][j]：以 (i-1, j-1) 为右下角的最大正方形边长
    best = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if matrix[i - 1][j - 1] == "1":
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
                best = max(best, dp[i][j])
    return best * best
```

**复杂度**：时间 O(mn)，空间 O(mn)，可以压缩到 O(n)。

## 易错点

- 矩阵里的元素是**字符** `'1'`，不是整数 1。
- 返回的是**面积**（边长的平方）。
