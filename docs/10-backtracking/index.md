# 回溯

## 核心框架

回溯 = 在决策树上 DFS：做选择 → 递归 → 撤销选择。排列用 used 数组，组合/子集用 start 下标。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| [78. 子集](./lc78) | 高频经典 | 回溯 / 二进制枚举 |
