# 494. 目标和

> [力扣 494](https://leetcode.cn/problems/target-sum/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

给每个数加正号或负号，求和为 target 的方案数：设加正号的数之和为 p，则 `p − (total − p) = target`，`p = (total + target) / 2`。转化成**选出和为 p 的方案数**，0-1 背包计数。

## 最优解法

**思路**：`total + target` 是奇数或者 `|target| > total` 时没有方案。`dp[j]` 是凑出 j 的方案数，`dp[0] = 1`，每个数倒序更新 `dp[j] += dp[j − x]`。

```python
def findTargetSumWays(nums, target):
    total = sum(nums)
    # 加正号的和为 p，则 p - (total - p) = target，p = (total + target) / 2
    if abs(target) > total or (total + target) % 2:
        return 0
    p = (total + target) // 2
    dp = [0] * (p + 1)                     # dp[j]：选出和为 j 的方案数
    dp[0] = 1
    for x in nums:
        for j in range(p, x - 1, -1):
            dp[j] += dp[j - x]
    return dp[p]
```

**复杂度**：时间 O(n · p)，空间 O(p)。

## 易错点

- 没检查 `|target| > total`：p 可能为负数，数组下标出错。
- 数组里有 0：0 加正号和负号是两种方案，背包写法自然会算两次（`dp[j] += dp[j − 0]` 让方案数翻倍），正确。
- 回溯暴力是 O(2ⁿ)，n = 20 时也能过，但面试官想听背包的转化。
