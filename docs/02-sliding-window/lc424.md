# 424. 替换后的最长重复字符

> [力扣 424](https://leetcode.cn/problems/longest-repeating-character-replacement/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

「最多替换 k 个字符，求最长的全相同子串」：窗口合法的条件是 `窗口长度 − 窗口里最多的那个字符的个数 ≤ k`（其他字符都要被替换）。

## 最优解法

**思路**：用计数数组记录窗口内每个字符的个数，`max_cnt` 记录**历史上**窗口里出现过的最大计数。窗口不合法时整体右移一格（左右各移一格），长度不变。

为什么 `max_cnt` 不用在收缩时更新：答案只在 `max_cnt` 变大时才可能变大（长度 ≤ max_cnt + k）。max_cnt 偏大（过时）时，窗口只是平移、不会变长，所以不会得到错误的更大答案。

```python
def characterReplacement(s, k):
    cnt = [0] * 26
    left = max_cnt = 0
    for right, ch in enumerate(s):
        cnt[ord(ch) - 65] += 1
        max_cnt = max(max_cnt, cnt[ord(ch) - 65])
        if right - left + 1 - max_cnt > k:   # 要替换的字符超过 k，窗口整体右移一格
            cnt[ord(s[left]) - 65] -= 1
            left += 1
    return len(s) - left
```

**复杂度**：时间 O(n)，空间 O(26)。

## 易错点

- 用 `if` 不用 `while` 收缩：这里是故意的「只增不减」窗口（每次最多移一格），所以最终答案是 `n − left`。如果习惯写 while 收缩的版本，就要每次重新算真实的最大计数（`max(cnt)`，O(26)），然后用 `right − left + 1` 更新答案。
- 字符是大写字母，下标用 `ord(ch) − ord('A')`。
