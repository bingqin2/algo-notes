# 279. 完全平方数

> [力扣 279](https://leetcode.cn/problems/perfect-squares/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

用最少的「物品」凑出一个数，物品可以重复用：**完全背包求最小个数**，和 [322. 零钱兑换](./lc322) 是同一题，物品是 1, 4, 9, 16……

## 最优解法

**思路**：`dp[i] = min(dp[i − j²] + 1)`，j² ≤ i。

```python
def numSquares(n):
    dp = [0] + [float("inf")] * n          # dp[i]：和为 i 最少需要几个完全平方数
    for i in range(1, n + 1):
        j = 1
        while j * j <= i:
            dp[i] = min(dp[i], dp[i - j * j] + 1)   # 完全背包：最后一个选 j²
            j += 1
    return dp[n]
```

**复杂度**：时间 O(n√n)，空间 O(n)。

**数学解法**：四平方和定理：任何正整数都能表示成最多 4 个平方数之和；只有形如 `4^a · (8b + 7)` 的数需要 4 个。判断是 1 个（本身是平方数）、2 个（枚举一个平方数看剩下的是不是平方数）、4 个（满足上面的形式），否则 3 个。O(√n)。

**BFS**：从 n 出发，每次减去一个平方数，第一次到达 0 时的层数就是答案。

## 易错点

- dp 初值用无穷大，`dp[0] = 0`。
- Python 里 O(n√n) 在 n = 10⁴ 时大约 100 万次，能过；Java 更快。
