# 64. 最小路径和

> [力扣 64](https://leetcode.cn/problems/minimum-path-sum/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

网格路径，只能向右或向下，求最小路径和：`dp[i][j] = min(上, 左) + grid[i][j]`。只依赖上一行和当前行左边，可以压缩成一维。

## 最优解法

**思路**：一维数组 `dp[j+1]` 在更新前是「上方」的值，`dp[j]` 是刚更新过的「左方」的值。`dp[0]` 设为无穷大当作左边界；第一行之前，让 `dp[1] = 0`，这样 (0, 0) 处 `min(0, ∞) + grid[0][0]` 正好等于 `grid[0][0]`。

```python
def minPathSum(grid):
    m, n = len(grid), len(grid[0])
    dp = [float("inf")] * (n + 1)
    dp[1] = 0                              # 让 (0, 0) 的「上方」为 0
    for i in range(m):
        for j in range(n):
            dp[j + 1] = min(dp[j + 1], dp[j]) + grid[i][j]   # 上方、左方取小
    return dp[n]
```

**复杂度**：时间 O(mn)，空间 O(n)。

## 易错点

- 第一行和第一列只有一个方向能来，边界处理是最容易错的地方；用多一格的数组 + 无穷大哨兵可以统一处理。
- 可以直接在 grid 上原地修改，空间 O(1)，但会改坏输入。
