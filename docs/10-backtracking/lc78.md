# 78. 子集

> [力扣 78](https://leetcode.cn/problems/subsets/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

求所有子集：回溯时**每个结点**都是一个答案（不只是叶子）；或者用 n 位二进制数枚举，每一位表示选不选。

## 解法一：回溯

**思路**：进入递归就记录当前 path（每个结点都是一个子集），然后从 start 开始依次尝试加入后面的数。start 保证只往后选，不会出现 `[1, 2]` 和 `[2, 1]` 两次。

<StepPlayer src="/viz/lc78.json" />

```python
def subsets(nums):
    res, path = [], []

    def backtrack(start):
        res.append(path[:])                # 每个结点都是一个子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return res
```

**复杂度**：时间 O(n · 2ⁿ)，空间 O(n)（递归栈）。

## 解法二：二进制枚举

**思路**：n 个元素的子集和 0 到 2ⁿ − 1 的二进制数一一对应：第 i 位是 1 就选 `nums[i]`。

```python
def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1] for mask in range(1 << n)]
```

**复杂度**：时间 O(n · 2ⁿ)，空间 O(1)（不算结果）。

## 易错点

- 只在叶子（`start == n`）记录：会漏掉中间的子集。另一种写法是「选 / 不选」二叉递归，只在叶子记录，也对。
- 有重复元素时见 [90](./lc90)。
