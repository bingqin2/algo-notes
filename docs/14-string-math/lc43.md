# 43. 字符串相乘

> [力扣 43](https://leetcode.cn/problems/multiply-strings/) · 中等 · 来源：面经 · 近两年面经：**腾讯微信读书 · 字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

两个很大的数用字符串表示，求乘积，不能直接转整数。模拟竖式乘法。关键观察：`a[i] × b[j]` 的结果只会落在结果的第 `i + j` 和 `i + j + 1` 位。

## 解法一：竖式：每一位乘完再做大数加法

**思路**：和手算一样，b 的每一位分别乘 a，得到一行，末尾补 k 个 0（错位），再用 [415](./lc415) 的字符串加法累加起来。

```python
def add_strings(a, b):
    i, j, carry = len(a) - 1, len(b) - 1, 0
    res = []
    while i >= 0 or j >= 0 or carry:
        x = ord(a[i]) - 48 if i >= 0 else 0
        y = ord(b[j]) - 48 if j >= 0 else 0
        s = x + y + carry
        res.append(chr(s % 10 + 48))
        carry = s // 10
        i -= 1
        j -= 1
    return "".join(reversed(res))
```

```python
def multiply(a, b):
    if a == "0" or b == "0":
        return "0"
    res = "0"
    for k, d in enumerate(reversed(b)):    # b 的每一位乘 a，错位后累加
        row, carry = [], 0
        for c in reversed(a):
            p = (ord(c) - 48) * (ord(d) - 48) + carry
            row.append(chr(p % 10 + 48))
            carry = p // 10
        if carry:
            row.append(chr(carry + 48))
        res = add_strings(res, "".join(reversed(row)) + "0" * k)
    return res
```

**复杂度**：时间 O(n × (m + n))：n 行，每行加法 O(m + n)。还会产生很多临时字符串。

## 解法二：结果数组 i + j 位累加

**思路**：长度为 m 和 n 的两个数相乘，结果最多 m + n 位，开一个 `pos[m + n]`。

- `a[i] × b[j]`（下标从左数）的个位落在 `pos[i + j + 1]`，进位加到 `pos[i + j]`。
- 从右往左算，每次把乘积加上 `pos[i + j + 1]` 原来的值，再拆成个位和进位。
- 最后去掉前导 0。

```python
def multiply(a, b):
    if a == "0" or b == "0":
        return "0"
    m, n = len(a), len(b)
    pos = [0] * (m + n)                    # 结果最多 m + n 位
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            p = (ord(a[i]) - 48) * (ord(b[j]) - 48) + pos[i + j + 1]
            pos[i + j + 1] = p % 10        # a[i] * b[j] 落在 i+j 和 i+j+1 两位
            pos[i + j] += p // 10
    s = "".join(map(str, pos)).lstrip("0")
    return s
```

**复杂度**：时间 O(mn)，空间 O(m + n)。

## 易错点

- 有一个是 "0" 时要直接返回 "0"，否则去前导 0 后得到空串。
- `pos[i + j]` 可能暂时 ≥ 10：没关系，它在之后算 `i + j − 1` 那一位时会被当成「原来的值」再拆开。最终只有 pos[0] 不会被再拆，但它不会超过 9（乘积最多 m + n 位）。
- 下标搞反：从左数的下标 i、j 对应结果的 i + j + 1，因为结果比 i + j 多一位。

## 面试追问

- **更快的乘法？** Karatsuba：把每个数劈成两半，用 3 次乘法代替 4 次，O(n^1.585)。更大的数用 FFT / NTT，O(n log n)。Java `BigInteger` 在位数大时会切换到 Karatsuba 和 Toom-Cook。
- **大数除法？** 模拟长除法：从高位开始，每一位用试商（减法或二分）得到商的这一位。
- **为什么结果最多 m + n 位？** a < 10^m，b < 10^n，所以 a × b < 10^(m+n)。

## Java 版

```java
public String multiply(String a, String b) {
    if (a.equals("0") || b.equals("0")) return "0";
    int m = a.length(), n = b.length();
    int[] pos = new int[m + n];
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            int p = (a.charAt(i) - '0') * (b.charAt(j) - '0') + pos[i + j + 1];
            pos[i + j + 1] = p % 10;
            pos[i + j] += p / 10;
        }
    }
    StringBuilder sb = new StringBuilder();
    for (int d : pos) if (sb.length() > 0 || d != 0) sb.append(d);
    return sb.toString();
}
```
