# 17. 电话号码的字母组合

> [力扣 17](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每一位有若干种选择，求所有组合：回溯，递归深度是数字个数，每层遍历这个数字对应的字母。

## 最优解法

```python
def letterCombinations(digits):
    if not digits:
        return []
    letters = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",
               "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}
    res, path = [], []

    def backtrack(i):
        if i == len(digits):
            res.append("".join(path))
            return
        for ch in letters[digits[i]]:
            path.append(ch)
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return res
```

**复杂度**：时间 O(4ⁿ · n)（每个结果长度 n），空间 O(n)（递归栈）。

## 易错点

- 输入为空字符串时返回 `[]`，不是 `[""]`。
- 7 和 9 对应 4 个字母。

**迭代写法**：结果列表从 `[""]` 开始，每读一个数字，把每个已有结果分别接上这个数字的每个字母。
