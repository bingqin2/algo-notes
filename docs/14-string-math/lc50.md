# 50. Pow(x, n)

> [力扣 50](https://leetcode.cn/problems/powx-n/) · 近两年面经里出现在：**腾讯 ×2**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

求 x^n、n 很大，或者求 a^b mod m：**快速幂**。思路是 x^n = (x^(n/2))²，每次指数减半，O(log n)。矩阵快速幂（斐波那契 O(log n)）也是同一个模板。

## 解法一：递归二分

**思路**：x^n = (x^(n/2))²，n 是奇数时再乘一个 x。n < 0 时算 1 / x^(−n)。

**关键**：`half` 只算一次。写成 `pow(x, n/2) * pow(x, n/2)` 会变成 T(n) = 2T(n/2) + O(1)，又是 O(n)。

```python
def myPow(x, n):
    if n < 0:
        return 1 / myPow(x, -n)
    if n == 0:
        return 1.0
    half = myPow(x, n // 2)              # 只算一次，不要写成 pow(x, n//2) * pow(x, n//2)
    return half * half if n % 2 == 0 else half * half * x
```

**复杂度**：时间 O(log n)，空间 O(log n) 递归栈。

## 解法二：迭代按二进制位

**思路**：把 n 写成二进制，比如 13 = 1101₂，那么 x^13 = x^8 × x^4 × x^1。从低位到高位扫 n 的每一位，x 依次自乘得到 x¹、x²、x⁴、x⁸……这一位是 1 就乘进结果。

```python
def myPow(x, n):
    if n < 0:
        x, n = 1 / x, -n
    res = 1.0
    while n:
        if n & 1:                          # 这一位是 1，乘上当前的 x^(2^k)
            res *= x
        x *= x
        n >>= 1
    return res
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 变体：取模快速幂

整数版，每次乘完取模防止溢出。密码学（RSA）、组合数取模（费马小定理求逆元：a^(p−2) mod p）都要用。

```python
def pow_mod(a, b, m):
    res, a = 1 % m, a % m
    while b:
        if b & 1:
            res = res * a % m
        a = a * a % m
        b >>= 1
    return res
```

## 易错点

- **n = −2³¹**：Java 里 `-n` 还是 −2³¹（int 溢出），要先转成 long 再取反。Python 没有这个问题。
- 递归里调两次自己，退化成 O(n)。
- 取模版本里 `res` 初值写 1：m = 1 时答案应该是 0，写成 `1 % m`。
- 取模版本 Java 里 `a * a` 可能溢出 long：m 接近 10⁹ 时 a < 10⁹，乘积 < 10¹⁸，long 能放下；m 更大要用 `Math.multiplyHigh` 或 BigInteger。

## 面试追问

- **x = 0、n < 0？** 1 / 0，题目保证不会出现；实际写代码要抛异常。
- **斐波那契数列 O(log n)？** [[F(n+1), F(n)], [F(n), F(n−1)]] = [[1, 1], [1, 0]]^n，用矩阵快速幂，每次乘法是 2 × 2 矩阵相乘。
- **为什么是 O(log n)？** 循环次数是 n 的二进制位数，⌊log₂ n⌋ + 1。
- **浮点数精度？** 每次乘法都会有误差，log n 次乘法的误差比 n 次累乘小。

## Java 版

```java
public double myPow(double x, int n) {
    long e = n;                                        // -2^31 取反会溢出 int
    if (e < 0) { x = 1 / x; e = -e; }
    double res = 1;
    while (e > 0) {
        if ((e & 1) == 1) res *= x;
        x *= x;
        e >>= 1;
    }
    return res;
}
```
