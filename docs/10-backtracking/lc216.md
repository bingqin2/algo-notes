# 216. 组合总和 III

> [力扣 216](https://leetcode.cn/problems/combination-sum-iii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

从 1–9 里选 k 个**不重复**的数，和为 n：组合型回溯，`start` 保证不重复、不回头；和超了就剪枝。

## 最优解法

**思路**：path 长度到 k 时检查剩余和是否为 0。数字从小到大试，`x > remain` 时后面的更大，直接 break。

```python
def combinationSum3(k, n):
    res, path = [], []

    def backtrack(start, remain):
        if len(path) == k:
            if remain == 0:
                res.append(path[:])
            return
        for x in range(start, 10):
            if x > remain:                 # 后面的数更大，剪枝
                break
            path.append(x)
            backtrack(x + 1, remain - x)
            path.pop()

    backtrack(1, n)
    return res
```

**复杂度**：时间 O(C(9, k) · k)，空间 O(k)。

## 易错点

- 长度到 k 但和不对时也要 return，否则会继续往下选。
- 剪枝用 break 而不是 continue：数字有序，当前的太大，后面的更大。
