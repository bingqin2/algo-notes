# 224. 基本计算器

> [力扣 224](https://leetcode.cn/problems/basic-calculator/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

表达式求值，带括号。224 只有 `+ - ( )`，`-` 可以是一元负号（`-(2+3)`）。字节面试经常在这题上追问「加上乘除怎么办」（[227](https://leetcode.cn/problems/basic-calculator-ii/)、[772](https://leetcode.cn/problems/basic-calculator-iii/)），所以三种都放在这里。

## 解法一：栈存符号 + 遇括号压栈

**思路**：用 `res` 记当前这一层的结果，`sign` 记下一个数的符号。

- 遇到 `(`：把外层的 `(res, sign)` 压栈，括号里从 0 开始算。
- 遇到 `)`：括号里的结果算完了，弹出外层状态，`res = 外层 res + 外层 sign × 括号结果`。

一元负号不用特殊处理：`-(2+3)` 开头的 `-` 让 sign = −1，括号整体乘上 −1。

<StepPlayer src="/viz/lc224.json" />

```python
def calculate(s):
    st = []                                # 存遇到 ( 之前的 (res, sign)
    res, num, sign = 0, 0, 1
    for c in s:
        if c.isdigit():
            num = num * 10 + int(c)
        elif c in '+-':
            res += sign * num
            num, sign = 0, (1 if c == '+' else -1)
        elif c == '(':
            st.append((res, sign))
            res, sign = 0, 1               # 括号里从头算
        elif c == ')':
            res += sign * num
            num = 0
            prev, psign = st.pop()
            res = prev + psign * res       # 整个括号当成一个数，接回外层
    return res + sign * num
```

**复杂度**：时间 O(n)，空间 O(括号层数)。

## 解法二：递归下降解析

**思路**：`expr()` 算到 `)` 或字符串结尾就返回；遇到 `(` 就递归调用自己算括号里的值。代码结构和语法一一对应，是解析器的写法。

```python
def calculate(s):
    i = 0

    def expr():                            # 计算到 ) 或字符串结尾
        nonlocal i
        res, sign = 0, 1
        while i < len(s):
            c = s[i]
            if c.isdigit():
                num = 0
                while i < len(s) and s[i].isdigit():
                    num = num * 10 + int(s[i])
                    i += 1
                res += sign * num
                continue
            i += 1
            if c == '+':
                sign = 1
            elif c == '-':
                sign = -1
            elif c == '(':
                res += sign * expr()       # 递归算括号里的值，返回时已经跳过 )
            elif c == ')':
                return res
        return res

    return expr()
```

**复杂度**：时间 O(n)，空间 O(括号层数)（递归栈）。

## 解法三：加上乘除（227 / 772）

**思路**：栈里存的是「最终要相加的项」。读到一个数时，根据它**前面**的运算符处理：

- `+`：压入 num；`-`：压入 −num；
- `*` / `/`：和栈顶算完再压回去，这样乘除就先算了。

括号用递归：遇到 `(` 递归算出括号的值，当成一个普通的数。

```python
def calculate(s):                          # + - * / 和括号都支持（772 题）
    i = 0

    def helper():
        nonlocal i
        st, num, op = [], 0, '+'           # op 是 num 前面的运算符
        while i < len(s):
            c = s[i]
            i += 1
            if c.isdigit():
                num = num * 10 + int(c)
            elif c == '(':
                num = helper()             # 括号整体当成一个数
            if c in '+-*/)' or i == len(s):
                if op == '+':
                    st.append(num)
                elif op == '-':
                    st.append(-num)
                elif op == '*':
                    st.append(st.pop() * num)
                else:
                    st.append(int(st.pop() / num))   # 向零取整
                if c == ')':
                    break
                op, num = c, 0
        return sum(st)                     # 乘除已经算完，栈里只剩要相加的项

    return helper()
```

**复杂度**：时间 O(n)，空间 O(n)。

Python 的 `//` 是向下取整，`-3 // 2 = -2`；题目要求向零取整，所以用 `int(a / b)`。数很大时浮点会有精度问题，可以换成 `abs(a) // abs(b)` 再补符号。

## 易错点

- 多位数：`num = num * 10 + 数字`，不能读一位就加。
- 遇到 `)` 和字符串结尾时，都要把最后一个 num 加进去。
- 解法三里，处理运算符的条件要包括「到了字符串结尾」，否则最后一个数会漏。
- 空格要跳过，但不能把它当成数字结束的唯一标志。

## 面试追问

- **怎么处理运算符优先级更通用？** 双栈（数字栈 + 运算符栈）：遇到运算符时，把栈顶优先级 ≥ 它的运算符先算掉再入栈；这就是调度场算法。
- **先转成逆波兰表达式再算？** 也是调度场算法的输出，求值见 [150](./lc150)。
- **有非法输入（括号不匹配、除以 0）？** 解析时检查栈状态，或在递归下降里遇到意外字符抛异常。

## Java 版

```java
public int calculate(String s) {
    Deque<int[]> st = new ArrayDeque<>();    // {括号前的 res, 括号前的符号}
    int res = 0, num = 0, sign = 1;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '+' || c == '-') {
            res += sign * num;
            num = 0;
            sign = c == '+' ? 1 : -1;
        } else if (c == '(') {
            st.push(new int[]{res, sign});
            res = 0;
            sign = 1;
        } else if (c == ')') {
            res += sign * num;
            num = 0;
            int[] top = st.pop();
            res = top[0] + top[1] * res;
        }
    }
    return res + sign * num;
}
```
