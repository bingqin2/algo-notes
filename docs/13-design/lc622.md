# 622. 设计循环队列

> [力扣 622](https://leetcode.cn/problems/design-circular-queue/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

固定容量的队列，数组实现，头尾下标**取模**绕回。难点是区分「空」和「满」：要么额外记录元素个数，要么多留一个空位。

## 最优解法

**思路**：记录队头下标 head 和元素个数 size。队尾的下一个位置是 `(head + size) % k`，最后一个元素在 `(head + size − 1) % k`。空：`size == 0`；满：`size == k`。

```python
class MyCircularQueue:
    def __init__(self, k):
        self.q = [0] * k
        self.head = 0                      # 队头下标
        self.size = 0                      # 用 size 区分空和满
        self.k = k

    def enQueue(self, value):
        if self.isFull():
            return False
        self.q[(self.head + self.size) % self.k] = value
        self.size += 1
        return True

    def deQueue(self):
        if self.isEmpty():
            return False
        self.head = (self.head + 1) % self.k
        self.size -= 1
        return True

    def Front(self):
        return -1 if self.isEmpty() else self.q[self.head]

    def Rear(self):
        return -1 if self.isEmpty() else self.q[(self.head + self.size - 1) % self.k]

    def isEmpty(self):
        return self.size == 0

    def isFull(self):
        return self.size == self.k
```

**复杂度**：每个操作 O(1)，空间 O(k)。

## 易错点

- 只用 head 和 tail 两个下标、不记 size：`head == tail` 时分不清空还是满。另一种解决办法是数组开 k + 1，满的条件是 `(tail + 1) % (k + 1) == head`。
- 并发场景（比如生产者消费者的环形缓冲区）要加锁，或者用单生产者单消费者的无锁写法（Disruptor 的 RingBuffer）。
