# 54. 螺旋矩阵

> [力扣 54](https://leetcode.cn/problems/spiral-matrix/) · 近两年面经里出现在：**美团 · 招银**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

按圈遍历矩阵。纯模拟题，考的是边界处理。两种写法选一种练熟。

## 解法一：四个边界收缩

**思路**：维护 top、bottom、left、right 四个边界，每一圈按「上边 → 右边 → 下边 → 左边」走完，然后四个边界都往里收一格。

```python
def spiralOrder(matrix):
    res = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for j in range(left, right + 1):           # 上边：左 → 右
            res.append(matrix[top][j])
        for i in range(top + 1, bottom + 1):       # 右边：上 → 下
            res.append(matrix[i][right])
        if top < bottom and left < right:          # 只剩一行或一列时，下边和左边会重复
            for j in range(right - 1, left - 1, -1):   # 下边：右 → 左
                res.append(matrix[bottom][j])
            for i in range(bottom - 1, top, -1):       # 左边：下 → 上
                res.append(matrix[i][left])
        top, bottom, left, right = top + 1, bottom - 1, left + 1, right - 1
    return res
```

**复杂度**：时间 O(mn)，空间 O(1)（不算结果）。

**最容易错的地方**：最后一圈只剩一行或一列时，「下边」和「上边」是同一行，「左边」和「右边」是同一列，会重复输出。所以下边和左边只在 `top < bottom and left < right` 时才走。

## 图解

3 × 4 的矩阵，第一圈按 ①②③④ 的顺序走，第二圈只剩中间一行 [6, 7]，只走上边：

| | 列 0 | 列 1 | 列 2 | 列 3 |
|---|---|---|---|---|
| 行 0 | ① 1 | ① 2 | ① 3 | ① 4 |
| 行 1 | ④ 5 | 第二圈 6 | 第二圈 7 | ② 8 |
| 行 2 | ③ 9 | ③ 10 | ③ 11 | ② 12 |

输出：1 2 3 4 → 8 12 → 11 10 9 → 5 → 6 7。

## 解法二：方向数组 + 撞墙右转

**思路**：按「右、下、左、上」循环的方向走，下一格越界或已经访问过就右转。不用考虑每一圈的边界，但要 O(mn) 的访问标记（可以改原矩阵省掉）。

```python
def spiralOrder(matrix):
    m, n = len(matrix), len(matrix[0])
    dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]       # 右、下、左、上
    seen = [[False] * n for _ in range(m)]
    res = []
    i = j = d = 0
    for _ in range(m * n):
        res.append(matrix[i][j])
        seen[i][j] = True
        ni, nj = i + dirs[d][0], j + dirs[d][1]
        if not (0 <= ni < m and 0 <= nj < n) or seen[ni][nj]:
            d = (d + 1) % 4                         # 撞墙或走过了就右转
            ni, nj = i + dirs[d][0], j + dirs[d][1]
        i, j = ni, nj
    return res
```

**复杂度**：时间 O(mn)，空间 O(mn)。

## 解法三：Python 技巧：取第一行，再逆时针旋转

```python
def spiralOrder(matrix):
    res = []
    m = [list(row) for row in matrix]
    while m:
        res += m.pop(0)                    # 取走第一行
        m = [list(r) for r in zip(*m)][::-1]   # 剩下的逆时针转 90°
    return res
```

每次取走第一行，剩下的逆时针转 90°，新的第一行就是原来的右边那一列。代码短，但每次旋转 O(mn)，总共 O(mn · min(m, n))，适合笔试快速写，面试主写解法一。

## 易错点

- 只剩一行或一列时重复输出（解法一）。
- 下边和左边的循环范围：下边从 right − 1 到 left，左边从 bottom − 1 到 top + 1，四个角每个只输出一次。
- 解法二忘了右转后重新计算下一格。

## 面试追问

- **反过来，按螺旋顺序填数（59）？** 用同样的四个边界，把读改成写，见 [59](./lc59)。
- **从中间某个点往外螺旋（885）？** 步长按 1, 1, 2, 2, 3, 3, … 增长，越界的格子不记录。
- **旋转图像（48）？** 原地顺时针转 90° = 先转置、再每行反转，见 [48](./lc48)。

## Java 版

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1, left = 0, right = matrix[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res.add(matrix[top][j]);
        for (int i = top + 1; i <= bottom; i++) res.add(matrix[i][right]);
        if (top < bottom && left < right) {
            for (int j = right - 1; j >= left; j--) res.add(matrix[bottom][j]);
            for (int i = bottom - 1; i > top; i--) res.add(matrix[i][left]);
        }
        top++; bottom--; left++; right--;
    }
    return res;
}
```
