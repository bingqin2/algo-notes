# 673. 最长递增子序列的个数

> [力扣 673](https://leetcode.cn/problems/number-of-longest-increasing-subsequence/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

[300. 最长递增子序列](./lc300) 的计数版本：除了记录以 i 结尾的 LIS **长度**，再记录这个长度的 LIS 有**几个**。

## 最优解法

**思路**：对每个 j < i 且 `nums[j] < nums[i]`：

- `length[j] + 1 > length[i]`：找到更长的，长度更新，个数**重置**为 `count[j]`；
- `length[j] + 1 == length[i]`：又一种同样长的，个数**累加** `count[j]`。

最后把所有长度等于最长长度的 count 加起来。

```python
def findNumberOfLIS(nums):
    n = len(nums)
    length = [1] * n                       # 以 i 结尾的 LIS 长度
    count = [1] * n                        # 以 i 结尾的 LIS 个数
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                if length[j] + 1 > length[i]:
                    length[i], count[i] = length[j] + 1, count[j]
                elif length[j] + 1 == length[i]:
                    count[i] += count[j]
    longest = max(length)
    return sum(c for l, c in zip(length, count) if l == longest)
```

**复杂度**：时间 O(n²)，空间 O(n)。

## 易错点

- 答案不是 `count[最后一个]`：最长的 LIS 可以以任何位置结尾，要把所有达到最长长度的位置的 count 加起来。
- 更新长度时个数要重置，不是加。

**进阶**：O(n log n) 解法要在 300 题的贪心 + 二分基础上，为每个长度维护前缀和数组，再二分，比较复杂，面试一般不要求。
