# 290. 单词规律

> [力扣 290](https://leetcode.cn/problems/word-pattern/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

pattern 的字符和单词之间要一一对应：和 [205](./lc205) 一样双向检查。

## 关键点

- 简洁写法：字符种数、单词种数、(字符, 单词) 对的种数三者相等，说明是双射。
- 先检查单词数和 pattern 长度是否相等。

```python
def wordPattern(pattern, s):
    words = s.split()
    if len(words) != len(pattern):
        return False
    return len(set(pattern)) == len(set(words)) == len(set(zip(pattern, words)))
```
