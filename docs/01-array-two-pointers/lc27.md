# 27. 移除元素

> [力扣 27](https://leetcode.cn/problems/remove-element/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

原地删除所有等于 val 的元素：读写双指针，不等于 val 的才写入。

## 关键点

- 顺序可以改变时还有更少写入的做法：遇到 val 就用最后一个元素覆盖它，数组长度减一。
- O(n) 时间，O(1) 空间。

```python
def removeElement(nums, val):
    k = 0
    for x in nums:
        if x != val:
            nums[k] = x
            k += 1
    return k
```
