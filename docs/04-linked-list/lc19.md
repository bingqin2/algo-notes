# 19. 删除链表的倒数第 N 个结点

> [力扣 19](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) · 中等 · 近两年面经：**美团 · 招银 · 字节**（字节社招问的是「倒数第 k 个结点」）
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

链表里「倒数第 k 个」。单链表没法从后往前走，要么先求长度，要么用两个相隔 k 步的指针。

## 解法一：两次遍历

**思路**：第一遍求长度 L，倒数第 n 个就是正数第 L − n + 1 个。第二遍走到它的前一个结点，删掉它。

```python
def removeNthFromEnd(head, n):
    length, p = 0, head
    while p:
        length += 1
        p = p.next
    dummy = ListNode(0, head)
    p = dummy
    for _ in range(length - n):       # 走到待删结点的前一个
        p = p.next
    p.next = p.next.next
    return dummy.next
```

**复杂度**：时间 O(L)，空间 O(1)。

## 解法二：快慢指针，一次遍历

**思路**：fast 先走 n 步，然后两个一起走。fast 走到最后一个结点时，slow 正好在待删结点的前一个。两个指针都从哑结点出发，这样删的是头结点时也不用特判。

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:                  # fast 停在最后一个结点
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next
    return dummy.next
```

**复杂度**：时间 O(L)，空间 O(1)。

## 解法三：栈

**思路**：把所有结点压栈，再弹出 n 个，栈顶就是待删结点的前一个。空间 O(L)，一般只作为思路提一下。

## 易错点

- 没用哑结点：删除头结点（n 等于链表长度）时会出错。
- 循环条件写成 `while fast`：那样 slow 会停在待删结点本身，而不是它的前一个。
- 返回 `head` 而不是 `dummy.next`：头结点被删时 `head` 已经不在链表里了。

## 面试追问

- **只返回倒数第 k 个结点（不删除）？** 两个指针都从 head 出发，fast 先走 k 步，然后一起走到 fast 为空，slow 就是答案。
- **n 可能大于链表长度怎么办？** fast 先走的时候检查是否为空，为空就直接返回原链表。
- **找中点也是同样的思路吗？** 是，只是速度不同：fast 走两步、slow 走一步，见 [143](./lc143)。

## Java 版

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head), fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next;
    while (fast.next != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}
```
