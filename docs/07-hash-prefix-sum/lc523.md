# 523. 连续的子数组和

> [力扣 523](https://leetcode.cn/problems/continuous-subarray-sum/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

判断是否存在和为 k 的**倍数**的子数组：两个前缀和**模 k 同余**，它们之间的子数组和就是 k 的倍数。哈希表存「余数 → 第一次出现的下标」。

## 最优解法

**思路**：初始 `{0: -1}`。遍历时 `s = (s + x) % k`；如果 s 以前出现过，并且距离 ≥ 2（题目要求子数组长度至少 2），返回 True；没出现过才记录下标（保留最早的，长度才最长）。

```python
def checkSubarraySum(nums, k):
    first = {0: -1}                        # 前缀和 % k → 第一次出现的下标
    s = 0
    for i, x in enumerate(nums):
        s = (s + x) % k
        if s in first:
            if i - first[s] >= 2:          # 长度至少为 2
                return True
        else:
            first[s] = i
    return False
```

**复杂度**：时间 O(n)，空间 O(min(n, k))。

## 易错点

- 出现过时更新了下标：变成记最晚位置，可能错过长度 ≥ 2 的解（比如 `[5, 0, 0]`、k = 3）。
- 忘了 `{0: -1}`：从开头开始的子数组算不到。
- 长度至少为 2：`i − first[s] >= 2`。
