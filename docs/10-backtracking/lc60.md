# 60. 排列序列

> [力扣 60](https://leetcode.cn/problems/permutation-sequence/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

n 个数的全排列按字典序排好，**直接求第 k 个**，不能枚举（n = 9 时有 362880 个，而且面试官就是想看你不枚举）。

## 解法一：暴力：从最小排列往后走 k−1 步

**思路**：用 [31. 下一个排列](../01-array-two-pointers/lc31) 的方法走 k − 1 次。

```python
def getPermutation(n, k):
    nums = list(range(1, n + 1))
    for _ in range(k - 1):                 # 用 31 题的方法往后走 k-1 步
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
        nums[i + 1:] = reversed(nums[i + 1:])
    return ''.join(map(str, nums))
```

**复杂度**：时间 O(k · n)，最坏 O(n · n!)。能过，但只能当第一句话说。

## 解法二：逐位确定（康托展开的逆）

**思路**：第一位固定成某个数之后，后面 n − 1 位有 (n − 1)! 种排法。所以把 k（先改成从 0 开始数）除以 (n − 1)!：

- **商**就是第一位在剩余数里的位置；
- **余数**是在这一组里的排名，继续确定下一位。

以 n = 4、k = 9 为例：k − 1 = 8，8 ÷ 3! = 1 余 2，第一位选剩余 [1, 2, 3, 4] 里下标 1 的数 2；2 ÷ 2! = 1 余 0，选 [1, 3, 4] 里的 3；0 ÷ 1! = 0，选 [1, 4] 里的 1；最后是 4。答案 "2314"。

```python
def getPermutation(n, k):
    fact = [1] * n                         # fact[i] = i!
    for i in range(1, n):
        fact[i] = fact[i - 1] * i
    digits = [str(i) for i in range(1, n + 1)]
    k -= 1                                 # 改成从 0 开始数
    res = []
    for i in range(n - 1, -1, -1):
        idx, k = divmod(k, fact[i])        # 后面 i 位有 i! 种排法
        res.append(digits.pop(idx))
    return ''.join(res)
```

**复杂度**：时间 O(n²)（列表删除是 O(n)；用树状数组可以做到 O(n log n)），空间 O(n)。

## 易错点

- 忘了 `k -= 1`：k 是从 1 开始数的，不减 1 的话整除的边界全错一位。
- 阶乘数组下标：后面还剩 i 位时除以 i!，不是 (i+1)!。
- Java 里 `List<Integer>.remove(idx)`：idx 是 int 时按下标删，正是这里要的。

## 面试追问

- **反过来，给一个排列求它是第几个（康托展开）？** 对每一位，数它右边有几个比它小的数 c，答案 = Σ c × (右边剩余位数)! + 1。
- **n 很大怎么办？** 阶乘会溢出。但 k 在 int 范围内时 13! 已经比它大，前面的位一定是 1, 2, 3, … 不变，只需要对最后 13 位做逐位确定。
- **为什么放在回溯这一章？** 它是「全排列」的追问：面试官先让你写 [46](./lc46)，再问只要第 k 个怎么办。

## Java 版

```java
public String getPermutation(int n, int k) {
    int[] fact = new int[n];
    fact[0] = 1;
    for (int i = 1; i < n; i++) fact[i] = fact[i - 1] * i;
    List<Integer> digits = new ArrayList<>();
    for (int i = 1; i <= n; i++) digits.add(i);
    k--;
    StringBuilder sb = new StringBuilder();
    for (int i = n - 1; i >= 0; i--) {
        int idx = k / fact[i];
        k %= fact[i];
        sb.append(digits.remove(idx));       // remove(int) 按下标删除
    }
    return sb.toString();
}
```
