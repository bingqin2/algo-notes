# 106. 从中序与后序遍历序列构造二叉树

> [力扣 106](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

用两种遍历序列还原二叉树：**后序的最后一个**（或前序的第一个）是根，在中序里找到根的位置，左边是左子树、右边是右子树，按左子树的大小切分后序序列，递归。

## 最优解法

**思路**：用哈希表存中序里每个值的下标，O(1) 找根的位置。递归函数用下标区间表示子数组，不切片。

- 中序：`[in_lo, k−1]` 是左子树，`[k+1, in_hi]` 是右子树，左子树大小 `left_size = k − in_lo`。
- 后序：`[post_lo, post_lo + left_size − 1]` 是左子树，`[post_lo + left_size, post_hi − 1]` 是右子树。

```python
def buildTree(inorder, postorder):
    idx = {v: i for i, v in enumerate(inorder)}

    def build(in_lo, in_hi, post_lo, post_hi):
        if in_lo > in_hi:
            return None
        root_val = postorder[post_hi]      # 后序最后一个是根
        k = idx[root_val]
        left_size = k - in_lo
        root = TreeNode(root_val)
        root.left = build(in_lo, k - 1, post_lo, post_lo + left_size - 1)
        root.right = build(k + 1, in_hi, post_lo + left_size, post_hi - 1)
        return root

    return build(0, len(inorder) - 1, 0, len(postorder) - 1)
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 后序的右子树区间末尾是 `post_hi − 1`（去掉根）。
- 用切片 `inorder[:k]` 递归：每次复制，O(n²)。
- 值有重复时无法唯一确定，题目保证不重复。
