# 875. 爱吃香蕉的珂珂

> [力扣 875](https://leetcode.cn/problems/koko-eating-bananas/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

「求能在 h 小时内吃完的最小速度」：速度越快越容易满足，单调，**二分答案**。

## 最优解法

**思路**：速度范围 [1, max(piles)]（速度再快也是一小时一堆）。速度 k 时需要的小时数是每堆 `⌈p / k⌉` 之和。小时数 ≤ h 就试更慢的，否则加快。

```python
def minEatingSpeed(piles, h):
    def hours(k):
        return sum((p + k - 1) // k for p in piles)   # 向上取整

    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if hours(mid) <= h:                # 速度 mid 来得及，试更慢的
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**复杂度**：时间 O(n log(max))，空间 O(1)。

## 易错点

- 向上取整写成 `p // k + 1`：p 能整除 k 时多算了一小时。用 `(p + k − 1) // k`，或者 `-(-p // k)`。
- 下界写成 0：除以 0。
