# 438. 找到字符串中所有字母异位词

> [力扣 438](https://leetcode.cn/problems/find-all-anagrams-in-a-string/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

在 s 里找 p 的所有**排列**出现的位置：窗口长度固定为 |p|，比较窗口内字符计数和 p 的字符计数是否相同。

## 解法一：固定窗口 + 计数数组

**思路**：先统计 p 的计数 `need`。窗口每右移一格：加入新字符、移出最左边的字符（下标 i − m），窗口满了就比较两个计数数组。

<StepPlayer src="/viz/lc438.json" />

```python
def findAnagrams(s, p):
    m = len(p)
    if m > len(s):
        return []
    need, win = [0] * 26, [0] * 26
    for ch in p:
        need[ord(ch) - 97] += 1
    res = []
    for i, ch in enumerate(s):
        win[ord(ch) - 97] += 1
        if i >= m:                         # 窗口长度固定为 m，移出最左边的
            win[ord(s[i - m]) - 97] -= 1
        if i >= m - 1 and win == need:
            res.append(i - m + 1)
    return res
```

**复杂度**：时间 O(26 · n)：每次比较 26 个数。空间 O(26)。

**优化到 O(n)**：不每次比较整个数组，而是维护一个 `diff`（有几种字符的计数还对不上），每次加入、移出时只更新受影响的那一种字符，`diff == 0` 时记录答案。写法见 [567](./lc567)。

## 易错点

- 移出的字符下标是 `i − m`，在加入第 m 个字符（i = m）时开始移出。
- 记录的是窗口的**起点** `i − m + 1`。
- p 比 s 长时直接返回空。
