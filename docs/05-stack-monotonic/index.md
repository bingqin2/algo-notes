# 栈与单调栈

## 核心框架

括号、表达式、嵌套结构用栈；「下一个更大/更小」用单调栈。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [20. 有效的括号](./lc20) | 腾讯 ×2 · 阿里笔试 | 栈匹配 / 只有一种括号时用计数 |
| [32. 最长有效括号](./lc32) | 字节 · 华为 | 栈存下标 / 动态规划 / 左右两遍计数 O(1) 空间 |
| [155. 最小栈（O(1) 取最值）](./lc155) | 字节 | 辅助栈同步存当前最小值 / 存差值 O(1) 额外空间 |
| [232. 用栈实现队列 / 用队列实现栈](./lc232) | 招银 · 字节 | 输入栈 + 输出栈，均摊 O(1) |
| [739. 每日温度](./lc739) | 腾讯 | 单调递减栈存下标 |
| [84. 柱状图中最大的矩形](./lc84) | 高频经典 | 单调递增栈，左右哨兵 |
