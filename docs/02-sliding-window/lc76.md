# 76. 最小覆盖子串

> [力扣 76](https://leetcode.cn/problems/minimum-window-substring/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

在 s 里找包含 t 所有字符（含重复）的**最短**子串：可变长窗口，「覆盖了就收缩」。滑动窗口最经典的模板题。

## 解法一：need/window 计数 + valid 计数

**思路**：

- `need`：t 里每个字符需要几个；`window`：窗口里这些字符有几个；`valid`：有几种字符的数量已经达到要求。
- right 扩张：加入字符 c，如果 c 是需要的，`window[c] += 1`，刚好达到 `need[c]` 时 `valid += 1`。
- `valid == len(need)` 时窗口覆盖了 t：更新最短答案，然后收缩 left；移出的字符 d 如果正好是「刚好够」的状态，移出后就不够了，`valid −= 1`。

```python
from collections import Counter

def minWindow(s, t):
    need = Counter(t)
    window = Counter()
    valid = 0                              # 有多少种字符已经满足了 need
    left, start, best = 0, 0, float("inf")
    for right, ch in enumerate(s):
        if ch in need:
            window[ch] += 1
            if window[ch] == need[ch]:
                valid += 1
        while valid == len(need):          # 窗口已覆盖 t，尽量收缩左边
            if right - left + 1 < best:
                start, best = left, right - left + 1
            d = s[left]
            left += 1
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1
    return "" if best == float("inf") else s[start:start + best]
```

**复杂度**：时间 O(|s| + |t|)，空间 O(字符集)。

## 易错点

- `valid` 只在 `window[c] == need[c]` 的那一刻 +1，超过了不再加；移出时只在「移出前正好相等」时 −1。顺序写反（先减再判断）就错了。
- valid 和 `len(need)`（字符**种类数**）比较，不是和 `len(t)` 比较。
- 记录起点和长度，最后再切片，不要在循环里反复切片。
