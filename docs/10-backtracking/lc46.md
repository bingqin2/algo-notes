# 46. 全排列

> [力扣 46](https://leetcode.cn/problems/permutations/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「所有排列」：每个位置放哪个数，用过的不能再用。数据范围很小（n ≤ 6），答案本身就有 n! 个，只能回溯枚举。

回溯的通用框架（这一章所有题都是它的变形）：

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        结果.append(路径的拷贝)
        return
    for 选择 in 选择列表:
        if 不合法 or 会重复: continue     # 剪枝
        做选择
        backtrack(路径, 新的选择列表)
        撤销选择
```

三个问题想清楚就能写：**每一层在决定什么**、**选择列表怎么变**、**怎么避免重复**。

## 解法一：used 数组

**思路**：每一层决定路径的下一个数，用 `used[i]` 记录哪些数已经在路径里。

<StepPlayer src="/viz/lc46.json" />

```python
def permute(nums):
    res, path = [], []
    used = [False] * len(nums)

    def dfs():
        if len(path) == len(nums):
            res.append(path[:])            # 要拷贝，path 之后还会变
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True                 # 做选择
            path.append(x)
            dfs()
            path.pop()                     # 撤销选择
            used[i] = False

    dfs()
    return res
```

**复杂度**：时间 O(n · n!)：n! 个叶子，每个叶子拷贝路径 O(n)。空间 O(n)（递归栈和路径，不算结果）。

## 解法二：原地交换

**思路**：第 k 层决定第 k 个位置：把 nums[k..n−1] 中的每一个依次换到位置 k，递归处理 k + 1，再换回来。不需要 used 数组和 path。

```python
def permute(nums):
    nums = nums[:]
    res = []

    def dfs(k):                            # 前 k 位已经确定
        if k == len(nums):
            res.append(nums[:])
            return
        for i in range(k, len(nums)):
            nums[k], nums[i] = nums[i], nums[k]   # 把 nums[i] 放到第 k 位
            dfs(k + 1)
            nums[k], nums[i] = nums[i], nums[k]   # 换回来

    dfs(0)
    return res
```

**复杂度**：时间 O(n · n!)，空间 O(n)。缺点是输出不是字典序，而且不好扩展到有重复元素的情况（47 用解法一更自然）。

## 易错点

- `res.append(path)` 没有拷贝：最后所有答案都是同一个空列表。Java 里同理要 `new ArrayList<>(path)`。
- 撤销选择漏了一步：`used[i] = False` 和 `path.pop()` 都要恢复。
- Java 的 `path.remove(path.size() - 1)`：参数是 int 时按下标删；如果写成 `path.remove(x)` 而 x 是 Integer，就变成按值删了。

## 面试追问

- **有重复元素？** 见 [47](./lc47)：排序 + 同层去重。
- **只要第 k 个排列？** 见 [60](./lc60)：逐位确定，不用枚举。
- **按字典序输出下一个？** 见 [31. 下一个排列](../01-array-two-pointers/lc31)。
- **排列、组合、子集有什么区别？** 排列每层都从头选（用 used 去掉已选的）；组合和子集每层只往后选（传 start），子集在每个结点都记录答案，组合只在长度够时记录。

## Java 版

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}

private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));      // 拷贝一份
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        dfs(nums, used, path, res);
        path.remove(path.size() - 1);        // 按下标删，不是按值删
        used[i] = false;
    }
}
```
