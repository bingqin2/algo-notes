# 235. 二叉搜索树的最近公共祖先

> [力扣 235](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

**二叉搜索树**的最近公共祖先：利用有序性，不用像普通二叉树（[236](./lc236)）那样搜索两边。从根往下走，第一个值在 p、q 之间（含等于）的结点就是答案。

## 最优解法

**思路**：p、q 都比当前小，往左；都比当前大，往右；否则当前结点就是分叉点。

```python
def lowestCommonAncestor(root, p, q):
    cur = root
    while cur:
        if p.val < cur.val and q.val < cur.val:
            cur = cur.left
        elif p.val > cur.val and q.val > cur.val:
            cur = cur.right
        else:                              # 分叉点（或者等于其中一个）就是答案
            return cur
```

**复杂度**：时间 O(h)，空间 O(1)。

## 易错点

- 用普通二叉树的递归解法也能过，但没利用 BST 性质，面试官会追问。
- p 或 q 本身就是另一个的祖先：当前结点等于 p 或 q 时也落入 else，直接返回，正确。
