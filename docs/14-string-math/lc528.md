# 528. 按权重随机选择

> [力扣 528](https://leetcode.cn/problems/random-pick-with-weight/) · 中等 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

按权重随机选下标：前缀和把每个下标映射成一段区间，随机取 [1, total] 里的整数，**二分**找它落在哪一段。

## 关键点

- 下标 i 占 `(pre[i−1], pre[i]]`，长度正好是 w[i]，所以概率是 w[i] / total。
- 用 `bisect_left` 找第一个 `pre[i] ≥ r`。随机数从 1 开始取，从 0 开始的话边界要改成 `bisect_right`。
- 初始化 O(n)，每次选 O(log n)。

```python
import random
import bisect

class Solution:
    def __init__(self, w):
        self.pre = []
        total = 0
        for x in w:
            total += x
            self.pre.append(total)         # 前缀和：下标 i 占 (pre[i-1], pre[i]]

    def pickIndex(self):
        r = random.randint(1, self.pre[-1])
        return bisect.bisect_left(self.pre, r)
```
