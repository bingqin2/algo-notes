# 452. 用最少数量的箭引爆气球

> [力扣 452](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

用最少的点覆盖所有区间：按**右端点**排序，每次在第一个还没被射穿的气球的右端点射一箭，这一箭能射穿所有起点 ≤ 这个位置的气球。

## 最优解法

**思路**：排序后，当前箭的位置是 end。下一个气球的起点 > end，说明这支箭射不到它，需要新的一箭，射在它的右端点。

```python
def findMinArrowShots(points):
    points.sort(key=lambda p: p[1])
    arrows, end = 0, float("-inf")
    for s, e in points:
        if s > end:                        # 当前的箭射不到这个气球（端点相接算能射到）
            arrows += 1
            end = e                        # 在这个气球的右端射一箭
    return arrows
```

**复杂度**：时间 O(n log n)，空间 O(log n)。

## 易错点

- 端点相接**算能射穿**（`[1,2]` 和 `[2,3]` 一箭就够），所以条件是 `s > end`，和 [435](./lc435) 的 `>=` 不同。
- Java 里比较器写 `a[1] − b[1]`：坐标到 ±2³¹ 时溢出，用 `Integer.compare`。
