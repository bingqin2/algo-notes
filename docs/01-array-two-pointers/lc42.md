# 42. 接雨水

> [力扣 42](https://leetcode.cn/problems/trapping-rain-water/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每个位置能接的水 = `min(左边最高, 右边最高) − 自己的高度`。三种算法都是在高效地求「左右最高」：预处理数组、双指针、单调栈。

## 解法一：按列：左右最大值数组

**思路**：`left[i]` 是 [0, i] 的最大高度，`right[i]` 是 [i, n−1] 的最大高度，两次遍历预处理，第三次累加。

```python
def trap(height):
    n = len(height)
    if n == 0:
        return 0
    left, right = [0] * n, [0] * n
    left[0] = height[0]
    for i in range(1, n):
        left[i] = max(left[i - 1], height[i])
    right[-1] = height[-1]
    for i in range(n - 2, -1, -1):
        right[i] = max(right[i + 1], height[i])
    return sum(min(left[i], right[i]) - height[i] for i in range(n))
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法二：双指针 O(1) 空间

**思路**：l、r 从两端向中间走，维护 lmax、rmax。如果 `lmax < rmax`，那么 l 处右边一定有一堵至少 rmax 高的墙，l 处的水位由 lmax 决定（虽然不知道 l 右边的真实最高值，但它 ≥ rmax > lmax，不影响 min），可以直接结算 l，然后 l 右移；反之结算 r。

```python
def trap(height):
    l, r = 0, len(height) - 1
    lmax = rmax = res = 0
    while l < r:
        lmax = max(lmax, height[l])
        rmax = max(rmax, height[r])
        if lmax < rmax:                    # 左边的瓶颈更低，l 处的水位就是 lmax
            res += lmax - height[l]
            l += 1
        else:
            res += rmax - height[r]
            r -= 1
    return res
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法三：单调栈按行计算

**思路**：栈里存下标，高度单调递减。遇到比栈顶高的柱子时，栈顶就是一个「坑底」：弹出它，新的栈顶是左墙，当前柱子是右墙，这一层水的高度是 `min(左墙, 右墙) − 坑底`，宽度是 `i − 左墙 − 1`。相当于**一层一层（按行）**往上加水。

```python
def trap(height):
    stack, res = [], 0                     # 单调递减栈，存下标
    for i, h in enumerate(height):
        while stack and height[stack[-1]] < h:
            bottom = stack.pop()
            if not stack:
                break                      # 左边没有墙，存不住水
            left = stack[-1]
            w = i - left - 1
            res += (min(height[left], h) - height[bottom]) * w   # 一层一层（按行）算
        stack.append(i)
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 双指针比较的是 `lmax < rmax`，不是 `height[l] < height[r]`（后者也对，但要先更新 max 再比较，写法容易乱，统一用 max 比较最不容易错）。
- 单调栈弹出坑底后栈空了：左边没有墙，存不住水，直接 break。
- 单调栈遇到相等高度：用 `<` 弹出，相等的不弹，计算时高度差为 0，不影响结果。
