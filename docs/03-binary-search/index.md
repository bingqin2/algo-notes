# 二分查找

## 核心框架

统一用左闭右开或左闭右闭一种写法；关键是写清「答案在哪一半」的判断。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| [704. 二分查找 + 左右边界（34）](./lc704) | 腾讯 CSIG | 标准二分 / lower_bound / upper_bound 写法 |
