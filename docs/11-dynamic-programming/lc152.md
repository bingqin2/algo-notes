# 152. 乘积最大子数组

> [力扣 152](https://leetcode.cn/problems/maximum-product-subarray/) · 中等 · 来源：Hot 100 · 面经 · 近两年面经：**字节 · 小红书**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

[53 最大子数组和](./lc53) 的乘积版。难点是**负数**：一个很小的负数乘上一个负数，会变成很大的正数。所以只记录最大值不够，还要记录最小值。

## 解法一：同时维护最大和最小

**思路**：hi / lo = 以当前元素结尾的子数组的最大 / 最小乘积。

- x 是正数：hi = max(x, hi·x)，lo = min(x, lo·x)。
- x 是负数：最大和最小会互换，先交换 hi 和 lo，再按上面的式子算。
- x 是 0：hi 和 lo 都变成 0，相当于从下一个元素重新开始，上面的式子已经包含了这种情况。

```python
def maxProduct(nums):
    hi = lo = best = nums[0]
    for x in nums[1:]:
        if x < 0: hi, lo = lo, hi  # 乘负数，最大最小互换
        hi = max(x, hi * x)
        lo = min(x, lo * x)
        best = max(best, hi)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法二：前后各扫一遍

**思路**：没有 0 时，负数个数是偶数则整个数组相乘最大；是奇数则要去掉最左边或最右边的一个负数（以及它外侧的部分）。所以从左往右、从右往左各算一遍前缀积，取最大值；遇到 0 就把前缀积重置为 1。

```python
def maxProduct(nums):
    best, pre, suf, n = nums[0], 1, 1, len(nums)
    for i in range(n):
        pre = (pre or 1) * nums[i]           # 前缀积，遇到 0 后重置
        suf = (suf or 1) * nums[n - 1 - i]   # 后缀积
        best = max(best, pre, suf)
    return best
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 只维护最大值：`[-2, 3, -4]` 的答案是 24，只看最大值会得到 3。
- 交换 hi、lo 之后，算 hi 和 lo 时要用交换后的值，而不是一边改一边用。Python 里也可以一行同时算：`hi, lo = max(x, hi*x, lo*x), min(x, hi*x, lo*x)`。
- Java 里如果数据范围大要注意溢出（这道题保证答案在 32 位整数范围内）。

## 面试追问

- **为什么要比较 x 本身？** 比如前面的乘积是 0，接上去还是 0，不如从 x 重新开始。
- **能返回子数组吗？** 和 53 一样，在重新开始和更新最优时记录下标。hi 和 lo 交换时，它们的起点也要一起交换。

## Java 版

```java
public int maxProduct(int[] nums) {
    int hi = nums[0], lo = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        int x = nums[i];
        if (x < 0) { int t = hi; hi = lo; lo = t; }   // 乘负数，最大最小互换
        hi = Math.max(x, hi * x);
        lo = Math.min(x, lo * x);
        best = Math.max(best, hi);
    }
    return best;
}
```
