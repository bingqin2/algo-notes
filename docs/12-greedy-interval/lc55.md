# 55. 跳跃游戏

> [力扣 55](https://leetcode.cn/problems/jump-game/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每个位置能跳的最大步数，判断能否到达终点：不需要关心具体怎么跳，只需要维护**目前能到达的最远位置**。

## 解法一：维护最远可达位置

**思路**：从左往右遍历，如果当前位置 i 已经超过了 far，说明到不了 i，返回 False；否则用 `i + nums[i]` 更新 far。

<StepPlayer src="/viz/lc55.json" />

```python
def canJump(nums):
    farthest = 0
    for i, x in enumerate(nums):
        if i > farthest:                   # 这个位置已经到不了
            return False
        farthest = max(farthest, i + x)
    return True
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法二：按层 BFS 思路求最少步数

追问「最少跳几次」就是 [45. 跳跃游戏 II](./lc45)：把能到达的位置按跳的次数分层，每走完一层（到达这一跳的边界）次数加一。

```python
def jump(nums):
    jumps = cur_end = farthest = 0
    for i in range(len(nums) - 1):         # 不需要在最后一个位置起跳
        farthest = max(farthest, i + nums[i])
        if i == cur_end:                   # 走到了当前这一跳能到的边界，必须再跳一次
            jumps += 1
            cur_end = farthest
    return jumps
```

## 易错点

- 只在 `nums[i] == 0` 时判断：要看的是能不能**到达** i，而不是 i 能不能跳出去。
- 从后往前的写法也可以：维护「能到达终点的最左位置」，看最后是不是 0。
