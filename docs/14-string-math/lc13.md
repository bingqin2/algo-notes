# 13. 罗马数字转整数

> [力扣 13](https://leetcode.cn/problems/roman-to-integer/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

罗马数字转整数：一个字符比它右边的字符小时减去它，否则加上它。

## 关键点

- 例如 `IV`：I < V，所以 −1 + 5 = 4。
- 从右往左遍历也行：当前值小于上一个加过的值就减。O(n)。

```python
def romanToInt(s):
    val = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
    total = 0
    for i, ch in enumerate(s):
        if i + 1 < len(s) and val[ch] < val[s[i + 1]]:
            total -= val[ch]               # 小的在大的左边：减
        else:
            total += val[ch]
    return total
```
