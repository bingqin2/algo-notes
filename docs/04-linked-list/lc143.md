# 143. 重排链表

> [力扣 143](https://leetcode.cn/problems/reorder-list/) · 中等 · 近两年面经：**美团 ×3**（有一场题面是「0, 1, …, n 重排成 0, n, 1, n−1…」，另一场叫「链表交错重排」）
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

L0 → Ln → L1 → Ln−1 → …，首尾交替取结点。这道题是三个基本操作的组合：**找中点 + 反转链表 + 合并链表**，面试官用它考你能不能把小模块拼起来。

## 解法一：存进数组 + 左右指针

**思路**：把结点按顺序存进数组，用左右两个指针从两端往中间交替连接。

```python
def reorderList(head):
    nodes = []
    while head:
        nodes.append(head)
        head = head.next
    i, j = 0, len(nodes) - 1
    while i < j:
        nodes[i].next = nodes[j]
        i += 1
        if i == j:
            break
        nodes[j].next = nodes[i]
        j -= 1
    nodes[i].next = None           # 新的尾巴，必须断开，否则成环
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法二：找中点 + 反转后半 + 交错合并（O(1) 空间）

**思路**：

1. 快慢指针找中点，从中点后面断开，分成前后两半。
2. 用 [206](./lc206) 的方法反转后半。
3. 两条链表交错合并：前 1 个、后 1 个、前 1 个……

```python
def reorderList(head):
    if not head or not head.next:
        return
    # 1. 找中点：偶数个结点时 slow 停在前半的最后一个
    slow = fast = head
    while fast.next and fast.next.next:
        slow, fast = slow.next, fast.next.next
    second, slow.next = slow.next, None
    # 2. 反转后半
    prev = None
    while second:
        second.next, prev, second = prev, second, second.next
    # 3. 交错合并
    first, second = head, prev
    while second:                  # 后半不比前半长，所以只看 second
        n1, n2 = first.next, second.next
        first.next, second.next = second, n1
        first, second = n1, n2
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法三：递归

**思路**：用递归回溯拿到「从尾部往前」的结点，同时用一个外部指针从头部往后走，在回溯时完成交错连接。代码绕、容易错，空间也是 O(n)，知道有这个思路即可。

## 易错点

- 找中点的循环条件：`fast.next and fast.next.next` 让 slow 停在前半最后一个，前半长度 ≥ 后半长度，合并时只要判断 second。
- 忘记 `slow.next = None` 断开前后两半，合并后会成环。
- 合并时没先存 `first.next` 和 `second.next`，改完指针就找不到下一个了。
- 解法一最后忘记把新尾巴的 `next` 置空。

## 面试追问

- **能不能不修改原链表？** 那就只能复制结点，空间 O(n)。
- **改成 L0 → L1 → Ln → Ln−1 …（每次取两个）？** 找中点和反转不变，只改合并的步长。
- **怎么测试？** 空链表、1 个、2 个、奇数个、偶数个结点。

## Java 版

```java
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode second = slow.next, prev = null;
    slow.next = null;
    while (second != null) {
        ListNode nxt = second.next;
        second.next = prev;
        prev = second;
        second = nxt;
    }
    ListNode first = head;
    second = prev;
    while (second != null) {
        ListNode n1 = first.next, n2 = second.next;
        first.next = second;
        second.next = n1;
        first = n1;
        second = n2;
    }
}
```
