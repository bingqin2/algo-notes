# 79. 单词搜索

> [力扣 79](https://leetcode.cn/problems/word-search/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

网格里找一条路径拼出单词，格子不能重复使用：从每个格子开始 DFS，**进入时标记、返回时恢复**（回溯）。

## 最优解法

**思路**：dfs(r, c, i) 判断从 (r, c) 出发能否匹配 `word[i:]`。当前格子字符不对就 False；对了就临时改成 `#`，向四个方向找 `word[i+1:]`，然后恢复原字符。

```python
def exist(board, word):
    m, n = len(board), len(board[0])

    def dfs(r, c, i):
        if i == len(word):
            return True
        if not (0 <= r < m and 0 <= c < n) or board[r][c] != word[i]:
            return False
        board[r][c] = "#"                  # 标记已用，防止同一格用两次
        found = (dfs(r + 1, c, i + 1) or dfs(r - 1, c, i + 1)
                 or dfs(r, c + 1, i + 1) or dfs(r, c - 1, i + 1))
        board[r][c] = word[i]              # 回溯：恢复
        return found

    return any(dfs(r, c, 0) for r in range(m) for c in range(n))
```

**复杂度**：时间 O(mn · 3^L)（除了第一步，每步最多 3 个方向，L 是单词长度），空间 O(L)。

## 易错点

- 忘了恢复格子：其他起点的搜索会受影响。
- 用 visited 集合也行，但修改原数组更快。

**剪枝**：单词里某个字符的数量比网格里多，直接 False；如果单词末尾字符在网格里出现得比开头少，把单词反过来搜，能减少起点。
