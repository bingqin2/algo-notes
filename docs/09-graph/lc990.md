# 990. 等式方程的可满足性

> [力扣 990](https://leetcode.cn/problems/satisfiability-of-equality-equations/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

一堆「相等」和「不等」的约束，判断是否矛盾：相等关系有传递性，用**并查集**把相等的合并；然后检查每个不等式的两边是否在同一个集合里。

## 最优解法

**思路**：两遍：第一遍处理所有 `==`，合并；第二遍处理所有 `!=`，两边在同一集合就矛盾。必须先处理完所有等式，因为后面的等式可能让前面的不等式变得矛盾。

```python
def equationsPossible(equations):
    parent = list(range(26))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for e in equations:                    # 先把所有相等的合并
        if e[1] == "=":
            parent[find(ord(e[0]) - 97)] = find(ord(e[3]) - 97)
    for e in equations:                    # 再检查不等式有没有矛盾
        if e[1] == "!" and find(ord(e[0]) - 97) == find(ord(e[3]) - 97):
            return False
    return True
```

**复杂度**：时间 O(n)，空间 O(26)。

## 易错点

- 一遍遍历时边合并边检查：`["a!=b", "b==a"]` 会漏判。
- `a != a` 本身就矛盾，上面的写法自然能检测到。
