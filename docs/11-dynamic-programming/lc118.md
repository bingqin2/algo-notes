# 118. 杨辉三角

> [力扣 118](https://leetcode.cn/problems/pascals-triangle/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

杨辉三角：每个数等于上一行左上和正上方两个数的和，首尾是 1。

## 关键点

- 第 i 行有 i + 1 个数，按上一行相邻两数相加生成中间部分。O(n²)。
- 追问：只要第 k 行（119 题）？用一维数组从右往左更新，O(k) 空间。

```python
def generate(numRows):
    res = [[1]]
    for _ in range(numRows - 1):
        prev = res[-1]
        res.append([1] + [prev[i] + prev[i + 1] for i in range(len(prev) - 1)] + [1])
    return res[:numRows]
```
