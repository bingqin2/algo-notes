# 108. 将有序数组转换为二叉搜索树

> [力扣 108](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序数组转平衡 BST：每次取**中间**的数当根，左右两半递归。

## 关键点

- 中间偏左或偏右都可以，结果不唯一。O(n)。

```python
def sortedArrayToBST(nums):
    def build(lo, hi):
        if lo > hi:
            return None
        mid = (lo + hi) // 2               # 中间的数当根，两边高度差不超过 1
        return TreeNode(nums[mid], build(lo, mid - 1), build(mid + 1, hi))

    return build(0, len(nums) - 1)
```
