# 138. 随机链表的复制

> [力扣 138](https://leetcode.cn/problems/copy-list-with-random-pointer/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

复制带额外指针（random）的链表：难点是复制 random 时，目标结点的副本可能还没创建。要么用**哈希表**记录「原结点 → 副本」，要么把副本**穿插**在原结点后面，用位置关系代替哈希表。

## 最优解法

**思路**（O(1) 额外空间）：

1. 在每个原结点后面插入它的副本：`A → A' → B → B' → …`
2. 设置副本的 random：`A'.random = A.random.next`（原结点 random 的下一个就是它的副本）。
3. 拆分：奇数位置还原成原链表，偶数位置连成新链表。

```python
import random

def copyRandomList(head):
    if not head:
        return None
    cur = head                             # 1. 每个结点后面插一个复制结点：A → A' → B → B'
    while cur:
        cur.next = Node(cur.val, cur.next)
        cur = cur.next.next
    cur = head                             # 2. 复制结点的 random = 原结点 random 的下一个
    while cur:
        if cur.random:
            cur.next.random = cur.random.next
        cur = cur.next.next
    new_head = head.next                   # 3. 拆成两条链，同时恢复原链表
    cur = head
    while cur:
        copy = cur.next
        cur.next = copy.next
        copy.next = copy.next.next if copy.next else None
        cur = cur.next
    return new_head
```

**复杂度**：时间 O(n)，空间 O(1)（不算输出）。

**更好写的版本**：哈希表两遍遍历，第一遍创建所有副本，第二遍连 next 和 random。O(n) 空间，面试时可以先写这个。

```python
def copyRandomList(head):
    mp = {None: None}
    cur = head
    while cur:
        mp[cur] = Node(cur.val)
        cur = cur.next
    cur = head
    while cur:
        mp[cur].next = mp[cur.next]
        mp[cur].random = mp[cur.random]
        cur = cur.next
    return mp[head]
```

## 易错点

- 第 2 步 random 可能为 None，要先判断。
- 第 3 步必须把原链表恢复：力扣会检查原链表有没有被改。
- 哈希表写法里放一个 `{None: None}`，就不用到处判断空指针。
