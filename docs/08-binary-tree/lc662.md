# 662. 二叉树最大宽度

> [力扣 662](https://leetcode.cn/problems/maximum-width-of-binary-tree/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

二叉树每层的「宽度」包括中间的空结点：给结点按**满二叉树**编号（左孩子 2i、右孩子 2i + 1），每层宽度 = 最右编号 − 最左编号 + 1。

## 最优解法

**思路**：BFS，队列里存 (结点, 编号)。每层先用首尾编号算宽度。为了防止深度很大时编号指数级增长，每层编号都减去这一层最左边的编号再生成孩子编号。

```python
def widthOfBinaryTree(root):
    best = 0
    q = [(root, 0)]                        # 结点和它在满二叉树里的编号
    while q:
        best = max(best, q[-1][1] - q[0][1] + 1)
        base = q[0][1]                     # 每层减去最左边的编号，防止编号过大
        nxt = []
        for node, i in q:
            i -= base
            if node.left:
                nxt.append((node.left, 2 * i))
            if node.right:
                nxt.append((node.right, 2 * i + 1))
        q = nxt
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 编号溢出：Python 没问题，Java 用 int 会溢出（深度可以到 3000），所以要每层减去最左编号；或者用 long 也不够，必须做偏移。
- 宽度只看每层第一个和最后一个**非空**结点，不是满二叉树这一层的总宽度。
