# 394. 字符串解码

> [力扣 394](https://leetcode.cn/problems/decode-string/) · 近两年面经里出现在：**美团 · 腾讯 ×2**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

`k[...]` 这样的嵌套展开，和 [224](./lc224) 一样：遇到左括号就**保存外层状态**、进入里层，遇到右括号就**用里层结果更新外层**。可以用栈，也可以用递归。

## 解法一：栈存 (之前的串, 次数)

**思路**：`cur` 是当前这一层正在拼的字符串，`k` 是正在读的数字。

- 数字：`k = k * 10 + d`（次数可能是多位数，比如 `10[a]`）。
- `[`：把 `(cur, k)` 压栈，`cur`、`k` 清空，开始拼里层。
- `]`：弹出 `(prev, times)`，`cur = prev + cur × times`。
- 字母：接到 `cur` 后面。

<StepPlayer src="/viz/lc394.json" />

```python
def decodeString(s):
    st = []                                # 存遇到 [ 之前的 (已有字符串, 重复次数)
    cur, k = '', 0
    for c in s:
        if c.isdigit():
            k = k * 10 + int(c)            # 次数可能是多位数
        elif c == '[':
            st.append((cur, k))
            cur, k = '', 0
        elif c == ']':
            prev, times = st.pop()
            cur = prev + cur * times
        else:
            cur += c
    return cur
```

**复杂度**：时间和空间都是 O(输出长度)。

题目页面的解法通常是「数字栈 + 字符串栈」两个栈，和这里存一个元组是一样的。下面的 Java 版就是两个栈。

## 解法二：递归下降

**思路**：`decode()` 读到 `]` 或结尾就返回当前这一层的字符串；遇到 `[` 就递归，把返回值重复 k 次。

```python
def decodeString(s):
    i = 0

    def decode():                          # 解码到 ] 或字符串结尾
        nonlocal i
        res, k = [], 0
        while i < len(s):
            c = s[i]
            i += 1
            if c.isdigit():
                k = k * 10 + int(c)
            elif c == '[':
                res.append(decode() * k)
                k = 0
            elif c == ']':
                break
            else:
                res.append(c)
        return ''.join(res)

    return decode()
```

**复杂度**：时间和空间都是 O(输出长度)。

## 易错点

- 次数是多位数。
- `[` 之后忘了把 `k` 清零，里层的次数会接在外层后面。
- Python 里在循环中反复 `cur += c` 是 O(长度) 的；字符串很长时用列表收集再 `join`（递归版就是这么做的）。Java 用 `StringBuilder`。

## 面试追问

- **反过来，压缩字符串？** 比如 `aaabb` → `3[a]2[b]`：先统计连续字符（443 题）。找重复子串的最优压缩是区间 DP（471 题，会员题）。
- **输入可能非法（括号不匹配）？** 栈解法结束时检查栈是否为空，`]` 时检查栈是否为空。

## Java 版

```java
public String decodeString(String s) {
    Deque<StringBuilder> strs = new ArrayDeque<>();
    Deque<Integer> counts = new ArrayDeque<>();
    StringBuilder cur = new StringBuilder();
    int k = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            k = k * 10 + (c - '0');
        } else if (c == '[') {
            strs.push(cur);
            counts.push(k);
            cur = new StringBuilder();
            k = 0;
        } else if (c == ']') {
            StringBuilder prev = strs.pop();
            prev.append(cur.toString().repeat(counts.pop()));
            cur = prev;
        } else {
            cur.append(c);
        }
    }
    return cur.toString();
}
```
