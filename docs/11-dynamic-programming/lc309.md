# 309. 买卖股票的最佳时机含冷冻期

> [力扣 309](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

股票问题加约束（冷冻期、手续费、次数限制）：用**状态机 DP**，每天在几个状态之间转移。冷冻期需要三个状态。

## 最优解法

**思路**：

- `hold`：今天结束时持有股票的最大利润；
- `sold`：今天刚卖出（明天是冷冻期）；
- `rest`：今天结束时不持有，且不在冷冻期（明天可以买）。

转移：`hold = max(hold, rest − p)`（继续持有，或者从可以买的状态买入）；`sold = hold + p`；`rest = max(rest, sold)`（昨天卖的今天解冻）。三个新值都用**昨天**的旧值计算（Python 同时赋值保证了这一点）。

```python
def maxProfit(prices):
    hold, sold, rest = float("-inf"), 0, 0     # 持有 / 今天刚卖出 / 不持有且不在冷冻期
    for p in prices:
        hold, sold, rest = max(hold, rest - p), hold + p, max(rest, sold)
    return max(sold, rest)
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 买入只能从 `rest` 转移，不能从 `sold`（冷冻期）转移。
- 分开写三行赋值时用了今天刚更新的值：要先保存旧值。
- 初始 `hold = −∞`（第一天之前不可能持有）。
