# 算法图解库

按数据结构和题型整理面试核心题。每道题写全所有常见解法，关键题配逐步可视化，复习时点「播放」就能想起整个过程。刷题语言是 Python，面试官要求用主语言时附 Java 版。

## 怎么用

1. **按章节过一遍**：先看每章的「核心框架」，再做表里的题。
2. **每题写全解法**：在题目页里填思路、代码、复杂度，标记 `status: done`。
3. **画图**：在 `tools/traces/` 里写一个 trace 脚本，生成执行过程的动画。
4. **复习**：每周从「近两年出现在」次数多的题里挑 5 道，闭卷写一遍。
