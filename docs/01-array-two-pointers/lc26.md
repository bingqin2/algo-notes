# 26. 删除有序数组中的重复项

> [力扣 26](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序数组原地去重，返回新长度：读写双指针（快慢指针）。

## 关键点

- 写指针 k 指向下一个要写的位置，只有当前数和结果里最后一个数不同时才写入。
- 和**结果里**的最后一个（`nums[k−1]`）比较，而不是和原数组的前一个比较。O(n) 时间，O(1) 空间。

```python
def removeDuplicates(nums):
    k = 0                                  # nums[:k] 是去重后的结果
    for x in nums:
        if k == 0 or x != nums[k - 1]:
            nums[k] = x
            k += 1
    return k
```
