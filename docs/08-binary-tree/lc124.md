# 124. 二叉树中的最大路径和

> [力扣 124](https://leetcode.cn/problems/binary-tree-maximum-path-sum/) · 近两年面经里出现在：**腾讯 · 最右笔试**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

二叉树里「路径」可以从任意结点到任意结点，**不一定经过根**。这类题的套路是后序遍历，每个结点做两件事：

1. **更新答案**：把自己当成路径的「最高点」，左右两边都可以带上。
2. **返回给父结点**：父结点要接上来，路径就不能分叉，只能带上一边。

腾讯后台开发和最右笔试都考过。同一套路的题还有 [543 二叉树的直径](./lc543)。

## 解法：后序遍历，返回单边最大贡献

<StepPlayer src="/viz/lc124.json" />

```python
def maxPathSum(root):
    best = float("-inf")
    def gain(node):                        # 从 node 往下走的单边路径最大和
        nonlocal best
        if not node: return 0
        l = max(gain(node.left), 0)        # 负数就不要
        r = max(gain(node.right), 0)
        best = max(best, node.val + l + r) # 以 node 为最高点的路径
        return node.val + max(l, r)        # 往上只能带一边
    gain(root)
    return best
```

**复杂度**：时间 O(n)，空间 O(h)。

**为什么要和 0 取 max？** 子树的贡献是负数时，不如不要这一边。

**为什么 best 初始化成负无穷？** 结点值可能全是负数，答案是最大的那个负数，至少要选一个结点。

## 易错点

- 返回值写成 `node.val + l + r`：父结点接上来的路径会在当前结点分叉，不是合法路径。
- best 初始化成 0：全负数的树会返回 0。
- 在 Python 里修改外层变量要用 `nonlocal`，或者用列表、类属性。

## 面试追问

- **二叉树的直径？** [543](./lc543)：一模一样的结构，只是「贡献」变成深度，更新答案时是 `左深度 + 右深度`。
- **路径必须从根出发？** 那就不需要更新全局答案，直接返回根的单边贡献。
- **要输出路径上的结点？** 每个结点除了返回贡献值，还要返回贡献来自哪一边；更新 best 时记下最高点，最后从最高点向两边沿着「来源」往下拼。
- **多叉树？** 每个结点取贡献最大的两个孩子（求最大的两个数），其余一样。

## Java 版

```java
private int best = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    gain(root);
    return best;
}

private int gain(TreeNode node) {
    if (node == null) return 0;
    int l = Math.max(gain(node.left), 0);
    int r = Math.max(gain(node.right), 0);
    best = Math.max(best, node.val + l + r);
    return node.val + Math.max(l, r);
}
```
