# 61. 旋转链表

> [力扣 61](https://leetcode.cn/problems/rotate-list/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

链表向右旋转 k 位：先连成环，再在合适的位置断开。

## 关键点

- 求长度 n，`k %= n`；新的尾结点是第 `n − k` 个，新头是它的下一个。
- k 为 0 或 n 的倍数时直接返回，否则成环后忘了断开会死循环。

```python
def rotateRight(head, k):
    if not head:
        return None
    n, tail = 1, head
    while tail.next:
        n, tail = n + 1, tail.next
    k %= n
    if k == 0:
        return head
    tail.next = head                       # 先连成环
    new_tail = head
    for _ in range(n - k - 1):             # 新的尾是第 n-k 个
        new_tail = new_tail.next
    new_head = new_tail.next
    new_tail.next = None                   # 再断开
    return new_head
```
