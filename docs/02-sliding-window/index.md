# 滑动窗口

## 核心框架

右指针扩张、左指针收缩，窗口内维护一个可增量更新的状态（计数、和、最大值）。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [3. 无重复字符的最长子串](./lc3) | 字节 ×3 · 小米 | 哈希集合 + 收缩左边界 / 记录最后出现位置，left 直接跳 |
| [76. 最小覆盖子串](./lc76) | 高频经典 | need/window 计数 + valid 计数 |
| [239. 滑动窗口最大值](./lc239) | 腾讯 | 暴力 O(nk) / 大顶堆 + 懒删除 O(n log n) / 单调递减队列 O(n) |
| [1004. 最大连续 1 的个数 III / 01 数组最长连续子数组](./lc1004) | 美团 | 窗口内 0 的个数 ≤ k |
| [438. 找到字符串中所有字母异位词](./lc438) | 高频经典 | 固定窗口 + 计数数组 |
