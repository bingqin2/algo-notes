# 94. 二叉树的中序遍历

> [力扣 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

中序遍历的**迭代**写法：栈，一路向左压栈，弹出访问，再转向右子树。

## 关键点

- 递归写法三行；面试常要求迭代。
- O(1) 空间的做法是 **Morris 遍历**：利用叶子的空右指针临时指回后继，遍历完恢复。

```python
def inorderTraversal(root):
    res, stack, cur = [], [], root
    while cur or stack:
        while cur:                         # 一路向左压栈
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res
```
