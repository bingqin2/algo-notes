# 12. 整数转罗马数字

> [力扣 12](https://leetcode.cn/problems/integer-to-roman/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

整数转罗马数字：把 13 个面值（包括 900、400、90、40、9、4 这些减法形式）从大到小排好，**贪心**能减就减。

## 关键点

- 把 CM、CD 这类特殊组合直接放进表里，就不用单独处理减法规则。
- 输入不超过 3999，循环次数有上限，O(1)。

```python
def intToRoman(num):
    table = [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"),
             (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")]
    res = []
    for v, sym in table:                   # 贪心：每次减去能减的最大值
        while num >= v:
            num -= v
            res.append(sym)
    return "".join(res)
```
