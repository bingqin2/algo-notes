# 253. 会议室 II

> [力扣 253](https://leetcode.cn/problems/meeting-rooms-ii/)（会员题） · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

一堆区间，问**同一时刻最多有几个重叠**（最少要几间会议室、最少几辆车、最多同时在线人数）。两种做法：小顶堆模拟分配房间；扫描线数重叠数。

## 解法一：小顶堆存结束时间

**思路**：按开始时间排序。堆里存每间正在用的房间什么时候空出来。新会议开始时，如果堆顶（最早空出来的那间）已经空了（结束时间 ≤ 开始时间），就复用，把它的结束时间换成新的；否则新开一间。最后堆的大小就是答案。

```python
import heapq

def minMeetingRooms(intervals):
    intervals.sort(key=lambda p: p[0])
    ends = []                              # 正在用的会议室的结束时间
    for s, e in intervals:
        if ends and ends[0] <= s:          # 最早结束的那间空出来了，复用
            heapq.heapreplace(ends, e)
        else:
            heapq.heappush(ends, e)
    return len(ends)
```

**复杂度**：时间 O(n log n)，空间 O(n)。这个写法还能顺便告诉你每个会议分到了哪间房。

## 解法二：扫描线：起点 +1 终点 −1

**思路**：每个会议拆成两个事件：开始时 +1、结束时 −1。按时间排序后依次累加，过程中的最大值就是答案。

同一时刻既有结束又有开始：要**先结束再开始**（`[1, 5]` 和 `[5, 10]` 只要一间）。事件写成 `(时间, ±1)`，−1 自然排在 +1 前面。

```python
def minMeetingRooms(intervals):
    events = []
    for s, e in intervals:
        events.append((s, 1))
        events.append((e, -1))
    events.sort()                          # 同一时刻 -1 排在 +1 前面：先散会再开会
    cur = best = 0
    for _, d in events:
        cur += d
        best = max(best, cur)
    return best
```

**复杂度**：时间 O(n log n)，空间 O(n)。时间范围小的话可以用差分数组代替排序，O(n + T)。

## 解法三：开始时间和结束时间分别排序

**思路**：扫描线的另一种写法。开始时间和结束时间各自排序，用指针 j 指向最早还没结束的会议。每来一个开始时间 s：如果 `s < ends[j]`，没有会议结束，要多一间；否则有一间空出来，j 前进，房间数不变。

```python
def minMeetingRooms(intervals):
    starts = sorted(s for s, _ in intervals)
    ends = sorted(e for _, e in intervals)
    rooms = j = 0
    for s in starts:
        if s < ends[j]:                    # 还没有会议结束，要新开一间
            rooms += 1
        else:                              # 有一间空出来了
            j += 1
    return rooms
```

## 易错点

- 堆的写法忘了先按开始时间排序。
- 扫描线同一时刻先 +1 后 −1：端点相接的会议会被算成重叠。
- 堆的写法每次只弹一个就够了：只关心有没有空房间，不用把所有已结束的都弹出来（弹多了不影响答案，但没必要）。

## 面试追问

- **三种写法怎么选？** 要知道分配方案用堆；只要数量用扫描线，代码最短；坐标范围小用差分数组。
- **会议室 I（252）？** 排序后检查相邻两个是否重叠，就是问答案是否 ≤ 1。
- **同时在线人数峰值（日志里有登录登出时间）？** 就是这题的扫描线。数据量大时按时间分桶做差分。
- **[1094 拼车](../07-hash-prefix-sum/lc1094)？** 每段带人数，起点 +人数，终点 −人数，检查是否超过容量。

## Java 版

```java
public int minMeetingRooms(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    PriorityQueue<Integer> ends = new PriorityQueue<>();
    for (int[] iv : intervals) {
        if (!ends.isEmpty() && ends.peek() <= iv[0]) ends.poll();   // 复用最早空出来的
        ends.offer(iv[1]);
    }
    return ends.size();
}

public int minMeetingRoomsSweep(int[][] intervals) {
    int n = intervals.length;
    int[] starts = new int[n], ends = new int[n];
    for (int i = 0; i < n; i++) { starts[i] = intervals[i][0]; ends[i] = intervals[i][1]; }
    Arrays.sort(starts);
    Arrays.sort(ends);
    int rooms = 0, j = 0;
    for (int s : starts) {
        if (s < ends[j]) rooms++;
        else j++;
    }
    return rooms;
}
```
