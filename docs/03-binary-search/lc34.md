# 34. 在排序数组中查找元素的第一个和最后一个位置

> [力扣 34](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

有序数组里找某个值的**起止位置**：两次二分找边界。只写一个 lower_bound 函数就够了：起点 = `lower_bound(target)`，终点 = `lower_bound(target + 1) − 1`。

## 最优解法

**思路**：lower_bound 找第一个 ≥ t 的位置。起点处要检查是否越界、是否真的等于 target，不等于说明不存在。

```python
def searchRange(nums, target):
    def lower_bound(t):
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] < t:
                lo = mid + 1
            else:
                hi = mid
        return lo

    first = lower_bound(target)
    if first == len(nums) or nums[first] != target:
        return [-1, -1]
    return [first, lower_bound(target + 1) - 1]
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 易错点

- 找到 target 后向两边线性扩展：全是 target 的数组退化成 O(n)。
- `lower_bound(target + 1)` 只适用于整数；浮点数或者一般情况用 upper_bound（第一个 > t，把 `<` 改成 `<=`）。
- 起点检查 `first == len(nums)` 要在访问 `nums[first]` 之前。
