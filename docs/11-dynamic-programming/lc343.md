# 343. 整数拆分

> [力扣 343](https://leetcode.cn/problems/integer-break/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把 n 拆成至少两个正整数，求乘积最大：`dp[i]` 是拆 i 的最大乘积，枚举拆出的第一个数 j，剩下的 `i − j` 可以继续拆（`dp[i−j]`）或者不拆（`i − j` 本身）。

## 最优解法

```python
def integerBreak(n):
    dp = [0] * (n + 1)                     # dp[i]：把 i 拆成至少两个数的最大乘积
    for i in range(2, n + 1):
        for j in range(1, i):              # 拆出第一个数 j，剩下的 i-j 拆或不拆
            dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
    return dp[n]
```

**复杂度**：时间 O(n²)，空间 O(n)。

**数学解法**：尽量拆成 3。余数为 1 时，把一个 3 + 1 换成 2 + 2（4 > 3）；余数为 2 时多乘一个 2。O(1)（快速幂 O(log n)）。

```python
def integerBreak(n):
    if n <= 3:
        return n - 1
    q, r = divmod(n, 3)                    # 尽量拆成 3
    if r == 0:
        return 3 ** q
    if r == 1:
        return 3 ** (q - 1) * 4            # 3 + 1 不如 2 + 2
    return 3 ** q * 2
```

## 易错点

- 转移时漏了 `j · (i − j)`（剩下的不再拆）：`dp[i − j]` 是「至少拆成两个」，比如 `dp[3] = 2 < 3`。
- n = 2、3 时答案是 1、2（必须拆）。
