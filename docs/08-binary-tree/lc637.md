# 637. 二叉树的层平均值

> [力扣 637](https://leetcode.cn/problems/average-of-levels-in-binary-tree/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

每层的平均值：层序遍历，每层求和除以个数。

## 关键点

- 用 `len(q)` 固定这一层的个数。O(n)。

```python
from collections import deque

def averageOfLevels(root):
    res, q = [], deque([root])
    while q:
        s, n = 0, len(q)
        for _ in range(n):
            node = q.popleft()
            s += node.val
            for c in (node.left, node.right):
                if c:
                    q.append(c)
        res.append(s / n)
    return res
```
