# 909. 蛇梯棋

> [力扣 909](https://leetcode.cn/problems/snakes-and-ladders/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

掷骰子最少几次到终点：每个格子是点，向后 1~6 格是边，**BFS**。难点在蛇形编号转行列。

## 关键点

- 编号 s（从 1 开始）：`r, c = divmod(s − 1, n)`，行是 `n − 1 − r`（从底往上数），r 是奇数时列要反过来 `n − 1 − c`。
- 走到有蛇或梯子的格子时**只传送一次**：到了目的地不再看那里的蛇或梯子。
- 访问标记用传送后的格子。O(n²)。

```python
from collections import deque

def snakesAndLadders(board):
    n = len(board)

    def pos(s):                            # 编号 s（1 开始）→ 行列，蛇形
        r, c = divmod(s - 1, n)
        row = n - 1 - r
        col = c if r % 2 == 0 else n - 1 - c
        return row, col

    dist = {1: 0}
    q = deque([1])
    while q:
        s = q.popleft()
        if s == n * n:
            return dist[s]
        for nxt in range(s + 1, min(s + 6, n * n) + 1):
            r, c = pos(nxt)
            if board[r][c] != -1:
                nxt = board[r][c]          # 只走一次梯子或蛇，不连续传送
            if nxt not in dist:
                dist[nxt] = dist[s] + 1
                q.append(nxt)
    return -1
```
