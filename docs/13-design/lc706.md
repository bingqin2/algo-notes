# 706. 设计哈希映射

> [力扣 706](https://leetcode.cn/problems/design-hashmap/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

不用内置哈希表实现 HashMap：数组 + 链地址法（每个桶一个链表），key 对桶数取模。

## 关键点

- 桶数取质数（如 1009），减少规律性的 key 撞到同一个桶。
- put 先在桶里找，存在就更新，否则追加；remove 找到后和最后一个交换再删。
- 追问：负载因子超过阈值（Java HashMap 是 0.75）时扩容为两倍并 rehash；Java 8 里一个桶超过 8 个元素会转成红黑树。

```python
class MyHashMap:
    def __init__(self):
        self.size = 1009                   # 取质数，分布更均匀
        self.buckets = [[] for _ in range(self.size)]

    def put(self, key, value):
        b = self.buckets[key % self.size]
        for pair in b:
            if pair[0] == key:
                pair[1] = value
                return
        b.append([key, value])

    def get(self, key):
        for k, v in self.buckets[key % self.size]:
            if k == key:
                return v
        return -1

    def remove(self, key):
        b = self.buckets[key % self.size]
        for i, (k, _) in enumerate(b):
            if k == key:
                b[i] = b[-1]               # 和最后一个交换后删除，O(1)
                b.pop()
                return
```
