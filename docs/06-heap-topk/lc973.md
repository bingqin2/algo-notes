# 973. 最接近原点的 K 个点

> [力扣 973](https://leetcode.cn/problems/k-closest-points-to-origin/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

Top K 问题的模板：求最小的 k 个，用**大小为 k 的大顶堆**（堆顶是这 k 个里最大的，新元素比它小就替换）。

## 最优解法

**思路**：距离用平方 `x² + y²` 比较，不用开根号。Python 用存负数的小顶堆模拟大顶堆：堆不满 k 个直接放；满了且新点比堆顶（最远的）更近，`heapreplace` 替换。

```python
import heapq

def kClosest(points, k):
    heap = []                              # 大顶堆（存负距离），保留最近的 k 个
    for x, y in points:
        d = -(x * x + y * y)
        if len(heap) < k:
            heapq.heappush(heap, (d, x, y))
        elif d > heap[0][0]:               # 比堆里最远的还近，替换
            heapq.heapreplace(heap, (d, x, y))
    return [[x, y] for _, x, y in heap]
```

**复杂度**：时间 O(n log k)，空间 O(k)。

**其他做法**：排序 O(n log n)；快速选择平均 O(n)（见 [215](../00-sorting/lc215)）。

## 易错点

- 用小顶堆存全部点再弹 k 次：O(n + k log n)，也行，但空间 O(n)。
- 求最小的 k 个用**大**顶堆，求最大的 k 个用**小**顶堆，容易搞反。
