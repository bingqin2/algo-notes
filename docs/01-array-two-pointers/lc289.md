# 289. 生命游戏

> [力扣 289](https://leetcode.cn/problems/game-of-life/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

所有格子要根据**同一时刻**的状态同时更新，又要求原地：用额外的位存「下一个状态」。

## 关键点

- 最低位是当前状态，第二位存下一代状态；统计邻居时只看 `& 1`。全部算完后统一右移一位。
- 也可以用 2、−1 之类的特殊值表示「活变死」「死变活」。O(mn) 时间，O(1) 空间。

```python
def gameOfLife(board):
    m, n = len(board), len(board[0])
    for i in range(m):
        for j in range(n):
            live = sum(board[x][y] & 1 for x in range(max(0, i - 1), min(m, i + 2))
                       for y in range(max(0, j - 1), min(n, j + 2)) if (x, y) != (i, j))
            if board[i][j] & 1 and live in (2, 3) or not board[i][j] & 1 and live == 3:
                board[i][j] |= 2           # 第 2 位存下一代的状态，第 1 位保持当前状态
    for i in range(m):
        for j in range(n):
            board[i][j] >>= 1
    return board
```
