# 378. 有序矩阵中第 K 小的元素

> [力扣 378](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

行列都有序的矩阵里找第 k 小：**值域二分**：猜一个值 x，统计矩阵里 ≤ x 的个数（从左下角走，O(n)），找第一个个数 ≥ k 的 x。

## 最优解法

**思路**：答案在 `[matrix[0][0], matrix[n-1][n-1]]` 之间。`count_le(x)` 从左下角出发：当前值 ≤ x，这一列上面的都 ≤ x，计数加 `r + 1`，向右；否则向上。二分找第一个满足 `count_le(x) >= k` 的 x，它一定是矩阵里的某个值。

```python
def kthSmallest(matrix, k):
    n = len(matrix)

    def count_le(x):                       # 矩阵里 <= x 的个数，从左下角走 O(n)
        r, c, cnt = n - 1, 0, 0
        while r >= 0 and c < n:
            if matrix[r][c] <= x:
                cnt += r + 1               # 这一列从 0 到 r 都 <= x
                c += 1
            else:
                r -= 1
        return cnt

    lo, hi = matrix[0][0], matrix[-1][-1]
    while lo < hi:                         # 找第一个 count_le(x) >= k 的 x
        mid = (lo + hi) // 2
        if count_le(mid) >= k:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**复杂度**：时间 O(n log(max − min))，空间 O(1)。

**堆的做法**：每行的第一个元素进小顶堆，弹出 k − 1 次，每次弹出后把同一行的下一个元素加进来（多路归并）。O(k log n)，k 小时更快。

```python
import heapq

def kthSmallest(matrix, k):
    n = len(matrix)
    heap = [(matrix[i][0], i, 0) for i in range(min(n, k))]   # 每行第一个
    heapq.heapify(heap)
    for _ in range(k - 1):
        _, i, j = heapq.heappop(heap)
        if j + 1 < n:
            heapq.heappush(heap, (matrix[i][j + 1], i, j + 1))
    return heap[0][0]
```

## 易错点

- 二分条件写成 `count_le(mid) == k` 就返回：mid 可能不在矩阵里。必须用 lower_bound 的写法找第一个满足的值。
- 计数从左上角走：无法判断方向（同 [240](../01-array-two-pointers/lc240)）。
