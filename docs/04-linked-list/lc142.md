# 142. 环形链表 II

> [力扣 142](https://leetcode.cn/problems/linked-list-cycle-ii/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

判断链表有没有环并找到**环的入口**，要求 O(1) 空间：Floyd 判圈。快慢指针相遇后，一个指针回到头，两个都每次走一步，再次相遇的地方就是入口。

## 最优解法

**思路**：设头到入口距离 a，入口到相遇点距离 b，环长 c。相遇时慢指针走了 `a + b`，快指针走了 `2(a + b)`，多走的 `a + b` 是环长的整数倍：`a + b = kc`，所以 `a = kc − b`。从相遇点再走 a 步，正好是绕了 k 圈再退回 b 步，也就是到达入口；而从头走 a 步也到入口，两者在入口相遇。

```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:                   # 相遇后，一个从头走，一个从相遇点走
            p = head
            while p is not slow:
                p, slow = p.next, slow.next
            return p
    return None
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 比较结点用 `is`（同一个对象），不要比较 val。
- 快指针判断 `fast and fast.next`，否则无环时访问 None 的 next。
- 慢指针在第一圈之内就会被追上，所以 b < c，推导成立。
