# 739. 每日温度

> [力扣 739](https://leetcode.cn/problems/daily-temperatures/) · 近两年面经里出现在：**腾讯**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

对每个元素，找**右边第一个比它大**的元素。这就是单调栈的模板题。

单调栈的套路：栈里存「还没找到答案」的元素。新元素来了，把栈里所有比它小的弹出，它就是这些元素的答案。所以栈从底到顶是递减的。

## 解法一：暴力 O(n²)

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    for i in range(n):
        for j in range(i + 1, n):
            if temperatures[j] > temperatures[i]:
                ans[i] = j - i
                break
    return ans
```

**复杂度**：时间 O(n²)，n = 10⁵ 会超时。

## 解法二：单调递减栈存下标

**思路**：从左往右遍历，栈里存下标，对应的温度递减。当前温度比栈顶高时，栈顶的答案就是 `i − 栈顶`，弹出，继续比较。最后把 i 入栈。

```python
def dailyTemperatures(temperatures):
    ans = [0] * len(temperatures)
    st = []                                # 存下标，对应温度从栈底到栈顶递减
    for i, t in enumerate(temperatures):
        while st and temperatures[st[-1]] < t:
            j = st.pop()                   # i 就是 j 右边第一个更高的
            ans[j] = i - j
        st.append(i)
    return ans                             # 留在栈里的下标，答案保持 0
```

**复杂度**：时间 O(n)：每个下标只入栈一次、出栈一次。空间 O(n)。

## 解法三：从右往左跳

**思路**：从右往左算。要找 i 右边第一个更高的，从 j = i + 1 开始：如果 j 不够高，那比 j 还矮的都不用看，直接跳到 j 右边第一个比 j 高的（`j + ans[j]`）。ans[j] = 0 说明 j 右边没有更高的，i 也就没有。

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    for i in range(n - 2, -1, -1):
        j = i + 1
        while temperatures[j] <= temperatures[i]:
            if ans[j] == 0:                # j 右边没有更高的，i 也不会有
                j = i
                break
            j += ans[j]                    # 直接跳到比 j 高的那一天
        ans[i] = j - i
    return ans
```

**复杂度**：时间 O(n)（均摊），额外空间 O(1)（不算答案数组）。

## 单调栈怎么选方向

| 要找 | 遍历方向 | 栈的单调性 | 什么时候出栈 |
|---|---|---|---|
| 右边第一个更大 | 从左往右 | 递减 | 当前 > 栈顶 |
| 右边第一个更小 | 从左往右 | 递增 | 当前 < 栈顶 |
| 左边第一个更大 | 从左往右 | 递减 | 当前 ≥ 栈顶，出完后的栈顶就是答案 |

记法：**找更大，栈就递减**；答案在出栈时得到。

## 易错点

- 栈里存温度而不是下标：没法算天数。
- 比较用 `<` 还是 `<=`：题目要「更高」，相等的不算，所以 `<` 时才出栈。
- 栈里剩下的元素答案是 0，数组初始化为 0 就不用再处理。

## Java 版

```java
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] ans = new int[n];
    Deque<Integer> st = new ArrayDeque<>();  // 下标，温度单调递减
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && temperatures[st.peek()] < temperatures[i]) {
            int j = st.pop();
            ans[j] = i - j;
        }
        st.push(i);
    }
    return ans;
}
```
