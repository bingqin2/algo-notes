# 72. 编辑距离

> [力扣 72](https://leetcode.cn/problems/edit-distance/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

两个字符串之间的最少编辑次数：双串 DP，`dp[i][j]` 表示 word1 前 i 个变成 word2 前 j 个的最少操作数。最后一个字符相同就不用操作，不同就从插入、删除、替换三种里取最小。

## 最优解法

**思路**：

- 边界：`dp[i][0] = i`（删光），`dp[0][j] = j`（全插入）。
- `word1[i−1] == word2[j−1]`：`dp[i][j] = dp[i−1][j−1]`。
- 否则 `1 + min(dp[i−1][j]（删除 word1 的这个字符）, dp[i][j−1]（插入 word2 的这个字符）, dp[i−1][j−1]（替换）)`。

```python
def minDistance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]   # dp[i][j]：word1 前 i 个变成 word2 前 j 个的最少操作
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],      # 删除 word1[i-1]
                                   dp[i][j - 1],      # 插入 word2[j-1]
                                   dp[i - 1][j - 1])  # 替换
    return dp[m][n]
```

**复杂度**：时间 O(mn)，空间 O(mn)，可以压缩成 O(n)。

## 易错点

- 边界初始化漏了：第 0 行、第 0 列不是 0。
- 三种操作分别对应哪个格子说不清楚：面试时一定要能解释。

**追问**：只允许插入和删除？去掉替换那一项，答案等于 `m + n − 2 · LCS`。
