# 动态规划

## 核心框架

定义 dp 含义 → 写转移方程 → 定初始值 → 确定遍历顺序 → 能否压缩空间。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [198. 打家劫舍 I / II / III](./lc198) | 字节 ×4 | dp[i] = max(dp[i-1], dp[i-2]+nums[i]) / 环形：拆成两段（213） / 树形 DP（337） |
| [300. 最长递增子序列](./lc300) | 字节 ×2 · 滴滴 | O(n²) DP / 贪心 + 二分 O(n log n) |
| [5. 最长回文子串](./lc5) | 字节 ×2 | 中心扩展 O(n²) / 区间 DP / Manacher O(n) |
| [53. 最大子数组和 / 乘积最大子数组（152）](./lc53) | 字节 ×2 · 小红书 | Kadane：以 i 结尾的最大和 / 152 同时维护最大和最小 |
| [121. 买卖股票的最佳时机（系列）](./lc121) | 字节 · 快手 | 一次交易：维护历史最低价 / 状态机 DP：持有/不持有 |
| [322. 零钱兑换](./lc322) | 美团 | 完全背包：dp[x] = min(dp[x-c]+1) / BFS 求最少步数 |
