# 48. 旋转图像

> [力扣 48](https://leetcode.cn/problems/rotate-image/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

原地旋转矩阵 90°：分解成两次**翻转**。顺时针 = 转置 + 每行左右翻转；逆时针 = 转置 + 上下翻转（或每行翻转 + 转置）。

## 最优解法

**思路**：顺时针旋转后，原来的 `(i, j)` 到了 `(j, n−1−i)`。转置把 `(i, j)` 变成 `(j, i)`，再左右翻转把 `(j, i)` 变成 `(j, n−1−i)`，正好。

```python
def rotate(matrix):
    n = len(matrix)
    for i in range(n):                     # 沿主对角线转置
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:                     # 每行左右翻转
        row.reverse()
    return matrix
```

**复杂度**：时间 O(n²)，空间 O(1)。

## 易错点

- 转置时 j 从 0 开始：每对元素被交换两次，等于没换。要从 `i + 1` 开始。
- 另一种写法是一圈一圈、每次四个元素轮换（`tmp = a; a = d; d = c; c = b; b = tmp`），下标容易写错，翻转法更不容易出错。
