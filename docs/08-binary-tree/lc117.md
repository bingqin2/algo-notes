# 117. 填充每个节点的下一个右侧节点指针 II

> [力扣 117](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node-ii/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

给每个结点的 next 指向同一层右边的结点，要求 O(1) 空间：利用**已经连好的上一层**的 next 遍历上一层，同时把下一层串起来。

## 关键点

- 下一层用一个哑结点 + 尾指针拼接；这一层走完，下一层的头就是 `dummy.next`。
- BFS 用队列也可以，但空间 O(n)。

```python
def connect(root):                           # 结点有 next 指针；O(1) 空间
    head = root
    while head:
        dummy = tail = Node(0)             # 下一层的链表（哑结点）
        cur = head
        while cur:                         # 沿着这一层已经连好的 next 走
            for child in (cur.left, cur.right):
                if child:
                    tail.next = child
                    tail = child
            cur = cur.next
        head = dummy.next
    return root
```
