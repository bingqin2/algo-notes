# 86. 分隔链表

> [力扣 86](https://leetcode.cn/problems/partition-list/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

按值把链表分成两部分、保持相对顺序：拆成「小于 x」和「≥ x」两条链，最后首尾相接。

## 关键点

- 两个哑结点分别当两条链的头。
- **大链表的尾要置空**：它原来的 next 可能指向小链表里的结点，不断开会成环。

```python
def partition(head, x):
    small = s = ListNode()
    large = l = ListNode()
    while head:
        if head.val < x:
            s.next = head; s = s.next
        else:
            l.next = head; l = l.next
        head = head.next
    l.next = None                          # 必须断开，否则可能成环
    s.next = large.next
    return small.next
```
