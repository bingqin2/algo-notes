# 204. 计数质数

> [力扣 204](https://leetcode.cn/problems/count-primes/) · 中等 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

统计小于 n 的质数个数：**埃氏筛**。

## 关键点

- 从 2 开始，每遇到一个质数 i，把 i² 开始的倍数都标成合数（小于 i² 的倍数已经被更小的质数筛过）。
- 外层只需要到 √n。时间 O(n log log n)，空间 O(n)。
- 线性筛（欧拉筛）每个合数只筛一次，O(n)，面试一般不要求。

```python
def countPrimes(n):
    if n < 3:
        return 0
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, n, i):   # 从 i² 开始，更小的倍数已经被更小的质数筛过
                is_prime[j] = False
    return sum(is_prime)
```
