# 88. 合并两个有序数组

> [力扣 88](https://leetcode.cn/problems/merge-sorted-array/) · 近两年面经里出现在：**美团 ×2 · 小米**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

两个有序数组合并，而且 **nums1 后面有空位**。从前往后放会覆盖 nums1 还没处理的元素，**从后往前放就不会**。

## 解法一：合并后排序

```python
def merge(nums1, m, nums2, n):
    nums1[m:] = nums2
    nums1.sort()
```

**复杂度**：时间 O((m + n) log(m + n))，没有利用有序。面试只能当第一句话说。

## 解法二：从后往前双指针 O(1) 空间

**思路**：i、j 分别指向 nums1、nums2 的最后一个有效元素，k 指向 nums1 的末尾。每次把两个里更大的放到 k。

**为什么不会覆盖**：k 右边一共放了 (m − 1 − i) + (n − 1 − j) 个元素，k = i + j + 1 ≥ i + 1，k 始终在 i 的右边，写入的位置要么是空位，要么是已经被移走的元素。

nums2 放完就可以结束：nums1 剩下的元素本来就在正确的位置。

```python
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1      # 从后往前放大的数，不会覆盖没处理的元素
    while j >= 0:                          # nums2 放完就结束，nums1 剩下的已经在原位
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

**复杂度**：时间 O(m + n)，空间 O(1)。

## 易错点

- 循环条件写成 `i >= 0 and j >= 0`，结束后忘了把 nums2 剩下的拷进去。上面的写法以 `j >= 0` 为条件，一步到位。
- 从前往后合并：会覆盖 nums1。要从前往后就得先把 nums1 的前 m 个复制出来，空间 O(m)。
- Python 里 `nums1 = sorted(...)` 只是改了局部变量，题目要求原地修改，要写 `nums1[:] = ...`。

## 面试追问

- **合并 k 个有序数组？** 小顶堆，O(N log k)；或者两两分治合并，见 [23. 合并 K 个升序链表](../04-linked-list/lc23)。
- **两个有序数组的中位数？** 不合并，二分，O(log(m + n))，见 [4](../03-binary-search/lc4)。
- **归并排序里的 merge 步骤？** 就是这题，只是要一个辅助数组。

## Java 版

```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    while (j >= 0) {
        if (i >= 0 && nums1[i] > nums2[j]) nums1[k--] = nums1[i--];
        else nums1[k--] = nums2[j--];
    }
}
```
