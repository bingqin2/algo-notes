# 718. 最长重复子数组

> [力扣 718](https://leetcode.cn/problems/maximum-length-of-repeated-subarray/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

两个数组的最长公共**子数组**（要求连续）：和 [LCS](./lc1143) 的区别是不相等时直接归 0。`dp[i][j]` 定义为**以** `nums1[i−1]` 和 `nums2[j−1]` **结尾**的公共子数组长度，答案是所有 dp 的最大值。

## 最优解法

**思路**：相等时 `dp[i][j] = dp[i−1][j−1] + 1`，否则 0。压缩成一维时 j 倒序，保证 `dp[j−1]` 还是上一行的值。

```python
def findLength(nums1, nums2):
    m, n = len(nums1), len(nums2)
    dp = [0] * (n + 1)                     # dp[j]：以 nums1[i-1] 和 nums2[j-1] 结尾的公共子数组长度
    best = 0
    for i in range(1, m + 1):
        for j in range(n, 0, -1):          # 倒序，dp[j-1] 还是上一行的值
            dp[j] = dp[j - 1] + 1 if nums1[i - 1] == nums2[j - 1] else 0
            best = max(best, dp[j])
    return best
```

**复杂度**：时间 O(mn)，空间 O(n)。

**更快的做法**：二分长度 + 滚动哈希，O((m + n) log min(m, n))。

## 易错点

- 一维正序：`dp[j−1]` 已经是这一行的新值了。
- 答案取过程中的最大值，不是 `dp[m][n]`。
