# 208. 实现 Trie (前缀树)

> [力扣 208](https://leetcode.cn/problems/implement-trie-prefix-tree/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

大量字符串的前缀查询（自动补全、拼写检查、敏感词过滤）：**前缀树（Trie）**。每个结点代表一个前缀，孩子按字符索引，`is_end` 标记这里是否是一个完整单词的结尾。

## 最优解法

**思路**：insert 沿着字符往下走，没有的结点就创建，最后标记 `is_end`。search 和 startsWith 共用一个「沿前缀走到底」的函数：search 要求走到的结点 `is_end` 为真，startsWith 只要能走到。

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            node = node.children.setdefault(ch, Trie())
        node.is_end = True

    def _find(self, prefix):
        node = self
        for ch in prefix:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_end

    def startsWith(self, prefix):
        return self._find(prefix) is not None
```

**复杂度**：每个操作 O(L)（L 是单词长度）；空间 O(所有单词的总长度 × 字符集)。

## 易错点

- search 只检查路径存在：插入了 "apple" 后 search("app") 应该是 False。
- 孩子用固定长度 26 的数组（Java 里常见）还是哈希表：数组更快，哈希表在字符集大时更省空间。
