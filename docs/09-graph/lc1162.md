# 1162. 地图分析

> [力扣 1162](https://leetcode.cn/problems/as-far-from-land-as-possible/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

求每个海洋格子到**最近陆地**的距离（再取最大）：从每个海洋格子分别 BFS 是 O(n⁴)。反过来，把**所有陆地同时作为起点**做一次多源 BFS，每个海洋格子第一次被访问时的层数就是它到最近陆地的距离。

## 最优解法

**思路**：所有陆地入队，一层一层向外扩，每扩一层距离 +1，最后一层的层数就是答案。全是陆地或全是海洋返回 −1。

```python
from collections import deque

def maxDistance(grid):
    n = len(grid)
    q = deque((r, c) for r in range(n) for c in range(n) if grid[r][c] == 1)
    if len(q) in (0, n * n):
        return -1
    dist = -1
    while q:                               # 所有陆地同时出发，一层一层向外扩
        dist += 1
        for _ in range(len(q)):
            r, c = q.popleft()
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 0:
                    grid[nr][nc] = 2
                    q.append((nr, nc))
    return dist
```

**复杂度**：时间 O(n²)，空间 O(n²)。

## 易错点

- 层数从 −1 开始计：第一轮处理的是陆地本身（距离 0）。
- 多源 BFS 等价于加一个「超级源点」连向所有陆地，再做普通 BFS。
