# 哈希与前缀和

## 核心框架

「之前出现过什么」用哈希表；「区间和」用前缀和；两者组合解决子数组计数。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [1. 两数之和](./lc1) | 高频经典 | 哈希表一次遍历 |
| [128. 最长连续序列](./lc128) | 得物 | 哈希集合，只从序列起点开始数 |
| [560. 和为 K 的子数组](./lc560) | 高频经典 | 前缀和 + 哈希表计数 |
| [525. 连续数组（0 和 1 数量相等）](./lc525) | 美团 | 0 看成 -1，前缀和 + 最早出现位置 |
