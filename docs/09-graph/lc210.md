# 210. 课程表 II

> [力扣 210](https://leetcode.cn/problems/course-schedule-ii/) · 中等 · 来源：面试经典 150 · 面经 · 近两年面经：**腾讯 WXG（输出拓扑序）**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

[207](./lc207) 的升级版：不仅要判断能不能修完，还要**输出一个合法的修课顺序**，也就是拓扑序。有环时返回空数组。

## 解法一：Kahn 算法，出队顺序就是拓扑序

**思路**：和 207 一样，入度为 0 的课先入队。每出队一门课就把它加入结果，它的后续课入度减 1，减到 0 入队。结果长度小于课程数说明有环。

<StepPlayer src="/viz/lc210.json" />

```python
from collections import deque

def findOrder(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses
    for a, b in prerequisites:
        graph[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)                    # 出队顺序就是拓扑序
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == numCourses else []
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

## 解法二：DFS 后序的逆序

**思路**：DFS 一个点时，要等它的**所有后续课**都处理完才把它加入列表（后序）。所以在后序列表里，每门课都排在它的后续课之后，**反转**过来就是拓扑序。判环用 207 的三色标记。

```python
def findOrder(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        graph[b].append(a)
    state = [0] * numCourses
    post = []                              # 后序：一门课在它的所有后续课之后才加入

    def dfs(u):
        state[u] = 1
        for v in graph[u]:
            if state[v] == 1:
                return False
            if state[v] == 0 and not dfs(v):
                return False
        state[u] = 2
        post.append(u)
        return True

    for i in range(numCourses):
        if state[i] == 0 and not dfs(i):
            return []
    return post[::-1]                      # 后序反过来就是拓扑序
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

## 两种解法对比

| | Kahn（BFS） | DFS 后序 |
|---|---|---|
| 顺序怎么得到 | 出队顺序 | 后序再反转 |
| 判环 | 结果长度 < V | 遇到灰色的点 |
| 递归 | 无 | 有，图很深时可能栈溢出 |
| 扩展 | 按层得到「每一学期修哪些课」；用优先队列可以得到字典序最小的拓扑序 | 适合顺便求强连通分量等 |

## 易错点

- DFS 版忘了反转后序。
- DFS 版在递归**进入**时加入列表（前序）：前序不是拓扑序，比如 0→2、1→2，从 0 出发前序是 [0, 2, 1]，2 排在了 1 前面。
- 有环时要返回空数组，而不是已经得到的部分顺序。

## 面试追问

- **拓扑序唯一吗？** 不一定。Kahn 过程中队列里始终最多只有一个元素时才唯一。
- **要字典序最小的拓扑序？** 把队列换成小顶堆。
- **任务有执行时间，求最短完成时间？** 关键路径：按拓扑序做 DP，finish[v] = max(finish[u]) + time[v]。
- **有循环依赖时要报出环上是哪几门课？** DFS 遇到灰色的点 v 时，递归栈里从 v 到当前点的那一段就是环。

## Java 版

```java
public int[] findOrder(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    int[] indeg = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);
        indeg[p[0]]++;
    }
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i);
    int[] order = new int[numCourses];
    int k = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[k++] = u;
        for (int v : graph.get(u))
            if (--indeg[v] == 0) q.offer(v);
    }
    return k == numCourses ? order : new int[0];
}
```
