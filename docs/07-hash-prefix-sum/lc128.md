# 128. 最长连续序列

> [力扣 128](https://leetcode.cn/problems/longest-consecutive-sequence/) · 近两年面经里出现在：**得物**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

无序数组里找**值连续**的最长一段（不要求在数组里相邻），要求 O(n)。排序是 O(n log n)，要 O(n) 就得用哈希集合 O(1) 查「x + 1 在不在」。

## 解法一：排序 O(n log n)

去重排序后扫一遍，相邻差 1 就延长，否则重新计数。面试时先说这个，再说要求 O(n) 怎么办。

```python
def longestConsecutive(nums):
    if not nums:
        return 0
    nums = sorted(set(nums))
    best = cur = 1
    for a, b in zip(nums, nums[1:]):
        cur = cur + 1 if b == a + 1 else 1
        best = max(best, cur)
    return best
```

## 解法二：哈希集合，只从序列起点开始数

**思路**：所有数放进集合。对每个 x，如果 x − 1 也在集合里，x 就不是起点，跳过；否则从 x 往后数 x + 1、x + 2……直到断开。

为什么是 O(n)：只有起点才会往后数，每个数最多被「往后数」访问一次（它只属于一段）。外层循环 n 次，内层 while 总共 n 次。

```python
def longestConsecutive(nums):
    s = set(nums)
    best = 0
    for x in s:                            # 遍历集合而不是原数组，重复元素只处理一次
        if x - 1 in s:                     # 不是起点，跳过
            continue
        y = x
        while y + 1 in s:
            y += 1
        best = max(best, y - x + 1)
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法三：并查集

**思路**：每个数是一个结点，x 和 x ± 1 都在的话合并。最后最大的集合大小就是答案。适合**数是一个个加进来**、要随时回答当前最长连续段的场景。

```python
def longestConsecutive(nums):
    parent, size = {}, {}

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # 路径压缩（隔代）
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra == rb:
            return
        if size[ra] < size[rb]:
            ra, rb = rb, ra
        parent[rb] = ra
        size[ra] += size[rb]

    for x in nums:
        if x in parent:
            continue
        parent[x], size[x] = x, 1
        if x - 1 in parent:
            union(x, x - 1)
        if x + 1 in parent:
            union(x, x + 1)
    return max(size[find(x)] for x in parent) if parent else 0
```

**复杂度**：近似 O(n)（路径压缩 + 按大小合并，每次操作接近 O(1)）。

## 易错点

- 不判断起点，对每个数都往后数：`[1, 2, …, n]` 这种输入退化成 O(n²)。
- 遍历原数组而不是集合：原数组里有大量重复的起点时（比如 n 个 1 再加一段长序列），每个重复的起点都会数一遍，又变成 O(n²)。遍历集合就没有这个问题。
- 空数组返回 0。

## 面试追问

- **哈希集合真的是 O(1) 吗？** 均摊 O(1)。Java 的 `HashSet<Integer>` 有装箱开销，n = 10⁵ 时实际可能比排序还慢，但复杂度上是 O(n)。
- **要输出这段序列本身？** 记下最优的起点 x 和长度，输出 x..x+len−1。
- **数据流，数一个个来？** 并查集，或者哈希表存「以 x 为端点的段长」（加入 x 时合并左右两段，只更新两端的值）。

## Java 版

```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) set.add(x);
    int best = 0;
    for (int x : set) {
        if (set.contains(x - 1)) continue;             // 只从起点开始数
        int y = x;
        while (set.contains(y + 1)) y++;
        best = Math.max(best, y - x + 1);
    }
    return best;
}
```
