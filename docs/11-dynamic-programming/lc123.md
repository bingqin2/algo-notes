# 123. 买卖股票的最佳时机 III

> [力扣 123](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

股票最多交易两次：状态机 DP，四个状态：第一次买入后、第一次卖出后、第二次买入后、第二次卖出后的最大收益。

## 关键点

- 依次更新 `b1 = max(b1, −p)`、`s1 = max(s1, b1 + p)`、`b2 = max(b2, s1 − p)`、`s2 = max(s2, b2 + p)`。
- 同一天里用刚更新的值没关系：相当于当天买当天卖，收益是 0，不影响结果。
- O(n) 时间，O(1) 空间。

```python
def maxProfit(prices):
    b1 = b2 = float("-inf")
    s1 = s2 = 0
    for p in prices:
        b1 = max(b1, -p)                   # 第一次买入后的最大收益
        s1 = max(s1, b1 + p)               # 第一次卖出后
        b2 = max(b2, s1 - p)               # 第二次买入后
        s2 = max(s2, b2 + p)               # 第二次卖出后
    return s2
```
