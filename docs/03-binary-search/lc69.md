# 69. x 的平方根 

> [力扣 69](https://leetcode.cn/problems/sqrtx/) · 近两年面经里出现在：**高频经典**
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

求整数平方根（向下取整）：答案 m 是「最后一个满足 m² ≤ x 的数」，单调，**对答案二分**；数学上还可以用牛顿迭代。

## 解法一：对答案二分

**思路**：在 [0, x] 上找最后一个 `mid² ≤ x` 的 mid。找「最后一个满足」时，`lo = mid`，所以 mid 要**上取整** `(lo + hi + 1) // 2`，否则 lo、hi 相邻时 mid 一直等于 lo，死循环。

<StepPlayer src="/viz/lc69.json" />

```python
def mySqrt(x):
    lo, hi = 0, x
    while lo < hi:                         # 找最后一个 m*m <= x，用「上取整」的 mid 防止死循环
        mid = (lo + hi + 1) // 2
        if mid * mid <= x:
            lo = mid
        else:
            hi = mid - 1
    return lo
```

**复杂度**：O(log x)。

## 解法二：牛顿迭代

**思路**：求 f(r) = r² − x 的零点，切线迭代 `r = (r + x / r) / 2`。整数版本从 r = x 开始，`r * r > x` 时继续迭代，结果会从上方单调收敛到 ⌊√x⌋。

```python
def mySqrt(x):
    if x < 2:
        return x
    r = x
    while r * r > x:
        r = (r + x // r) // 2              # 切线与 x 轴的交点，整数版本
    return r
```

**复杂度**：二次收敛，迭代次数约 O(log x) 但实际很少。

## 易错点

- Java 里 `mid * mid` 溢出：用 long，或者比较 `mid <= x / mid`。
- 上取整和下取整的 mid 与 `lo = mid` / `hi = mid` 要配对。
- 直接用 `int(x ** 0.5)`：x 很大时浮点误差可能差 1。
