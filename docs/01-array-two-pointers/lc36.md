# 36. 有效的数独

> [力扣 36](https://leetcode.cn/problems/valid-sudoku/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

数独是否有效：每行、每列、每个 3×3 宫里数字不重复。一次遍历，用 27 个集合（或者位掩码）记录。

## 关键点

- 宫的编号 `(i // 3) * 3 + j // 3`。
- 只检查已填的数是否冲突，不需要判断能不能解出来。

```python
def isValidSudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    for i in range(9):
        for j in range(9):
            v = board[i][j]
            if v == ".":
                continue
            b = (i // 3) * 3 + j // 3      # 第几个 3×3 宫
            if v in rows[i] or v in cols[j] or v in boxes[b]:
                return False
            rows[i].add(v); cols[j].add(v); boxes[b].add(v)
    return True
```
