# 1631. 最小体力消耗路径

> [力扣 1631](https://leetcode.cn/problems/path-with-minimum-effort/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

路径的代价不是边权之和，而是路径上的**最大边权**，求代价最小的路径：Dijkstra 的变体（把「加」换成「取最大」仍然满足贪心性质）。也可以二分答案 + BFS，或者并查集按边权从小到大合并。

## 最优解法

**思路**：`best[r][c]` 是到达这个格子的最小「最大高度差」。小顶堆按这个值弹出，弹出终点时就是答案。扩展邻居时，新代价 = `max(当前代价, 这一步的高度差)`，更小才更新并入堆。

```python
import heapq

def minimumEffortPath(heights):
    m, n = len(heights), len(heights[0])
    best = [[float("inf")] * n for _ in range(m)]
    best[0][0] = 0
    heap = [(0, 0, 0)]                     # (路径上的最大高度差, r, c)
    while heap:
        e, r, c = heapq.heappop(heap)
        if (r, c) == (m - 1, n - 1):
            return e
        if e > best[r][c]:
            continue                       # 过期的记录
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < m and 0 <= nc < n:
                ne = max(e, abs(heights[nr][nc] - heights[r][c]))
                if ne < best[nr][nc]:
                    best[nr][nc] = ne
                    heapq.heappush(heap, (ne, nr, nc))
    return 0
```

**复杂度**：时间 O(mn log(mn))，空间 O(mn)。

**二分答案**：猜一个阈值 t，只走高度差 ≤ t 的边，BFS 看能不能到终点；t 越大越容易，单调，二分。O(mn log(max))。

## 易错点

- 用普通 BFS：步数最少不等于代价最小。
- 弹出时没跳过过期记录（`e > best[r][c]`）：不影响正确性，但会多做很多无用扩展。
