# 704. 二分查找

> [力扣 704](https://leetcode.cn/problems/binary-search/) · 近两年面经里出现在：**腾讯 CSIG**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

有序数组里找一个值，或者找**第一个 / 最后一个**满足条件的位置。二分的思路简单，难在边界。这一页把两种最常用的写法固定下来，之后所有二分题都套这两种。

## 解法一：标准二分（闭区间）

**思路**：搜索区间是闭区间 [lo, hi]，区间不为空（`lo <= hi`）就继续。mid 不是答案时，答案一定不在 mid，所以 `lo = mid + 1` 或 `hi = mid − 1`。

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1              # 闭区间 [lo, hi]
    while lo <= hi:                        # 区间不为空
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 解法二：lower_bound / upper_bound 写法（左闭右开）

**思路**：找**第一个 ≥ target** 的位置（lower_bound）。区间是 [lo, hi)，hi 从 n 开始，表示「可能一个都不满足」。

- `nums[mid] < target`：mid 和它左边都不满足，`lo = mid + 1`；
- 否则 mid 满足，但左边可能还有更早的，`hi = mid`（不能减 1，mid 可能就是答案）。

循环结束时 lo == hi，就是答案。把 `<` 换成 `<=` 就得到 upper_bound（第一个 > target）。

```python
def lower_bound(nums, target):            # 第一个 >= target 的下标，没有就返回 len
    lo, hi = 0, len(nums)                  # 左闭右开 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1                   # mid 太小，答案在右边
        else:
            hi = mid                       # mid 可能就是答案，留着
    return lo
```

```python
def upper_bound(nums, target):            # 第一个 > target 的下标
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] <= target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

```python
def search(nums, target):
    i = lower_bound(nums, target)
    return i if i < len(nums) and nums[i] == target else -1
```

**复杂度**：时间 O(log n)，空间 O(1)。

## 用 lower_bound 能解决的问题

| 要找 | 写法 |
|---|---|
| target 是否存在 | `i = lower_bound(t)`，检查 `i < n and nums[i] == t` |
| 第一个 = t 的位置（[34](./lc34)） | 同上 |
| 最后一个 = t 的位置 | `upper_bound(t) − 1`，再检查是否等于 t |
| t 出现了几次 | `upper_bound(t) − lower_bound(t)` |
| 插入位置（[35](./lc35)） | `lower_bound(t)` |
| 最后一个 < t 的位置 | `lower_bound(t) − 1` |

**更一般的二分**：只要能写出一个**单调**的判断函数 check(x)（前面都是 False，后面都是 True），就能用 lower_bound 的写法找第一个 True。「二分答案」类题（[875](./lc875)、[1011](./lc1011)、[410](./lc410)）都是这样。

Python 自带 `bisect.bisect_left` / `bisect_right`，就是 lower_bound / upper_bound；Java 的 `Arrays.binarySearch` 有重复元素时不保证返回哪一个，找边界要自己写。

## 易错点

- 闭区间写成 `while lo < hi`：区间里只剩一个元素时没检查。
- 左闭右开写成 `hi = mid − 1`：可能跳过答案。
- `lo = mid` 而不是 `mid + 1`：区间只剩两个元素时 mid == lo，死循环。
- Java 里 `(lo + hi) / 2` 可能溢出：写成 `lo + (hi − lo) / 2` 或 `(lo + hi) >>> 1`。

## 面试追问

- **两种写法怎么选？** 找具体某个值用闭区间；找边界（第一个、最后一个）用左闭右开的 lower_bound。记住一种找边界的写法就够了，其他都由它推出来。
- **为什么二分是 O(log n)？** 每次区间减半，n 个元素最多减半 log₂ n 次。
- **数组是旋转过的？** 见 [33](./lc33)。
- **二维有序矩阵？** 当成一维数组二分（[74](./lc74)），或者从右上角开始走（[240](../01-array-two-pointers/lc240)）。

## Java 版

```java
public int search(int[] nums, int target) {
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;                 // 防止 lo + hi 溢出
        if (nums[mid] == target) return mid;
        if (nums[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

public int lowerBound(int[] nums, int target) {       // 第一个 >= target 的下标
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}
```
