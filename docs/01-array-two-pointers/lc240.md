# 240. 搜索二维矩阵 II

> [力扣 240](https://leetcode.cn/problems/search-a-2d-matrix-ii/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每行递增、每列递增的矩阵里找一个数：从**右上角**（或左下角）出发，每一步排除一行或一列，O(m + n)。

## 最优解法

**思路**：右上角的数是这一行最大、这一列最小。

- 比 target 大：这一列下面的都更大，排除这一列，c 左移；
- 比 target 小：这一行左边的都更小，排除这一行，r 下移。

```python
def searchMatrix(matrix, target):
    m, n = len(matrix), len(matrix[0])
    r, c = 0, n - 1                        # 从右上角出发
    while r < m and c >= 0:
        v = matrix[r][c]
        if v == target:
            return True
        if v > target:
            c -= 1                         # 这一列下面都更大，排除这一列
        else:
            r += 1                         # 这一行左边都更小，排除这一行
    return False
```

**复杂度**：时间 O(m + n)，空间 O(1)。

## 易错点

- 从左上角出发不行：比 target 小时，右边和下面都更大，不知道往哪走。
- 和 [74](../03-binary-search/lc74) 区分：74 的矩阵每行第一个数大于上一行最后一个数，整体有序，可以当成一维数组二分，O(log mn)。
