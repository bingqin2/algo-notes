# 201. 数字范围按位与

> [力扣 201](https://leetcode.cn/problems/bitwise-and-of-numbers-range/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

[left, right] 所有数按位与：结果就是 left 和 right 二进制的**公共前缀**，后面全是 0。

## 关键点

- 区间里只要跨过某一位的进位，这一位以下就一定出现过 0。
- 写法一：两个数同时右移直到相等，再左移回去。写法二：`right &= right − 1` 不断去掉最低位的 1，直到 `right ≤ left`。O(log n)。

```python
def rangeBitwiseAnd(left, right):
    while left < right:
        right &= right - 1                 # 不断去掉 right 最低位的 1，直到不超过 left
    return right
```
