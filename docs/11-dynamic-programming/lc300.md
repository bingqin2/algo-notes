# 300. 最长递增子序列

> [力扣 300](https://leetcode.cn/problems/longest-increasing-subsequence/) · 近两年面经里出现在：**字节 ×2 · 滴滴**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

最长递增子序列（LIS），子序列可以不连续。字节考了 2 次，其中一次明确要求 **O(n log n)**，滴滴也考过。面试一般先写 O(n²)，再被要求优化。

## 解法一：O(n²) DP

**思路**：dp[i] = 以 nums[i] **结尾**的最长递增子序列长度。往前找所有比它小的 nums[j]，接在后面：dp[i] = max(dp[j] + 1)。答案是 dp 里的最大值。

```python
def lengthOfLIS(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]: dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

**复杂度**：时间 O(n²)，空间 O(n)。

## 解法二：贪心 + 二分，O(n log n)

**思路**：维护数组 tails，tails[k] = 所有长度为 k+1 的递增子序列中，**最小的结尾**。结尾越小，后面越容易接上更长的。

对每个 x：

- x 比 tails 里所有数都大：接在最后，长度加一。
- 否则，用二分找到第一个 ≥ x 的位置，替换成 x（同样长度，但结尾更小了）。

tails 一直是递增的，所以可以二分。

```python
from bisect import bisect_left

def lengthOfLIS(nums):
    tails = []                     # tails[k]：长度为 k+1 的递增子序列的最小结尾
    for x in nums:
        i = bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)
```

**复杂度**：时间 O(n log n)，空间 O(n)。

## 易错点

- tails 不是真正的最长递增子序列，只有它的**长度**是对的。比如 [3, 4, 1]，结束时 tails = [1, 4]，而 [1, 4] 并不是原数组的子序列。
- 严格递增用 `bisect_left`（找第一个 ≥ x）；如果题目是「非递减」，要改成 `bisect_right`（找第一个 > x）。
- O(n²) 解法的答案是 `max(dp)`，不是 `dp[-1]`。

## 面试追问

- **要输出具体的子序列？** O(n²) 解法里记录每个 dp[i] 的前驱 j，从最大值往回找。O(n log n) 解法里，记录每个元素放进 tails 时的位置和它前一个位置上的元素下标。
- **求最长递增子序列的个数？** 见 [673](./lc673)：除了 dp[i]（长度），再维护 cnt[i]（方案数）。
- **二维（信封嵌套）？** 见 [354 俄罗斯套娃信封](./lc354)：按宽度升序、宽度相同时高度降序排序，再对高度做 LIS。高度降序是为了避免相同宽度的信封互相套。

## Java 版

```java
public int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int len = 0;
    for (int x : nums) {
        int lo = 0, hi = len;                // 在 tails[0..len) 里找第一个 >= x 的位置
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;
        if (lo == len) len++;
    }
    return len;
}
```
