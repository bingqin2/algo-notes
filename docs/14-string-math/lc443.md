# 443. 压缩字符串

> [力扣 443](https://leetcode.cn/problems/string-compression/) · 中等 · 来源：面经 · 近两年面经：**腾讯 ×2（字符串压缩）**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「原地修改数组，返回新长度」：**读写双指针**。read 往前读，write 写结果，只要压缩后的结果不会比原串长（write 永远 ≤ read），就能在同一个数组里写。

## 解法一：读写双指针原地压缩（443）

**思路**：

1. read 从当前位置找到这段相同字符的结尾，个数 `cnt = read − start`。
2. 在 write 处写这个字符；cnt > 1 时再把 cnt 的每一位数字写进去（12 要写成 '1'、'2' 两个字符）。
3. 重复直到 read 到末尾，返回 write。

为什么不会覆盖还没读的内容：一段长度为 cnt 的字符压缩后最多占 1 + cnt 的位数个格子，cnt ≥ 2 时 1 + 位数 ≤ cnt，cnt = 1 时只占 1 格。所以 write 永远不会超过 read。

```python
def compress(chars):
    write = read = 0
    n = len(chars)
    while read < n:
        start = read
        while read < n and chars[read] == chars[start]:
            read += 1
        chars[write] = chars[start]
        write += 1
        cnt = read - start
        if cnt > 1:
            for d in str(cnt):             # 次数可能是多位数
                chars[write] = d
                write += 1
    return write
```

**复杂度**：时间 O(n)，空间 O(1)。

## 解法二：返回新字符串的版本（面试金典 01.06）

面试里更常见的说法：`"aabcccccaaa"` 压缩成 `"a2b1c5a3"`，**每个字符后面都写次数**（包括 1），压缩后没有变短就返回原串。用一个列表拼接，最后比较长度。

```python
def compressString(s):
    """面试金典 01.06：aabcccccaaa -> a2b1c5a3；没有变短就返回原串。"""
    parts, i = [], 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        parts.append(s[i] + str(j - i))
        i = j
    t = "".join(parts)
    return t if len(t) < len(s) else s
```

**复杂度**：时间 O(n)，空间 O(n)。

## 追问：解压

面试官经常接着让写解压：`"a2b1c12"` 还原。读到字母后，把后面连续的数字都读完，转成次数（次数可能是多位数）。

```python
def decompress(s):
    """a2b1c12 -> aabcccccccccccc"""
    res, i = [], 0
    while i < len(s):
        c = s[i]
        i += 1
        j = i
        while j < len(s) and s[j].isdigit():
            j += 1
        res.append(c * int(s[i:j]))
        i = j
    return "".join(res)
```

## 易错点

- 次数是多位数时只写了一个字符：12 写成 `chr(12)` 或者只写 '2'。
- 443 里 cnt = 1 不写次数，01.06 里每个都写：先问清楚格式。
- 01.06 用字符串 `+=` 拼接：Java 里每次都复制，要用 StringBuilder。
- 解压时只读一位数字。

## 面试追问

- **字符本身就是数字怎么办（"aa111"）？** 这种格式会有歧义，要换编码，比如 `次数 + 分隔符 + 字符`，或者固定用 1 个字节存次数。
- **这种压缩什么时候有用？** 叫游程编码（RLE），适合连续重复多的数据，比如位图、传真黑白图像、列式数据库里排好序的列。随机文本反而会变长。
- **流式压缩？** 记住上一个字符和当前次数，字符变化时输出一段。

## Java 版

```java
public int compress(char[] chars) {
    int write = 0, read = 0, n = chars.length;
    while (read < n) {
        int start = read;
        while (read < n && chars[read] == chars[start]) read++;
        chars[write++] = chars[start];
        int cnt = read - start;
        if (cnt > 1) for (char d : Integer.toString(cnt).toCharArray()) chars[write++] = d;
    }
    return write;
}
```
