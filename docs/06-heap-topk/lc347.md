# 347. 前 K 个高频元素

> [力扣 347](https://leetcode.cn/problems/top-k-frequent-elements/) · 近两年面经里出现在：**美团 ×3 · 字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

按**频率**取前 K 个。分两步：先用哈希表计数，再从「元素 → 频率」里选频率最大的 k 个。第二步有三种做法，美团考了 3 次，常追问「能不能比 O(n log n) 更快」。

## 解法一：计数 + 小顶堆 O(n log k)

**思路**：维护一个大小为 k 的**小顶堆**，按频率比较。每放进一个，堆超过 k 就弹出堆顶（当前最小的频率）。最后堆里剩下的就是频率最大的 k 个。

为什么用小顶堆：堆顶是「前 k 名里最弱的那个」，新来的只要比它强就把它挤掉。

```python
from collections import Counter
import heapq

def topKFrequent(nums, k):
    cnt = Counter(nums)
    heap = []                              # 小顶堆，存 (频率, 数)，大小保持 k
    for x, c in cnt.items():
        heapq.heappush(heap, (c, x))
        if len(heap) > k:
            heapq.heappop(heap)            # 弹出频率最小的，留下的是前 k 大
    return [x for _, x in heap]
```

**复杂度**：时间 O(n log k)，空间 O(n)。

## 解法二：桶排序 O(n)

**思路**：频率最多是 n。开 n + 1 个桶，`buckets[c]` 放出现 c 次的数。从高频桶往低频桶取，取够 k 个就停。

```python
from collections import Counter

def topKFrequent(nums, k):
    cnt = Counter(nums)
    buckets = [[] for _ in range(len(nums) + 1)]   # buckets[c]：出现 c 次的数
    for x, c in cnt.items():
        buckets[c].append(x)
    res = []
    for c in range(len(nums), 0, -1):      # 从高频往低频取
        for x in buckets[c]:
            res.append(x)
            if len(res) == k:
                return res
    return res
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法三：快速选择

**思路**：对 (元素, 频率) 列表按频率做快排式的划分（大的放左边），只递归包含第 k 个位置的那一边。划分点正好落在 k − 1 时，左边就是前 k 个。

```python
from collections import Counter
import random

def topKFrequent(nums, k):
    cnt = Counter(nums)
    items = list(cnt.items())

    def partition(lo, hi):                 # 按频率从大到小划分
        p = random.randint(lo, hi)
        items[p], items[hi] = items[hi], items[p]
        pivot, i = items[hi][1], lo
        for j in range(lo, hi):
            if items[j][1] > pivot:
                items[i], items[j] = items[j], items[i]
                i += 1
        items[i], items[hi] = items[hi], items[i]
        return i

    lo, hi = 0, len(items) - 1
    while lo < hi:                         # 让第 k 大的频率落在下标 k-1
        p = partition(lo, hi)
        if p == k - 1:
            break
        if p < k - 1:
            lo = p + 1
        else:
            hi = p - 1
    return [x for x, _ in items[:k]]
```

**复杂度**：期望 O(n)，最坏 O(n²)（随机主元让最坏情况概率极低）。

## 三种解法怎么选

| 解法 | 时间 | 适合 |
|---|---|---|
| 小顶堆 | O(n log k) | k 远小于 n；数据是流，不能一次拿到全部 |
| 桶排序 | O(n) | 频率范围有限（这里最多是 n） |
| 快速选择 | 期望 O(n) | 一次性拿到全部数据，可以修改 |

数据量大到内存放不下时，见 [海量数据 Top K](./stream-topk)。

## 易错点

- 用大顶堆把所有元素放进去再弹 k 次：O(n log n)，没有利用 k 小。
- 小顶堆写成按元素值比较，而不是按频率。
- 桶的大小开成 max(nums)：频率最多是 n，不是数值范围。

## 面试追问

- **频率相同时要按字典序？** 见 [692](./lc692)：比较规则要加一层。
- **数据是流，随时要查前 k？** 计数用哈希表，前 k 名用小顶堆维护，见 [海量数据 Top K](./stream-topk)。
- **第 K 大的元素（不是频率）？** 同样三种思路，见 [215](../00-sorting/lc215)。

## Java 版

```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    for (int x : nums) cnt.merge(x, 1, Integer::sum);
    PriorityQueue<int[]> heap = new PriorityQueue<>((p, q) -> p[1] - q[1]);   // 按频率的小顶堆
    for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
        heap.offer(new int[]{e.getKey(), e.getValue()});
        if (heap.size() > k) heap.poll();
    }
    int[] res = new int[k];
    for (int i = 0; i < k; i++) res[i] = heap.poll()[0];
    return res;
}
```
