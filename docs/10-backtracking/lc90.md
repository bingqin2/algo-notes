# 90. 子集 II

> [力扣 90](https://leetcode.cn/problems/subsets-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

有重复元素的子集：[78](./lc78) + [40](./lc40) 的树层去重：排序，同一层跳过和前一个相同的值。

## 最优解法

```python
def subsetsWithDup(nums):
    nums.sort()
    res, path = [], []

    def backtrack(start):
        res.append(path[:])
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:
                continue                   # 同一层跳过相同的数
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return res
```

**复杂度**：时间 O(n · 2ⁿ)，空间 O(n)。

## 易错点

- 去重条件是 `i > start`，不是 `i > 0`。
- 必须先排序。
