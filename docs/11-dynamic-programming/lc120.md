# 120. 三角形最小路径和

> [力扣 120](https://leetcode.cn/problems/triangle/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

三角形从顶到底的最小路径和，每步只能走到下一行的相邻两格：**自底向上** DP 最简单。

## 关键点

- `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`，从倒数第二行往上算，最后 `dp[0]` 就是答案。
- 自顶向下也行，但要处理两端边界，最后还要在底行取最小值。O(n²) 时间，O(n) 空间。

```python
def minimumTotal(triangle):
    dp = triangle[-1][:]                   # 自底向上：dp[j] 是从 (i, j) 走到底的最小和
    for i in range(len(triangle) - 2, -1, -1):
        for j in range(i + 1):
            dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])
    return dp[0]
```
