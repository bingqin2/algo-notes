# 698. 划分为k个相等的子集

> [力扣 698](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把数组分成 k 个和相等的子集：回溯，把每个数依次放进 k 个桶之一。关键在**剪枝**：大数先放、和相同的桶只试一个、超过目标就不放。

## 最优解法

**思路**：

1. 总和不能被 k 整除、或者最大的数比目标大，直接 False。
2. 从大到小排序（大数先放，更早发现失败）。
3. 依次给每个数选一个桶。剪枝：放进去超过 target 不试；**当前和相同的两个桶是等价的**，放进哪个结果都一样，只试第一个（这也包括了「多个空桶只试一个」）。
4. 所有数都放完了就成功（每个桶都不超过 target 且总和 = k × target，所以每个都正好等于 target）。

```python
def canPartitionKSubsets(nums, k):
    total = sum(nums)
    if total % k:
        return False
    target = total // k
    nums.sort(reverse=True)                # 大的先放，更早失败
    if nums[0] > target:
        return False
    buckets = [0] * k

    def backtrack(i):
        if i == len(nums):
            return True                    # 总和相等且每个桶都没超，一定都等于 target
        seen = set()
        for b in range(k):
            if buckets[b] + nums[i] > target or buckets[b] in seen:
                continue                   # 当前和相同的桶，放哪个结果都一样，只试一个
            seen.add(buckets[b])
            buckets[b] += nums[i]
            if backtrack(i + 1):
                return True
            buckets[b] -= nums[i]
        return False

    return backtrack(0)
```

**复杂度**：最坏 O(kⁿ)，剪枝后实际快得多。

**状态压缩 DP**：用 n 位的 mask 表示哪些数已经用了，`dp[mask]` 记录当前未满的桶里的和（取模 target），O(n · 2ⁿ)，n ≤ 16 时稳定。

## 易错点

- 不做「相同和的桶只试一个」剪枝：会超时。
- 回溯时忘了把数从桶里拿出来。
