# 133. 克隆图

> [力扣 133](https://leetcode.cn/problems/clone-graph/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

深拷贝一张图（可能有环）：DFS/BFS 遍历，同时用哈希表记录「原结点 → 复制结点」。

## 关键点

- 哈希表既是 visited，又用来找到已经复制过的结点。
- 一定要**先登记再递归**邻居，否则遇到环会无限递归。
- 题目里的结点类叫 `Node`，这里为了和其他题区分叫 `GNode`。O(V + E)。

```python
class GNode:                               # 133 的图结点（力扣里叫 Node）
    def __init__(self, val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []
```

```python
def cloneGraph(node):
    copies = {}                            # 原结点 -> 复制出的结点

    def dfs(u):
        if u in copies:
            return copies[u]
        c = GNode(u.val)
        copies[u] = c                      # 先登记再递归，处理环
        c.neighbors = [dfs(v) for v in u.neighbors]
        return c

    return dfs(node) if node else None
```
