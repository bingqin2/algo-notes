# 24. 两两交换链表中的节点

> [力扣 24](https://leetcode.cn/problems/swap-nodes-in-pairs/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

链表结点两两交换（不能只交换值）：哑结点 + 每次处理一对。是 [25. K 个一组翻转链表](./lc25) 在 k = 2 时的特例。

## 最优解法

**思路**：`prev` 指向待交换的一对之前的结点。对于 `prev → a → b → rest`，改成 `prev → b → a → rest`，然后 prev 移到 a。三个指针一次赋值，避免顺序问题。

```python
def swapPairs(head):
    dummy = ListNode(0, head)
    prev = dummy
    while prev.next and prev.next.next:
        a, b = prev.next, prev.next.next
        prev.next, a.next, b.next = b, b.next, a     # prev → b → a → 后面
        prev = a
    return dummy.next
```

**复杂度**：时间 O(n)，空间 O(1)。

递归写法更短：`b = head.next; head.next = swapPairs(b.next); b.next = head; return b`，空间 O(n)。

## 易错点

- 分步赋值时顺序错误导致断链：先改 `prev.next = b`，再 `a.next = b.next`，再 `b.next = a`。Python 的多重赋值是先算右边再从左到右赋值，上面代码那种写法是安全的。
- 不用哑结点：头结点会变，要特殊处理。
