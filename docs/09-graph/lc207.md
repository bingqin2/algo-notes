# 207. 课程表

> [力扣 207](https://leetcode.cn/problems/course-schedule/) · 近两年面经里出现在：**字节 ×2 · 腾讯 WXG**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

依赖关系、先后顺序、是否有循环依赖：**有向图判环 / 拓扑排序**。字节考了 2 次，腾讯 WXG 还追问了「输出顺序」（见 [210](./lc210)）。

建图约定：`[a, b]` 表示先修 b 才能修 a，建边 **b → a**（从先修课指向后续课）。

## 解法一：Kahn 算法（入度 BFS）

**思路**：入度 = 还有几门先修课没修。入度为 0 的课可以直接修，先放进队列。每修一门，把它的后续课入度减 1，减到 0 就入队。最后修了的门数等于总课程数，说明没有环。

有环时，环上每门课的入度都至少是 1（来自环上的前一门），永远减不到 0，不会入队。

```python
from collections import deque

def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses
    for a, b in prerequisites:             # 先修 b 才能修 a：边 b → a
        graph[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    done = 0
    while q:
        u = q.popleft()
        done += 1
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:              # 先修课都修完了
                q.append(v)
    return done == numCourses              # 有环时，环上的课入度永远减不到 0
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

Kahn 的动画在 [210](./lc210)：出队顺序就是拓扑序。

## 解法二：DFS 三色标记判环

**思路**：每个点三种状态：

- **白**（0）：还没访问；
- **灰**（1）：在当前 DFS 路径上；
- **黑**（2）：已经访问完，确认从它出发没有环。

DFS 时走到一个**灰色**的点，说明沿着路径绕回来了，有环。走到黑色的点直接跳过。

```python
def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        graph[b].append(a)
    state = [0] * numCourses               # 0 没访问，1 在当前路径上，2 已完成

    def has_cycle(u):
        state[u] = 1
        for v in graph[u]:
            if state[v] == 1:              # 又走回了当前路径上的点：有环
                return True
            if state[v] == 0 and has_cycle(v):
                return True
        state[u] = 2
        return False

    return not any(state[i] == 0 and has_cycle(i) for i in range(numCourses))
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

## 为什么需要三种颜色

只用 visited（两种状态）不够：走到一个访问过的点，不知道它是**在当前路径上**（有环），还是**之前其他路径访问过**（没环，比如菱形 0→1→3、0→2→3，第二次到 3 不是环）。灰和黑就是用来区分这两种情况的。

## 易错点

- 边的方向建反了：判环不受影响，但 210 输出顺序会反。
- 只用 visited 判环：菱形图会被误判为有环。
- 有多个连通分量：DFS 要从每个白色的点都出发一次；Kahn 一开始要把所有入度为 0 的点都入队。

## 面试追问

- **输出一个合法的修课顺序？** 见 [210](./lc210)。
- **最少需要几个学期（每学期可以修多门）？** Kahn 按层 BFS，层数就是答案（1136 题）。
- **无向图判环？** 用并查集：加一条边时两端已经连通，就有环，见 [684](./lc684)。DFS 也行，但要排除「走回父结点」的情况。
- **实际场景？** 构建系统的任务依赖（Maven、Gradle）、Spring Bean 的循环依赖检测、数据库死锁检测（等待图里有环）。

## Java 版

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    int[] indeg = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);
        indeg[p[0]]++;
    }
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i);
    int done = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        done++;
        for (int v : graph.get(u))
            if (--indeg[v] == 0) q.offer(v);
    }
    return done == numCourses;
}
```
