# 219. 存在重复元素 II

> [力扣 219](https://leetcode.cn/problems/contains-duplicate-ii/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

是否存在距离不超过 k 的两个相等元素：哈希表记录每个值**最近一次**出现的下标。

## 关键点

- 也可以用大小为 k 的滑动窗口集合：窗口里已有就返回 True，超过 k 个就删掉最左边的。O(n)。

```python
def containsNearbyDuplicate(nums, k):
    last = {}
    for i, x in enumerate(nums):
        if x in last and i - last[x] <= k:
            return True
        last[x] = i
    return False
```
