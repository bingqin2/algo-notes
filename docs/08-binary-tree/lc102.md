# 102. 二叉树的层序遍历

> [力扣 102](https://leetcode.cn/problems/binary-tree-level-order-traversal/) · 近两年面经里出现在：**字节 ×2**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

按层处理二叉树：层序输出、每层最大值、每层最右边的结点（[199](./lc199)）、锯齿形遍历（[103](./lc103)）、最大宽度（[662](./lc662)）、最小深度。核心技巧是**每一轮先记下队列长度，正好就是这一层的结点数**。

## 解法一：BFS 按层（最常写）

<StepPlayer src="/viz/lc102.json" />

```python
from collections import deque

def levelOrder(root):
    if not root: return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):            # 当前队列里正好是一层
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
```

**复杂度**：时间 O(n)，空间 O(w)，w 是最宽一层的结点数（满二叉树最后一层约 n/2）。

## 解法二：DFS 带深度

**思路**：前序遍历时带上深度，第一次到达某个深度就新建一个列表。因为先左后右，同一层里左边的结点先被加入，顺序正确。

```python
def levelOrder(root):
    res = []
    def dfs(node, depth):
        if not node: return
        if depth == len(res): res.append([])
        res[depth].append(node.val)
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    dfs(root, 0)
    return res
```

**复杂度**：时间 O(n)，空间 O(h)，h 是树高（递归栈）。

## 易错点

- 不记录 `len(q)` 直接循环到队列为空：所有层会混在一起。
- Python 用 `list.pop(0)` 当队列：每次 O(n)。要用 `collections.deque`。
- Java 用 `ArrayDeque` 时不能放 null，入队前要判断孩子不为空。

## 面试追问

- **锯齿形（之字形）层序遍历？** [103](./lc103)：按层遍历，偶数层正常加入，奇数层反转后加入（或用双端队列从头部插入）。
- **从底向上输出？** 正常层序，最后把结果反转。
- **二叉树的最大宽度？** [662](./lc662)：给结点编号（左孩子 2i，右孩子 2i+1），每层宽度 = 最右编号 − 最左编号 + 1。编号可能很大，Python 不怕溢出，Java 要每层把编号减去这一层的最小值。
- **BFS 和 DFS 怎么选？** 和层有关的问题、求最短距离用 BFS；要找路径、需要回溯用 DFS。

## Java 版

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        List<Integer> level = new ArrayList<>();
        for (int size = q.size(); size > 0; size--) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```
