# 977. 有序数组的平方

> [力扣 977](https://leetcode.cn/problems/squares-of-a-sorted-array/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序数组（含负数）的平方排序：平方最大的一定在两端，相向双指针从结果的末尾往前填。

## 关键点

- 比较两端的绝对值，大的平方放到结果的当前末尾。
- O(n) 时间（比排序 O(n log n) 好）。

```python
def sortedSquares(nums):
    n = len(nums)
    res = [0] * n
    l, r = 0, n - 1
    for i in range(n - 1, -1, -1):         # 平方最大的一定在两端，从后往前填
        if abs(nums[l]) > abs(nums[r]):
            res[i] = nums[l] ** 2
            l += 1
        else:
            res[i] = nums[r] ** 2
            r -= 1
    return res
```
