# 39. 组合总和

> [力扣 39](https://leetcode.cn/problems/combination-sum/) · 近两年面经里出现在：**阿里**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

从候选数里选若干个凑成目标和，**同一个数可以重复选**，结果是组合（不同顺序算一种）。

和排列的区别：组合要避免 [2, 3] 和 [3, 2] 重复，办法是**每层只往后选**（传 start）。

## 解法一：start 下标 + 可重复选

**思路**：dfs(start, rest) 表示从 candidates[start:] 里选，还差 rest。递归时传 `i` 而不是 `i + 1`：选了 candidates[i] 之后还可以再选它。

```python
def combinationSum(candidates, target):
    res, path = [], []

    def dfs(start, rest):
        if rest == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):   # 只往后选，避免 [2,3] 和 [3,2] 重复
            c = candidates[i]
            if c > rest:
                continue
            path.append(c)
            dfs(i, rest - c)                       # 传 i 而不是 i+1：同一个数可以重复选
            path.pop()

    dfs(0, target)
    return res
```

**复杂度**：指数级，和答案规模相关。设 T = target，M = 最小的候选数，递归深度最多 T / M。

## 解法二：排序后提前结束

**思路**：先排序。某个候选数已经大于 rest，后面的更大，整层都不用试了，直接 `break`。

```python
def combinationSum(candidates, target):
    candidates = sorted(candidates)
    res, path = [], []

    def dfs(start, rest):
        if rest == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            c = candidates[i]
            if c > rest:                   # 排过序：后面的更大，整层都不用试了
                break
            path.append(c)
            dfs(i, rest - c)
            path.pop()

    dfs(0, target)
    return res
```

**复杂度**：最坏仍是指数级，但剪掉了大量无用分支。

## 组合类问题怎么改

| 题 | 同一个数能重复用吗 | 候选有重复吗 | 递归传 | 去重 |
|---|---|---|---|---|
| 39 组合总和 | 能 | 无 | `i` | start 本身就够 |
| [40](./lc40) 组合总和 II | 不能 | 有 | `i + 1` | 排序 + `i > start and c[i] == c[i−1]` 跳过 |
| [216](./lc216) 组合总和 III | 不能 | 无（1~9） | `i + 1` | 还要限制个数为 k |
| [77](./lc77) 组合 | 不能 | 无 | `i + 1` | 长度为 k 时记录 |

## 易错点

- 递归传了 `i + 1`：每个数只能用一次，变成 40 题。
- 递归传了 `0`：会生成 [2, 3, 2] 这样的重复排列。
- 没排序就 `break`：会漏解；没排序只能 `continue`。

## 面试追问

- **只要组合的个数？** 完全背包，dp[j] += dp[j − c]，外层循环候选数，见 [518. 零钱兑换 II](../11-dynamic-programming/lc518)。
- **要最少用几个数？** 也是完全背包，见 [322. 零钱兑换](../11-dynamic-programming/lc322)。
- **外层循环 target、内层循环候选数会怎样？** 那算的是排列数（顺序不同算不同的），对应 377 题。

## Java 版

```java
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    Arrays.sort(candidates);
    List<List<Integer>> res = new ArrayList<>();
    dfs(candidates, 0, target, new ArrayList<>(), res);
    return res;
}

private void dfs(int[] c, int start, int rest, List<Integer> path, List<List<Integer>> res) {
    if (rest == 0) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < c.length && c[i] <= rest; i++) {   // 排过序，超了就停
        path.add(c[i]);
        dfs(c, i, rest - c[i], path, res);
        path.remove(path.size() - 1);
    }
}
```
