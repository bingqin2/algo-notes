# 547. 省份数量

> [力扣 547](https://leetcode.cn/problems/number-of-provinces/) · 近两年面经里出现在：**华为 OD**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

给一个邻接矩阵，求连通分量的个数。和 [200](./lc200) 本质一样，只是图用矩阵表示。华为 OD 考的就是并查集，所以把并查集模板讲透。

## 解法一：并查集：路径压缩 + 按秩合并

**思路**：每个集合用一棵树表示，`parent[x]` 是 x 的父结点，根结点代表整个集合。

- `find(x)`：一直往上找到根。**路径压缩**：找的过程中把路径上的结点直接挂到根上，下次就快了。
- `union(a, b)`：找到两个根，把一个挂到另一个下面。**按秩合并**：把矮的树挂到高的树下面，树不会变高太快。`rank` 是树高的上界。

一开始有 n 个集合，每成功合并一次少一个。

<StepPlayer src="/viz/lc547.json" />

```python
def findCircleNum(isConnected):
    n = len(isConnected)
    parent = list(range(n))
    rank = [0] * n                         # 树高的上界

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])    # 路径压缩：直接挂到根上
        return parent[x]

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra == rb:
            return False
        if rank[ra] < rank[rb]:            # 按秩合并：矮的挂到高的下面
            ra, rb = rb, ra
        parent[rb] = ra
        if rank[ra] == rank[rb]:
            rank[ra] += 1
        return True

    count = n
    for i in range(n):
        for j in range(i + 1, n):
            if isConnected[i][j] and union(i, j):
                count -= 1
    return count
```

**复杂度**：时间 O(n² · α(n))：要看矩阵里的 n² 个元素。两个优化都用时，单次操作均摊 O(α(n))，可以看作常数；只用路径压缩是 O(log n) 均摊。空间 O(n)。

## 解法二：DFS

**思路**：从每个没访问过的城市出发 DFS，能到达的都标记掉，DFS 了几次就有几个省份。

```python
def findCircleNum(isConnected):
    n = len(isConnected)
    seen = [False] * n

    def dfs(i):
        seen[i] = True
        for j in range(n):
            if isConnected[i][j] and not seen[j]:
                dfs(j)

    count = 0
    for i in range(n):
        if not seen[i]:
            count += 1
            dfs(i)
    return count
```

**复杂度**：时间 O(n²)，空间 O(n)。

## 并查集模板要点

| 部分 | 写法 | 作用 |
|---|---|---|
| 初始化 | `parent[i] = i` | 每个点自成一个集合 |
| find | `parent[x] = find(parent[x])` | 路径压缩 |
| union | 比较 rank，矮的挂到高的下面 | 按秩合并 |
| 计数 | 合并成功就 count − 1 | 直接得到集合个数 |

递归的 find 在链很长时可能栈溢出，可以写成迭代：`while parent[x] != x: parent[x] = parent[parent[x]]; x = parent[x]`（路径减半，[200](./lc200) 解法三就是这么写的）。

## 易错点

- union 时直接 `parent[a] = b`，而不是 `parent[find(a)] = find(b)`：只改了 a 自己，a 所在的集合没有合并。
- 判断是否同一集合时比较 `parent[a] == parent[b]`：要比较 `find(a) == find(b)`。
- 矩阵是对称的，只看 j > i 的一半就够了。

## 面试追问

- **并查集适合什么场景？** 动态地合并集合、查询两个元素是否连通；不支持拆分集合。
- **多余的边（找出让图出现环的那条边）？** 合并时发现两端已经在同一集合，这条边就是，见 [684](./lc684)。
- **带权并查集？** 除法求值（[399](./lc399)）：`parent` 之外再维护「到父结点的比值」，路径压缩时一起更新。
- **最小生成树（Kruskal）？** 边按权重排序，用并查集判断加入后会不会成环，见 [1584](./lc1584)。

## Java 版

```java
private int[] parent, rank;

public int findCircleNum(int[][] isConnected) {
    int n = isConnected.length, count = n;
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (isConnected[i][j] == 1 && union(i, j)) count--;
    return count;
}

private int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}

private boolean union(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return false;
    if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
    parent[rb] = ra;
    if (rank[ra] == rank[rb]) rank[ra]++;
    return true;
}
```
