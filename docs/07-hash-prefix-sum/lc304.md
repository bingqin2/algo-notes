# 304. 二维区域和检索 - 矩阵不可变

> [力扣 304](https://leetcode.cn/problems/range-sum-query-2d-immutable/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

二维矩阵多次查询子矩形的和：**二维前缀和**。预处理 O(mn)，每次查询 O(1)，用容斥原理。

## 最优解法

**思路**：`pre[i][j]` 表示左上角 `i × j` 区域（行 0..i−1、列 0..j−1）的和，多开一行一列避免边界判断。

- 构建：`pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] − pre[i][j] + matrix[i][j]`（上 + 左 − 重复的左上 + 自己）。
- 查询 `(r1, c1)` 到 `(r2, c2)`：`pre[r2+1][c2+1] − pre[r1][c2+1] − pre[r2+1][c1] + pre[r1][c1]`。

```python
class NumMatrix:
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        self.pre = [[0] * (n + 1) for _ in range(m + 1)]    # pre[i][j]：左上角 i 行 j 列的和
        for i in range(m):
            for j in range(n):
                self.pre[i + 1][j + 1] = (self.pre[i][j + 1] + self.pre[i + 1][j]
                                          - self.pre[i][j] + matrix[i][j])

    def sumRegion(self, r1, c1, r2, c2):
        p = self.pre
        return p[r2 + 1][c2 + 1] - p[r1][c2 + 1] - p[r2 + 1][c1] + p[r1][c1]
```

**复杂度**：构建 O(mn)，查询 O(1)，空间 O(mn)。

## 易错点

- 下标偏移：pre 比矩阵多一行一列，查询时右下角要 +1。
- 容斥时减了两次左上角区域，要加回来一次。
