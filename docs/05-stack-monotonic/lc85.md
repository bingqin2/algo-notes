# 85. 最大矩形

> [力扣 85](https://leetcode.cn/problems/maximal-rectangle/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

二进制矩阵中全为 1 的最大矩形：每一行当作底，向上连续的 1 的个数就是柱子高度，转化成 [84. 柱状图中最大的矩形](./lc84)。

## 关键点

- 逐行更新 heights：是 1 就加一，是 0 就归零。
- 每行跑一次单调栈。O(mn)。

```python
def maximalRectangle(matrix):
    if not matrix:
        return 0
    n = len(matrix[0])
    heights = [0] * n
    best = 0
    for row in matrix:
        for j in range(n):                 # 以这一行为底，每列向上连续 1 的高度
            heights[j] = heights[j] + 1 if row[j] == "1" else 0
        h = [0] + heights + [0]            # 84 题的单调栈
        stack = []
        for i, x in enumerate(h):
            while stack and h[stack[-1]] > x:
                height = h[stack.pop()]
                best = max(best, height * (i - stack[-1] - 1))
            stack.append(i)
    return best
```
