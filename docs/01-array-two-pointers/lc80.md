# 80. 删除有序数组中的重复项 II

> [力扣 80](https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序数组去重，每个数最多保留两个：读写双指针，和结果里**倒数第二个**比较。

## 关键点

- 保留 k 个就和 `nums[写指针 − k]` 比较，是 [26](./lc26) 的通用写法。
- O(n) 时间，O(1) 空间。

```python
def removeDuplicates(nums):
    k = 0
    for x in nums:
        if k < 2 or x != nums[k - 2]:      # 和结果里倒数第二个比较
            nums[k] = x
            k += 1
    return k
```
