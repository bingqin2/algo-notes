# 714. 买卖股票的最佳时机含手续费

> [力扣 714](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

无限次交易、每笔交易有手续费：股票状态机 DP，两个状态（持有 / 不持有），卖出时扣手续费。

## 最优解法

**思路**：`hold = max(hold, cash − p)`；`cash = max(cash, hold + p − fee)`。同时赋值用的都是昨天的值。

```python
def maxProfit(prices, fee):
    hold, cash = -prices[0], 0             # 持有股票 / 不持有 时的最大利润
    for p in prices[1:]:
        hold, cash = max(hold, cash - p), max(cash, hold + p - fee)
    return cash
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 手续费在买入和卖出时各扣一次：题目是**一笔交易**扣一次，只在卖出（或只在买入）时扣。
- 贪心「涨了就卖」不适用：手续费让频繁交易不划算。
