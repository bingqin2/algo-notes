# 74. 搜索二维矩阵

> [力扣 74](https://leetcode.cn/problems/search-a-2d-matrix/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

矩阵每行有序，并且每行第一个数大于上一行最后一个数：整个矩阵按行展开就是一个有序数组，直接二分，下标 k 对应 `(k // n, k % n)`。

## 最优解法

```python
def searchMatrix(matrix, target):
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1                  # 当成一个长度 m*n 的有序数组
    while lo <= hi:
        mid = (lo + hi) // 2
        v = matrix[mid // n][mid % n]
        if v == target:
            return True
        if v < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return False
```

**复杂度**：时间 O(log(mn))，空间 O(1)。

## 易错点

- 行号是 `mid // n`（除以**列数**），不是 `mid // m`。
- 也可以先二分找行、再在行里二分，复杂度一样，但边界更多。
- 和 [240](../01-array-two-pointers/lc240) 区分：240 只保证行列各自递增，整体无序，要用右上角出发的方法。
