# 283. 移动零

> [力扣 283](https://leetcode.cn/problems/move-zeroes/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

把 0 移到末尾、保持其他元素的相对顺序：读写双指针，非 0 的和写指针**交换**。

## 关键点

- 用交换而不是覆盖，就不用最后再补 0。
- O(n) 时间，O(1) 空间。

```python
def moveZeroes(nums):
    k = 0
    for i, x in enumerate(nums):
        if x != 0:
            nums[k], nums[i] = nums[i], nums[k]   # 交换而不是覆盖，0 自然被换到后面
            k += 1
    return nums
```
