# 392. 判断子序列

> [力扣 392](https://leetcode.cn/problems/is-subsequence/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断 s 是不是 t 的子序列：双指针，在 t 里依次找 s 的每个字符（贪心：能匹配就匹配）。

## 关键点

- O(|t|) 时间。
- 追问：有大量的 s 要判断？预处理 t 中每个字符出现的所有位置，每次在位置列表里二分找下一个，或者 `next[i][c]` 表示 i 之后字符 c 第一次出现的位置。

```python
def isSubsequence(s, t):
    i = 0
    for ch in t:
        if i < len(s) and s[i] == ch:
            i += 1
    return i == len(s)
```
