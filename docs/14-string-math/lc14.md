# 14. 最长公共前缀

> [力扣 14](https://leetcode.cn/problems/longest-common-prefix/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

最长公共前缀：以第一个串为前缀，和后面的每个串比较，不匹配就缩短。

## 关键点

- 也可以纵向扫描：比较所有串的第 i 个字符，有不同或者某个串到头了就停。
- 或者排序后只比较第一个和最后一个串。时间 O(所有字符总数)。

```python
def longestCommonPrefix(strs):
    prefix = strs[0]
    for s in strs[1:]:
        while not s.startswith(prefix):
            prefix = prefix[:-1]
    return prefix
```
