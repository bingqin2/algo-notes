# 41. 缺失的第一个正数

> [力扣 41](https://leetcode.cn/problems/first-missing-positive/) · 困难 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

要求 O(n) 时间、O(1) 空间，并且答案一定在 [1, n + 1] 范围内：把**数组本身当哈希表**，值 x 放到下标 x − 1 的位置（原地哈希）。

## 最优解法

**思路**：

1. 遍历数组，只要 `nums[i]` 在 [1, n] 内、并且它应该在的位置 `nums[i] − 1` 上还不是它，就交换过去。用 while：换过来的新数也要继续放好。
2. 再遍历一次，第一个 `nums[i] != i + 1` 的位置，答案就是 i + 1；都放对了，答案是 n + 1。

```python
def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        # 把 x 放到下标 x-1 的位置；目标位置已经是 x 就停（防止重复值死循环）
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

**复杂度**：时间 O(n)：每次交换都把一个数放到正确位置，最多 n 次交换。空间 O(1)。

## 易错点

- 循环条件写成 `nums[i] != i + 1`：遇到重复值（比如 `[1, 1]`）会无限交换。必须判断**目标位置**上是不是已经是这个数。
- Python 里 `nums[i], nums[nums[i] − 1] = nums[nums[i] − 1], nums[i]` 有坑：赋值从左到右进行，先改了 `nums[i]`，第二个下标就算错了。先把目标下标存到变量里。
- 负数、0、大于 n 的数直接跳过。
