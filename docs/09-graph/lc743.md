# 743. 网络延迟时间

> [力扣 743](https://leetcode.cn/problems/network-delay-time/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

单源、边权非负、求到所有点的最短距离：**Dijkstra**。信号从 k 传到所有点的时间 = 最短距离里的最大值。

## 最优解法

**思路**（堆优化）：小顶堆存 (距离, 点)。每次弹出距离最小的、还没确定的点，它的距离就确定了；用它更新邻居，把新距离入堆。所有点都确定后取最大值；有点到不了返回 −1。

```python
from collections import defaultdict
import heapq

def networkDelayTime(times, n, k):
    g = defaultdict(list)
    for u, v, w in times:
        g[u].append((v, w))
    dist = {}
    heap = [(0, k)]
    while heap:                            # Dijkstra：每次确定一个最近的点
        d, u = heapq.heappop(heap)
        if u in dist:
            continue
        dist[u] = d
        for v, w in g[u]:
            if v not in dist:
                heapq.heappush(heap, (d + w, v))
    return max(dist.values()) if len(dist) == n else -1
```

**复杂度**：时间 O(E log E)，空间 O(V + E)。

## 易错点

- 弹出时不检查是否已确定：同一个点会被多次处理（堆里有它的旧记录）。用 `if u in dist: continue` 跳过。
- Dijkstra 不能处理**负权边**：一个点被确定后，可能通过负权边得到更短的路径。有负权用 Bellman-Ford 或 SPFA。
