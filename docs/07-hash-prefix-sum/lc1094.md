# 1094. 拼车

> [力扣 1094](https://leetcode.cn/problems/car-pooling/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

很多区间各自加上一个值，最后查每个位置的值（或最大值）：**差分数组**。区间 `[l, r)` 加 v 只要 `diff[l] += v`、`diff[r] −= v`，最后求前缀和。

## 最优解法

**思路**：乘客在 start 上车、在 end 下车（end 这站已经不占座位），所以是区间 `[start, end)`。差分后从左到右累加，任何时刻超过容量就返回 False。

```python
def carPooling(trips, capacity):
    diff = [0] * 1002                      # 差分数组：上车 +num，下车 -num
    for num, start, end in trips:
        diff[start] += num
        diff[end] -= num                   # 在 end 下车，end 这一站已经不占座位
    cur = 0
    for d in diff:
        cur += d
        if cur > capacity:
            return False
    return True
```

**复杂度**：时间 O(n + 站点数)，空间 O(站点数)。

**站点范围很大时**：把上下车事件 `(位置, ±人数)` 排序后扫描（扫描线），O(n log n)，同一位置先下车再上车。

## 易错点

- 区间写成 `[start, end]` 闭区间：end 那站乘客已经下车，多算了。
- 差分数组长度要能放下最大的 end。
