# 84. 柱状图中最大的矩形

> [力扣 84](https://leetcode.cn/problems/largest-rectangle-in-histogram/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

对每个柱子，求它**左边和右边第一个比它矮**的位置，就能算出以它为高的最大矩形：单调递增栈一次求出所有柱子的左右边界。

## 解法一：单调递增栈，左右哨兵

**思路**：

- 栈里存下标，高度单调递增。
- 当前柱子比栈顶矮时，栈顶柱子的右边界就找到了（当前位置 i），它的左边界是弹出后的新栈顶（栈里它下面那个比它矮的），宽度 `i − 新栈顶 − 1`，面积 = 高 × 宽。
- 两端加高度为 0 的**哨兵**：左哨兵保证栈永远不空（不用判断左边界不存在），右哨兵保证遍历结束时所有柱子都被弹出结算。

```python
def largestRectangleArea(heights):
    h = [0] + heights + [0]                # 左右哨兵：左边保证栈不空，右边保证最后全部弹出
    stack, best = [], 0
    for i, x in enumerate(h):
        while stack and h[stack[-1]] > x:
            height = h[stack.pop()]        # 以它为高的矩形，右边界是 i，左边界是新栈顶
            width = i - stack[-1] - 1
            best = max(best, height * width)
        stack.append(i)
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 不加哨兵：要在循环结束后再处理一遍栈里剩下的柱子，还要处理栈空时左边界为 −1 的情况，容易出错。
- 宽度是 `i − stack[-1] − 1`（弹出后的栈顶），不是 `i − j`：被弹出的柱子左边可能还有更高的柱子已经被弹掉了。
- 相等高度：用 `>` 弹出（相等不弹），相等的柱子在后面那个被弹时一起算到，结果正确。
