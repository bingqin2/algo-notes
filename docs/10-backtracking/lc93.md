# 93. 复原 IP 地址

> [力扣 93](https://leetcode.cn/problems/restore-ip-addresses/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把字符串切成满足条件的几段：回溯枚举每段的结束位置。IP 地址是 4 段，每段 1–3 位、不超过 255、不能有前导 0。

## 最优解法

**思路**：path 存已经切好的段。每段尝试长度 1 到 3，非法就停（更长的也不会合法）。剪枝：剩下的字符数必须在 `[剩余段数, 剩余段数 × 3]` 之间。

```python
def restoreIpAddresses(s):
    res, path = [], []

    def backtrack(start):
        if len(path) == 4:
            if start == len(s):
                res.append(".".join(path))
            return
        remain = 4 - len(path)
        if not remain <= len(s) - start <= remain * 3:
            return                         # 剩下的字符太多或太少，剪枝
        for end in range(start + 1, min(start + 3, len(s)) + 1):
            seg = s[start:end]
            if (len(seg) > 1 and seg[0] == "0") or int(seg) > 255:
                break                      # 有前导 0 或超过 255，更长的也不行
            path.append(seg)
            backtrack(end)
            path.pop()

    backtrack(0)
    return res
```

**复杂度**：时间 O(3⁴)，常数级；空间 O(1)。

## 易错点

- `"0"` 合法，`"00"`、`"01"` 不合法。
- 切满 4 段时要检查字符串是否刚好用完。
- 长度超过 12 或小于 4 时直接没有答案（剪枝条件已经包含）。
