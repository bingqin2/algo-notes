# 787. K 站中转内最便宜的航班

> [力扣 787](https://leetcode.cn/problems/cheapest-flights-within-k-stops/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

最短路**限制最多经过 k 个中转**（最多 k + 1 条边）：普通 Dijkstra 不能直接处理边数限制。用 **Bellman-Ford**：第 i 轮松弛后，得到的是最多 i 条边的最短距离，跑 k + 1 轮。

## 最优解法

**思路**：每一轮用**上一轮的距离数组**（复制一份）去松弛所有边，保证这一轮只比上一轮多走一条边。

```python
def findCheapestPrice(n, flights, src, dst, k):
    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):                 # 最多 k+1 条边：Bellman-Ford 迭代 k+1 轮
        prev = dist[:]                     # 每轮只用上一轮的结果，保证本轮最多多走一条边
        for u, v, w in flights:
            if prev[u] + w < dist[v]:
                dist[v] = prev[u] + w
    return -1 if dist[dst] == INF else dist[dst]
```

**复杂度**：时间 O(k · E)，空间 O(n)。

## 易错点

- 不复制上一轮的数组、直接在 dist 上更新：同一轮里可能连续走多条边，突破了 k 的限制。
- 中转 k 次 = k + 1 条边，循环 k + 1 轮。

**其他做法**：BFS 按层（层数就是边数）；Dijkstra 的状态加上「已用边数」(点, 边数)。
