# 260. 只出现一次的数字 III

> [力扣 260](https://leetcode.cn/problems/single-number-iii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

数组里只有两个数出现一次，其他都出现两次：全部异或得到 `a ^ b`。a 和 b 不同，所以 `a ^ b` 至少有一位是 1，按这一位把数组分成两组，a 和 b 分到不同的组，每组内部异或就得到一个。

## 最优解法

**思路**：`xor & −xor` 取出最低位的 1（补码的性质）。按这一位是否为 1 分组，其中一组的异或和就是 a，`b = xor ^ a`。

```python
def singleNumber(nums):
    xor = 0
    for x in nums:
        xor ^= x                           # 结果是两个目标数的异或
    low = xor & -xor                       # 取最低位的 1：两个数在这一位不同
    a = 0
    for x in nums:
        if x & low:                        # 按这一位分成两组，每组各有一个目标数
            a ^= x
    return [a, xor ^ a]
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- Java 里 xor 是 `Integer.MIN_VALUE` 时 `−xor` 溢出，但结果仍然是它自己，正好是最高位那一位，不影响。Python 整数无限精度，也没问题。
- 用哈希表计数也能做，但是 O(n) 空间。
