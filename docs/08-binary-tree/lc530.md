# 530. 二叉搜索树的最小绝对差

> [力扣 530](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

BST 中任意两结点值的最小差：中序遍历是有序的，最小差一定在**相邻**两个之间。

## 关键点

- 中序遍历时记录上一个值 prev。O(n)。

```python
def getMinimumDifference(root):
    best, prev = float("inf"), None

    def inorder(node):                     # BST 中序有序，最小差一定在相邻两个之间
        nonlocal best, prev
        if not node:
            return
        inorder(node.left)
        if prev is not None:
            best = min(best, node.val - prev)
        prev = node.val
        inorder(node.right)

    inorder(root)
    return best
```
