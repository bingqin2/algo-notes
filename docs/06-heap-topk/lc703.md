# 703. 数据流中的第 K 大元素

> [力扣 703](https://leetcode.cn/problems/kth-largest-element-in-a-stream/) · 简单 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

数据流中的第 k 大：维护一个大小为 k 的**小顶堆**，堆顶就是第 k 大。

## 关键点

- 新元素入堆，超过 k 个就弹出最小的。每次 add O(log k)。

```python
import heapq

class KthLargest:                          # 703
    def __init__(self, k, nums):
        self.k = k
        self.heap = []
        for x in nums:
            self.add(x)

    def add(self, val):
        heapq.heappush(self.heap, val)
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        return self.heap[0]
```
