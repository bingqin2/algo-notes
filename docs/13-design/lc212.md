# 212. 单词搜索 II

> [力扣 212](https://leetcode.cn/problems/word-search-ii/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

在网格里同时找很多单词：对每个单词做一遍 [79](../10-backtracking/lc79) 会超时。把所有单词建成**字典树**，从每个格子出发 DFS，沿着字典树走。

## 关键点

- 字典树结点里存完整单词，到达时直接加入结果，然后**删掉**这个标记，避免同一个词重复加入。
- 剪枝：一个结点的子树空了就从父结点删除，后面不再走这条路。不剪枝在大数据下会超时。
- 访问标记直接把格子改成 `#`，回溯时改回来。

```python
def findWords(board, words):
    root = {}
    for w in words:                        # 把所有单词建成一棵字典树
        node = root
        for ch in w:
            node = node.setdefault(ch, {})
        node["$"] = w
    m, n, res = len(board), len(board[0]), []

    def dfs(i, j, parent):
        ch = board[i][j]
        node = parent[ch]
        if "$" in node:
            res.append(node.pop("$"))      # 找到后删掉，避免重复
        board[i][j] = "#"
        for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
            if 0 <= x < m and 0 <= y < n and board[x][y] in node:
                dfs(x, y, node)
        board[i][j] = ch
        if not node:                       # 剪枝：子树已经空了，从父结点删掉
            parent.pop(ch)

    for i in range(m):
        for j in range(n):
            if board[i][j] in root:
                dfs(i, j, root)
    return res
```
