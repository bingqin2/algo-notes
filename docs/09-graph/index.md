# 图：搜索、拓扑、并查集、最短路

## 核心框架

网格题把格子当结点，用 DFS 或 BFS；依赖关系用拓扑排序；动态连通性用并查集；带权最短路用 Dijkstra（边权非负），限制步数的最短路用 Bellman-Ford；最小生成树用 Kruskal（排序 + 并查集）或 Prim。
