# 337. 打家劫舍 III

> [力扣 337](https://leetcode.cn/problems/house-robber-iii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

树上的「选或不选、相邻不能同时选」：**树形 DP**，每个结点返回两个值：选它时子树的最优解、不选它时子树的最优解，后序遍历自底向上计算。

## 最优解法

**思路**：`dfs(node)` 返回 `(rob, skip)`：

- 偷这个结点：孩子都不能偷，`rob = val + 左.skip + 右.skip`；
- 不偷：每个孩子偷不偷都行，取较大的，`skip = max(左) + max(右)`。

```python
def rob(root):
    def dfs(node):                         # 返回 (偷这个结点的最大值, 不偷的最大值)
        if not node:
            return 0, 0
        l_rob, l_skip = dfs(node.left)
        r_rob, r_skip = dfs(node.right)
        rob = node.val + l_skip + r_skip   # 偷了它，孩子都不能偷
        skip = max(l_rob, l_skip) + max(r_rob, r_skip)
        return rob, skip

    return max(dfs(root))
```

**复杂度**：时间 O(n)，空间 O(h)。

## 易错点

- 只考虑「偷爷爷 + 孙子」或「偷儿子」两种情况的递归：不加记忆化会重复计算，指数级超时；用哈希表记忆化可以过，但返回两个值的写法更简洁。
- 不偷当前结点时，孩子**不一定要偷**，要取 max。
