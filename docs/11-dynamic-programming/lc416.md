# 416. 分割等和子集

> [力扣 416](https://leetcode.cn/problems/partition-equal-subset-sum/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

能否把数组分成和相等的两部分：等价于能否选出一些数，和恰好为总和的一半。**0-1 背包**的可行性问题。

## 最优解法

**思路**：总和是奇数直接 False。`dp[j]` 表示能否凑出 j，每个数只能用一次，内层**倒序**遍历（保证 `dp[j − x]` 还是上一轮的值）。

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for j in range(target, x - 1, -1): # 每个数只能用一次：倒序
            dp[j] = dp[j] or dp[j - x]
    return dp[target]
```

**复杂度**：时间 O(n · sum)，空间 O(sum)。

## 易错点

- 内层正序：同一个数被用了多次，`[1, 2, 5]` 会被误判为 True（2 = 1 + 1）。
- 可以加剪枝：最大的数大于一半直接 False；`dp[target]` 一旦为真就提前返回。
- Python 也可以用位运算：`bits |= bits << x`，最后检查第 target 位，非常快。
