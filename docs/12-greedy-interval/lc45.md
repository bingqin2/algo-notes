# 45. 跳跃游戏 II

> [力扣 45](https://leetcode.cn/problems/jump-game-ii/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

保证能到终点，求最少跳几次：把能到达的位置按「跳了几次」分层，类似 BFS。维护当前这一跳能覆盖的边界 `cur_end`，以及在这一层里能跳到的最远位置 `farthest`；走到边界时必须再跳一次。

## 最优解法

**思路**：遍历到 `n − 2`（到了最后一个位置就不用再跳）。每个位置更新 farthest；`i == cur_end` 时，这一层走完了，跳一次，下一层的边界是 farthest。

```python
def jump(nums):
    jumps = cur_end = farthest = 0
    for i in range(len(nums) - 1):         # 不需要在最后一个位置起跳
        farthest = max(farthest, i + nums[i])
        if i == cur_end:                   # 走到了当前这一跳能到的边界，必须再跳一次
            jumps += 1
            cur_end = farthest
    return jumps
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 遍历到最后一个位置：如果 cur_end 正好等于 n − 1，会多跳一次。
- 用 DP `dp[j] = min(dp[i] + 1)`：O(n²)，能过但不是最优。
