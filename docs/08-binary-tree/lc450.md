# 450. 删除二叉搜索树中的节点

> [力扣 450](https://leetcode.cn/problems/delete-node-in-a-bst/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

BST 删除结点：找到后分三种情况：没有孩子直接删；只有一个孩子用孩子顶替；有两个孩子用**后继**（右子树的最小结点）或前驱的值替换，再去右子树里删掉后继。

## 最优解法

**思路**：递归函数返回删除后的子树根。比 key 小去左子树删、大去右子树删、等于时按上面三种情况处理。两个孩子时，把后继的值复制过来，再递归地在右子树里删除后继（后继最多只有右孩子，会落到简单情况）。

```python
def deleteNode(root, key):
    if not root:
        return None
    if key < root.val:
        root.left = deleteNode(root.left, key)
    elif key > root.val:
        root.right = deleteNode(root.right, key)
    else:
        if not root.left:
            return root.right
        if not root.right:
            return root.left
        succ = root.right                  # 两个孩子都有：用右子树的最小结点（后继）替换
        while succ.left:
            succ = succ.left
        root.val = succ.val
        root.right = deleteNode(root.right, succ.val)
    return root
```

**复杂度**：时间 O(h)，空间 O(h)。

## 易错点

- 两个孩子的情况直接 `root = root.right`：丢了左子树。另一种不复制值的写法是把左子树接到后继的左边，但会让树变高。
- 递归返回值要接回父结点：`root.left = deleteNode(root.left, key)`。
