# 228. 汇总区间

> [力扣 228](https://leetcode.cn/problems/summary-ranges/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

有序无重复数组，把连续的数合并成区间：一次遍历，j 往后扩展到不连续为止。

## 关键点

- 区间只有一个数时输出 `"a"`，否则 `"a->b"`。
- 判断连续用 `nums[j+1] == nums[j] + 1`；Java 里注意 `nums[j] + 1` 在 `Integer.MAX_VALUE` 时溢出，可以改成相减比较或者用 long。O(n)。

```python
def summaryRanges(nums):
    res, i = [], 0
    while i < len(nums):
        j = i
        while j + 1 < len(nums) and nums[j + 1] == nums[j] + 1:
            j += 1
        res.append(str(nums[i]) if i == j else f"{nums[i]}->{nums[j]}")
        i = j + 1
    return res
```
