# 58. 最后一个单词的长度

> [力扣 58](https://leetcode.cn/problems/length-of-last-word/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

最后一个单词的长度：从末尾往前，先跳过空格，再数非空格字符。

## 关键点

- O(n) 最坏，但通常只扫最后一段。`len(s.split()[-1])` 也可以，但多用 O(n) 空间。

```python
def lengthOfLastWord(s):
    i = len(s) - 1
    while i >= 0 and s[i] == " ":
        i -= 1
    j = i
    while j >= 0 and s[j] != " ":
        j -= 1
    return i - j
```
