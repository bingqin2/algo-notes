# 692. 前K个高频单词

> [力扣 692](https://leetcode.cn/problems/top-k-frequent-words/) · 近两年面经里出现在：**美团**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

Top K，而且有**并列时的排序规则**：频率高的在前，频率相同时字典序小的在前。和 [347](./lc347) 的区别全在比较规则上。

## 解法一：计数 + 排序 O(n log n)

**思路**：按 (−频率, 单词) 排序，取前 k 个。先说这个，一行就能讲清规则。

```python
from collections import Counter

def topKFrequent(words, k):
    cnt = Counter(words)
    return sorted(cnt, key=lambda w: (-cnt[w], w))[:k]   # 频率降序，同频率字典序升序
```

**复杂度**：时间 O(n log n)，空间 O(n)。

## 解法二：大小为 k 的堆 O(n log k)

**思路**：和 347 一样维护大小为 k 的堆，堆顶是前 k 名里**最差**的那个。「差」的定义要和题目的排序规则**完全相反**：

- 频率小的更差；
- 频率相同时，**字典序大的更差**（因为字典序小的应该排前面）。

所以这个堆的比较规则是「频率升序，频率相同时单词降序」。Python 的 `heapq` 只能按元组升序比较，单词降序没法直接写进元组，这里用一个自定义 `__lt__` 的类。最后堆里弹出的顺序是从差到好，要反转。

```python
class Entry:
    def __init__(self, freq, word):
        self.freq, self.word = freq, word

    def __lt__(self, other):               # 堆顶是「最差」的：频率小的差；同频率时字典序大的差
        if self.freq != other.freq:
            return self.freq < other.freq
        return self.word > other.word
```

```python
from collections import Counter
import heapq

def topKFrequent(words, k):
    cnt = Counter(words)
    heap = []
    for w, c in cnt.items():
        heapq.heappush(heap, Entry(c, w))
        if len(heap) > k:
            heapq.heappop(heap)
    res = []
    while heap:
        res.append(heapq.heappop(heap).word)
    return res[::-1]                       # 堆里弹出是从差到好，反转
```

**复杂度**：时间 O(n log k)，空间 O(n)。

## 易错点

- 堆的比较规则写成和输出顺序一样（频率降序、字典序升序）：那样堆顶是最好的，被弹出的反而是最好的。
- 忘了最后反转。
- Java 里比较 `Integer` 用 `==`：频率超过 127 后比较的是引用。下面的 Java 版用 `equals`。

## 面试追问

- **为什么不能直接把 (频率, 单词) 放进小顶堆？** 频率相同时它会认为字典序小的更小（更差），先被弹出，正好和题目要求相反。
- **Java 里怎么写比较器？** 见下面：`cnt.get(a).equals(cnt.get(b)) ? b.compareTo(a) : cnt.get(a) − cnt.get(b)`。
- **一般化的套路？** 「保留最好的 k 个」就用一个按「好坏」排序、**堆顶是最差**的堆，比较规则和最终输出顺序相反。

## Java 版

```java
public List<String> topKFrequent(String[] words, int k) {
    Map<String, Integer> cnt = new HashMap<>();
    for (String w : words) cnt.merge(w, 1, Integer::sum);
    // 堆顶是最差的：频率小的差；频率相同时字典序大的差
    PriorityQueue<String> heap = new PriorityQueue<>((a, b) ->
            cnt.get(a).equals(cnt.get(b)) ? b.compareTo(a) : cnt.get(a) - cnt.get(b));
    for (String w : cnt.keySet()) {
        heap.offer(w);
        if (heap.size() > k) heap.poll();
    }
    LinkedList<String> res = new LinkedList<>();
    while (!heap.isEmpty()) res.addFirst(heap.poll());
    return res;
}
```
