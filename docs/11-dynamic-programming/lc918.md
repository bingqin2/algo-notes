# 918. 环形子数组的最大和

> [力扣 918](https://leetcode.cn/problems/maximum-sum-circular-subarray/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

环形数组的最大子数组和：要么不跨首尾（普通 [53](./lc53)），要么跨首尾，等于**总和减去中间的最小子数组和**。

## 关键点

- 一次遍历同时算最大子数组和、最小子数组和（都是 Kadane）。
- 全是负数时最小子数组就是整个数组，`总和 − 最小和 = 0` 对应空数组，不合法，此时直接返回最大子数组和。O(n)。

```python
def maxSubarraySumCircular(nums):
    cur_max = cur_min = 0
    best_max, best_min = float("-inf"), float("inf")
    for x in nums:
        cur_max = max(cur_max + x, x)
        best_max = max(best_max, cur_max)
        cur_min = min(cur_min + x, x)
        best_min = min(best_min, cur_min)
    if best_max < 0:                       # 全是负数：不能取空数组
        return best_max
    return max(best_max, sum(nums) - best_min)
```
