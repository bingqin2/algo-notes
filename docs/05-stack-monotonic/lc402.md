# 402. 移掉 K 位数字

> [力扣 402](https://leetcode.cn/problems/remove-k-digits/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

删掉 k 个数字使剩下的数最小：越高位越重要，**贪心**：从左往右，遇到「前一位比当前位大」就删前一位。用**单调递增栈**实现。

## 最优解法

**思路**：遍历每一位 d，只要还能删、栈顶比 d 大，就弹出栈顶（删掉它）。遍历完 k 还没用完，说明剩下的是非递减的，删末尾的 k 个。最后去掉前导 0，空了返回 "0"。

```python
def removeKdigits(num, k):
    stack = []
    for d in num:
        while k and stack and stack[-1] > d:   # 前面的数字比后面大，删掉它结果更小
            stack.pop()
            k -= 1
        stack.append(d)
    if k:
        stack = stack[:-k]                 # 还没删够，删末尾（此时栈单调不减）
    return "".join(stack).lstrip("0") or "0"
```

**复杂度**：时间 O(n)，空间 O(n)。

## 易错点

- 遍历完还有 k 没用：要删末尾，不能忽略。
- 去前导 0 后为空串：返回 `"0"`。
- 栈顶和 d 相等时不弹：删掉相等的不会让结果更小。
