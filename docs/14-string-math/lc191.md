# 191. 位1的个数

> [力扣 191](https://leetcode.cn/problems/number-of-1-bits/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

数二进制里 1 的个数：`n & (n − 1)` 会去掉最低位的 1，能去几次就有几个 1。

## 关键点

- 循环次数等于 1 的个数，比逐位检查 32 次少。
- Java 里输入是有符号 int，逐位做法要用 `>>>`；`n & (n − 1)` 写法不受符号影响。

```python
def hammingWeight(n):
    cnt = 0
    while n:
        n &= n - 1                         # 去掉最低位的 1
        cnt += 1
    return cnt
```
