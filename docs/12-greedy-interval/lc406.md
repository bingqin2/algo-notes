# 406. 根据身高重建队列

> [力扣 406](https://leetcode.cn/problems/queue-reconstruction-by-height/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

每个人有两个维度 (h, k)，要重建队列：**先确定一个维度**。按身高从高到低排，矮的人插入时不会影响已经排好的高个子的 k 值；所以每个人直接插到下标 k 的位置。

## 最优解法

**思路**：按身高降序、同身高按 k 升序排序。依次插入：插第 i 个人时，队列里都是不比他矮的人，他前面应该正好有 k 个，所以插在位置 k。之后插入的人都更矮（或同样高但 k 更大，插在他后面），不会改变他的 k。

```python
def reconstructQueue(people):
    people.sort(key=lambda p: (-p[0], p[1]))   # 高的先排，同样高的 k 小的在前
    res = []
    for p in people:
        res.insert(p[1], p)                # 前面都是不矮于它的人，插到第 k 个位置正好
    return res
```

**复杂度**：时间 O(n²)（列表插入），空间 O(n)。用树状数组或线段树可以做到 O(n log n)。

## 易错点

- 同样高的人 k 要升序：k 小的先插，否则后插的 k 小的人会插到前面，把先插的人的 k 变大。
