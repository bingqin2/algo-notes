# 56. 合并区间

> [力扣 56](https://leetcode.cn/problems/merge-intervals/) · 近两年面经里出现在：**腾讯**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

一堆区间，**重叠的合并**。区间题的第一步几乎都是排序：合并、插入、求交集按**起点**排；选最多不重叠的区间（[435](./lc435)、[452](./lc452)）按**终点**排。

## 解法一：按起点排序后合并

**思路**：按起点排序后，和当前区间重叠的只可能是结果里的**最后一个**区间（前面的终点都更早）。

- 当前起点 ≤ 最后一个的终点：重叠，把最后一个的终点更新成两者的较大值；
- 否则不重叠，直接加入结果。

<StepPlayer src="/viz/lc56.json" />

```python
def merge(intervals):
    intervals.sort(key=lambda p: p[0])     # 按起点排序
    res = []
    for s, e in intervals:
        if res and s <= res[-1][1]:        # 和上一个重叠（端点相接也算）
            res[-1][1] = max(res[-1][1], e)
        else:
            res.append([s, e])
    return res
```

**复杂度**：时间 O(n log n)（排序），空间 O(log n) 排序栈（不算输出）。

## 变体：插入区间（57）

区间已经有序且不重叠，插入一个新区间。不用重新排序，分三段扫一遍：完全在左边的、和新区间重叠的（并成一个）、完全在右边的。O(n)。

```python
def insert(intervals, new):
    res, i, n = [], 0, len(intervals)
    while i < n and intervals[i][1] < new[0]:     # 完全在左边
        res.append(intervals[i]); i += 1
    s, e = new
    while i < n and intervals[i][0] <= e:         # 和 new 重叠的都并进来
        s, e = min(s, intervals[i][0]), max(e, intervals[i][1]); i += 1
    res.append([s, e])
    res.extend(intervals[i:])                     # 完全在右边
    return res
```

## 易错点

- 合并时直接用当前终点 `res[-1][1] = e`：`[1, 10]` 和 `[2, 3]` 合并后应该还是 `[1, 10]`，要取 max。
- 端点相接（`[1, 4]` 和 `[4, 5]`）算不算重叠：本题算，用 `<=`。题目说不算时改成 `<`。
- Java 比较器写 `a[0] - b[0]`：值很大或有负数时可能溢出，用 `Integer.compare`。

## 面试追问

- **为什么按起点排序是对的？** 排序后，如果当前区间和最后一个不重叠，那它和更前面的也都不重叠（它们的终点都 ≤ 最后一个的终点），而后面的区间起点更大，也不会再和最后一个重叠。
- **区间是流式到达的？** 用有序结构（Java `TreeMap`）按起点存，插入时找前驱和后继合并，每次 O(log n)。
- **求两组区间的交集（986）？** 两个指针，交集是 [max(起点), min(终点)]，终点小的那个指针前进。
- **区间很多但坐标范围小？** 差分数组：起点 +1、终点 −1，前缀和 > 0 的连续段就是合并后的区间。

## Java 版

```java
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> res = new ArrayList<>();
    for (int[] cur : intervals) {
        if (!res.isEmpty() && cur[0] <= res.get(res.size() - 1)[1]) {
            int[] last = res.get(res.size() - 1);
            last[1] = Math.max(last[1], cur[1]);
        } else {
            res.add(new int[]{cur[0], cur[1]});
        }
    }
    return res.toArray(new int[0][]);
}
```
