# 383. 赎金信

> [力扣 383](https://leetcode.cn/problems/ransom-note/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

magazine 里的字符能否拼出 ransomNote：计数，每个字符 magazine 里的数量 ≥ ransomNote 里的数量。

## 关键点

- `Counter` 相减后为空说明够用。只有小写字母时用 26 位数组。

```python
from collections import Counter

def canConstruct(ransomNote, magazine):
    return not Counter(ransomNote) - Counter(magazine)
```
