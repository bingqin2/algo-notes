# 198. 打家劫舍

> [力扣 198](https://leetcode.cn/problems/house-robber/) · 近两年面经里出现在：**字节 ×4**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

一排元素，**相邻的不能同时选**，求选出元素的最大和。字节近两年考了 4 次，还有「打家劫舍变体」，通常是 [213 环形](./lc213) 或 [337 树形](./lc337)。

这是动态规划的入门模板题，用它把 DP 的五步讲清楚：

1. **定义**：dp[i] = 只考虑前 i 间房（下标 0..i）能偷到的最大金额。
2. **转移**：第 i 间要么不偷，等于 dp[i−1]；要么偷，那第 i−1 间就不能偷，等于 dp[i−2] + nums[i]。取较大的。
3. **初始值**：dp[0] = nums[0]，dp[1] = max(nums[0], nums[1])。
4. **顺序**：从左到右。
5. **压缩**：dp[i] 只依赖前两个值，用两个变量就够了。

## 解法一：记忆化搜索（自顶向下）

**思路**：f(i) = max(f(i−1), f(i−2) + nums[i])，用缓存避免重复计算。面试时先写这个能帮你理清转移方程。

```python
from functools import lru_cache

def rob(nums):
    @lru_cache(None)
    def f(i):                      # 从 0..i 能偷到的最大值
        if i < 0: return 0
        return max(f(i - 1), f(i - 2) + nums[i])
    return f(len(nums) - 1)
```

**复杂度**：时间 O(n)，空间 O(n)（缓存 + 递归栈）。

## 解法二：DP 数组（自底向上）

```python
def rob(nums):
    n = len(nums)
    if n == 1: return nums[0]
    dp = [0] * n
    dp[0], dp[1] = nums[0], max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]
```

**复杂度**：时间 O(n)，空间 O(n)。

## 解法三：滚动变量（最终写法）

```python
def rob(nums):
    prev2 = prev1 = 0              # dp[i-2]、dp[i-1]
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```

**复杂度**：时间 O(n)，空间 O(1)。`prev2, prev1` 初始为 0 相当于在数组前面补了两间空房，不用单独处理 n = 1。

## 易错点

- 定义成「必须偷第 i 间」也可以，但答案就要取 max(dp)，而不是 dp[n−1]。先说清楚定义再写转移。
- 写数组版时 n = 1 要特判，否则 dp[1] 越界。
- 滚动变量更新顺序：用 Python 的同时赋值，或者 Java 里先用临时变量算出新值。

## 面试追问

- **房子围成一圈？** 首尾不能同时偷：分别算「不偷最后一间」和「不偷第一间」，取较大值，见 [213](./lc213)。
- **房子在二叉树上？** 每个结点返回两个值：偷它时的最大值、不偷它时的最大值，后序遍历合并，见 [337](./lc337)。
- **要输出偷了哪几间？** 保留 dp 数组，从后往前回溯：如果 dp[i] == dp[i−1] 说明第 i 间没偷，否则偷了并跳到 i−2。
- **有负数怎么办？** 题目保证非负。如果有负数，「不偷」的选项天然会避开它，转移方程不用变。

## Java 版

```java
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;            // dp[i-2]、dp[i-1]
    for (int x : nums) {
        int cur = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```
