# 57. 插入区间

> [力扣 57](https://leetcode.cn/problems/insert-interval/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

在**有序且不重叠**的区间列表里插入一个新区间：不用重新排序，一次遍历分三段：完全在新区间左边的、和新区间重叠的（合并成一个）、完全在右边的。

## 最优解法

**思路**：

1. 终点 < 新区间起点：完全在左边，原样加入。
2. 起点 ≤ 新区间终点：和新区间重叠，合并（取最小起点、最大终点）。
3. 剩下的都在右边，原样加入。

```python
def insert(intervals, newInterval):
    res, i, n = [], 0, len(intervals)
    s, e = newInterval
    while i < n and intervals[i][1] < s:   # 完全在左边
        res.append(intervals[i]); i += 1
    while i < n and intervals[i][0] <= e:  # 和新区间重叠的都合并
        s, e = min(s, intervals[i][0]), max(e, intervals[i][1]); i += 1
    res.append([s, e])
    res.extend(intervals[i:])              # 完全在右边
    return res
```

**复杂度**：时间 O(n)，空间 O(n)（结果）。

## 易错点

- 重叠的判断：第二个 while 只检查起点 ≤ e，因为经过第一个 while 后，剩下区间的终点都 ≥ s。
- 端点相接（`[1,2]` 插入 `[2,3]`）要合并。
