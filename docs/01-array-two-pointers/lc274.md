# 274. H 指数

> [力扣 274](https://leetcode.cn/problems/h-index/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

H 指数：有 h 篇论文引用数都 ≥ h 的最大 h。答案在 [0, n] 之间，可以**计数排序**。

## 关键点

- 引用数大于 n 的都记在 n 里（h 不可能超过 n）。
- 从大到小累加「引用数 ≥ h 的论文数」，第一次 ≥ h 时 h 就是答案。O(n) 时间。
- 排序做法：降序排序后，找最大的 i 使 `citations[i−1] ≥ i`，O(n log n)。

```python
def hIndex(citations):
    n = len(citations)
    cnt = [0] * (n + 1)                    # 引用数 >= n 的都算在 n 里
    for c in citations:
        cnt[min(c, n)] += 1
    total = 0
    for h in range(n, -1, -1):
        total += cnt[h]                    # 引用数 >= h 的论文数
        if total >= h:
            return h
    return 0
```
