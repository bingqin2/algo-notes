# 堆与 Top K

## 核心框架

前 K 大用小顶堆、前 K 小用大顶堆；Python 用 heapq（只有小顶堆，取负数做大顶堆）。

## 核心题目

「近两年出现在」统计自 2025–2026 年的后端面经（见[说明](/#数据来源)）；「高频经典」表示这份样本里没出现，但属于 Hot 100 必会题。

| 题目 | 近两年出现在 | 要掌握的解法 |
|---|---|---|
| [347. 前 K 个高频元素](./lc347) | 美团 ×3 · 字节 | 计数 + 小顶堆 O(n log k) / 桶排序 O(n) / 快速选择 |
| [692. 前 K 个高频单词](./lc692) | 美团 | 计数 + 堆，频率相同按字典序 |
| [295. 数据流的中位数](./lc295) | 高频经典 | 大顶堆存较小一半 + 小顶堆存较大一半 |
| [流式 / 海量数据 Top K（日志中出现最多的 IP）](./stream-topk) | 字节 ×2 · 华为 | 哈希分桶到小文件 + 每桶计数 + 堆合并 / Count-Min Sketch 近似 |
