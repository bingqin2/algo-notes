# 125. 验证回文串

> [力扣 125](https://leetcode.cn/problems/valid-palindrome/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断回文，但要忽略非字母数字字符、不区分大小写：相向双指针，遇到无效字符就跳过。

## 关键点

- 左右指针各自跳过非字母数字的字符，再比较小写形式。
- 不要先拼出一个过滤后的新字符串再反转比较：能过，但多用 O(n) 空间。O(n) 时间，O(1) 空间。

```python
def isPalindrome(s):
    l, r = 0, len(s) - 1
    while l < r:
        if not s[l].isalnum():
            l += 1
        elif not s[r].isalnum():
            r -= 1
        else:
            if s[l].lower() != s[r].lower():
                return False
            l += 1
            r -= 1
    return True
```
