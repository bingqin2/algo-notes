# 169. 多数元素

> [力扣 169](https://leetcode.cn/problems/majority-element/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

找出现次数超过一半的数，O(1) 空间：**摩尔投票**。

## 关键点

- 计数为 0 时换候选人；相同 +1，不同 −1。多数元素比其他所有元素加起来还多，抵消完一定剩下它。
- 题目保证存在多数元素；不保证时要再遍历一遍确认。
- 其他做法：哈希计数 O(n) 空间；排序后取中间 O(n log n)。

```python
def majorityElement(nums):
    cand, cnt = None, 0
    for x in nums:                         # 摩尔投票：不同的两两抵消
        if cnt == 0:
            cand = x
        cnt += 1 if x == cand else -1
    return cand
```
