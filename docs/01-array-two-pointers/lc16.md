# 16. 最接近的三数之和

> [力扣 16](https://leetcode.cn/problems/3sum-closest/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

三数之和的变体：不要求等于目标，而是**最接近**。同样排序 + 固定一个 + 双指针，过程中更新和 target 差距最小的和。

## 最优解法

**思路**：固定 `nums[i]`，左右指针求和 s。|s − target| 更小就更新答案；s 小于 target 就 l 右移让和变大，大于就 r 左移，等于直接返回。

```python
def threeSumClosest(nums, target):
    nums.sort()
    best = nums[0] + nums[1] + nums[2]
    for i in range(len(nums) - 2):
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if abs(s - target) < abs(best - target):
                best = s
            if s < target:
                l += 1
            elif s > target:
                r -= 1
            else:
                return s
    return best
```

**复杂度**：时间 O(n²)，空间 O(log n)。

## 易错点

- 答案初值用 `float('inf')`：和 target 相减时可能出问题（`inf − target` 还是 inf，比较没问题，但返回值类型不对）；用前三个数的和做初值最稳。
- 不需要去重：只求一个和，重复不影响结果（去重只是剪枝）。
