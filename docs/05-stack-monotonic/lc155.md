# 155. 最小栈

> [力扣 155](https://leetcode.cn/problems/min-stack/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

设计一个栈，push、pop、top、getMin 都是 O(1)。关键是：**每个元素入栈时，栈里的最小值就确定了**，之后只要它还在栈里，它下面的元素就不会变。所以可以把「入栈那一刻的最小值」跟着元素一起存。

## 解法一：辅助栈同步存当前最小值

**思路**：再开一个栈 `mins`，和主栈同步 push / pop，`mins[k]` 是主栈从底到第 k 个元素的最小值。

```python
class MinStack:
    def __init__(self):
        self.st = []
        self.mins = []                     # mins[k] = st[0..k] 的最小值

    def push(self, val):
        self.st.append(val)
        self.mins.append(val if not self.mins else min(val, self.mins[-1]))

    def pop(self):
        self.st.pop()
        self.mins.pop()

    def top(self):
        return self.st[-1]

    def getMin(self):
        return self.mins[-1]
```

**复杂度**：每个操作 O(1)，额外空间 O(n)。

变体：辅助栈只在 `val <= 当前最小值` 时才压入，pop 时如果弹出的值等于最小值才弹辅助栈，平均更省空间。注意必须是 `<=`：有重复的最小值时，用 `<` 会提前把最小值弹掉。

## 解法二：存差值 O(1) 额外空间

**思路**：只存一个变量 `mn`（当前最小值），栈里存 `val − 入栈前的最小值`。

- 差值 ≥ 0：最小值不变，真实值 = mn + 差值。
- 差值 < 0：这个元素就是新的最小值，真实值 = mn。弹出它时，上一个最小值 = mn − 差值。

```python
class MinStack:
    def __init__(self):
        self.st = []                       # 存 val - 入栈前的最小值
        self.mn = 0

    def push(self, val):
        if not self.st:
            self.st.append(0)
            self.mn = val
        else:
            self.st.append(val - self.mn)
            if val < self.mn:              # 差值为负：说明它是新的最小值
                self.mn = val

    def pop(self):
        d = self.st.pop()
        if d < 0:                          # 弹出的是当前最小值，恢复上一个最小值
            self.mn -= d

    def top(self):
        d = self.st[-1]
        return self.mn if d < 0 else self.mn + d

    def getMin(self):
        return self.mn
```

**复杂度**：每个操作 O(1)，除了栈本身只用一个变量。

Java 里差值要用 `long`：`Integer.MAX_VALUE − Integer.MIN_VALUE` 超出 int 范围（见下面的 Java 版）。这个解法面试时说出来是加分项，但第一选择还是解法一，清晰不容易错。

## 图解

依次 push −2、0、−3，再 pop：

| 操作 | 主栈 | 辅助栈 mins | getMin |
|---|---|---|---|
| push(−2) | [−2] | [−2] | −2 |
| push(0) | [−2, 0] | [−2, −2] | −2 |
| push(−3) | [−2, 0, −3] | [−2, −2, −3] | −3 |
| pop() | [−2, 0] | [−2, −2] | −2 |

## 易错点

- 辅助栈不同步：pop 时只弹了主栈。
- 省空间的变体用了 `<` 而不是 `<=`。
- Java 用 `Integer` 比较时写 `st.peek() == mins.peek()`：超过 −128~127 的缓存范围后比较的是引用，结果错误。要用 `equals` 或先拆箱成 int。

## 面试追问

- **同时要 getMax？** 再开一个辅助栈。
- **最小队列（O(1) 取队列最小值）？** 用两个最小栈拼一个队列（[232](./lc232) 的思路），或者用单调队列（[239](../02-sliding-window/lc239)）。
- **线程安全？** 方法加锁；或者把主栈和辅助栈合成一个存 `(val, min)` 的栈，用一个锁保护。

## Java 版

```java
class MinStack {
    private final Deque<Integer> st = new ArrayDeque<>();
    private final Deque<Integer> mins = new ArrayDeque<>();

    public void push(int val) {
        st.push(val);
        mins.push(mins.isEmpty() ? val : Math.min(val, mins.peek()));
    }

    public void pop() {
        st.pop();
        mins.pop();
    }

    public int top() { return st.peek(); }

    public int getMin() { return mins.peek(); }
}
```

差值版：

```java
class MinStack {
    private final Deque<Long> st = new ArrayDeque<>();   // 差值可能超出 int，用 long
    private long min;

    public void push(int val) {
        if (st.isEmpty()) {
            st.push(0L);
            min = val;
        } else {
            st.push(val - min);
            if (val < min) min = val;
        }
    }

    public void pop() {
        long d = st.pop();
        if (d < 0) min -= d;                   // 弹出的是最小值，恢复上一个
    }

    public int top() {
        long d = st.peek();
        return (int) (d < 0 ? min : min + d);
    }

    public int getMin() { return (int) min; }
}
```
