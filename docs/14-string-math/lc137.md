# 137. 只出现一次的数字 II

> [力扣 137](https://leetcode.cn/problems/single-number-ii/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

其他数都出现三次：按**位**统计，每一位上 1 的个数模 3 就是答案在这一位的值。

## 关键点

- 好讲的写法：统计 32 位，每位 `sum % 3`。Java 直接拼回 int 就行；Python 要把第 31 位为 1 的结果减去 2³² 转成负数。
- 下面是状态机写法：`ones`、`twos` 两个变量合起来表示每一位出现次数模 3（00 → 01 → 10 → 00）。O(n) 时间，O(1) 空间。

```python
def singleNumber(nums):
    ones = twos = 0                        # 每一位出现次数 mod 3 的两位状态
    for x in nums:
        ones = (ones ^ x) & ~twos
        twos = (twos ^ x) & ~ones
    return ones
```
