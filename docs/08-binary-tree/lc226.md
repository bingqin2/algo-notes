# 226. 翻转二叉树

> [力扣 226](https://leetcode.cn/problems/invert-binary-tree/) · 近两年面经里出现在：**高频经典**
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

镜像类问题：翻转二叉树就是把每个结点的左右孩子交换；判断对称就是比较左右子树是否互为镜像。

## 解法一：前序或后序交换左右

**思路**：递归翻转左右子树，再交换当前结点的两个孩子（后序）；或者先交换再递归（前序）。中序不行：交换后原来的左子树变成了右子树，会被翻转两次。

<StepPlayer src="/viz/lc226.json" />

```python
def invertTree(root):
    if root:
        root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
```

**迭代写法**：BFS，每弹出一个结点就交换它的孩子。

```python
from collections import deque

def invertTree(root):
    q = deque([root] if root else [])
    while q:
        node = q.popleft()
        node.left, node.right = node.right, node.left
        for c in (node.left, node.right):
            if c:
                q.append(c)
    return root
```

**复杂度**：时间 O(n)，空间 O(h)（递归）或 O(w)（BFS 队列宽度）。

## 解法二：双指针递归比较

翻转的反问题是判断对称（[101](./lc101)）：两个指针分别从左右子树出发，外侧和外侧比、内侧和内侧比。

```python
def isSymmetric(root):
    def mirror(a, b):                      # a 和 b 是否互为镜像
        if not a or not b:
            return a is b
        return a.val == b.val and mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right) if root else True
```

## 易错点

- Python 一行写 `root.left, root.right = invertTree(root.right), invertTree(root.left)` 没问题（右边先全部算完）；分两行写要先保存一个孩子。
- 中序遍历翻转会出错（见上）。
