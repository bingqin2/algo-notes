# 127. 单词接龙

> [力扣 127](https://leetcode.cn/problems/word-ladder/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

每次改一个字母、求最少几步变成目标词：无权图最短路，**BFS**。单词是点，差一个字母的单词之间有边。

## 关键点

- 不要两两比较单词建图（O(n² · L)）。对当前单词的每一位试 26 个字母，查是否在字典集合里：O(n · L · 26)。
- 入队时就标记已访问，否则同一个词会被多次入队。
- 答案是单词个数（步数 + 1）。endWord 不在字典里直接返回 0。
- 追问优化：**双向 BFS**，每次从较小的一端扩展。

```python
from collections import deque

def ladderLength(beginWord, endWord, wordList):
    words = set(wordList)
    if endWord not in words:
        return 0
    q, seen = deque([(beginWord, 1)]), {beginWord}
    while q:
        w, d = q.popleft()
        if w == endWord:
            return d
        for i in range(len(w)):
            for ch in "abcdefghijklmnopqrstuvwxyz":
                nw = w[:i] + ch + w[i + 1:]
                if nw in words and nw not in seen:
                    seen.add(nw)                 # 入队时标记，避免重复入队
                    q.append((nw, d + 1))
    return 0
```
