# 525. 连续数组

> [力扣 525](https://leetcode.cn/problems/contiguous-array/) · 近两年面经里出现在：**美团**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「两类元素**个数相等**的最长子数组」：把一类看成 +1、另一类看成 −1，就变成「**和为 0** 的最长子数组」，用前缀和 + 哈希表记每个前缀和**第一次**出现的位置。

## 解法一：暴力 O(n²)

枚举起点，往右累加，和为 0 就更新答案。用来对拍。

```python
def findMaxLength(nums):
    best = 0
    for i in range(len(nums)):
        bal = 0
        for j in range(i, len(nums)):
            bal += 1 if nums[j] == 1 else -1
            if bal == 0:
                best = max(best, j - i + 1)
    return best
```

## 解法二：0 看成 −1，前缀和 + 最早出现位置

**思路**：s 是前缀和（0 记 −1）。如果下标 j 和 i 处的前缀和相等，(j, i] 这段的和就是 0，也就是 0 和 1 一样多。要最长，j 就要尽量靠左，所以哈希表只记每个前缀和**第一次**出现的下标。

初始放 `{0: -1}`：表示空前缀，这样从下标 0 开始的子数组也能算到。

```python
def findMaxLength(nums):
    first = {0: -1}                        # 前缀和 -> 第一次出现的下标；空前缀在 -1
    best = s = 0
    for i, x in enumerate(nums):
        s += 1 if x == 1 else -1           # 0 当成 -1
        if s in first:
            best = max(best, i - first[s]) # (first[s], i] 这段和为 0
        else:
            first[s] = i                   # 只记第一次，长度才最长
    return best
```

**复杂度**：时间 O(n)，空间 O(n)。前缀和的范围是 [−n, n]，也可以用长度 2n + 1 的数组代替哈希表，常数更小。

## 前缀和 + 哈希表的几种变体

| 题 | 哈希表存什么 | 找什么 |
|---|---|---|
| 525 本题 | 前缀和 → 最早下标 | 相同前缀和，求最长 |
| [560](./lc560) 和为 K 的子数组 | 前缀和 → 出现次数 | s − k 出现了几次，求个数 |
| [523](./lc523) 连续的子数组和 | 前缀和 % k → 最早下标 | 余数相同且长度 ≥ 2 |
| [974](./lc974) 和可被 K 整除 | 前缀和 % k → 次数 | 余数相同的对数 |

求**最长**就记最早位置，求**个数**就记次数。

## 易错点

- 忘了初始化 `{0: -1}`：从开头开始的整段（比如 `[0, 1]`）算不到。
- 前缀和重复出现时更新了下标：更新就变成记最晚位置，长度变短。
- 0 没有换成 −1，直接用原数组的前缀和：和为 0 不代表 0、1 个数相等。

## 面试追问

- **为什么不能用滑动窗口？** 窗口合法性不单调：一个窗口 0、1 不相等，扩大以后可能又相等，没法决定什么时候收缩。
- **三类元素个数都相等？** 记 (cnt_a − cnt_b, cnt_b − cnt_c) 这个二元组第一次出现的位置，思路一样。
- **Java 里用 int[] 代替 HashMap？** 下标偏移 n：`first[s + n]`，初始化成 −2 表示没出现过。

## Java 版

```java
public int findMaxLength(int[] nums) {
    Map<Integer, Integer> first = new HashMap<>();
    first.put(0, -1);                                  // 空前缀
    int best = 0, s = 0;
    for (int i = 0; i < nums.length; i++) {
        s += nums[i] == 1 ? 1 : -1;
        Integer j = first.putIfAbsent(s, i);           // 只记第一次出现
        if (j != null) best = Math.max(best, i - j);
    }
    return best;
}
```
