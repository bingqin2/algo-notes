# 435. 无重叠区间

> [力扣 435](https://leetcode.cn/problems/non-overlapping-intervals/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

最少删除几个区间让剩下的不重叠 = 最多能保留几个不重叠的区间（**活动选择问题**）：按**结束时间**排序，每次选结束最早的、和已选的不重叠的区间。

## 最优解法

**思路**：结束得越早，留给后面区间的空间越多。排序后遍历，起点 ≥ 上一个保留区间的终点就保留它并更新终点。答案 = 总数 − 保留数。

```python
def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda p: p[1])     # 按结束时间排序
    keep, end = 0, float("-inf")
    for s, e in intervals:
        if s >= end:                       # 不重叠，保留（结束越早，留给后面的空间越多）
            keep += 1
            end = e
    return len(intervals) - keep
```

**复杂度**：时间 O(n log n)，空间 O(log n)。

## 易错点

- 按起点排序：需要在重叠时保留终点更小的那个，逻辑更绕；按终点排序最直接。
- 端点相接（`[1,2]` 和 `[2,3]`）不算重叠，用 `>=`。
