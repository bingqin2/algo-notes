# 415. 字符串相加

> [力扣 415](https://leetcode.cn/problems/add-strings/) · 近两年面经里出现在：**腾讯 · 字节 · 腾讯微信读书**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

数字太大，超出 long 的范围，用字符串表示，要求**不能直接转成整数**。就是手工模拟竖式：从低位开始，一位一位算，处理进位或借位。乘法见 [43](./lc43)。

## 解法一：双指针从低位模拟进位

**思路**：两个指针从末尾往前走，每一位是 `x + y + carry`，写下个位、保留进位。短的那个走完了就当 0。循环条件里带上 `carry`，最高位的进位才不会丢。

<StepPlayer src="/viz/lc415.json" />

```python
def addStrings(a, b):
    i, j, carry = len(a) - 1, len(b) - 1, 0
    res = []
    while i >= 0 or j >= 0 or carry:
        x = ord(a[i]) - 48 if i >= 0 else 0
        y = ord(b[j]) - 48 if j >= 0 else 0
        s = x + y + carry
        res.append(chr(s % 10 + 48))
        carry = s // 10
        i -= 1
        j -= 1
    return "".join(reversed(res))
```

**复杂度**：时间 O(max(m, n))，空间 O(1)（不算结果）。

## 解法二：大数相减

面试常把加法改成减法继续问。

**思路**：

1. 先比较大小（长度不同看长度，长度相同按字典序），a < b 就算 b − a 再加负号。
2. 保证 a ≥ b 以后，从低位往前减，不够减就向高位借 1（这一位 +10，下一位多减 1）。
3. 去掉结果的前导 0，全减没了返回 "0"。

```python
def subStrings(a, b):
    """两个非负整数字符串相减，结果可以是负数。"""
    def less(a, b):                        # a < b ?
        return len(a) < len(b) or (len(a) == len(b) and a < b)

    if less(a, b):
        return "-" + subStrings(b, a)
    i, j, borrow = len(a) - 1, len(b) - 1, 0
    res = []
    while i >= 0:                          # 现在 a >= b，a 至少和 b 一样长
        x = ord(a[i]) - 48 - borrow
        y = ord(b[j]) - 48 if j >= 0 else 0
        borrow = 1 if x < y else 0
        res.append(chr(x + 10 * borrow - y + 48))
        i -= 1
        j -= 1
    s = "".join(reversed(res)).lstrip("0")
    return s or "0"
```

**复杂度**：时间 O(max(m, n))。

## 易错点

- 循环条件漏了 `or carry`：`"9" + "1"` 得到 "0"。
- 字符转数字：Python 用 `ord(c) − ord('0')`，Java 用 `c − '0'`，不要用 `int()` / `Integer.parseInt` 一次性转整个字符串。
- 结果用字符串拼接 `res = d + res`：每次都复制一遍，变成 O(n²)。先追加再反转。
- 减法忘了去前导 0：`"100" − "99"` 得到 "001"。

## 面试追问

- **带小数点的两个数相加？** 按小数点拆开，小数部分右边补 0 对齐，先加小数部分，进位带到整数部分。
- **带负号？** 同号相加、加符号；异号变成大的减小的，符号跟绝对值大的。
- **36 进制、二进制（[67](./lc67)）？** 把 10 换成进制数，字符和数字的转换换一下。
- **链表表示的大数相加？** 见 [2. 两数相加](../04-linked-list/lc2)（低位在前）、[445](../04-linked-list/lc445)（高位在前，用栈或先反转）。

## Java 版

```java
public String addStrings(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry > 0) {
        int x = i >= 0 ? a.charAt(i--) - '0' : 0;
        int y = j >= 0 ? b.charAt(j--) - '0' : 0;
        int s = x + y + carry;
        sb.append((char) ('0' + s % 10));
        carry = s / 10;
    }
    return sb.reverse().toString();
}
```
