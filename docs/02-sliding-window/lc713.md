# 713. 乘积小于 K 的子数组

> [力扣 713](https://leetcode.cn/problems/subarray-product-less-than-k/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

正整数数组里统计乘积 < k 的**子数组个数**：可变长窗口，每次 right 右移后，以 right 结尾的合法子数组有 `right − left + 1` 个，累加起来就是答案。

## 最优解法

**思路**：乘积随窗口扩大而变大（元素 ≥ 1），满足单调性。right 扩张、乘上新元素；乘积 ≥ k 就除掉 left 并右移。合法窗口 [left, right] 里，以 right 结尾的子数组 `[left..right]、[left+1..right]、…、[right..right]` 都合法，共 `right − left + 1` 个。

```python
def numSubarrayProductLessThanK(nums, k):
    if k <= 1:
        return 0                           # 元素都是正整数，乘积至少为 1
    prod, left, res = 1, 0, 0
    for right, x in enumerate(nums):
        prod *= x
        while prod >= k:
            prod //= nums[left]
            left += 1
        res += right - left + 1            # 以 right 结尾的合法子数组个数
    return res
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- k ≤ 1 时直接返回 0：乘积最小是 1，不可能 < 1；否则 while 会把 left 移过 right 导致出错。
- 「以 right 结尾」的计数方式是求子数组个数的通用技巧，不要去枚举左端点。
