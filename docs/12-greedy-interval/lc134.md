# 134. 加油站

> [力扣 134](https://leetcode.cn/problems/gas-station/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

环形路线、找能走完一圈的起点：总油量 ≥ 总消耗就一定有解；从某个起点出发，**油箱第一次变负的地方**之前的所有站都不可能是起点，直接把起点跳到下一站。

## 最优解法

**思路**：先判断 `sum(gas) >= sum(cost)`，不满足返回 −1。然后从 0 出发累加 `gas[i] − cost[i]`，变成负数就把起点设为 `i + 1`、油箱清零。最后的起点就是答案。

为什么可以跳过中间的站：从 start 到 i 的过程中，每一步油箱都 ≥ 0（否则更早就重置了）。如果从中间某站 k 出发，相当于少了 start 到 k−1 这一段的非负贡献，到 i 时油箱只会更少，也到不了 i + 1。

```python
def canCompleteCircuit(gas, cost):
    if sum(gas) < sum(cost):
        return -1
    start = tank = 0
    for i in range(len(gas)):
        tank += gas[i] - cost[i]
        if tank < 0:                       # 从 start 到 i 之间的任何站出发都到不了 i+1
            start, tank = i + 1, 0
    return start
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 不先判断总和：最后得到的 start 不一定能走完一圈。
- 暴力枚举每个起点是 O(n²)。
