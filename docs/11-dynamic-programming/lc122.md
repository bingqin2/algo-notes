# 122. 买卖股票的最佳时机 II

> [力扣 122](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

股票可以无限次买卖（同一时间最多持有一股）：**所有上涨的差价都能赚到**。贪心：相邻两天只要涨了就累加。

## 最优解法

```python
def maxProfit(prices):
    return sum(max(0, b - a) for a, b in zip(prices, prices[1:]))   # 所有上涨都吃到
```

**复杂度**：时间 O(n)，空间 O(1)。

为什么对：任何一次「第 i 天买、第 j 天卖」的收益 `p[j] − p[i]` 都等于中间每天差价之和，只取正的差价不会比它少。

**DP 写法**（股票问题的通用框架）：`hold = max(hold, cash − p)`、`cash = max(cash, hold + p)`。加手续费、冷冻期、限制次数时都在这个框架上改，见 [714](./lc714)、[309](./lc309)、[123](./lc123)。

## 易错点

- 贪心算出来的是最大利润，但不代表真的每天都交易，面试时说清楚这一点。
