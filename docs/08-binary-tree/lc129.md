# 129. 求根节点到叶节点数字之和

> [力扣 129](https://leetcode.cn/problems/sum-root-to-leaf-numbers/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

根到叶子路径组成的数字之和：DFS 时把当前数字往下传，`cur * 10 + val`，到叶子时返回。

## 关键点

- 只在**叶子**处累加；空结点返回 0。O(n)。

```python
def sumNumbers(root):
    def dfs(node, cur):
        if not node:
            return 0
        cur = cur * 10 + node.val
        if not node.left and not node.right:
            return cur
        return dfs(node.left, cur) + dfs(node.right, cur)

    return dfs(root, 0)
```
