# 73. 矩阵置零

> [力扣 73](https://leetcode.cn/problems/set-matrix-zeroes/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

矩阵原地置零，要求 O(1) 额外空间：用**第一行和第一列**当标记数组，第一行、第一列自己是否有 0 用两个变量单独记。

## 最优解法

**思路**：

1. 先记下第一行、第一列本身有没有 0。
2. 遍历其余格子，`matrix[i][j] == 0` 就把 `matrix[i][0]` 和 `matrix[0][j]` 置 0（标记这一行、这一列）。
3. 再遍历其余格子，所在行或列被标记了就置 0。
4. 最后按第 1 步的两个变量处理第一行、第一列。

```python
def setZeroes(matrix):
    m, n = len(matrix), len(matrix[0])
    first_row_zero = any(matrix[0][j] == 0 for j in range(n))
    first_col_zero = any(matrix[i][0] == 0 for i in range(m))
    for i in range(1, m):                  # 用第 0 行、第 0 列当标记
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = matrix[0][j] = 0
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0
    if first_row_zero:
        for j in range(n):
            matrix[0][j] = 0
    if first_col_zero:
        for i in range(m):
            matrix[i][0] = 0
    return matrix
```

**复杂度**：时间 O(mn)，空间 O(1)。

## 易错点

- 先处理了第一行、第一列：标记信息被覆盖，后面的格子全错。第一行第一列必须**最后**处理。
- 边遍历边置零（发现 0 就立刻把整行整列置 0）：新置的 0 会被当成原来的 0，导致全部变 0。
