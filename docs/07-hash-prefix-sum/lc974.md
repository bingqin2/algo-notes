# 974. 和可被 K 整除的子数组

> [力扣 974](https://leetcode.cn/problems/subarray-sums-divisible-by-k/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

统计和能被 k 整除的子数组**个数**：前缀和模 k 相同的两个位置之间就是一个答案。按余数计数，每遇到一个前缀和，之前有几个同余的就加几个。

## 最优解法

```python
from collections import Counter

def subarraysDivByK(nums, k):
    count = Counter({0: 1})
    s = res = 0
    for x in nums:
        s = (s + x) % k                    # Python 的 % 结果非负；Java 要 ((s % k) + k) % k
        res += count[s]
        count[s] += 1
    return res
```

**复杂度**：时间 O(n)，空间 O(k)。

## 易错点

- **负数取模**：Python 的 `%` 结果总是非负，没问题；Java / C++ 里 `-1 % 5 = -1`，要写成 `((s % k) + k) % k`，否则 −1 和 4 被当成不同的余数。
- 初始 `count[0] = 1`。
