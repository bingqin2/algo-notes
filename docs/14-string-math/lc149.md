# 149. 直线上最多的点数

> [力扣 149](https://leetcode.cn/problems/max-points-on-a-line/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

最多有几个点在同一条直线上：固定一个点，统计其他点和它的**斜率**，同斜率最多的那组加上自己。

## 关键点

- 斜率不要用浮点数（精度问题），用约分后的 `(dx, dy)`：除以 gcd，再统一符号（dx 为负时两个都取反，dx 为 0 时让 dy 为正）。
- 只需要和后面的点比，O(n²)。题目保证点不重复；有重复点时要单独计数。

```python
from collections import Counter
import math

def maxPoints(points):
    n, best = len(points), 1
    for i in range(n):
        slopes = Counter()
        for j in range(i + 1, n):
            dx = points[j][0] - points[i][0]
            dy = points[j][1] - points[i][1]
            g = math.gcd(dx, dy)
            dx, dy = dx // g, dy // g
            if dx < 0 or (dx == 0 and dy < 0):   # 统一符号，(1,2) 和 (−1,−2) 是同一个斜率
                dx, dy = -dx, -dy
            slopes[(dx, dy)] += 1
            best = max(best, slopes[(dx, dy)] + 1)
    return best
```
