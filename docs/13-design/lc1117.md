# 1117. H2O 生成

> [力扣 1117](https://leetcode.cn/problems/building-h2o/) · 中等 · 来源：面经
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

多线程按「组」放行：每组正好 2 个氢线程 + 1 个氧线程，凑齐了才一起通过。用**信号量**限制每种线程每组能进来几个，用**屏障**（Barrier）等凑齐 3 个线程。

## 最优解法

**思路**：

- 氢信号量初值 2、氧信号量初值 1：每组最多放进 2 个氢、1 个氧。
- 进来的线程在容量为 3 的屏障上等待，3 个都到了才一起往下走，输出后释放各自的信号量，让下一组进来。
- 为什么不会混组：下一组的线程要拿到信号量才能进入，而信号量要等上一组的线程输出后才释放。

Python：

```python
import threading

class H2O:
    def __init__(self):
        self.h = threading.Semaphore(2)    # 每个分子最多放进 2 个氢
        self.o = threading.Semaphore(1)    # 和 1 个氧
        self.barrier = threading.Barrier(3)   # 凑齐 3 个线程才一起继续

    def hydrogen(self, releaseHydrogen):
        self.h.acquire()
        self.barrier.wait()
        releaseHydrogen()
        self.h.release()

    def oxygen(self, releaseOxygen):
        self.o.acquire()
        self.barrier.wait()
        releaseOxygen()
        self.o.release()
```

Java（面试更常用）：

```java
class H2O {
    private final Semaphore h = new Semaphore(2);
    private final Semaphore o = new Semaphore(1);
    private final CyclicBarrier barrier = new CyclicBarrier(3);   // 凑齐 3 个线程一起放行，然后自动重置

    public void hydrogen(Runnable releaseHydrogen) throws InterruptedException {
        h.acquire();
        await();
        releaseHydrogen.run();
        h.release();
    }

    public void oxygen(Runnable releaseOxygen) throws InterruptedException {
        o.acquire();
        await();
        releaseOxygen.run();
        o.release();
    }

    private void await() throws InterruptedException {
        try {
            barrier.await();
        } catch (BrokenBarrierException e) {
            throw new IllegalStateException(e);
        }
    }
}
```

**复杂度**：每个线程 O(1)。

## 易错点

- 只用信号量不用屏障：两个氢一个氧都进来了，但输出顺序可能和下一组交错。
- `CyclicBarrier` 每次凑齐后**自动重置**，可以反复用；`CountDownLatch` 是一次性的，不适合。
- 不用屏障的写法：氧线程每次 `release` 两个氢的许可，并等待两个氢都输出完（再用一个信号量计数），逻辑更复杂。
