# 399. 除法求值

> [力扣 399](https://leetcode.cn/problems/evaluate-division/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

已知 a / b = k，求其他变量之比：变量是点，比值是带权边。查询就是找路径并把权值乘起来。可以每次 DFS，也可以用**带权并查集**。

## 关键点

- 带权并查集：`weight[x]` 表示 x / parent[x]。路径压缩时把一路上的权值乘起来，于是压缩后 `weight[x] = x / root`。
- 合并 a / b = v：设 ra、rb 是根，ra / rb = v · weight[b] / weight[a]。
- 查询 a / b：同一个根时答案是 weight[a] / weight[b]；不连通或变量没出现过返回 −1。
- DFS 做法：每个查询从 a 出发搜 b，路上累乘，O(Q · (V + E))，面试里也完全可以。

```python
def calcEquation(equations, values, queries):
    parent, weight = {}, {}                # weight[x] = x / parent[x]

    def find(x):
        if parent[x] != x:
            root = find(parent[x])
            weight[x] *= weight[parent[x]]  # 路径压缩时把权值乘上去
            parent[x] = root
        return parent[x]

    for (a, b), v in zip(equations, values):
        for x in (a, b):
            if x not in parent:
                parent[x], weight[x] = x, 1.0
        ra, rb = find(a), find(b)
        if ra != rb:                       # a / b = v，合并后 ra / rb = v * w[b] / w[a]
            parent[ra] = rb
            weight[ra] = v * weight[b] / weight[a]
    res = []
    for a, b in queries:
        if a not in parent or b not in parent or find(a) != find(b):
            res.append(-1.0)
        else:
            res.append(weight[a] / weight[b])
    return res
```
