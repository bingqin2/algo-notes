# 28. 找出字符串中第一个匹配项的下标

> [力扣 28](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

在主串里找模式串第一次出现的位置：暴力 O(mn) 能过；面试追问的是 **KMP**，O(m + n)。

## 关键点

- 先算模式串的 `lps`（next 数组）：`lps[i]` 是 needle[:i+1] 最长的相等前后缀长度。
- 匹配失败时模式串跳到 `lps[k−1]`，主串指针不回退。
- 求 lps 的过程本身就是模式串自己和自己做 KMP。

```python
def strStr(haystack, needle):
    m = len(needle)
    lps = [0] * m                          # lps[i]: needle[:i+1] 最长的相等前后缀长度
    k = 0
    for i in range(1, m):
        while k and needle[i] != needle[k]:
            k = lps[k - 1]
        if needle[i] == needle[k]:
            k += 1
        lps[i] = k
    k = 0
    for i, ch in enumerate(haystack):
        while k and ch != needle[k]:
            k = lps[k - 1]                 # 失配时回退到最长相等前后缀，主串不回退
        if ch == needle[k]:
            k += 1
        if k == m:
            return i - m + 1
    return -1
```
