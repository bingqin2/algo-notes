# 1049. 最后一块石头的重量 II

> [力扣 1049](https://leetcode.cn/problems/last-stone-weight-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

石头两两相撞，求最后剩下的最小重量：等价于把石头分成**两堆**，让两堆的重量差最小。转化成 0-1 背包：容量为 `总和 // 2`，最多能装多重。

## 最优解法

**思路**：`dp[j]` 表示能否选出一些石头，重量和恰好为 j。每块石头只能用一次，内层倒序。找到不超过总和一半的最大可达重量 best，答案是 `total − 2 · best`。

```python
def lastStoneWeightII(stones):
    total = sum(stones)
    half = total // 2
    dp = [False] * (half + 1)              # dp[j]：能否选出一些石头，重量和恰好为 j
    dp[0] = True
    for s in stones:
        for j in range(half, s - 1, -1):   # 0-1 背包，倒序
            dp[j] = dp[j] or dp[j - s]
    best = max(j for j in range(half + 1) if dp[j])
    return total - 2 * best                # 两堆尽量接近，差值就是答案
```

**复杂度**：时间 O(n · sum)，空间 O(sum)。

## 易错点

- 想不到转化：每次相撞相当于给两块石头分别加正号和负号，最终结果是一个「带符号的和」，所以就是分成两堆求差。
- 内层正序：同一块石头会被用多次，变成完全背包。
