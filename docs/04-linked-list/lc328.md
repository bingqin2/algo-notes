# 328. 奇偶链表

> [力扣 328](https://leetcode.cn/problems/odd-even-linked-list/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

按位置奇偶重排链表：拆成两条链（奇数位一条、偶数位一条），最后首尾相连。拆分链表的通用技巧。

## 最优解法

**思路**：odd 指向奇数链的尾，even 指向偶数链的尾，交替往后接：`odd.next = even.next`、`even.next = odd.next`。最后奇数链的尾接上偶数链的头。

```python
def oddEvenList(head):
    if not head:
        return None
    odd, even = head, head.next
    even_head = even
    while even and even.next:
        odd.next = even.next
        odd = odd.next
        even.next = odd.next
        even = even.next
    odd.next = even_head                   # 奇数链的尾接上偶数链的头
    return head
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 循环条件是 `even and even.next`：偶数链走到头或者后面没有奇数结点了就停。
- 一定要事先保存偶数链的头 `even_head`。
