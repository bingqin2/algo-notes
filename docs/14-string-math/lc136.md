# 136. 只出现一次的数字

> [力扣 136](https://leetcode.cn/problems/single-number/) · 简单 · 来源：Hot 100
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

其他数都出现两次，找只出现一次的数，要求 O(1) 空间：**异或**全部数。

## 关键点

- `x ^ x = 0`、`x ^ 0 = x`，异或满足交换律，成对的全部抵消。O(n) 时间，O(1) 空间。

```python
def singleNumber(nums):
    x = 0
    for v in nums:
        x ^= v                             # 成对的异或抵消
    return x
```
