# 1584. 连接所有点的最小费用

> [力扣 1584](https://leetcode.cn/problems/min-cost-to-connect-all-points/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

连接所有点、总费用最小：**最小生成树**。点之间两两都有边（完全图，边数 O(n²)），用 **Prim**（O(n²)，不需要堆）比 Kruskal（要先给 n² 条边排序）更合适。

## 最优解法

**思路**（朴素 Prim）：`dist[i]` 是点 i 到当前生成树的最短距离。每轮选一个不在树里、dist 最小的点加入树，累加它的 dist，再用它更新其他点的 dist。n 轮结束。

```python
def minCostConnectPoints(points):
    n = len(points)
    dist = [float("inf")] * n              # Prim：每个点到当前生成树的最短距离
    in_tree = [False] * n
    dist[0] = 0
    total = 0
    for _ in range(n):
        u = min((d, i) for i, d in enumerate(dist) if not in_tree[i])[1]
        in_tree[u] = True
        total += dist[u]
        ux, uy = points[u]
        for v in range(n):
            if not in_tree[v]:
                d = abs(ux - points[v][0]) + abs(uy - points[v][1])
                if d < dist[v]:
                    dist[v] = d
    return total
```

**复杂度**：时间 O(n²)，空间 O(n)。

**Kruskal**：所有边按权重排序，从小到大用并查集判断两端是否已连通，没连通就加入。O(E log E)，E = n²/2，适合稀疏图。

## 易错点

- 完全图上用堆优化 Prim：堆里最多 O(n²) 条边，反而比朴素版慢。
- 曼哈顿距离是 `|x1 − x2| + |y1 − y2|`。
