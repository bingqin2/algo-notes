# 139. 单词拆分

> [力扣 139](https://leetcode.cn/problems/word-break/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

字符串能否被拆成字典里的单词：`dp[i]` 表示前 i 个字符能否拆分，枚举最后一个单词的起点 j：`dp[j]` 为真且 `s[j:i]` 在字典里。类似完全背包（单词可以重复用、并且顺序有关）。

## 最优解法

**思路**：字典放进 set，O(1) 查找。j 只需要从 `i − 最长单词长度` 开始枚举，找到一个可行的就 break。

```python
def wordBreak(s, wordDict):
    words = set(wordDict)
    max_len = max(map(len, words))
    n = len(s)
    dp = [False] * (n + 1)                 # dp[i]：s 的前 i 个字符能否拆分
    dp[0] = True
    for i in range(1, n + 1):
        for j in range(max(0, i - max_len), i):   # 最后一个单词是 s[j:i]
            if dp[j] and s[j:i] in words:
                dp[i] = True
                break
    return dp[n]
```

**复杂度**：时间 O(n · L)（L 是最长单词长度，切片还要 O(L)，所以严格是 O(n · L²)），空间 O(n)。

## 易错点

- `dp[0] = True`：空串可以拆分。
- 用回溯不加记忆化：`"aaaa…ab"` 这种输入会指数级超时。
