# 100. 相同的树

> [力扣 100](https://leetcode.cn/problems/same-tree/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

判断两棵树是否相同：同时递归，结构和值都相同。

## 关键点

- 两个都为空返回 True，一个为空返回 False，否则比较值并递归左右。O(n)。

```python
def isSameTree(p, q):
    if not p or not q:
        return p is q
    return p.val == q.val and isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
```
