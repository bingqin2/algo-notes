# 131. 分割回文串

> [力扣 131](https://leetcode.cn/problems/palindrome-partitioning/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

把串切成若干段，每段都要满足某个条件（这里是回文），求所有切法。回溯：**每一层决定下一段切多长**。

## 解法一：回溯 + 回文预处理 DP

**思路**：

1. 先用 DP 算出 `pal[i][j]`：s[i..j] 是否回文。`pal[i][j] = s[i] == s[j] and pal[i+1][j−1]`，i 从大到小算。
2. dfs(i)：s[:i] 已经切好，枚举下一段的结尾 j，只有 `pal[i][j]` 为真才往下走。

```python
def partition(s):
    n = len(s)
    pal = [[True] * n for _ in range(n)]   # pal[i][j]：s[i..j] 是不是回文
    for i in range(n - 1, -1, -1):
        for j in range(i + 1, n):
            pal[i][j] = s[i] == s[j] and pal[i + 1][j - 1]
    res, path = [], []

    def dfs(i):                            # s[:i] 已经切好
        if i == n:
            res.append(path[:])
            return
        for j in range(i, n):              # 下一段是 s[i..j]
            if pal[i][j]:
                path.append(s[i:j + 1])
                dfs(j + 1)
                path.pop()

    dfs(0)
    return res
```

**复杂度**：时间 O(n · 2ⁿ)：最坏情况（全是同一个字母）有 2ⁿ⁻¹ 种切法，每种拷贝 O(n)。预处理 O(n²)。空间 O(n²)。

## 解法二：记忆化搜索

**思路**：parts(i) 返回 s[i:] 的所有切法。同一个后缀会被多次用到（比如 "aab" 切成 "a"+"a" 和 "aa" 之后，都要切 "b"），缓存起来。

```python
from functools import lru_cache

def partition(s):
    @lru_cache(None)
    def parts(i):                          # s[i:] 的所有切法
        if i == len(s):
            return [[]]
        res = []
        for j in range(i + 1, len(s) + 1):
            t = s[i:j]
            if t == t[::-1]:
                for rest in parts(j):
                    res.append([t] + rest)
        return res

    return parts(0)
```

**复杂度**：最坏仍是 O(n · 2ⁿ)（答案本身就这么大），但重复后缀只算一次。这里用切片 + 反转判断回文，为了代码短；要更快可以换成解法一的 pal 表。

## 易错点

- 每次都用 `t == t[::-1]` 判断回文，没有预处理：时间多一个 O(n) 因子。n ≤ 16 时能过，但面试官会问怎么优化。
- pal 表的计算顺序：`pal[i][j]` 依赖 `pal[i+1][j−1]`，所以 i 要从大到小。
- Java 里 `pal` 默认是 false，要单独处理 j − i < 2 的情况（见下面的 Java 版）。

## 面试追问

- **只要最少切几刀（132）？** 不用回溯，DP：cut[j] = min(cut[i−1] + 1)，对所有 s[i..j] 是回文的 i。
- **怎么判断回文子串最快？** 中心扩展或 Manacher，见 [5. 最长回文子串](../11-dynamic-programming/lc5)。
- **IP 地址也是切串吗？** 是，[93. 复原 IP 地址](./lc93) 也是每层决定下一段长度（1~3），条件换成 0~255 且没有前导 0。

## Java 版

```java
public List<List<String>> partition(String s) {
    int n = s.length();
    boolean[][] pal = new boolean[n][n];
    for (int i = n - 1; i >= 0; i--)
        for (int j = i; j < n; j++)
            pal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || pal[i + 1][j - 1]);
    List<List<String>> res = new ArrayList<>();
    dfs(s, 0, pal, new ArrayList<>(), res);
    return res;
}

private void dfs(String s, int i, boolean[][] pal, List<String> path, List<List<String>> res) {
    if (i == s.length()) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int j = i; j < s.length(); j++) {
        if (!pal[i][j]) continue;
        path.add(s.substring(i, j + 1));
        dfs(s, j + 1, pal, path, res);
        path.remove(path.size() - 1);
    }
}
```
