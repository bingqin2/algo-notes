# 66. 加一

> [力扣 66](https://leetcode.cn/problems/plus-one/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

数组表示的大整数加一：从最低位开始，小于 9 就加一返回，等于 9 就变成 0 继续进位。

## 关键点

- 全是 9（比如 999）时，循环结束后在最前面补一个 1。O(n)。

```python
def plusOne(digits):
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0                      # 9 变 0，继续进位
    return [1] + digits                    # 全是 9
```
