# 51. N 皇后

> [力扣 51](https://leetcode.cn/problems/n-queens/) · 困难 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

经典回溯：每行放一个皇后，逐行尝试每一列，用集合记录已占用的**列**和两条**对角线**，O(1) 判断冲突。

## 最优解法

**思路**：同一条主对角线（左上到右下）上 `r − c` 相同，同一条副对角线上 `r + c` 相同。放皇后时把列、`r − c`、`r + c` 加进三个集合，回溯时移除。

```python
def solveNQueens(n):
    res = []
    queens = []                            # queens[r] = 第 r 行皇后所在的列
    cols, diag1, diag2 = set(), set(), set()

    def backtrack(r):
        if r == n:
            res.append(["." * c + "Q" + "." * (n - c - 1) for c in queens])
            return
        for c in range(n):
            if c in cols or r - c in diag1 or r + c in diag2:
                continue                   # 同列、同主对角线（r-c 相同）、同副对角线（r+c 相同）
            queens.append(c); cols.add(c); diag1.add(r - c); diag2.add(r + c)
            backtrack(r + 1)
            queens.pop(); cols.remove(c); diag1.remove(r - c); diag2.remove(r + c)

    backtrack(0)
    return res
```

**复杂度**：时间 O(n!)，空间 O(n)。

## 易错点

- 每次放之前遍历整个棋盘检查冲突：O(n) 的检查让总时间多一个 n 倍。
- 回溯时三个集合都要恢复。

**进阶**：只求个数（[52](./lc52)）可以用位运算表示三个集合，`available = ~(cols | d1 | d2) & ((1 << n) − 1)`，每次取最低位的 1，速度快很多。
