# 47. 全排列 II

> [力扣 47](https://leetcode.cn/problems/permutations-ii/) · 中等 · 来源：面经 · 近两年面经：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

[46](./lc46) 加上「数组有重复元素，结果不能重复」。去重是回溯里最常被追问的点。

## 解法一：排序 + 同层去重

**思路**：先排序，相同的数挨在一起。规定相同的数**只能按从左到右的顺序使用**：如果 `nums[i] == nums[i−1]` 且 `nums[i−1]` 没被用，就跳过 nums[i]。

为什么是 `not used[i−1]`：此时 nums[i−1] 在这一层**已经试过并撤销了**，再选 nums[i] 会得到和刚才一模一样的子树（这叫「同层去重」）。如果 `used[i−1]` 为真，说明 nums[i−1] 在路径上（上面某一层选的），这时选 nums[i] 是合法的。

<StepPlayer src="/viz/lc47.json" />

```python
def permuteUnique(nums):
    nums = sorted(nums)                    # 排序后相同的数挨在一起
    res, path = [], []
    used = [False] * len(nums)

    def dfs():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            # 相同的数只按从左到右的顺序用：前一个相同的数没用，就不能用这个
            if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                continue
            used[i] = True
            path.append(nums[i])
            dfs()
            path.pop()
            used[i] = False

    dfs()
    return res
```

**复杂度**：时间 O(n · n!)，空间 O(n)。

## 解法二：计数，每层只遍历不同的值

**思路**：用 `Counter` 记每个值还剩几个。每一层遍历的是**不同的值**，而不是下标，同一层不可能两次选同一个值，天然不重复。

```python
from collections import Counter

def permuteUnique(nums):
    cnt = Counter(nums)                    # 每个值还剩几个
    res, path = [], []

    def dfs():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for x in cnt:                      # 每一层只遍历不同的值，天然不重复
            if cnt[x] == 0:
                continue
            cnt[x] -= 1
            path.append(x)
            dfs()
            path.pop()
            cnt[x] += 1

    dfs()
    return res
```

**复杂度**：时间 O(n · n!)，空间 O(n)。这个写法更好解释，也不需要排序。

## 易错点

- 忘了排序：相同的数不挨着，`nums[i] == nums[i−1]` 判断不出来。
- 写成 `used[i−1]`（不加 not）：也能得到正确答案，但剪枝发生在更深的层，效率低很多。面试时要能说出两者区别，推荐 `not used[i−1]`。
- 用 set 对结果去重：能过，但生成了大量重复，面试官会追问怎么不生成重复。

## 面试追问

- **组合总和里有重复元素（40）？** 同样排序后同层去重，条件是 `i > start and c[i] == c[i−1]`，见 [40](./lc40)。
- **子集有重复元素（90）？** 同上，见 [90](./lc90)。
- **只用一个 set 在每层去重可以吗？** 可以：每层开一个 `set` 记录这一层已经选过的值，适合不方便排序的场景（比如 491 递增子序列）。

## Java 版

```java
public List<List<Integer>> permuteUnique(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}

private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
        used[i] = true;
        path.add(nums[i]);
        dfs(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```
