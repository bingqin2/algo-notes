# 502. IPO

> [力扣 502](https://leetcode.cn/problems/ipo/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

资本有限、每次选一个项目、最多 k 次，最大化资本：**贪心 + 堆**：每次在「现在做得起的项目」里选利润最大的。

## 关键点

- 项目按所需资本排序；每轮把资本够的项目都放进大顶堆，弹出利润最大的做。
- 堆空了说明做不起任何项目，提前结束。O(n log n + k log n)。

```python
import heapq

def findMaximizedCapital(k, w, profits, capital):
    projects = sorted(zip(capital, profits))
    heap, i = [], 0
    for _ in range(k):
        while i < len(projects) and projects[i][0] <= w:   # 现在做得起的都放进大顶堆
            heapq.heappush(heap, -projects[i][1])
            i += 1
        if not heap:
            break
        w -= heapq.heappop(heap)           # 选利润最大的
    return w
```
