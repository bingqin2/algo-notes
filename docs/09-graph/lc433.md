# 433. 最小基因变化

> [力扣 433](https://leetcode.cn/problems/minimum-genetic-mutation/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

和 [127](./lc127) 一模一样的 BFS：基因长度 8，字符集只有 ACGT。

## 关键点

- 每次改一位，试 4 个字符，在 bank 里且没访问过就入队。
- 返回的是**步数**（127 返回的是单词个数），起点就是终点时返回 0。

```python
from collections import deque

def minMutation(startGene, endGene, bank):
    bank = set(bank)
    q, seen = deque([(startGene, 0)]), {startGene}
    while q:
        g, d = q.popleft()
        if g == endGene:
            return d
        for i in range(len(g)):
            for ch in "ACGT":
                ng = g[:i] + ch + g[i + 1:]
                if ng in bank and ng not in seen:
                    seen.add(ng)
                    q.append((ng, d + 1))
    return -1
```
