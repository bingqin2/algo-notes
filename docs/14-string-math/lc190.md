# 190. 颠倒二进制位

> [力扣 190](https://leetcode.cn/problems/reverse-bits/) · 简单 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

颠倒 32 位无符号整数的二进制位：循环 32 次，每次取 n 的最低位接到结果的末尾。

## 关键点

- `res = (res << 1) | (n & 1)`，`n >>= 1`。Java 里要用无符号右移 `>>>`。
- 追问被多次调用：分治交换（先交换高低 16 位，再交换每 8 位……），或者按字节查表。

```python
def reverseBits(n):
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)
        n >>= 1
    return res
```
