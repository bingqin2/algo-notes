# 382. 链表随机节点

> [力扣 382](https://leetcode.cn/problems/linked-list-random-node/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

从长度未知（或者很长、只能遍历一次）的数据流里**等概率**选一个：**蓄水池抽样**：第 i 个元素以 1/i 的概率替换当前的选择。

## 最优解法

**思路**：遍历链表，第 i 个结点（从 1 数）以 1/i 的概率成为答案。

为什么等概率：第 i 个结点最终被选中，要在第 i 步被选中（1/i），并且之后每一步都不被替换：`(1 − 1/(i+1)) · … · (1 − 1/n) = i/(i+1) · … · (n−1)/n = i/n`。相乘得 1/n。

```python
import random

class Solution:
    def __init__(self, head):
        self.head = head

    def getRandom(self):
        res, node, i = None, self.head, 0
        while node:                        # 蓄水池抽样（k = 1）
            i += 1
            if random.randrange(i) == 0:   # 第 i 个结点以 1/i 的概率替换
                res = node.val
            node = node.next
        return res
```

**复杂度**：getRandom 时间 O(n)，空间 O(1)。

## 易错点

- 如果链表长度固定、getRandom 调用很多次：直接存进数组，每次 O(1) 随机下标更快；蓄水池适合不能提前存储、只能遍历一次的场景。
- 选 k 个：前 k 个直接放入，第 i 个以 k/i 的概率替换池中随机一个。
