# 236. 二叉树的最近公共祖先

> [力扣 236](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/) · 近两年面经里出现在：**字节 · 阿里笔试**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

找两个结点在树上的最近公共祖先（LCA）。字节考过，阿里笔试考过「树上 LCA 查询」。

## 解法一：后序递归（必须会）

**思路**：每个结点向上返回「在我的子树里找到的 p、q 或者答案」：

- 当前结点就是 p 或 q：直接返回它（另一个要么在它下面，那它就是答案；要么在别处，由上层判断）。
- 左右子树都返回了非空：p、q 分在两边，当前结点就是 LCA。
- 只有一边非空：把那一边的结果往上传。

<StepPlayer src="/viz/lc236.json" />

```python
def lowestCommonAncestor(root, p, q):
    if not root or root is p or root is q: return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right: return root         # p、q 分别在两边
    return left or right
```

**复杂度**：时间 O(n)，空间 O(h)。

## 解法二：记录父指针 + 祖先集合

**思路**：遍历一遍记下每个结点的父结点。把 p 的所有祖先（包括自己）放进集合，再从 q 往上走，第一个出现在集合里的就是 LCA。

```python
def lowestCommonAncestor(root, p, q):
    parent = {root: None}; stack = [root]
    while p not in parent or q not in parent:
        node = stack.pop()
        for ch in (node.left, node.right):
            if ch: parent[ch] = node; stack.append(ch)
    ancestors = set()
    while p: ancestors.add(p); p = parent[p]
    while q not in ancestors: q = parent[q]
    return q
```

**复杂度**：时间 O(n)，空间 O(n)。思路直观，适合在面试中先说出来。

## 易错点

- 比较结点时用了值（`root.val == p.val`）：题目给的是结点对象，而且值可能重复，要比较引用。
- 以为遇到 p 就要继续往下找 q：不需要。如果 q 在 p 下面，p 就是答案；如果不在，q 会从别的分支被找到。

## 面试追问

- **BST 上的 LCA？** [235](./lc235)：利用大小关系，p、q 都比当前结点小就往左，都大就往右，否则当前结点就是答案，O(h) 且不需要递归栈。
- **p 或 q 可能不在树里？** 解法一会把找到的那一个当成答案。要额外统计找到了几个，两个都找到才返回。
- **很多次查询？** 预处理后每次 O(log n)：倍增法（记录每个结点的第 2^k 个祖先）；或者离线的 Tarjan 算法。阿里笔试的「树上 LCA 查询」就是这类。
- **结点有父指针（没有根）？** 变成 [160 相交链表](/04-linked-list/lc160)：两个指针分别从 p、q 往上走，走到头后换到对方的起点。

## Java 版

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
```
