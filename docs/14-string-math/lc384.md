# 384. 打乱数组

> [力扣 384](https://leetcode.cn/problems/shuffle-an-array/) · 近两年面经里出现在：**字节**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「等概率」生成随机排列 / 随机抽样。打乱数组用 **Fisher–Yates**（洗牌算法），面试官最关心的是**为什么每种排列概率都是 1/n!**，以及一个常见的错误写法为什么不对。

## 解法一：Fisher–Yates

**思路**：从最后一个位置 i = n − 1 往前，每次在 [0, i] 里等概率选一个 j（包括 i 自己），交换 a[i] 和 a[j]。交换后 a[i] 就定了，接着处理 [0, i − 1]。

<StepPlayer src="/viz/lc384.json" />

```python
import random

class Solution:
    def __init__(self, nums):
        self.orig = nums[:]
        self.a = nums[:]

    def reset(self):
        self.a = self.orig[:]
        return self.a

    def shuffle(self):
        a = self.a
        for i in range(len(a) - 1, 0, -1):
            j = random.randint(0, i)       # 从 [0, i] 里选，包括 i 自己
            a[i], a[j] = a[j], a[i]
        return a
```

**复杂度**：shuffle O(n)，reset O(n)，空间 O(n) 存原数组。

## 证明每种排列的概率都是 1/n!

**方法一：数路径**。第一步有 n 种选法，第二步 n − 1 种……一共 n! 条等可能的选择路径。不同的路径得到不同的排列（每一步定下的那个位置放的是谁，由这一步的选择唯一决定），所以 n! 条路径和 n! 种排列一一对应，每种概率 1/n!。

**方法二：看某个元素落在某个位置的概率**。元素 x 落在最后一个位置的概率是 1/n。落在倒数第二个位置：第一步没被选中（(n − 1)/n），第二步被选中（1/(n − 1)），乘起来还是 1/n。以此类推，每个元素落在每个位置的概率都是 1/n。

## 常见错误：每次都在整个数组里选

```python
import random

def shuffle_wrong(a):
    for i in range(len(a)):
        j = random.randint(0, len(a) - 1)  # 错：每次都在整个数组里选
        a[i], a[j] = a[j], a[i]
    return a
```

这样一共有 nⁿ 条等可能的路径，要分给 n! 种排列。n = 3 时是 27 条分给 6 种，27 不能被 6 整除，**不可能均匀**。实际是 3 种排列各 5 条、另外 3 种各 4 条。本页测试里用 12 万次采样验证了：正确写法的卡方值在正常范围，错误写法偏差非常明显。

## 易错点

- j 的范围写成 [0, i − 1]（不包括 i 自己）：这是 Sattolo 算法，只会生成「每个元素都离开原位」的循环排列，不是等概率。
- reset 返回的是同一个数组对象，之后 shuffle 又改了它：要保存原数组的副本，reset 时再复制一份。
- 从前往后写也可以：i 从 0 到 n − 1，在 [i, n − 1] 里选 j。

## 面试追问

- **从 n 个数里等概率选 k 个？** 只做 Fisher–Yates 的前 k 步，O(k)。
- **数据流，不知道 n 有多大，等概率选 k 个？** 蓄水池抽样：前 k 个直接放进去，第 i 个（从 0 数）以 k/(i + 1) 的概率替换池里随机一个。见 [382](./lc382)。

```python
import random

def reservoir(stream, k):
    res = []
    for i, x in enumerate(stream):
        if i < k:
            res.append(x)
        else:
            j = random.randint(0, i)       # 第 i 个元素以 k/(i+1) 的概率留下
            if j < k:
                res[j] = x
    return res
```

- **Java 里有现成的吗？** `Collections.shuffle` 就是 Fisher–Yates。
- **怎么测试打乱是均匀的？** n 小的时候枚举 n! 种排列，大量采样后做卡方检验。

## Java 版

```java
class Solution {
    private final int[] orig;
    private int[] a;
    private final Random rnd = new Random();

    public Solution(int[] nums) {
        orig = nums.clone();
        a = nums.clone();
    }

    public int[] reset() {
        a = orig.clone();
        return a;
    }

    public int[] shuffle() {
        for (int i = a.length - 1; i > 0; i--) {
            int j = rnd.nextInt(i + 1);                // [0, i]
            int t = a[i]; a[i] = a[j]; a[j] = t;
        }
        return a;
    }
}
```
