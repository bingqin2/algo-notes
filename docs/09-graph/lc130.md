# 130. 被围绕的区域

> [力扣 130](https://leetcode.cn/problems/surrounded-regions/) · 中等 · 来源：面试经典 150
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

「被包围」很难直接判断，**反过来想**：不被包围的 O 一定和边界上的 O 连通。从边界的 O 出发做 DFS / BFS，标记所有连通的 O，剩下没被标记的就是被包围的。

## 最优解法

**思路**：从四条边上的每个 O 出发，把连通的 O 改成临时标记 `#`。最后遍历：`#` 恢复成 O，其余的 O 改成 X。

```python
def solve(board):
    m, n = len(board), len(board[0])

    def mark(r, c):                        # 从边界的 O 出发，能连到的 O 都不会被围住
        stack = [(r, c)]
        while stack:
            r, c = stack.pop()
            if 0 <= r < m and 0 <= c < n and board[r][c] == "O":
                board[r][c] = "#"
                stack.extend(((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)))

    for r in range(m):
        mark(r, 0); mark(r, n - 1)
    for c in range(n):
        mark(0, c); mark(m - 1, c)
    for r in range(m):
        for c in range(n):
            board[r][c] = "O" if board[r][c] == "#" else "X"
    return board
```

**复杂度**：时间 O(mn)，空间 O(mn)（栈）。

## 易错点

- 递归 DFS 在大网格上可能栈溢出（Python 默认递归深度 1000），用显式栈或 BFS 更稳。
- 从每个 O 出发判断它能否到达边界：重复搜索，可能 O((mn)²)。
