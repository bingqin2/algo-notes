# 63. 不同路径 II

> [力扣 63](https://leetcode.cn/problems/unique-paths-ii/) · 中等 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

[62. 不同路径](./lc62) 加上障碍物：障碍格子的路径数为 0，其他格子 = 上 + 左。

## 关键点

- 一维 DP：`dp[j] += dp[j−1]`，遇到障碍 `dp[j] = 0`。
- 起点有障碍时答案是 0，代码里第一行处理 `dp[0]` 时会自然变成 0。O(mn) 时间，O(n) 空间。

```python
def uniquePathsWithObstacles(obstacleGrid):
    n = len(obstacleGrid[0])
    dp = [0] * n
    dp[0] = 1
    for row in obstacleGrid:
        for j in range(n):
            if row[j] == 1:
                dp[j] = 0
            elif j > 0:
                dp[j] += dp[j - 1]
    return dp[-1]
```
