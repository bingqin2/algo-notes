# 135. 分发糖果

> [力扣 135](https://leetcode.cn/problems/candy/) · 困难 · 来源：面试经典 150
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

分糖果：评分比相邻高的孩子要拿得更多，求最少总数。条件分成左右两个方向，**两次遍历**分别满足。

## 关键点

- 从左到右：比左边高就 `左边 + 1`；从右到左：比右边高就取 `max(自己, 右边 + 1)`。
- 第二遍一定要取 max，否则会破坏第一遍满足的左边条件。O(n) 时间，O(n) 空间。

```python
def candy(ratings):
    n = len(ratings)
    candy = [1] * n
    for i in range(1, n):                  # 从左到右：比左边高就比左边多
        if ratings[i] > ratings[i - 1]:
            candy[i] = candy[i - 1] + 1
    for i in range(n - 2, -1, -1):         # 从右到左：比右边高就至少比右边多
        if ratings[i] > ratings[i + 1]:
            candy[i] = max(candy[i], candy[i + 1] + 1)
    return sum(candy)
```
