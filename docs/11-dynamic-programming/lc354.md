# 354. 俄罗斯套娃信封问题

> [力扣 354](https://leetcode.cn/problems/russian-doll-envelopes/) · 困难 · 来源：题型补强
>
> C 层：认得题型，说得出方法和关键点

## 识别信号

信封要宽和高都严格更大才能套进去，求最多套几层：二维的最长递增子序列。按宽排序后对高求 LIS。

## 关键点

- 关键排序：宽**升序**，宽相同时高**降序**。这样宽相同的信封在高的序列里是递减的，不会被同时选进严格递增序列。
- 然后对高做 [300](./lc300) 的贪心 + 二分（`bisect_left`，严格递增）。O(n log n)。
- O(n²) 的 DP 在这题会超时。

```python
import bisect

def maxEnvelopes(envelopes):
    envelopes.sort(key=lambda e: (e[0], -e[1]))   # 宽升序，宽相同时高降序
    tails = []                             # 对高求最长严格递增子序列
    for _, h in envelopes:
        i = bisect.bisect_left(tails, h)
        if i == len(tails):
            tails.append(h)
        else:
            tails[i] = h
    return len(tails)
```
