# 1004. 最大连续1的个数 III

> [力扣 1004](https://leetcode.cn/problems/max-consecutive-ones-iii/) · 近两年面经里出现在：**美团**
>
> A 层：所有常见解法都要会，闭卷写出，能讲清追问

## 识别信号

「最多改 k 次，求最长连续段」：转换成「找最长的子数组，里面**不满足条件的元素不超过 k 个**」，就是可变长滑动窗口。

## 解法一：窗口内 0 的个数 ≤ k

**思路**：右边界一直往右扩，用 zeros 记窗口里 0 的个数。zeros > k 时收缩左边界，直到窗口重新合法。每一步窗口都是以 right 结尾的最长合法窗口，更新答案。

<StepPlayer src="/viz/lc1004.json" />

```python
def longestOnes(nums, k):
    best = left = zeros = 0
    for right, x in enumerate(nums):
        zeros += x == 0
        while zeros > k:                   # 0 太多了，收缩左边
            zeros -= nums[left] == 0
            left += 1
        best = max(best, right - left + 1)
    return best
```

**复杂度**：时间 O(n)：left 和 right 都只往右走。空间 O(1)。

## 解法二：窗口只增不减

**思路**：只关心最大长度，所以窗口**不需要缩小**：不合法时左右边界一起右移一格，长度保持不变；合法时只有右边界动，长度加 1。最后的窗口长度就是历史最大值。

```python
def longestOnes(nums, k):
    left = 0
    for x in nums:
        k -= x == 0                        # k 变负说明窗口不合法
        if k < 0:                          # 不合法时窗口整体右移一格，长度不变
            k += nums[left] == 0
            left += 1
    return len(nums) - left                # 窗口只增不减，最终长度就是历史最大值
```

**复杂度**：时间 O(n)，空间 O(1)。代码更短，但不好解释，面试时先写解法一。

## 可变长滑动窗口模板

```python
left = 0
for right in range(n):
    把 nums[right] 加入窗口，更新状态
    while 窗口不合法:
        把 nums[left] 移出窗口，更新状态
        left += 1
    用 right - left + 1 更新答案
```

能用这个模板的前提：窗口合法性是**单调**的。一个窗口不合法，包含它的更大窗口也不合法。这题 0 只会越加越多，满足。

## 易错点

- 收缩用 `if` 而不是 `while`：这题每次只多一个 0，`if` 碰巧也对；但其他题（比如 [76](./lc76)）一次可能要收缩很多步。习惯写 `while`。
- 移出左边元素时忘了判断它是不是 0。
- k = 0 时也要能正确处理：退化成「最长连续 1」。

## 面试追问

- **数组里有负数、求和 ≤ k 的最长子数组？** 不满足单调性，滑动窗口不能用，要用前缀和 + 单调栈或有序结构。
- **替换后的最长重复字符（424）？** 窗口长度 − 窗口内最多的字符数 ≤ k，同一个思路，见 [424](./lc424)。
- **只能删除一个元素（1493）？** k = 1，答案再减 1。

## Java 版

```java
public int longestOnes(int[] nums, int k) {
    int best = 0, left = 0, zeros = 0;
    for (int right = 0; right < nums.length; right++) {
        if (nums[right] == 0) zeros++;
        while (zeros > k) {
            if (nums[left] == 0) zeros--;
            left++;
        }
        best = Math.max(best, right - left + 1);
    }
    return best;
}
```
