# 1143. 最长公共子序列

> [力扣 1143](https://leetcode.cn/problems/longest-common-subsequence/) · 近两年面经里出现在：**高频经典**
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

两个字符串（或序列）的匹配问题：`dp[i][j]` 表示第一个串的前 i 个和第二个串的前 j 个之间的答案。看最后两个字符相不相等来转移。编辑距离、最长公共子序列、不同的子序列都是这个框架。

## 解法一：二维 DP：两个串各一维

**思路**：

- `text1[i−1] == text2[j−1]`：这两个字符可以同时放进公共子序列，`dp[i][j] = dp[i−1][j−1] + 1`。
- 不相等：至少有一个用不上，`dp[i][j] = max(dp[i−1][j], dp[i][j−1])`。
- 多开一行一列表示空串，初始全为 0。

```python
def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]   # dp[i][j]：text1 前 i 个和 text2 前 j 个的 LCS
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

**复杂度**：时间 O(mn)，空间 O(mn)。

**空间优化到一维**：只依赖上一行，用一维数组 + 一个变量 `prev` 保存左上角的旧值。

```python
def longestCommonSubsequence(text1, text2):
    n = len(text2)
    dp = [0] * (n + 1)
    for i in range(1, len(text1) + 1):
        prev = 0                           # 左上角 dp[i-1][j-1]
        for j in range(1, n + 1):
            tmp = dp[j]                    # 更新前是 dp[i-1][j]，下一轮的左上角
            if text1[i - 1] == text2[j - 1]:
                dp[j] = prev + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev = tmp
    return dp[n]
```

## 易错点

- 下标偏移：`dp[i][j]` 对应的字符是 `text1[i−1]` 和 `text2[j−1]`。
- 一维优化时左上角的值会被覆盖：更新 `dp[j]` 之前先存到 tmp，处理完再赋给 prev。
- 要输出具体的子序列：从右下角倒推，相等就记下并走左上，否则走较大的那一边。
