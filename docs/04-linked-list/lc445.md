# 445. 两数相加 II

> [力扣 445](https://leetcode.cn/problems/add-two-numbers-ii/) · 中等 · 来源：题型补强
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

大数相加，但链表**高位在前**：要从低位开始加，但链表只能从头走。用**栈**把顺序反过来；结果用**头插法**生成，自然就是高位在前。

## 最优解法

**思路**：两个链表的值分别压栈，然后同时弹栈相加、处理进位，每一位都新建结点插在结果链表的最前面。

```python
def addTwoNumbers(l1, l2):
    s1, s2 = [], []
    while l1:
        s1.append(l1.val); l1 = l1.next
    while l2:
        s2.append(l2.val); l2 = l2.next
    head, carry = None, 0
    while s1 or s2 or carry:
        s = carry + (s1.pop() if s1 else 0) + (s2.pop() if s2 else 0)
        carry, d = divmod(s, 10)
        head = ListNode(d, head)           # 头插法，结果自然是高位在前
    return head
```

**复杂度**：时间 O(m + n)，空间 O(m + n)。

**不用栈的做法**：先把两个链表反转，按 [2](./lc2) 相加，再把结果反转。空间 O(1)，但会修改输入（题目进阶要求不修改输入时就用栈）。

## 易错点

- 头插法：`head = ListNode(d, head)`，不需要哑结点。
- 别忘了最后的进位。
