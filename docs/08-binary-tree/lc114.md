# 114. 二叉树展开为链表

> [力扣 114](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/) · 中等 · 来源：Hot 100
>
> B 层：掌握最优解法，20 分钟内写出

## 识别信号

把二叉树原地展开成「按前序顺序、只用右指针」的链表，要求 O(1) 空间：对每个结点，把左子树插到它和右子树之间，类似 Morris 遍历。

## 最优解法

**思路**：从根开始沿右指针走。当前结点有左子树时：找到左子树的**最右结点** pre（前序里左子树的最后一个），把当前的右子树接到 pre 的右边，再把左子树整体移到右边，左指针置空。然后走到右孩子。

```python
def flatten(root):
    cur = root
    while cur:
        if cur.left:
            pre = cur.left                 # 左子树最右边的结点
            while pre.right:
                pre = pre.right
            pre.right = cur.right          # 右子树接到它后面
            cur.right, cur.left = cur.left, None
        cur = cur.right
    return root
```

**复杂度**：时间 O(n)（每个结点最多被「找最右结点」经过一次），空间 O(1)。

**递归写法**：按「右 → 左 → 根」的逆前序遍历，维护上一个访问的结点 prev，`node.right = prev; node.left = None; prev = node`。O(h) 栈空间。

## 易错点

- 忘了把 `left` 置空。
- 用前序遍历存进列表再重连：O(n) 空间，不满足进阶要求。
